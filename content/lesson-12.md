# લેશન - ૧૨ : બુટીંગ પ્રક્રિયાની શરૂઆત

## બુટીંગ પ્રોસેસ શું છે?
કમ્પ્યુટર ચાલુ કર્યા પછી ઓપરેટિંગ સિસ્ટમને મેમરીમાં લોડ કરીને કમ્પ્યુટરને ઉપયોગ માટે તૈયાર કરવાની પ્રક્રિયાને બુટીંગ પ્રોસેસ કહેવામાં આવે છે. |

## બુટીંગ પ્રોસેસના મુખ્ય કાર્યો

| ક્રમાંક | મુખ્ય કાર્ય |
|:---:|:---:|
| 1 | કમ્પ્યુટર ચાલુ કરવું અને પાવર સપ્લાય આપવો. |
| 2 | BIOS/UEFI દ્વારા હાર્ડવેરની પ્રાથમિક તપાસ કરવી. |
| 3 | POST દ્વારા RAM, કીબોર્ડ, ડિસ્ક વગેરે હાર્ડવેર ચકાસવા. |
| 4 | Boot Device શોધવું. |
| 5 | Boot Loader ને મેમરીમાં લોડ કરવું. |
| 6 | Operating System ના Kernel અને જરૂરી Drivers ને મેમરીમાં લોડ કરવા. |
| 7 | Operating System શરૂ કરીને કમ્પ્યુટરને વપરાશ માટે તૈયાર કરવું. |

## બુટીંગ પ્રોસેસની વિશેષતા
**1) Cold Booting**  કમ્પ્યુટર સંપૂર્ણપણે બંધ હોય ત્યારે તેને પાવર બટન દબાવીને શરૂ કરવાની પ્રક્રિયાને Cold Booting કહે છે.

 **2) Warm Booting**  કમ્પ્યુટર ચાલુ હોય ત્યારે તેને Restart કરીને ફરીથી શરૂ કરવાની પ્રક્રિયાને Warm Booting કહે છે.
