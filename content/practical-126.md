# પ્રેકટિકલ-૧૨૬ : નેટવર્ક મુશ્કેલીઓનું નિવારણ અને તેની સુરક્ષા

![image](/images/practical-126.webp)

| સાધન | ઉપયોગ / હેતુ |
|---|---|
| **Ping** | નેટવર્કમાં કોઈ કમ્પ્યુટર અથવા ઉપકરણ ઉપલબ્ધ છે કે નહીં અને તેની સાથે કનેક્શન યોગ્ય છે કે નહીં તે તપાસવા માટે ઉપયોગ થાય છે. |
| **ipconfig** | કમ્પ્યુટરની IP Address, Subnet Mask, Default Gateway વગેરે નેટવર્ક માહિતી જોવા અને નેટવર્કની સમસ્યા શોધવા માટે ઉપયોગ થાય છે. |
| **Traceroute** | કમ્પ્યુટરથી કોઈ ચોક્કસ સર્વર અથવા ગંતવ્ય સુધી ડેટા કયા કયા નેટવર્ક માર્ગ પરથી પસાર થાય છે તે જાણવા અને કનેક્શનની સમસ્યા શોધવા માટે ઉપયોગ થાય છે. |
| **netstat** | કમ્પ્યુટરના સક્રિય નેટવર્ક કનેક્શન, ખુલ્લા પોર્ટ અને નેટવર્ક સંબંધિત માહિતી જોવા માટે ઉપયોગ થાય છે. |
| **Nmap** | નેટવર્કમાં રહેલા ઉપકરણો, ખુલ્લા પોર્ટ અને ઉપલબ્ધ નેટવર્ક સેવાઓ શોધવા તથા સુરક્ષા તપાસવા માટે ઉપયોગ થાય છે. |
| **Firewall** | અનધિકૃત નેટવર્ક ટ્રાફિકને રોકવા અને કમ્પ્યુટર અથવા નેટવર્કને અનધિકૃત પ્રવેશથી સુરક્ષિત રાખવા માટે ઉપયોગ થાય છે. |
| **Antivirus** | કમ્પ્યુટરમાં રહેલા વાયરસ, માલવેર, સ્પાયવેર વગેરે હાનિકારક પ્રોગ્રામને શોધવા, રોકવા અને દૂર કરવા માટે ઉપયોગ થાય છે. |
| **OpenVAS** | નેટવર્ક અને કમ્પ્યુટરમાં રહેલી સુરક્ષા ખામીઓ (Vulnerabilities) શોધવા અને સુરક્ષા તપાસ કરવા માટે ઉપયોગ થાય છે. |
| **Snort** | નેટવર્ક ટ્રાફિકનું નિરીક્ષણ કરીને શંકાસ્પદ અથવા હાનિકારક પ્રવૃત્તિઓ શોધવા માટે Intrusion Detection System તરીકે ઉપયોગ થાય છે. |
| **pfSense** | નેટવર્કને મેનેજ કરવા અને સુરક્ષિત રાખવા માટે Firewall, Router, VPN તથા અન્ય નેટવર્ક સુવિધાઓ પૂરી પાડે છે. |
