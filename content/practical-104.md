# પ્રેકટિકલ-૧૦૪ : MY SQL ઇન્સ્ટોલ કરવું : MY SQL

| સ્ટેપ | સામાન્ય સમજુતી |
|---|---|
| 1 | સૌપ્રથમ MySQL ની અધિકૃત વેબસાઇટ પરથી **MySQL Installer** ડાઉનલોડ કરો. Windows માટે યોગ્ય Installer પસંદ કરો અને **Download** પર ક્લિક કરો. |
| 2 | ડાઉનલોડ થયેલી **MySQL Installer** ફાઇલ ખોલો. ઇન્સ્ટોલેશન શરૂ કરવા માટે જરૂરી સૂચનાઓ અનુસરો. |
| 3 | Setup Type માં જરૂરી વિકલ્પ પસંદ કરો. સામાન્ય રીતે **Developer Default** પસંદ કરવાથી MySQL Server સાથે જરૂરી ટૂલ્સ પણ ઇન્સ્ટોલ થાય છે. |
| 4 | જરૂરી Components પસંદ કર્યા પછી **Execute** બટન પર ક્લિક કરો. પસંદ કરેલા MySQL Components કમ્પ્યુટરમાં ઇન્સ્ટોલ થશે. |
| 5 | MySQL Server Configuration દરમિયાન **Authentication Method** અને અન્ય જરૂરી Settings પસંદ કરો. ત્યારબાદ MySQL માટે Root Password સેટ કરો. |
| 6 | Windows Service માટે જરૂરી Settings પસંદ કરો અને MySQL Server ને Service તરીકે Configure કરો. ત્યારબાદ **Execute** પર ક્લિક કરીને Configuration પૂર્ણ કરો. |
| 7 | અંતે MySQL Installer માં **Finish** પર ક્લિક કરો. MySQL Server સફળતાપૂર્વક ઇન્સ્ટોલ અને Configure થયા પછી MySQL Workbench અથવા Command Line દ્વારા તેનો ઉપયોગ કરી શકાય છે. |
