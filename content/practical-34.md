# પ્રેકટિકલ-૩૪ : દસ્તાવેજોમાં નેવિગેટ કરો

| વિષય | સામાન્ય સમજ / કાર્ય |
|---|---|
| **ટેક્સ્ટ શોધવો (Search for text)** | MS Word માં લાંબા દસ્તાવેજમાંથી કોઈ શબ્દ અથવા વાક્ય ઝડપથી શોધવા માટે **Find** વિકલ્પનો ઉપયોગ થાય છે. `Ctrl + F` દબાવીને Navigation Pane ખોલી શકાય છે અને તેમાં શોધવાનો શબ્દ લખી શકાય છે. |
| **દસ્તાવેજની અંદરના સ્થાન માટે લિંક બનાવવી (Link to locations within documents)** | દસ્તાવેજના એક ભાગમાંથી બીજા ભાગમાં ઝડપથી જવા માટે **Bookmark** અને **Hyperlink** નો ઉપયોગ કરી શકાય છે. પહેલા Bookmark બનાવો અને પછી જરૂરી ટેક્સ્ટને તે Bookmark સાથે Link કરો. |
| **દસ્તાવેજમાં ચોક્કસ સ્થાન અને ઑબ્જેક્ટ પર જવું (Move to specific locations and objects in documents)** | Word માં ચોક્કસ પેજ, હેડિંગ, ટેબલ, ગ્રાફિક અથવા અન્ય ઑબ્જેક્ટ સુધી ઝડપથી જવા માટે **Navigation Pane** અથવા **Go To** વિકલ્પનો ઉપયોગ કરી શકાય છે. `Ctrl + G` દબાવીને ચોક્કસ પેજ અથવા સ્થાન પર જઈ શકાય છે. |
| **Formatting Symbols અને Hidden Text બતાવવું અથવા છુપાવવું (Show and hide formatting symbols and hidden text)** | દસ્તાવેજમાં Paragraph mark, Space, Tab વગેરે Formatting Symbols જોવા માટે **Home → ¶ Show/Hide** વિકલ્પનો ઉપયોગ થાય છે. Hidden Text જોવા અથવા છુપાવવા માટે **File → Options → Display → Hidden text** વિકલ્પનો ઉપયોગ કરી શકાય છે. |
