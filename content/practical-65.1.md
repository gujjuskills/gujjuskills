# પ્રેકટિકલ-૬૫.૧ : બુલેટેડ ટેક્સ્ટ બનાવો અને ફેરફાર કરો
| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| **Format paragraphs as numbered and bulleted lists** | પેરાગ્રાફને **Numbered List** અને **Bulleted List** માં ફોર્મેટ કરવાનું શીખવું. |
| **Change bullet characters and number formats** | બુલેટના **ચિહ્નો** અને નંબરના **ફોર્મેટ** બદલવાનું શીખવું. |
| **Increase and decrease list indents** | લિસ્ટના **Indent** ને વધારવા અને ઘટાડવાનું શીખવું. |
| **Set starting number values** | નંબરવાળી લિસ્ટ માટે **Starting Number** નક્કી કરવાનું શીખવું. |
| **Restart and continue list numbering on different slides** | અલગ અલગ **Slides** પર લિસ્ટનું નંબરિંગ **Restart** અને **Continue** કરવાનું શીખવું. |
