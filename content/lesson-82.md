# લેશન - ૮૨ : વેબ સર્વરનો પરિચય અને તેની વિશેષતાઓ

| Topic | માહિતી |
|---|---|
| **What is Web Server?** | **Web Server** એ એક કમ્પ્યુટર અથવા સોફ્ટવેર છે, જે વેબસાઇટની ફાઇલો અને વેબ પેજને સંગ્રહિત કરે છે અને યુઝરની વિનંતી પ્રમાણે તેને ઇન્ટરનેટ દ્વારા મોકલે છે. જ્યારે આપણે બ્રાઉઝરમાં કોઈ વેબસાઇટનું URL દાખલ કરીએ છીએ ત્યારે બ્રાઉઝર Web Server ને Request મોકલે છે. Web Server આ Request ને Process કરીને જરૂરી Web Page, Image, CSS, JavaScript વગેરે Browser ને મોકલે છે. **ઉદાહરણ:** Apache, Nginx, Microsoft IIS અને LiteSpeed. |
| **Types of Web Server** | Web Server ના મુખ્ય પ્રકારોમાં **Apache Web Server, Nginx Web Server, Microsoft IIS Web Server, LiteSpeed Web Server** અને **Node.js Web Server**નો સમાવેશ થાય છે. Apache ખુલ્લા સ્ત્રોતનું લોકપ્રિય Web Server છે. Nginx ઝડપી અને મોટા પ્રમાણમાં Traffic માટે ઉપયોગી છે. Microsoft IIS Windows Server પર ચાલે છે. LiteSpeed ઉચ્ચ Performance માટે જાણીતું છે અને Node.js નો ઉપયોગ JavaScript આધારિત Server Applications માટે થાય છે. |
| **How Web Server Works** | જ્યારે User Browser માં Website નું URL દાખલ કરે છે, ત્યારે Browser Server ને **HTTP અથવા HTTPS Request** મોકલે છે. Web Server આ Request પ્રાપ્ત કરીને જરૂરી File અથવા Data શોધે છે. ત્યારબાદ Server તેને **HTTP Response** દ્વારા Browser ને મોકલે છે. Browser મળેલા HTML, CSS, JavaScript, Images વગેરેને Process કરીને વેબપેજ Userની Screen પર દર્શાવે છે. સરળ પ્રક્રિયા: **User → Browser → Request → Web Server → Response → Browser → Web Page**. |
| **Web Server Uses** | Web Server નો ઉપયોગ **Website અને Web Applications Host કરવા, Web Pages Deliver કરવા, Images અને Files ઉપલબ્ધ કરાવવા, Online Services ચલાવવા, Dynamic Content આપવા અને User Requests Handle કરવા** માટે થાય છે. E-commerce Websites, Banking Websites, Blogs, Educational Websites, Social Media Platforms અને અન્ય Online Applications Web Server નો ઉપયોગ કરે છે. |
| **Web Server Security Methods** | Web Server ને સુરક્ષિત રાખવા માટે **HTTPS/SSL Certificate, Firewall, Strong Password, Regular Software Updates, User Authentication, Access Control, Secure Configuration, Malware Protection અને Regular Backup** જેવી પદ્ધતિઓનો ઉપયોગ થાય છે. HTTPS દ્વારા User અને Server વચ્ચેનો Data Encrypt થાય છે. Firewall અનધિકૃત Network Access અટકાવવામાં મદદ કરે છે. Server Software ને નિયમિત Update કરવાથી Security Vulnerabilities ઘટાડવામાં મદદ મળે છે. |
