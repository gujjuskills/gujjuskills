# ES-3.1 : ડિજિટલ સાક્ષરતા અને કોમ્પ્યુટરની મૂળભૂત બાબતો

## 1.1 Digital Literacy એટલે શું?
**Digital Literacy** એટલે ડિજિટલ ઉપકરણો અને સાધનોનો યોગ્ય, અસરકારક અને સલામત ઉપયોગ કરવાની ક્ષમતા. તેમાં કમ્પ્યુટર વાપરવું, ફાઇલ ખોલવી, માહિતી શોધવી અને ઑનલાઇન સાવચેતી રાખવી જેવી બાબતો આવે છે.

## 1.2 Digital Literacy શા માટે જરૂરી છે?
- અભ્યાસ અને તાલીમની માહિતી મેળવવા.
- નોકરીની તકો શોધવા અને અરજી કરવા.
- દસ્તાવેજો અને રેકોર્ડ તૈયાર કરવા.
- ઇમેઇલ અને ઑનલાઇન મીટિંગ દ્વારા સંવાદ કરવા.
- ડિજિટલ સેવાઓનો વધુ સુરક્ષિત ઉપયોગ કરવા.

## 1.3 Computer System ના મુખ્ય ભાગો
| ભાગ | અર્થ અને કાર્ય |
|---|---|
| Hardware | કમ્પ્યુટરના સ્પર્શી શકાય તેવા ભાગો, જેમ કે Monitor, Keyboard, Mouse, CPU/સિસ્ટમ યુનિટ |
| Software | કમ્પ્યુટરને કાર્ય કરાવતાં પ્રોગ્રામ્સ અને એપ્લિકેશન્સ |
| Operating System (OS) | Hardware અને Software વચ્ચે સંકલન કરે છે અને ફાઇલ, એપ્લિકેશન તથા ઉપકરણોનું સંચાલન કરે છે |
| Input Devices | માહિતી દાખલ કરવા માટે, જેમ કે Keyboard અને Mouse |
| Output Devices | પરિણામ દર્શાવવા માટે, જેમ કે Monitor અને Printer |
| Storage | ફાઇલો અને માહિતી સંગ્રહવા માટે, જેમ કે SSD, Hard Drive અથવા USB Drive |

## 1.4 Desktop પર મૂળભૂત કામગીરી
1. કમ્પ્યુટર ચાલુ કરો અને જરૂર હોય તો તમારા User Account માં Sign In કરો.
2. Desktop પરના Icons અને Taskbar ઓળખો.
3. Start Menu અથવા Search નો ઉપયોગ કરીને એપ્લિકેશન ખોલો.
4. File Explorer માંથી જરૂરી Folder અથવા File શોધો.
5. ફાઇલ ખોલો, તેમાં જરૂરી કામ કરો અને યોગ્ય સ્થાન પર Save કરો.
6. જાહેર અથવા શેર કરેલા કમ્પ્યુટરનો ઉપયોગ કર્યા પછી Sign Out કરો.

## 1.5 ફાઇલ અને ફોલ્ડર
**File** એ દસ્તાવેજ, ચિત્ર, સ્પ્રેડશીટ અથવા અન્ય ડિજિટલ માહિતી છે. **Folder** ફાઇલોને ગોઠવી રાખવા માટે વપરાય છે.

ફાઇલ સાચવતી વખતે સ્પષ્ટ નામ આપો, યોગ્ય Folder પસંદ કરો અને કામ પૂર્ણ થયા પછી ફાઇલ ફરી ખોલીને ચકાસો.

## 1.6 પ્રાયોગિક પ્રવૃત્તિ
- કમ્પ્યુટર પર Sign In કરો.
- Desktop પર એક Folder બનાવો અને તેનું નામ `My Practice` રાખો.
- ઉપલબ્ધ Text Editor અથવા Word Processor માં એક નાનો દસ્તાવેજ બનાવો.
- દસ્તાવેજને Folder માં Save કરો.
- File Explorer માંથી તેને ફરી ખોલો.

## 1.7 પુનરાવર્તન પ્રશ્નો
1. Digital Literacy શું છે?
2. Hardware અને Software વચ્ચેનો તફાવત લખો.
3. Operating System નું કાર્ય શું છે?
4. File અને Folder નો ઉપયોગ સમજાવો.
