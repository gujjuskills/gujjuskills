# પ્રેકટિકલ-૪૧ : ટેબલ બનાવો

| વિષય | સામાન્ય સમજ / કાર્ય |
|---|---|
| ટેક્સ્ટને ટેબલમાં ફેરવવું | MS Word માં લખાણને ટેબલમાં ફેરવવા માટે લખાણ પસંદ કરો. ત્યારબાદ **Insert → Table → Convert Text to Table** વિકલ્પ પસંદ કરો. જરૂરી મુજબ Columns અને Separator પસંદ કરીને OK કરો. |
| ટેબલને ટેક્સ્ટમાં ફેરવવું | MS Word માં ટેબલને ટેક્સ્ટમાં ફેરવવા માટે ટેબલ પસંદ કરો. ત્યારબાદ **Layout → Convert to Text** વિકલ્પ પસંદ કરો. Text separator તરીકે Tabs, Commas વગેરે પસંદ કરીને OK કરો. |
| પંક્તિઓ અને કૉલમની સંખ્યા નક્કી કરીને ટેબલ બનાવવું | MS Word માં **Insert → Table** પસંદ કરો અને જરૂરી Rows તથા Columns ની સંખ્યા પસંદ કરો. અથવા **Insert Table** વિકલ્પ દ્વારા Rows અને Columns ની ચોક્કસ સંખ્યા દાખલ કરીને ટેબલ બનાવો. |
