# પ્રેક્ટિકલ - ૩૧.૨ : લિનક્સમાં વપરાશકર્તાઓના એકાઉન્ટ મેનેજ કરવા

| પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|---|---|
| **વપરાશકર્તાનું એકાઉન્ટ કેવી રીતે ખોલવું? (How to Open User Account?)** | Linux માં **Settings → Users** ખોલો. **Unlock** પર ક્લિક કરીને Administrator Password દાખલ કરો. ત્યારબાદ **Add User** પસંદ કરીને નવા વપરાશકર્તાની વિગતો દાખલ કરો. |
| **અનલોક (Unlock)** | **Settings → Users** માં જઈને **Unlock** પર ક્લિક કરો અને Administrator Password દાખલ કરો. ત્યારબાદ User Account ની સેટિંગ્સમાં ફેરફાર કરી શકાય છે. |
| **વપરાશકર્તા ઉમેરવો (Add User)** | **Settings → Users → Add User** પસંદ કરો. વપરાશકર્તાનું નામ અને પાસવર્ડ દાખલ કરીને **Add** પર ક્લિક કરો. Terminal દ્વારા પણ `sudo adduser username` કમાન્ડનો ઉપયોગ કરી શકાય છે. |
| **અવતાર બદલવો (Change Avatar)** | **Settings → Users** માં વપરાશકર્તા પસંદ કરો. Profile/Avatar પર ક્લિક કરીને ઉપલબ્ધ ચિત્ર પસંદ કરો અથવા નવું ચિત્ર સેટ કરો. |
| **વપરાશકર્તા દૂર કરવો (Remove User)** | **Settings → Users** માંથી વપરાશકર્તા પસંદ કરો અને **Remove User** પર ક્લિક કરો. જરૂરી હોય તો વપરાશકર્તાની Home Directory અને ફાઇલો પણ દૂર કરી શકાય છે. |
| **પાસવર્ડ (Password)** | **Settings → Users** માં વપરાશકર્તા પસંદ કરીને **Password** વિકલ્પ પર ક્લિક કરો. નવો પાસવર્ડ દાખલ કરીને તેની પુષ્ટિ કરો. Terminal માં `sudo passwd username` કમાન્ડનો ઉપયોગ કરી શકાય છે. |
