# લેશન - ૬૬ : એન્ડ યુજર ડીવાઇઝ અને સ્થાનિક નેટવર્કસની વૈશ્વિક ઈન્ટરનેટ સાથે કેવી રીતે ક્રિયા પ્રતિક્રિયા કરે છે તે સમજાવો

| Topics | માહિતી |
|---|---|
| OSI Model | ![image](/gujjuskills/images/practical-67.png) |
| Physical Layer | ડેટાને બિટ્સ અને સિગ્નલના સ્વરૂપમાં ટ્રાન્સમિટ કરે છે અને ભૌતિક જોડાણ સ્થાપિત કરે છે. |
| Data-link Layer | ડેટાને ફ્રેમમાં વહેંચે છે અને MAC Address દ્વારા ડેટા ટ્રાન્સમિશન તથા ભૂલ નિયંત્રણ કરે છે. |
| Network Layer | IP Address અને Routing દ્વારા ડેટા પેકેટને યોગ્ય ગંતવ્ય સુધી પહોંચાડે છે. |
| Transport Layer | સ્રોતથી ગંતવ્ય સુધી ડેટાની વિશ્વસનીય અને યોગ્ય ડિલિવરી સુનિશ્ચિત કરે છે. |
| Session Layer | બે ઉપકરણો વચ્ચે કમ્યુનિકેશન સેશન સ્થાપિત, સંચાલિત અને સમાપ્ત કરે છે. |
| Presentation Layer | ડેટાનું Format Conversion, Encryption, Decryption અને Compression કરે છે. |
| Application Layer | વપરાશકર્તાની એપ્લિકેશનને નેટવર્ક સેવાઓ પૂરી પાડે છે. |
