# લેશન - ૩૪ : સ્પ્રેડશીટમાં વિવિધ ફંક્શનનો પરિચય

| **ફંક્શન** | **ઉપયોગ (ગુજરાતીમાં)** | **MS Excel ઉદાહરણ** |
|------------|--------------------------|-----------------------|
| SUM | સંખ્યાઓનો કુલ સરવાળો કરે છે. | `=SUM(A1:A5)` |
| AVERAGE | સંખ્યાઓની સરેરાશ કાઢે છે. | `=AVERAGE(A1:A5)` |
| MAX | સૌથી મોટી કિંમત બતાવે છે. | `=MAX(A1:A5)` |
| MIN | સૌથી નાની કિંમત બતાવે છે. | `=MIN(A1:A5)` |
| ROUND | સંખ્યાને નિર્ધારિત દશાંશ સુધી ગોળ કરે છે. | `=ROUND(A1,2)` |
| IF | શરત મુજબ પરિણામ આપે છે. | `=IF(A1>=35,"પાસ","નાપાસ")` |
| AND | બધી શરતો સાચી હોય તો TRUE આપે છે. | `=AND(A1>35,B1>35)` |
| OR | કોઈ એક શરત સાચી હોય તો TRUE આપે છે. | `=OR(A1>35,B1>35)` |
| NOT | પરિણામને ઉલટાવે છે. | `=NOT(A1>35)` |
| IFERROR | ભૂલ આવે તો વૈકલ્પિક પરિણામ આપે છે. | `=IFERROR(A1/B1,0)` |
| CONCATENATE | બે અથવા વધુ લખાણ જોડે છે. | `=CONCATENATE(A1," ",B1)` |
| LEFT | ડાબી બાજુથી અક્ષરો આપે છે. | `=LEFT(A1,3)` |
| LEN | લખાણની લંબાઈ ગણે છે. | `=LEN(A1)` |
| UPPER | લખાણને મોટા અક્ષરમાં ફેરવે છે. | `=UPPER(A1)` |
| TRIM | વધારાની ખાલી જગ્યાઓ દૂર કરે છે. | `=TRIM(A1)` |
| VLOOKUP | ઊભી કોષ્ટકમાંથી માહિતી શોધે છે. | `=VLOOKUP(A1,C1:E10,2,FALSE)` |
| HLOOKUP | આડી કોષ્ટકમાંથી માહિતી શોધે છે. | `=HLOOKUP(A1,A1:E5,2,FALSE)` |
| MATCH | કિંમતનું સ્થાન (પોઝિશન) શોધે છે. | `=MATCH(A1,B1:B10,0)` |
| INDEX | નિર્ધારિત સ્થાનની કિંમત આપે છે. | `=INDEX(A1:A10,3)` |
| TRANSPOSE | પંક્તિને સ્તંભમાં અથવા સ્તંભને પંક્તિમાં ફેરવે છે. | `=TRANSPOSE(A1:C3)` |
| TODAY | આજની તારીખ બતાવે છે. | `=TODAY()` |
| NOW | વર્તમાન તારીખ અને સમય બતાવે છે. | `=NOW()` |
| YEAR | તારીખમાંથી વર્ષ આપે છે. | `=YEAR(A1)` |
| MONTH | તારીખમાંથી મહિનો આપે છે. | `=MONTH(A1)` |
| DAY | તારીખમાંથી દિવસ આપે છે. | `=DAY(A1)` |
| Start Date | શરૂઆતની તારીખ. | `01/01/2026` |
| End Date | અંતિમ તારીખ. | `31/12/2026` |
