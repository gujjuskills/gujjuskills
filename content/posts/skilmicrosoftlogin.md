Windows 11 normally asks you to connect to the internet and sign in with a Microsoft account during the initial setup.

If you want to use Windows 11 with a **local account** instead, you can sometimes bypass the Microsoft account requirement during the installation process.

This guide explains the process step by step, including what to do when the normal local account option is not displayed.

## What Is a Local Account in Windows 11?

A local account is an account that exists only on your Windows computer.

You can use a local account to:

1. Sign in to Windows
2. Create a password
3. Install applications
4. Change Windows settings
5. Manage files and folders
6. Use Windows without connecting the account to Microsoft online services

A Microsoft account is different because it is connected to Microsoft's online services.

## What You Need Before Starting

Before installing Windows 11, keep the following things ready.

1. Windows 11 installation USB drive
2. A Windows 11 compatible computer
3. Keyboard
4. Mouse
5. Windows 11 installation media
6. Product key if your installation requires one

An internet connection may be requested during setup. If you want to create a local account, the steps below can help you reach the local account setup option on supported Windows 11 installation builds.

# Method 1: Use OOBE Bypass Command

This is one of the commonly used methods during Windows 11 setup.

## Step 1: Start Windows 11 Installation

Start your computer using the Windows 11 installation USB drive.

Select your preferred options such as:

**Language**

**Time and currency format**

**Keyboard layout**

Then click:

**Next**

Click:

**Install now**

Continue with the normal Windows 11 installation process.

## Step 2: Select the Windows Edition

If Windows asks you to select an edition, choose the edition that matches your license.

For example:

**Windows 11 Home**

**Windows 11 Pro**

Then click:

**Next**

Follow the installation instructions.

## Step 3: Reach the Network Connection Screen

After Windows finishes installing, the initial Windows setup process will start.

You may eventually see a screen asking you to connect to a network.

The screen can contain wording similar to:

**Let's connect you to a network**

Windows may ask you to connect to WiFi or Ethernet before continuing.

## Step 4: Open Command Prompt

At this screen, press:

**Shift + F10**

On some laptops, you may need to press:

**Shift + Fn + F10**

A Command Prompt window should appear.
