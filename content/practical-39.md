# પ્રેકટિકલ-૩૯ : ટેક્સ્ટ અને ફકરાઓને ફોરમેટ કરો

| ક્રમ | કાર્ય | સામાન્ય સમજ / કાર્ય |
|---|---|---|
| 1 | ટેક્સ્ટ ઇફેક્ટ લાગુ કરવો | MS Word માં લખેલા ટેક્સ્ટ પર Text Effects લાગુ કરવા. ટેક્સ્ટનો રંગ, Outline, Shadow, Reflection અને Glow જેવા ઇફેક્ટનો ઉપયોગ કરવો. |
| 2 | Format Painter દ્વારા ફોર્મેટિંગ લાગુ કરવું | એક ટેક્સ્ટનું ફોર્મેટિંગ બીજા ટેક્સ્ટ પર લાગુ કરવા માટે Format Painter નો ઉપયોગ કરવો. |
| 3 | લાઇન અને પેરાગ્રાફ સ્પેસિંગ તથા ઇન્ડેન્ટેશન સેટ કરવું | પેરાગ્રાફમાં Line Spacing, Paragraph Spacing અને Indentation સેટ કરવું. જરૂરી મુજબ Left, Right, First Line અને Hanging Indent લાગુ કરવું. |
| 4 | ટેક્સ્ટ પર Built-in Styles લાગુ કરવા | MS Word માં ઉપલબ્ધ Heading 1, Heading 2, Title, Subtitle વગેરે Built-in Styles નો ઉપયોગ ટેક્સ્ટને યોગ્ય રીતે ફોર્મેટ કરવા માટે કરવો. |
| 5 | ફોર્મેટિંગ દૂર કરવું | ટેક્સ્ટ પર લાગુ કરેલું Bold, Italic, Font Color, Size, Style વગેરે ફોર્મેટિંગ દૂર કરવા Clear All Formatting નો ઉપયોગ કરવો. |
