# પ્રેકટિકલ-૬ : ડેસ્કટોપ કોમ્પ્યુટરના ઘટકો જુદા કરવા
![image](/gujjuskills/images/assemble-of-computer.webp)
| સ્ટેપ | કાર્ય |
|:---:|:---|
| 1 | કમ્પ્યુટર બંધ કરી પાવર કેબલ અને અન્ય કેબલને ડિસ્કનેક્ટ કરો. |
| 2 | CPU કેબિનેટનું સાઇડ કવર ખોલો અને અંદરના ભાગોને ઓળખો. |
| 3 | મધરબોર્ડને કેબિનેટમાં યોગ્ય રીતે ગોઠવીને સ્ક્રૂથી ફિટ કરો. |
| 4 | CPU ને મધરબોર્ડના CPU સોકેટમાં યોગ્ય દિશામાં બેસાડો અને CPU ફેન લગાવો. |
| 5 | RAM ને મધરબોર્ડના RAM સ્લોટમાં યોગ્ય રીતે લગાવો. |
| 6 | SMPS ને કેબિનેટમાં ફિટ કરો અને તેના પાવર કનેક્ટર જોડો. |
| 7 | HDD/SSD ને ડ્રાઇવ બેમાં ફિટ કરી SATA ડેટા અને પાવર કેબલ જોડો. |
| 8 | કેબિનેટના Front Panel, USB અને Audio કનેક્ટર મધરબોર્ડ સાથે જોડો. |
| 9 | બધા કનેક્શન તપાસી કેબિનેટનું કવર બંધ કરો અને પાવર કેબલ જોડીને કમ્પ્યુટર ચાલુ કરો. |
