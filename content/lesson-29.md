# લેશન - ૨૯ : ઈમેજના ફોર્મેટ અને તેનો ઉપયોગ

## ઈમેજના મુખ્ય પ્રકાર

| Raster Image | Vector Image |
|---|---|
| રાસ્ટર ઈમેજ પિક્સેલથી બનેલી હોય છે. | વેક્ટર ઈમેજ લાઇન, પાથ અને જ્યોમેટ્રિક આકારોથી બનેલી હોય છે. |
| ઈમેજની ગુણવત્તા પિક્સેલના રિઝોલ્યુશન પર આધારિત હોય છે. | ઈમેજને મોટું કે નાનું કરવાથી ગુણવત્તામાં ઘટાડો થતો નથી. |
| ફોટોગ્રાફ અને વાસ્તવિક ચિત્રો માટે વધુ યોગ્ય છે. | લોગો, આઇકન અને ગ્રાફિક ડિઝાઇન માટે વધુ યોગ્ય છે. |
| વધુ ઝૂમ કરવાથી ઈમેજ પિક્સેલેટ થઈ શકે છે. | વધુ ઝૂમ કરવાથી પણ ઈમેજ સ્પષ્ટ રહે છે. |
| સામાન્ય રાસ્ટર ફોર્મેટમાં JPG, PNG, GIF, BMP અને TIFFનો સમાવેશ થાય છે. | સામાન્ય વેક્ટર ફોર્મેટમાં SVG, AI, EPS, CDR અને PDFનો સમાવેશ થાય છે. |

## Raster Image ના ઉદાહરણ અને તેના પૂરાં નામ

| ઈમેજ ફોર્મેટ | પૂરું નામ |
|---|---|
| JPG / JPEG | Joint Photographic Experts Group |
| PNG | Portable Network Graphics |
| GIF | Graphics Interchange Format |
| BMP | Bitmap Image File |
| TIFF | Tagged Image File Format |
| WebP | Web Picture |

## Vector Image ના ઉદાહરણ અને તેના પૂરાં નામ

| ઈમેજ ફોર્મેટ | પૂરું નામ |
|---|---|
| SVG | Scalable Vector Graphics |
| AI | Adobe Illustrator Artwork |
| EPS | Encapsulated PostScript |
| CDR | CorelDRAW File |
| PDF | Portable Document Format |
| WMF | Windows Metafile |
