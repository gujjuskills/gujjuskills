# પ્રેકટિકલ-૯૭ : એડવાંન્સ તારીખ ફંક્શનનો ઉપયોગ કરો : MS-EXCEL

## કેવી રીતે બનાવવું

1. Microsoft Excel ખોલો.
2. નવી Workbook બનાવો.
3. Name, DOB અને Today માટે અલગ અલગ Cell બનાવો.
4. ઉપર દર્શાવેલી તારીખોની માહિતી Excel માં દાખલ કરો.
5. `TODAY()` Function માટે `=TODAY()` લખો.
6. `NOW()` Function માટે `=NOW()` લખો.
7. `DATE()` Function માટે `=DATE(1990,2,12)` લખો.
8. `DAY()` Function માટે `=DAY(તમારી તારીખવાળી Cell)` લખો.
9. `MONTH()` Function માટે `=MONTH(તમારી તારીખવાળી Cell)` લખો.
10. `YEAR()` Function માટે `=YEAR(તમારી તારીખવાળી Cell)` લખો.
11. `DAYS360()` અથવા `DAYS()` Function નો ઉપયોગ કરીને બે તારીખો વચ્ચેના દિવસો શોધો.
12. `EDATE()` Function દ્વારા તારીખમાં મહિના ઉમેરો અથવા ઘટાડો.
13. `EOMONTH()` Function દ્વારા મહિનાની છેલ્લી તારીખ શોધો.
14. `DATEDIF()` Function દ્વારા બે તારીખો વચ્ચેના વર્ષ, મહિના અને દિવસો શોધો.
15. તમામ Function, Input અને Result ને યોગ્ય Table માં ગોઠવો.
16. Header ને **Bold** કરો અને જરૂર મુજબ Border તથા Alignment આપો.
17. અંતે Excel File ને Save કરો.
