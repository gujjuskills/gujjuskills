# લેશન - ૧૧૩ : વિવિધ ડેટા ટાઈપ્સ

## What is Data Types :

**Data Type** એટલે પ્રોગ્રામમાં સંગ્રહિત થતા ડેટાનો પ્રકાર.  
Data Type દ્વારા નક્કી થાય છે કે Variable માં કયા પ્રકારનો Data સંગ્રહિત કરવામાં આવ્યો છે.

Python માં અલગ અલગ પ્રકારના Data માટે અલગ Data Types નો ઉપયોગ કરવામાં આવે છે.

## Types of Data Types :

| Category | Data Type | Description | Example |
|---|---|---|---|
| **1. Numbers** | **int** | પૂર્ણ સંખ્યા દર્શાવવા માટે `int` નો ઉપયોગ થાય છે. તેમાં દશાંશ ભાગ હોતો નથી. | `10`, `25`, `100` |
|  | **Float** | દશાંશ સંખ્યા દર્શાવવા માટે `Float` નો ઉપયોગ થાય છે. | `10.5`, `25.75` |
|  | **Complex** | વાસ્તવિક અને કાલ્પનિક ભાગ ધરાવતી સંખ્યા માટે `Complex` નો ઉપયોગ થાય છે. | `3 + 2j` |
| **2. Dictionary** | **Dictionary** | Dictionary માં Data ને Key અને Value ના સ્વરૂપમાં સંગ્રહિત કરવામાં આવે છે. | `{"name": "Ravi", "age": 20}` |
| **3. Boolean** | **Boolean** | Boolean માં માત્ર બે Value હોય છે: `True` અને `False`. તેનો ઉપયોગ શરત ચકાસવા માટે થાય છે. | `True`, `False` |
| **4. Set** | **Set** | Set એ અનન્ય Values નો સમૂહ છે. તેમાં એક જ Value વારંવાર સંગ્રહિત થતી નથી. | `{10, 20, 30}` |
| **5. Sequence Type** | **String** | String માં અક્ષરો, શબ્દો અથવા Text સંગ્રહિત કરવામાં આવે છે. | `"Hello"` |
|  | **List** | List માં એકથી વધુ Values ને ક્રમમાં સંગ્રહિત કરી શકાય છે. List ની Values બદલી શકાય છે. | `[10, 20, 30]` |
|  | **Tuple** | Tuple માં એકથી વધુ Values ને ક્રમમાં સંગ્રહિત કરવામાં આવે છે. Tuple ની Values બદલી શકાતી નથી. | `(10, 20, 30)` |
