# પ્રેકટિકલ-૨૫ : સામાન્ય DOS કમાન્ડનો ઉપયોગ: (ભાગ-B)
| પ્રેકટિકલ ટૉપિક  | સામાન્ય માહિતી |
|---|---|
| **COPY** | ફાઇલની નકલ કરવા માટે ઉપયોગ થાય છે. |
| **COPY CON** | કમાન્ડ પ્રોમ્પ્ટમાં નવી ટેક્સ્ટ ફાઇલ બનાવવા માટે ઉપયોગ થાય છે. |
| **XCOPY** | ફાઇલો અને ફોલ્ડરોને એક સ્થાનેથી બીજા સ્થાને નકલ કરવા માટે ઉપયોગ થાય છે. |
| **CHKDSK** | ડિસ્કની ભૂલો તપાસવા અને ડિસ્કની સ્થિતિ જાણવા માટે ઉપયોગ થાય છે. |
| **PROMPT** | DOS કમાન્ડ પ્રોમ્પ્ટનો દેખાવ બદલવા માટે ઉપયોગ થાય છે. |
| **TREE** | ડ્રાઇવ અથવા ફોલ્ડરની ડિરેક્ટરી રચના વૃક્ષ સ્વરૂપે દર્શાવવા માટે ઉપયોગ થાય છે. |
| **VER** | Windows/DOS નું વર્ઝન જાણવા માટે ઉપયોગ થાય છે. |
| **PATH** | એક્ઝિક્યુટેબલ ફાઇલો શોધવા માટેના ડિરેક્ટરી પાથને સેટ અથવા દર્શાવવા માટે ઉપયોગ થાય છે. |
| **PRINT** | ટેક્સ્ટ ફાઇલને પ્રિન્ટ કરવા માટે ઉપયોગ થાય છે. |
| **FORMAT** | ડિસ્ક અથવા ડ્રાઇવને ફોર્મેટ કરવા માટે ઉપયોગ થાય છે. |
| **TYPE** | ટેક્સ્ટ ફાઇલની અંદરની માહિતી સ્ક્રીન પર દર્શાવવા માટે ઉપયોગ થાય છે. |
| **EDIT** | ટેક્સ્ટ ફાઇલ બનાવવા અથવા તેમાં ફેરફાર કરવા માટે ઉપયોગ થાય છે. |
| **MOVE** | ફાઇલ અથવા ફોલ્ડરને એક સ્થાનેથી બીજા સ્થાને ખસેડવા માટે ઉપયોગ થાય છે. |
| **LABEL** | ડિસ્ક અથવા ડ્રાઇવનું નામ સેટ કરવા અથવા બદલવા માટે ઉપયોગ થાય છે. |
| **COMP** | બે ફાઇલોની સામગ્રીની સરખામણી કરવા માટે ઉપયોગ થાય છે. |
| **SYS** | ડ્રાઇવને સિસ્ટમ ફાઇલો ટ્રાન્સફર કરીને બૂટેબલ બનાવવા માટે ઉપયોગ થાય છે. |
| **PING** | નેટવર્ક કનેક્શન અને બીજા કમ્પ્યુટર સુધી પહોંચ ચકાસવા માટે ઉપયોગ થાય છે. |
| **EXIT** | DOS કમાન્ડ પ્રોમ્પ્ટમાંથી બહાર નીકળવા માટે ઉપયોગ થાય છે. |
