# લેશન - ૩૦.૨ : ડિઝાઇન ટેબ : MS-POWERPOINT
![image](/gujjuskills/images/lesson-30.2.png)
| ડિઝાઇન ટેબ | ગુજરાતી માહિતી |
|---|---|
| Page Setup | સ્લાઇડનું કદ, પહોળાઈ અને ઊંચાઈ નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Slide Orientation | સ્લાઇડને Portrait અથવા Landscape દિશામાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| Themes | સ્લાઇડને આકર્ષક અને એકસરખી ડિઝાઇન આપવા માટે તૈયાર Theme પસંદ કરી શકાય છે. |
| Colors | પસંદ કરેલી Theme ના રંગોને બદલવા અથવા નવી રંગ યોજના પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Fonts | સ્લાઇડના લખાણ માટે Heading અને Body ના Font પસંદ અથવા બદલવા માટે ઉપયોગ થાય છે. |
| Effects | આકારો અને અન્ય ડિઝાઇન તત્વો માટે વિવિધ Visual Effects પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Background Styles | સ્લાઇડના Background માટે વિવિધ રંગ, Gradient અને Style પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Hide Background Graphics | સ્લાઇડના Background Graphics છુપાવવા માટે આ વિકલ્પનો ઉપયોગ થાય છે. |
