# પ્રેકટિકલ-૯૯ : પાઇવોટ ટેબલ બનાવો અને તેમાં ફેરફાર કરો : MS-EXCEL

### Steps to Create a PivotTable

1. સૌપ્રથમ Excel માં આપેલ Data Table બનાવો.

2. Data Table ના બધા records select કરો.

3. Excel માં **Insert** tab પર click કરો.

4. **PivotTable** option પસંદ કરો.

5. Create PivotTable dialog box ખુલશે.

6. **Table/Range** માં યોગ્ય data range પસંદ કરો.

7. **New Worksheet** પસંદ કરો.

8. **OK** પર click કરો.

9. PivotTable Fields માંથી **Employee Name** ને **Rows** વિસ્તારમાં drag કરો.

10. **Quantity** ને **Values** વિસ્તારમાં drag કરો.

11. **Rate** ને **Values** વિસ્તારમાં drag કરો.

12. **Amount** ને **Values** વિસ્તારમાં drag કરો.

13. Values માટે જરૂરી હોય તો **Sum** option પસંદ કરો.

14. હવે દરેક Employee માટે Quantity, Rate અને Amount નો summary દેખાશે.

15. અંતે **Grand Total** માં બધા records નો કુલ સરવાળો જોવા મળશે.

16. PivotTable માં ફેરફાર કરવા માટે જરૂરી Field ને Rows, Columns, Filters અથવા Values વિસ્તારમાં drag કરો.

17. Data માં ફેરફાર કર્યા પછી PivotTable પર Right Click કરીને **Refresh** પસંદ કરો.
