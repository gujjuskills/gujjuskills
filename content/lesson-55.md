# લેશન - ૫૫ : ટેબલોનું જોડાણ

### SQL માં JOIN શું છે?

 SQL માં JOIN નો ઉપયોગ બે અથવા વધુ ટેબલના સંબંધિત ડેટાને એકસાથે મેળવવા માટે થાય છે.  સામાન્ય કૉલમ અથવા સંબંધિત કૉલમના આધારે અલગ અલગ ટેબલનો ડેટા જોડવામાં આવે છે. 

### SQL માં JOIN ના પ્રકાર

| JOIN નો પ્રકાર | માહિતી |
|---|---|
| **INNER JOIN** | બંને ટેબલમાં મેળ ખાતા રેકોર્ડ્સ જ દર્શાવે છે. |
| **SELF JOIN** | એક જ ટેબલને તેની પોતાની સાથે જોડવામાં આવે છે. તેનો ઉપયોગ ટેબલના રેકોર્ડ્સ વચ્ચે સંબંધ શોધવા માટે થાય છે. |
| **CROSS JOIN** | બે ટેબલના દરેક રેકોર્ડને બીજા ટેબલના દરેક રેકોર્ડ સાથે જોડે છે. તેને Cartesian Product પણ કહેવામાં આવે છે. |
| **OUTER JOIN**|OUTER JOIN નો ઉપયોગ બે ટેબલને જોડતી વખતે મેળ ખાતા તેમજ જરૂરી બિનમેળ ખાતા રેકોર્ડ્સ મેળવવા માટે થાય છે. |
| **LEFT OUTER JOIN** | ડાબી બાજુના ટેબલના બધા રેકોર્ડ અને જમણી બાજુના ટેબલના મેળ ખાતા રેકોર્ડ દર્શાવે છે. જો જમણા ટેબલમાં મેળ ખાતો રેકોર્ડ ન હોય, તો તેની જગ્યાએ `NULL` દર્શાવવામાં આવે છે. |
| **RIGHT OUTER JOIN** | જમણી બાજુના ટેબલના બધા રેકોર્ડ અને ડાબી બાજુના ટેબલના મેળ ખાતા રેકોર્ડ દર્શાવે છે. જો ડાબા ટેબલમાં મેળ ખાતો રેકોર્ડ ન હોય, તો તેની જગ્યાએ `NULL` દર્શાવવામાં આવે છે. |
| **FULL OUTER JOIN** | બંને ટેબલના બધા રેકોર્ડ દર્શાવે છે. જ્યાં રેકોર્ડ મેળ ખાતો ન હોય ત્યાં `NULL` દર્શાવવામાં આવે છે. |
