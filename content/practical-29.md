# પ્રેક્ટિકલ - ૨૯ : સામાન્ય લિનક્સ કમાન્ડ્સ નો ઉપયોગ

| Linux Command | ગુજરાતી અર્થ / ઉપયોગ |
|---|---|
|How to start linux Terminal|Applications / Show Applications ખોલો → Terminal શોધો → Terminal પર click કરો.|
| `date` | વર્તમાન તારીખ અને સમય દર્શાવવા માટે ઉપયોગ થાય છે. |
| `clear` | ટર્મિનલ સ્ક્રીન સાફ કરવા માટે ઉપયોગ થાય છે. |
| `cal` | કેલેન્ડર દર્શાવવા માટે ઉપયોગ થાય છે. |
| `who` | સિસ્ટમમાં હાલમાં લૉગિન થયેલા યુઝર્સની માહિતી દર્શાવે છે. |
| `ls` | વર્તમાન ડિરેક્ટરીમાં રહેલી ફાઇલો અને ફોલ્ડર્સની યાદી દર્શાવે છે. |
| `mkdir` | નવી ડિરેક્ટરી અથવા ફોલ્ડર બનાવવા માટે ઉપયોગ થાય છે. |
| `rmdir` | ખાલી ડિરેક્ટરી દૂર કરવા માટે ઉપયોગ થાય છે. |
| `cd` | બીજી ડિરેક્ટરીમાં જવા માટે ઉપયોગ થાય છે. |
| `cd ..` | વર્તમાન ડિરેક્ટરીની એક લેવલ ઉપર જવા માટે ઉપયોગ થાય છે. |
| `echo` | સ્ક્રીન પર ટેક્સ્ટ અથવા મેસેજ દર્શાવવા માટે ઉપયોગ થાય છે. |
| `pwd` | વર્તમાન ડિરેક્ટરીનું સંપૂર્ણ પાથ દર્શાવે છે. |
| `bc` | ટર્મિનલમાં ગણિતની ગણતરી કરવા માટે ઉપયોગ થાય છે. |
| `cat` | ફાઇલની સામગ્રી જોવા અથવા દર્શાવવા માટે ઉપયોગ થાય છે. |
| `cp` | ફાઇલ અથવા ડિરેક્ટરીની નકલ કરવા માટે ઉપયોગ થાય છે. |
| `rm` | ફાઇલ અથવા ડિરેક્ટરી દૂર કરવા માટે ઉપયોગ થાય છે. |
| `mv` | ફાઇલ અથવા ડિરેક્ટરીનું નામ બદલવા અથવા તેને બીજી જગ્યાએ ખસેડવા માટે ઉપયોગ થાય છે. |
| `man` | Linux command નું મેન્યુઅલ અથવા મદદની માહિતી જોવા માટે ઉપયોગ થાય છે. |
| `wc` | ફાઇલમાં રહેલી લાઇન્સ, શબ્દો અને અક્ષરોની સંખ્યા જાણવા માટે ઉપયોગ થાય છે. |
| `grep` | ફાઇલ અથવા ટેક્સ્ટમાં ચોક્કસ શબ્દ અથવા પેટર્ન શોધવા માટે ઉપયોગ થાય છે. |
| `lp` | પ્રિન્ટર પર ફાઇલ પ્રિન્ટ કરવા માટે ઉપયોગ થાય છે. |
| `more` | લાંબી ફાઇલની સામગ્રી એક સમયે એક સ્ક્રીન પ્રમાણે જોવા માટે ઉપયોગ થાય છે. |
| `sort` | ટેક્સ્ટ અથવા ફાઇલની લાઇનોને ક્રમમાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| `chmod` | ફાઇલ અથવા ડિરેક્ટરીની permissions બદલવા માટે ઉપયોગ થાય છે. |
| `passwd` | યુઝરનો પાસવર્ડ બદલવા માટે ઉપયોગ થાય છે. |
