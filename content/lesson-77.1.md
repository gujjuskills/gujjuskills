# લેશન - ૭૭.૧ : HTML : ફોર્મ કંટ્રોલ

| ફોર્મ કંટ્રોલ | ઉપયોગ |
|---|---|
| **Form** | વપરાશકર્તા પાસેથી માહિતી મેળવવા માટે ફોર્મ બનાવવામાં ઉપયોગ થાય છે. |
| **Input** | વપરાશકર્તા પાસેથી વિવિધ પ્રકારની માહિતી દાખલ કરાવવા માટે ઉપયોગ થાય છે. |
| **Textarea** | વપરાશકર્તા પાસેથી લાંબો ટેક્સ્ટ દાખલ કરાવવા માટે ઉપયોગ થાય છે. |
| **Label** | ફોર્મના કંટ્રોલ માટે નામ અથવા વર્ણન દર્શાવવા માટે ઉપયોગ થાય છે. |
| **Fieldset** | સંબંધિત ફોર્મ કંટ્રોલને એક જૂથમાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| **Legend** | Fieldset માટે શીર્ષક અથવા નામ દર્શાવવા માટે ઉપયોગ થાય છે. |
| **Select** | ડ્રોપડાઉન સૂચિ બનાવવા માટે ઉપયોગ થાય છે. |
| **Optgroup** | Select માં વિકલ્પોને જૂથમાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| **Option** | Select અથવા Optgroup માં એક વિકલ્પ દર્શાવવા માટે ઉપયોગ થાય છે. |
| **Button** | બટન બનાવવા અને કોઈ ક્રિયા કરવા માટે ઉપયોગ થાય છે. |
| **Datalist** | Input માટે પહેલેથી ઉપલબ્ધ વિકલ્પોની સૂચિ આપવા માટે ઉપયોગ થાય છે. |
| **Output** | ગણતરી અથવા ક્રિયાનું પરિણામ દર્શાવવા માટે ઉપયોગ થાય છે. |
