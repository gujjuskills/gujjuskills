# પ્રેકટિકલ-૧૨૧ : કોમ્પ્યુટર લેબમાં વાયરલેસ લેન ગોઠવો અને સેટ કરો

![image](/images/practical-121.webp)

1. **રાઉટર જોડવું:** રાઉટરને પાવર એડેપ્ટર સાથે જોડીને ચાલુ કરો.

2. **કમ્પ્યુટર જોડવું:** LAN કેબલ દ્વારા કમ્પ્યુટરને રાઉટર સાથે જોડો.

3. **રાઉટરનું સેટિંગ ખોલવું:** વેબ બ્રાઉઝરમાં રાઉટરનું IP સરનામું જેમ કે 192.168.0.1 અથવા 192.168.1.1 દાખલ કરો.

4. **Login કરવું:** રાઉટરનું Username અને Password દાખલ કરીને Admin પેનલમાં Login કરો.

5. **Wireless સેટિંગ કરવું:** Wireless અથવા Wi-Fi Settings માં જઈને નેટવર્કનું નામ એટલે કે SSID સેટ કરો.

6. **Security સેટ કરવી:** WPA2 અથવા WPA3 Security પસંદ કરીને મજબૂત Wi-Fi Password સેટ કરો.

7. **DHCP ચાલુ કરવું:** DHCP Server ચાલુ રાખો જેથી જોડાયેલા કમ્પ્યુટરને આપમેળે IP Address મળી શકે.

8. **સેટિંગ સેવ કરવું:** કરેલા તમામ સેટિંગને Save અથવા Apply કરો અને જરૂર હોય તો રાઉટર Restart કરો.

9. **Wi-Fi સાથે જોડાવું:** લેબના કમ્પ્યુટર અથવા અન્ય ઉપકરણોમાં Wi-Fi ચાલુ કરીને સેટ કરેલા SSID સાથે જોડાઓ.

10. **નેટવર્ક ચકાસવું:** બધા કમ્પ્યુટરને IP Address મળ્યું છે કે નહીં અને નેટવર્ક યોગ્ય રીતે કાર્ય કરે છે કે નહીં તે ચકાસો.
