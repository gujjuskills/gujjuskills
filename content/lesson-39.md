## લેશન - ૩૯ : એક્સેલ લીનકેજ કસ્ટમ ફોરમેટ અને એકસેલ પ્રોટેક્શન

### Excel Linkage શું છે?
 Excel Linkage એટલે એક Excel વર્કબુક, વર્કશીટ અથવા અન્ય Excel ડેટાને બીજી જગ્યાના ડેટા સાથે જોડવાની પ્રક્રિયા. Link બનાવવાથી મૂળ ડેટામાં ફેરફાર થાય ત્યારે જોડાયેલ ડેટા પણ અપડેટ થઈ શકે છે. 

### Excel Linkage ના પ્રકાર

| ક્રમાંક | Excel Linkage નો પ્રકાર | માહિતી |
|---|---|---|
| 1 | Data Links | એક Excel ફાઇલ અથવા વર્કબુકના ડેટાને બીજી Excel ફાઇલ અથવા વર્કબુક સાથે જોડવા માટે Data Link નો ઉપયોગ થાય છે. |
| 2 | Linked Data Types | Excel માં ઉપલબ્ધ Linked Data Types દ્વારા ઇન્ટરનેટ અથવા અન્ય સ્રોતમાંથી સંબંધિત માહિતી Excel માં મેળવી શકાય છે. |
| 3 | Connections | Excel ને બાહ્ય ડેટા સ્રોત, જેમ કે Database, Web અથવા અન્ય ફાઇલ સાથે જોડવા માટે Connections નો ઉપયોગ થાય છે. |

### Excel Protection શું છે?

Excel Protection એટલે વર્કબુક, વર્કશીટ અથવા ચોક્કસ સેલને અનધિકૃત ફેરફાર, ડેટા કાઢી નાખવા અથવા ખોટી રીતે સંપાદિત થવાથી સુરક્ષિત રાખવાની સુવિધા.
