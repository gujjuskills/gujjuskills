# લેશન - ૮૯ : જાવાસ્ક્રિપ્ટમાં આંતરપ્રસ્થાપિત ફંક્શનનુ અવલોકન

| JavaScript ફંક્શન | ગુજરાતી અર્થ / ઉપયોગ |
|---|---|
| `console.log()` | કન્સોલમાં માહિતી અથવા પરિણામ દર્શાવવા માટે ઉપયોગ થાય છે. |
| `map()` | Array ના દરેક Element પર પ્રક્રિયા કરીને નવી Array બનાવવા માટે ઉપયોગ થાય છે. |
| `filter()` | આપેલી શરત મુજબ Array માંથી જરૂરી Elements પસંદ કરવા માટે ઉપયોગ થાય છે. |
| `reduce()` | Array ના બધા Elements ને એક જ પરિણામમાં રૂપાંતરિત કરવા માટે ઉપયોગ થાય છે. |
| `forEach()` | Array ના દરેક Element માટે એકસરખો Code ચલાવવા માટે ઉપયોગ થાય છે. |
| `split()` | String ને આપેલા Separator મુજબ અલગ કરીને Array બનાવવા માટે ઉપયોગ થાય છે. |
| `join()` | Array ના બધા Elements ને જોડીને એક String બનાવવા માટે ઉપયોગ થાય છે. |
| `toUpperCase()` | String ના બધા અક્ષરોને મોટા અક્ષરોમાં બદલવા માટે ઉપયોગ થાય છે. |
| `alert()` | વેબપેજ પર સંદેશો દર્શાવવા માટે Popup Box બતાવે છે. |
| `Object.keys()` | Object ની બધી Keys ને Array સ્વરૂપે મેળવવા માટે ઉપયોગ થાય છે. |
| `parseInt()` | String અથવા અન્ય મૂલ્યને પૂર્ણાંક Number માં રૂપાંતરિત કરવા માટે ઉપયોગ થાય છે. |
| `Math.random()` | 0 થી 1 વચ્ચે Random Number મેળવવા માટે ઉપયોગ થાય છે. |
| `Math.floor()` | Number ને નીચેની નજીકની પૂર્ણ સંખ્યામાં રૂપાંતરિત કરવા માટે ઉપયોગ થાય છે. |
| `trim()` | String ની શરૂઆત અને અંતમાં રહેલા વધારાના Spaces દૂર કરવા માટે ઉપયોગ થાય છે. |
| `includes()` | String અથવા Array માં આપેલ મૂલ્ય હાજર છે કે નહીં તે તપાસવા માટે ઉપયોગ થાય છે. |
| `find()` | Array માં આપેલી શરતને પૂર્ણ કરતું પ્રથમ Element શોધવા માટે ઉપયોગ થાય છે. |
| `setTimeout()` | આપેલા સમય પછી કોઈ Function અથવા Code ચલાવવા માટે ઉપયોગ થાય છે. |
| `JSON.stringify()` | JavaScript Object અથવા Array ને JSON String માં રૂપાંતરિત કરવા માટે ઉપયોગ થાય છે. |
| `JSON.parse()` | JSON String ને JavaScript Object અથવા Array માં રૂપાંતરિત કરવા માટે ઉપયોગ થાય છે. |
