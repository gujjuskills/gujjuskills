### What is Python :

Python એક ઉચ્ચ સ્તરની (High-Level), સરળ અને લોકપ્રિય Programming Language છે. તેનો ઉપયોગ Software Development, Web Development, Data Science, Artificial Intelligence, Machine Learning, Automation વગેરે ક્ષેત્રોમાં થાય છે.

Python ને Guido van Rossum દ્વારા વિકસાવવામાં આવી હતી અને તેનો પ્રથમ જાહેર પ્રકાશન વર્ષ 1991માં થયું હતું.

Python નું Syntax સરળ અને વાંચવામાં સરળ હોવાથી નવા વિદ્યાર્થીઓ માટે શીખવું સરળ છે.


### Features of Python :

1. **Easy to Learn :** Python નું Syntax સરળ અને સમજવામાં સરળ છે.

2. **Free and Open Source :** Python મફતમાં ઉપલબ્ધ છે અને તેનો Source Code પણ ઉપલબ્ધ છે.

3. **High Level Language :** Python માં Programming કરતી વખતે Machine Level Details જાણવાની જરૂર પડતી નથી.

4. **Portable :** Python Program Windows, Linux અને macOS જેવી વિવિધ Operating Systems પર ચલાવી શકાય છે.

5. **Interpreted Language :** Python Program સામાન્ય રીતે Interpreter દ્વારા Execute થાય છે.

### Setting Path for Python :

### Path Set કરવાની રીત:

1. Windows Search માં **Environment Variables** લખો.
2. **Edit the system environment variables** પસંદ કરો.
3. **Environment Variables** પર Click કરો.
4. **Path** પસંદ કરીને **Edit** પર Click કરો.
5. **New** પર Click કરો.
6. Python અને Scripts ના Path ઉમેરો.
7. **OK** પર Click કરીને Settings Save કરો.
8. Command Prompt ખોલીને નીચેનો Command લખો:

`python --version`

Python નું Version દેખાય તો Path યોગ્ય રીતે Set થયેલ છે.


### Basic Syntax for Python :

Python માં Program લખવા માટે સરળ Syntax નો ઉપયોગ થાય છે.

Example:

print("Hello World")

### Comments in Python :

Program માં સમજ માટે લખવામાં આવેલી એવી માહિતી જે Python દ્વારા Execute કરવામાં આવતી નથી તેને Comment કહેવામાં આવે છે.

Single Line Comment માટે # નો ઉપયોગ થાય છે.

Example:

#### This is a comment
print("Hello")

### Variables in Python :

Variable એ Memory માં Data Store કરવા માટે ઉપયોગમાં લેવાતું નામ છે.

Python માં Variable બનાવતી વખતે Data Type અલગથી લખવાની જરૂર નથી.

Example:

name = "Rahul"
age = 20
marks = 85.5
