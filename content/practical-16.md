# પ્રેકટિકલ-૧૬ : BIOS સેટિંગ જોવા અને તેમાં ફેરફાર કરવા
![image](/gujjuskills/images/practical-16.png)
| પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|:---:|:---|
| BIOS ખોલવું (Open BIOS) | કમ્પ્યુટર ચાલુ કરતી વખતે BIOS ખોલવા માટે સામાન્ય રીતે `Delete`, `F2`, `F10` અથવા `Esc` કી દબાવવામાં આવે છે. |
| BIOS મેનુ (BIOS Menu) | BIOS મેનુમાં સિસ્ટમની વિવિધ સેટિંગ્સ જેમ કે Boot, Security, Advanced અને Main સેટિંગ્સ જોવા અને બદલવા મળે છે. |
| તારીખ અને સમય બદલવો (Change Date & Time) | BIOS ના Main મેનુમાં જઈને System Date અને System Time પસંદ કરી જરૂરી તારીખ અને સમય સેટ કરી શકાય છે. |
| બૂટિંગ ઓર્ડર બદલવો (Change Booting Order) | Boot મેનુમાં જઈને Hard Disk, USB અથવા CD/DVD જેવા બૂટ ડિવાઇસનો ક્રમ બદલી શકાય છે. |
| ડિફોલ્ટ સેટિંગ સેટ કરવું (Set Default Setting) | BIOS માં Load Default Settings અથવા Load Optimized Defaults વિકલ્પ પસંદ કરીને BIOS સેટિંગ્સને મૂળભૂત સ્થિતિમાં લાવી શકાય છે. |
| પાસવર્ડ સેટ કરવો (Set Password) | Security મેનુમાં Supervisor Password અથવા User Password વિકલ્પ દ્વારા BIOS માટે પાસવર્ડ સેટ કરી શકાય છે. |
| BIOS સેટિંગ્સ સેવ કરવી (Save BIOS Settings) | ફેરફાર કર્યા પછી Save Changes and Exit અથવા `F10` વિકલ્પ પસંદ કરીને BIOS સેટિંગ્સ સેવ કરી શકાય છે. |
| BIOS માંથી બહાર નીકળવું (Exit BIOS) | BIOSમાંથી બહાર નીકળવા માટે Exit વિકલ્પ પસંદ કરીને Exit Saving Changes અથવા Exit Discarding Changes પસંદ કરી શકાય છે. |
