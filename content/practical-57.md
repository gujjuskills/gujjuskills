# પ્રેકટિકલ-૫૭ : પાવરપોઈન્ટ પ્રેજેંટેશન સાચવો અને શેર કરો

| ટોપિક | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| વૈકલ્પિક ફાઇલ ફોર્મેટમાં પ્રેઝન્ટેશન સેવ કરવું | PowerPoint પ્રેઝન્ટેશનને PPTX સિવાય PDF, PPT, ODP જેવા વિવિધ ફાઇલ ફોર્મેટમાં સેવ કરી શકાય છે. **File → Save As** પસંદ કરીને જરૂરી ફાઇલ ફોર્મેટ પસંદ કરો અને **Save** પર ક્લિક કરો. |
| વિવિધ પ્રિન્ટ સેટિંગ્સ ગોઠવવા | PowerPointમાં પ્રિન્ટ કરતા પહેલાં સ્લાઇડનો કદ, ઓરિએન્ટેશન, કેટલા સ્લાઇડ પ્રતિ પેજ, કલર અથવા ગ્રેસ્કેલ અને પ્રિન્ટર જેવી સેટિંગ્સ ગોઠવી શકાય છે. **File → Print** માંથી જરૂરી વિકલ્પો પસંદ કરો. |
| પ્રેઝન્ટેશન ઇલેક્ટ્રોનિક રીતે શેર કરવું | PowerPoint પ્રેઝન્ટેશનને ઈમેલ, OneDrive, લિંક અથવા અન્ય ઇલેક્ટ્રોનિક માધ્યમ દ્વારા શેર કરી શકાય છે. **Share** વિકલ્પ પસંદ કરીને જરૂરી વ્યક્તિ સાથે પ્રેઝન્ટેશન શેર કરો. |
