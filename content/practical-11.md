# પ્રેક્ટિકલ - ૧૧  : કંટ્રોલ પેનલ અને સિસ્ટમ પ્રોપર્ટીઝની માહિતી  
![image](/gujjuskills/images/practical-11.png)
| કંટ્રોલ પેનલ વિકલ્પ | વિગતો / ઉપયોગ |
|:---:|:---|
| Autoplay | CD, DVD, USB અથવા અન્ય મીડિયા ડિવાઇસ જોડાય ત્યારે કઈ ક્રિયા આપમેળે કરવી તે નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Backup and Restore | મહત્વપૂર્ણ ફાઇલો અને સિસ્ટમ ડેટાનો બેકઅપ લેવા તથા જરૂર પડે ત્યારે તેને પુનઃસ્થાપિત કરવા માટે ઉપયોગ થાય છે. |
| BitLocker Drive Encryption | ડ્રાઇવમાં રહેલા ડેટાને એન્ક્રિપ્ટ કરીને અનધિકૃત વ્યક્તિથી સુરક્ષિત રાખવા માટે ઉપયોગ થાય છે. |
| Color Management | મોનિટર, પ્રિન્ટર અને અન્ય ડિવાઇસ માટે રંગોની ચોકસાઈ અને કલર પ્રોફાઇલ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Credential Manager | Windows અને વેબસાઇટ માટે સાચવેલા યુઝરનેમ, પાસવર્ડ તથા અન્ય ઓળખ સંબંધિત માહિતી મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Date & Time | કમ્પ્યુટરની તારીખ, સમય, સમય ઝોન અને ઇન્ટરનેટ આધારિત સમય સિંક્રનાઇઝેશન સેટ કરવા માટે ઉપયોગ થાય છે. |
| Default Programs | ફાઇલ અથવા લિંક ખોલવા માટે કયો પ્રોગ્રામ ડિફોલ્ટ તરીકે ઉપયોગ કરવો તે નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Device Manager | કમ્પ્યુટર સાથે જોડાયેલા હાર્ડવેર ડિવાઇસ, ડ્રાઇવર અને તેમની સ્થિતિ જોવા તથા મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Devices and Printers | કમ્પ્યુટર સાથે જોડાયેલા પ્રિન્ટર, સ્કેનર, માઉસ, કીબોર્ડ અને અન્ય ડિવાઇસ જોવા તથા મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Ease of Access Center | દિવ્યાંગ અથવા વિશેષ જરૂરિયાત ધરાવતા વપરાશકર્તાઓ માટે Windows ની Accessibility સેટિંગ્સ બદલવા માટે ઉપયોગ થાય છે. |
| File Explorer Options | File Explorer માં ફાઇલો અને ફોલ્ડર્સ કેવી રીતે દેખાય અને કાર્ય કરે તે માટેની સેટિંગ્સ બદલવા માટે ઉપયોગ થાય છે. |
| File History | વ્યક્તિગત ફાઇલોની અગાઉની નકલો આપમેળે સાચવવા અને જરૂર પડે ત્યારે જૂની ફાઇલ પુનઃપ્રાપ્ત કરવા માટે ઉપયોગ થાય છે. |
| Fonts | કમ્પ્યુટરમાં ઇન્સ્ટોલ કરેલા ફોન્ટ જોવા, ઉમેરવા અથવા દૂર કરવા માટે ઉપયોગ થાય છે. |
| Indexing Options | ફાઇલો અને ફોલ્ડર્સનું ઇન્ડેક્સિંગ મેનેજ કરવા માટે ઉપયોગ થાય છે, જેથી Windows Search ઝડપથી પરિણામ આપી શકે. |
| Internet Options | ઇન્ટરનેટ કનેક્શન, બ્રાઉઝિંગ, સુરક્ષા, પ્રાઇવસી અને હોમપેજ સંબંધિત સેટિંગ્સ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Keyboard | કીબોર્ડની ટાઇપિંગ સ્પીડ, કર્સર બ્લિંક રેટ અને અન્ય કીબોર્ડ સેટિંગ્સ બદલવા માટે ઉપયોગ થાય છે. |
| Mail | Microsoft Outlook જેવી એપ્લિકેશનમાં ઇમેઇલ પ્રોફાઇલ અને સંબંધિત સેટિંગ્સ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Mouse | માઉસના બટન, પોઇન્ટર સ્પીડ, પોઇન્ટર દેખાવ અને અન્ય માઉસ સેટિંગ્સ બદલવા માટે ઉપયોગ થાય છે. |
| Network and Sharing Center | નેટવર્ક કનેક્શન, Wi Fi, ઇન્ટરનેટ અને નેટવર્ક શેરિંગ સેટિંગ્સ જોવા તથા મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Phone and Modem | કમ્પ્યુટરમાં ફોન અથવા મોડેમની ડાયલિંગ અને સંબંધિત કનેક્શન સેટિંગ્સ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Power Options | કમ્પ્યુટર ક્યારે Sleep અથવા Hibernate થાય, પાવર પ્લાન અને ઊર્જા બચત સંબંધિત સેટિંગ્સ માટે ઉપયોગ થાય છે. |
| Programs and Features | કમ્પ્યુટરમાં ઇન્સ્ટોલ કરેલા પ્રોગ્રામ જોવા, બદલવા અથવા અનઇન્સ્ટોલ કરવા માટે ઉપયોગ થાય છે. |
| Recovery | Windows સિસ્ટમને અગાઉની સ્થિતિમાં પાછી લાવવા, Recovery Drive બનાવવા અને અન્ય Recovery વિકલ્પો માટે ઉપયોગ થાય છે. |
| Region | દેશ અથવા પ્રદેશ, ભાષા, તારીખ, સમય, નંબર અને કરન્સીનું ફોર્મેટ સેટ કરવા માટે ઉપયોગ થાય છે. |
| Remote App and Desktop Connections | રિમોટ કમ્પ્યુટર અથવા RemoteApp સાથે કનેક્ટ થવા માટે જરૂરી કનેક્શન સેટિંગ્સ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Security and Maintenance | Windows ની સુરક્ષા, સિસ્ટમ મેન્ટેનન્સ, બેકઅપ અને અન્ય મહત્વપૂર્ણ સૂચનાઓની સ્થિતિ જોવા માટે ઉપયોગ થાય છે. |
| Sound | સ્પીકર, માઇક્રોફોન, રેકોર્ડિંગ ડિવાઇસ અને Windows ના સાઉન્ડ સંબંધિત સેટિંગ્સ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Speech Recognition | અવાજ દ્વારા કમ્પ્યુટરને નિયંત્રિત કરવા અને બોલેલા શબ્દોને ટેક્સ્ટમાં રૂપાંતરિત કરવા માટે ઉપયોગ થાય છે. |
| Storage Spaces | એકથી વધુ ડ્રાઇવને એકસાથે જોડીને સ્ટોરેજ પૂલ બનાવવા અને ડેટા સુરક્ષા સાથે સ્ટોરેજ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Sync Center | કમ્પ્યુટર અને અન્ય નેટવર્ક ડિવાઇસ વચ્ચેની ફાઇલો અથવા ડેટાના સિંક્રનાઇઝેશનને મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| System | કમ્પ્યુટરની RAM, પ્રોસેસર, Windows આવૃત્તિ, કમ્પ્યુટરનું નામ અને અન્ય સિસ્ટમ માહિતી જોવા માટે ઉપયોગ થાય છે. |
| Taskbar and Navigation | Taskbar, Navigation અને Start સંબંધિત વિવિધ સેટિંગ્સને કસ્ટમાઇઝ કરવા માટે ઉપયોગ થાય છે. |
| Troubleshooting | હાર્ડવેર, નેટવર્ક, સાઉન્ડ, પ્રિન્ટર અને અન્ય Windows સમસ્યાઓ શોધવા તથા ઉકેલવા માટે ઉપયોગ થાય છે. |
| User Accounts | Windows માં યુઝર એકાઉન્ટ, પાસવર્ડ, એકાઉન્ટ પ્રકાર અને અન્ય યુઝર સંબંધિત સેટિંગ્સ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Windows Defender Firewall | કમ્પ્યુટરને અનધિકૃત નેટવર્ક કનેક્શન અને કેટલીક સુરક્ષા સમસ્યાઓથી બચાવવા માટે Firewall સેટિંગ્સ મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Windows Tools | Windows માં ઉપલબ્ધ વિવિધ સિસ્ટમ ટૂલ્સ અને એડમિનિસ્ટ્રેટિવ ટૂલ્સને ઍક્સેસ કરવા માટે ઉપયોગ થાય છે. |
| Work Folders | સંસ્થા અથવા કાર્યસ્થળના સર્વર સાથે ફાઇલોને સિંક્રનાઇઝ કરીને અલગ અલગ ડિવાઇસ પરથી કામની ફાઇલો ઍક્સેસ કરવા માટે ઉપયોગ થાય છે. |
