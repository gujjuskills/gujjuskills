# લેશન - ૨૦ :  PowerShell Cmdlet શીખો

## PowerShell અને Cmdlet શું છે?

| વિષય | માહિતી |
|---|---|
| **PowerShell** | PowerShell એ Windows તથા અન્ય સિસ્ટમમાં કાર્ય કરવા માટેનું શક્તિશાળી Command-Line Shell અને Scripting Environment છે. તેનો ઉપયોગ કમ્પ્યુટરનું સંચાલન, ફાઇલ મેનેજમેન્ટ, સિસ્ટમ એડમિનિસ્ટ્રેશન અને Automation માટે થાય છે. |
| **Cmdlet** | Cmdlet એ PowerShell માં ચોક્કસ કાર્ય કરવા માટેનો નાનો અને વિશિષ્ટ Command છે. Cmdlet સામાન્ય રીતે **Verb-Noun** સ્વરૂપમાં હોય છે, જેમ કે `Get-Process`. |
 
## PowerShell Cmdlet

| Cmdlet | ઉપયોગ |
|---|---|
| **Get-Command** | ઉપલબ્ધ PowerShell Commands અને Cmdlets ની યાદી તથા તેમની માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| **Get-Help** | કોઈ Cmdlet અથવા Command વિશે મદદ અને વિગતવાર માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| **Get-Location** | હાલમાં PowerShell માં કઈ Directory અથવા Location પર કામ થઈ રહ્યું છે તે જાણવા માટે ઉપયોગ થાય છે. |
| **Set-Location** | PowerShell માં વર્તમાન Directory અથવા Location બદલવા માટે ઉપયોગ થાય છે. |
| **Get-ChildItem** | વર્તમાન Location માં રહેલી Files અને Folders ની યાદી જોવા માટે ઉપયોગ થાય છે. |
| **New-Item** | નવી File, Folder અથવા અન્ય Item બનાવવા માટે ઉપયોગ થાય છે. |
| **Copy-Item** | File અથવા Folder ની Copy બનાવવા માટે ઉપયોગ થાય છે. |
| **Move-Item** | File અથવા Folder ને એક Location માંથી બીજી Location પર ખસેડવા માટે ઉપયોગ થાય છે. |
| **Rename-Item** | File અથવા Folder નું નામ બદલવા માટે ઉપયોગ થાય છે. |
| **Remove-Item** | File અથવા Folder ને દૂર અથવા Delete કરવા માટે ઉપયોગ થાય છે. |
| **Get-Content** | File ની અંદર રહેલો Text અથવા Data વાંચવા માટે ઉપયોગ થાય છે. |
| **Set-Content** | File માં નવી માહિતી લખવા અથવા અગાઉની માહિતી બદલવા માટે ઉપયોગ થાય છે. |
| **Clear-Host** | PowerShell Console માં દેખાતી અગાઉની માહિતી સાફ કરવા માટે ઉપયોગ થાય છે. |
| **Get-Process** | કમ્પ્યુટરમાં હાલમાં ચાલી રહેલી Processes ની માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| **Stop-Process** | ચાલી રહેલી Process ને બંધ કરવા માટે ઉપયોગ થાય છે. |
| **Get-Service** | કમ્પ્યુટરમાં ઉપલબ્ધ Windows Services અને તેમની સ્થિતિ જાણવા માટે ઉપયોગ થાય છે. |
| **Start-Service** | બંધ થયેલી Windows Service શરૂ કરવા માટે ઉપયોગ થાય છે. |
| **Stop-Service** | ચાલી રહેલી Windows Service બંધ કરવા માટે ઉપયોગ થાય છે. |
| **Get-History** | વર્તમાન PowerShell Session માં અગાઉ ચલાવવામાં આવેલા Commands ની યાદી જોવા માટે ઉપયોગ થાય છે. |
| **Restart-Computer** | કમ્પ્યુટરને Restart કરવા માટે ઉપયોગ થાય છે. |
