# પ્રેકટિકલ-૧૨૭ : ઈન્ટરનેટ એક્સેસ અમે કોમ્યુનિકેશન સેટ કરો

![image](/images/practical-127.webp)

| Topic | Answer |
|---|---|
| **Wired Connections** | Cable: કેબલ મોડેમ દ્વારા ઈન્ટરનેટ મેળવી શકાય છે.  |
| |DSL: ટેલિફોન લાઇન દ્વારા DSL મોડેમનો ઉપયોગ કરીને ઈન્ટરનેટ મેળવી શકાય છે.  |
| |Fiber: ફાઈબર ઓપ્ટિક કેબલ દ્વારા ઝડપી ઈન્ટરનેટ મેળવી શકાય છે. |
| **Wireless Connections** | Wi-Fi: વાયરલેસ રાઉટર અથવા હોટસ્પોટ દ્વારા ઈન્ટરનેટ મેળવી શકાય છે. |
| | Satellite: સેટેલાઇટ ડિશ દ્વારા ઈન્ટરનેટ કનેક્શન મેળવી શકાય છે. |
| **Mobile & USB Connections** | Mobile Data: મોબાઇલ નેટવર્ક 3G, 4G અથવા 5G દ્વારા ઈન્ટરનેટ મેળવી શકાય છે.  |
| | USB Dongle: USB ડોંગલમાં SIM કાર્ડ લગાવીને કમ્પ્યુટરમાં ઈન્ટરનેટ મેળવી શકાય છે.|
| |  Mobile Hotspot: મોબાઇલ હોટસ્પોટ દ્વારા અન્ય ઉપકરણોને ઈન્ટરનેટ સાથે જોડી શકાય છે.|
| **Other Methods** | Broadband: બ્રોડબેન્ડ કનેક્શન દ્વારા ઈન્ટરનેટ મેળવી શકાય છે.  |
| | Public Wi-Fi: જાહેર Wi-Fi નેટવર્ક દ્વારા ઈન્ટરનેટનો ઉપયોગ કરી શકાય છે.|
