# Create a GitHub Repository

GitHub Repository કેવી રીતે બનાવી શકાય?

GitHub Repository એ તમારા project ના files, source code અને અન્ય જરૂરી documents ને online store અને manage કરવા માટેની જગ્યા છે. Repository નો ઉપયોગ project ને backup રાખવા, version control કરવા અને અન્ય લોકો સાથે share કરવા માટે કરી શકાય છે.

## GitHub Repository બનાવવાના Steps

### Step 1: GitHub Website Open કરો

સૌપ્રથમ browser માં [GitHub](https://github.com/) ની website open કરો.

તમારા GitHub account માં **Sign In** કરો.

### Step 2: New Repository પસંદ કરો

GitHub માં login કર્યા પછી ઉપરની બાજુમાં આવેલ **+** icon પર click કરો.

ત્યારબાદ **New repository** option પસંદ કરો.

### Step 3: Repository Name દાખલ કરો

**Repository name** field માં તમારા project માટે યોગ્ય નામ લખો.

ઉદાહરણ:

```text
my-first-project
