## લેશન - ૨૩.૨ : પેજ લેઆઉટ ટેબ : MS Word

| Page layout tab | ઉપયોગ |
|:---:|---|
| Themes | દસ્તાવેજ માટે તૈયાર ડિઝાઇન, રંગ અને ફોન્ટની થીમ પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Colors | થીમના રંગો બદલવા માટે ઉપયોગ થાય છે. |
| Fonts | દસ્તાવેજની થીમના ફોન્ટ બદલવા માટે ઉપયોગ થાય છે. |
| Effects | દસ્તાવેજમાં ઉપયોગમાં લેવાતા આકારો અને અન્ય ઑબ્જેક્ટની અસર બદલવા માટે ઉપયોગ થાય છે. |
| Margins | પેજની ચારેય બાજુના ખાલી વિસ્તારનું માપ નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Orientation | પેજને Portrait અથવા Landscape દિશામાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| Size | પેજનું કદ, જેમ કે A4, Letter વગેરે પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Columns | દસ્તાવેજના લખાણને બે અથવા વધુ કૉલમમાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| Breaks | પેજ અથવા વિભાગમાં Page Break અને Section Break ઉમેરવા માટે ઉપયોગ થાય છે. |
| Line Numbers | દસ્તાવેજની દરેક લાઇનને નંબર આપવા માટે ઉપયોગ થાય છે. |
| Hyphenation | લાંબા શબ્દોને લાઇનના અંતે હાઇફન વડે વિભાજિત કરવા માટે ઉપયોગ થાય છે. |
| Watermark | પેજના પાછળના ભાગમાં હળવું લખાણ અથવા ચિત્ર મૂકવા માટે ઉપયોગ થાય છે. |
| Page Color | પેજના બેકગ્રાઉન્ડનો રંગ બદલવા માટે ઉપયોગ થાય છે. |
| Page Borders | પેજની આસપાસ બોર્ડર લગાવવા માટે ઉપયોગ થાય છે. |
| Indent | પેરાગ્રાફને ડાબી અથવા જમણી બાજુથી અંદર ખસેડવા માટે ઉપયોગ થાય છે. |
| Spacing | પેરાગ્રાફ પહેલાં અને પછીનું અંતર નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Position | પેજ પર ઑબ્જેક્ટની સ્થિતિ નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Wrap Text | ટેક્સ્ટની આસપાસ ચિત્ર અથવા ઑબ્જેક્ટ કેવી રીતે ગોઠવાશે તે નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Bring Forward | પસંદ કરેલા ઑબ્જેક્ટને બીજા ઑબ્જેક્ટની આગળ લાવવા માટે ઉપયોગ થાય છે. |
| Send Backward | પસંદ કરેલા ઑબ્જેક્ટને બીજા ઑબ્જેક્ટની પાછળ મોકલવા માટે ઉપયોગ થાય છે. |
| Selection Pane | દસ્તાવેજમાં રહેલા ઑબ્જેક્ટની યાદી જોવા અને પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Align | એકથી વધુ ઑબ્જેક્ટને સરખી લાઇનમાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| Group | બે અથવા વધુ ઑબ્જેક્ટને એક જ ગ્રુપ તરીકે જોડવા માટે ઉપયોગ થાય છે. |
| Rotate | ઑબ્જેક્ટને ફેરવવા અથવા તેની દિશા બદલવા માટે ઉપયોગ થાય છે. |
