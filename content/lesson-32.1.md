# લેશન - ૩૨.૧ : સ્પ્રેડશીટનો પરિચય અને તેની વિશેષતાઓ
 #### સ્પ્રેડશીટ શું છે? 
 સ્પ્રેડશીટ એ પંક્તિઓ અને કૉલમથી બનેલું ઇલેક્ટ્રોનિક કાર્યપત્રક છે, જેમાં માહિતી દાખલ કરી શકાય છે, ગણતરી કરી શકાય છે, માહિતીનું વિશ્લેષણ કરી શકાય છે અને ચાર્ટ બનાવી શકાય છે. 
| વિશેષતા | વર્ણન |
|---|---|
| ગણતરી | ફોર્મ્યુલા અને ફંક્શન દ્વારા સરળતાથી ગણતરી કરી શકાય છે. |
| ડેટા ગોઠવણી | માહિતીનું Sort અને Filter કરી શકાય છે. |
| ડેટા ફોર્મેટિંગ | અક્ષર, રંગ, બોર્ડર અને સંખ્યાનું ફોર્મેટ બદલી શકાય છે. |

|---|---|
