# પ્રેકટિકલ-૬૬ : ચિત્રો અને ટેક્સ્ટ બોક્સ દાખલ કરો

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| Insert Shapes | **Shapes** વિકલ્પનો ઉપયોગ કરીને દસ્તાવેજમાં વિવિધ આકારો જેમ કે Rectangle, Circle, Arrow, Line વગેરે દાખલ કરી શકાય છે. આકારમાં રંગ, બોર્ડર અને ટેક્સ્ટ પણ ઉમેરી શકાય છે. |
| Insert Pictures | **Pictures** વિકલ્પ દ્વારા કમ્પ્યુટર અથવા અન્ય સ્થાનેથી ચિત્રને દસ્તાવેજમાં દાખલ કરી શકાય છે. ચિત્રનું કદ, સ્થાન, બોર્ડર અને અન્ય ફોર્મેટિંગ બદલી શકાય છે. |
| Insert SmartArt Graphics | **SmartArt Graphics** નો ઉપયોગ માહિતી, પ્રક્રિયા, ક્રમ, સંબંધ અથવા હાયરાર્કીને આકર્ષક ગ્રાફિક સ્વરૂપે દર્શાવવા માટે થાય છે. |
| Insert Screenshots and Screen Clippings | **Screenshots and Screen Clippings** વિકલ્પનો ઉપયોગ કમ્પ્યુટર સ્ક્રીનનો સ્ક્રીનશોટ અથવા સ્ક્રીનના પસંદ કરેલા ભાગને દસ્તાવેજમાં દાખલ કરવા માટે થાય છે. |
