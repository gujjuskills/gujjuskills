## પ્રેકટિકલ ૧૩.૨ : કીબોર્ડ શોર્ટકટ આદેશો

| શોર્ટકટ કી | ઉપયોગ / વિશેષતા |
|---|---|
| Windows Key + A | ઝડપી સેટિંગ્સ (Quick Settings) ખોલે છે. |
| Windows Key + C | Copilot ખોલે છે. |
| Windows Key + I | Windows Settings ખોલે છે. |
| Windows Key + S | Windows Search ખોલે છે. |
| Windows Key + Tab | Task View ખોલે છે અને ખુલ્લી વિન્ડોઝ દર્શાવે છે. |
| Windows Key + Print Screen | સ્ક્રીનશોટ લઈને તેને આપમેળે સાચવે છે. |
| Alt + D | File Explorer અથવા વેબ બ્રાઉઝરમાં Address Bar પસંદ કરે છે. |
| Windows Key + Ctrl + D | નવું Virtual Desktop બનાવે છે. |
| Windows Key + Ctrl + Left/Right Arrow | Virtual Desktop વચ્ચે આગળ અથવા પાછળ જાય છે. |
| Windows Key + Ctrl + F4 | હાલનું Virtual Desktop બંધ કરે છે. |
| Windows Key + T | Taskbar પરના એપ્સ વચ્ચે પસંદગી કરે છે. |
| Windows Key + Alt + [Number] | Taskbar પર નંબર મુજબની એપની Jump List ખોલે છે. |
| Windows Key + . (Period) | Emoji અને અન્ય symbols પેનલ ખોલે છે. |
| Windows Key + , (Comma) | Desktop નું તાત્કાલિક Preview દર્શાવે છે. |
| Ctrl + Shift + T | બંધ થયેલ Browser Tab ફરીથી ખોલે છે. |
| Alt + Left Arrow | અગાઉના પેજ અથવા સ્થાન પર પાછા જાય છે. |
| Alt + Right Arrow | આગળના પેજ અથવા સ્થાન પર જાય છે. |
