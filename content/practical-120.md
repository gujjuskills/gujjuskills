# પ્રેકટિકલ-૧૨૦ : હબ અને સ્વિચ ગોઠવો

![image](/images/practical-120.webp)

| ક્રમ | વિગત | માહિતી |
|---|---|---|
| 1 | જરૂરી સાધનો | સ્વિચ, કમ્પ્યુટર, UTP/LAN કેબલ અને પાવર એડેપ્ટર |
| 2 | પ્રક્રિયા | સૌપ્રથમ સ્વિચને પાવર સપ્લાય સાથે જોડો. ત્યારબાદ LAN કેબલની મદદથી બધા કમ્પ્યુટરને સ્વિચના અલગ અલગ પોર્ટ સાથે જોડો. |
| 3 | IP સરનામું | બધા કમ્પ્યુટરને એક જ નેટવર્ક રેન્જના IP Address આપો. ઉદાહરણ: 192.168.1.10, 192.168.1.11, 192.168.1.12 |
| 4 | ચકાસણી | Command Prompt માં `ping` કમાન્ડનો ઉપયોગ કરીને એક કમ્પ્યુટરથી બીજા કમ્પ્યુટર સાથે કનેક્ટિવિટી તપાસો. |
| 5 | પરિણામ | સ્વિચની મદદથી બધા કમ્પ્યુટરને જોડીને સફળતાપૂર્વક વાયર્ડ LAN નેટવર્ક તૈયાર કરવામાં આવ્યું. |
