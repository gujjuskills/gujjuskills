# પ્રેકટિકલ-૬૯ : ઓડિયો તત્વો ઉમેરો
# Add Audio Elements

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| **Import audio files in presentations** | પ્રેઝન્ટેશનમાં Audio File ઉમેરવા માટે સૌપ્રથમ PowerPoint Presentation ખોલો. ત્યારબાદ **Insert → Audio → Audio on My PC** વિકલ્પ પસંદ કરો. કમ્પ્યુટરમાં રહેલી MP3, WAV જેવી Audio File પસંદ કરીને **Insert** પર ક્લિક કરો. Audio File Slide પર ઉમેરાઈ જશે. |
| **Configure audio playback options** | ઉમેરેલી Audio File કેવી રીતે અને ક્યારે વગાડવી તે માટે Playback Options સેટ કરી શકાય છે. Audio File પસંદ કરીને **Playback** ટેબમાં જઈને Start, Volume, Trim Audio, Fade In, Fade Out અને Loop until stopped જેવા વિકલ્પો સેટ કરી શકાય છે. **Start Automatically** પસંદ કરવાથી Slide શરૂ થતાં Audio આપમેળે વાગે છે. **On Click** પસંદ કરવાથી Audio પર ક્લિક કર્યા પછી વાગે છે. |
