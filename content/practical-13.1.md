# પ્રેક્ટિકલ - ૧૩.૧ : કીબોર્ડ શોર્ટકટ આદેશ સાથે કાર્ય 

| શોર્ટકટ કી | ઉપયોગ / વિશેષતા |
|:---:|:---|
| Ctrl + C | પસંદ કરેલ લખાણ અથવા ફાઇલની નકલ કરવા માટે |
| Ctrl + X | પસંદ કરેલ લખાણ અથવા ફાઇલ કાપવા માટે |
| Ctrl + V | નકલ કરેલ અથવા કાપેલ લખાણ અથવા ફાઇલ પેસ્ટ કરવા માટે |
| Ctrl + Z | કરેલું છેલ્લું કાર્ય પાછું રદ કરવા માટે |
| Ctrl + Y | રદ કરેલું કાર્ય ફરીથી કરવા માટે |
| Ctrl + A | પેજ અથવા દસ્તાવેજની બધી વસ્તુઓ પસંદ કરવા માટે |
| Ctrl + S | દસ્તાવેજ અથવા ફાઇલ સેવ કરવા માટે |
| Ctrl + P | દસ્તાવેજ પ્રિન્ટ કરવા માટે |
| Ctrl + F | લખાણ અથવા શબ્દ શોધવા માટે |
| Ctrl + N | નવી ફાઇલ અથવા નવું દસ્તાવેજ બનાવવા માટે |
| Ctrl + O | પહેલેથી સેવ કરેલી ફાઇલ ખોલવા માટે |
| Ctrl + B | પસંદ કરેલા લખાણને બોલ્ડ કરવા માટે |
