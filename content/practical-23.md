# પ્રેકટિકલ-૨૩ : ISO ઇમેજ બનાવવી - ફ્લેશ ડ્રાઈવ
![image](/gujjuskills/images/practical-23.png)
## OS ઇન્સ્ટોલ કરવા બુટેબલ પેનડ્રાઇવ બનાવવાની રીત જણાવો. 
| સ્ટેપ | કાર્ય / સમજુતી |
|---|---|
| 1 | સૌપ્રથમ જરૂરી ISO ફાઇલ કમ્પ્યુટરમાં ડાઉનલોડ કરો અને USB પેન ડ્રાઇવ જોડો. |
| 2 | **Rufus** સોફ્ટવેર ખોલો અને USB પેન ડ્રાઇવને પસંદ કરો. |
| 3 | **Boot Selection** માં `Disk or ISO image` પસંદ કરો. |
| 4 | **SELECT** બટન પર ક્લિક કરીને જરૂરી ISO ફાઇલ પસંદ કરો. |
| 5 | **Partition Scheme** માં કમ્પ્યુટર મુજબ `MBR` અથવા `GPT` પસંદ કરો. |
| 6 | **File System** તરીકે સામાન્ય રીતે `NTFS` અથવા `FAT32` પસંદ કરો. |
| 7 | બધી સેટિંગ ચકાસીને **START** બટન પર ક્લિક કરો. |
| 8 | USB પેન ડ્રાઇવનો ડેટા ડિલીટ થવાની ચેતવણી આવે ત્યારે **OK** પર ક્લિક કરો. |
| 9 | ISO ફાઇલ પેન ડ્રાઇવમાં લખાય ત્યાં સુધી રાહ જુઓ અને પ્રક્રિયા પૂર્ણ થવા દો. |
| 10 | પ્રક્રિયા પૂર્ણ થયા પછી **READY** દેખાશે. હવે બુટેબલ પેન ડ્રાઇવ તૈયાર છે. |
| 11 | પેન ડ્રાઇવને સુરક્ષિત રીતે Eject કરો અને OS ઇન્સ્ટોલ કરવા તેનો ઉપયોગ કરો. |
