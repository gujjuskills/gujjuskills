# પ્રેકટિકલ-૬૧ : ટેક્સ્ટ અને ફકરાઓને ફોરમેટ કરો
| વિષય | સામાન્ય સમજ / કાર્ય |
|---|---|
| **ટેક્સ્ટ ઇફેક્ટ લાગુ કરવું** | ટેક્સ્ટને આકર્ષક બનાવવા માટે **Shadow, Reflection, Glow, Outline** જેવા ટેક્સ્ટ ઇફેક્ટ લાગુ કરવા. |
| **Format Painter નો ઉપયોગ કરીને ફોર્મેટિંગ લાગુ કરવું** | એક ટેક્સ્ટનું ફોર્મેટિંગ જેમ કે **Font, Size, Color, Bold, Italic** વગેરે બીજા ટેક્સ્ટ પર લાગુ કરવા માટે **Format Painter** નો ઉપયોગ કરવો. |
| **લાઇન અને પેરાગ્રાફ સ્પેસિંગ તથા ઇન્ડેન્ટેશન સેટ કરવું** | પેરાગ્રાફમાં **Line Spacing, Paragraph Spacing, Left/Right Indent, First Line Indent** વગેરે સેટ કરવા. |
| **ટેક્સ્ટ પર બિલ્ટ-ઇન સ્ટાઇલ લાગુ કરવી** | ટેક્સ્ટને યોગ્ય દેખાવ આપવા માટે **Title, Heading 1, Heading 2, Subtitle** જેવી બિલ્ટ-ઇન સ્ટાઇલ લાગુ કરવી. |
