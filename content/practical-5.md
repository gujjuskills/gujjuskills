# પ્રેકટિકલ-૫ : CPUના ભાગો અને તેનો ઉપયોગ 
![image](/gujjuskills/images/computer-parts-with-motherboard.webp)
| CPUનો પોર્ટ | ઉપયોગ |
|:---:|---|
| પાવર કનેક્ટર | વીજ પુરવઠો જોડવા માટે |
| થમ્બ સ્ક્રૂ | કેબિનેટનું કવર ખોલવા/બંધ કરવા માટે |
| SMPS | કમ્પ્યુટરના ભાગોને વીજ પુરવઠો આપવા માટે |
| સિક્યુરિટી લોક પોર્ટ | કમ્પ્યુટરની સુરક્ષા માટે |
| PS/2 પોર્ટ | કીબોર્ડ અને માઉસ જોડવા માટે |
| VGA પોર્ટ | મોનિટર જોડવા માટે |
| USB પોર્ટ | USB ઉપકરણો જોડવા માટે |
| ઑડિયો IN / OUT / માઇક્રોફોન જેક | સ્પીકર, હેડફોન અને માઇક્રોફોન માટે |
| CPU કૂલિંગ ફેન | CPUને ઠંડુ રાખવા માટે |
| ઈથરનેટ LAN પોર્ટ | નેટવર્ક / ઈન્ટરનેટ માટે |
| પેરલલ પોર્ટ | જૂના પ્રકારના પ્રિન્ટર માટે |
| સિરિયલ પોર્ટ | સિરિયલ ઉપકરણો જોડવા માટે |
| એક્સ્પાન્શન સ્લોટ્સ | વધારાના કાર્ડ લગાવવા માટે |
| CD / DVD રાઇટર | CD/DVD વાંચવા અને લખવા માટે |
| પાવર ON | કમ્પ્યુટર ચાલુ કરવા માટે |
