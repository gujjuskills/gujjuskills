# પ્રેકટિકલ-૧૪૮ : ક્લાઉડ સેવાઓનો ઉપયોગ કરીને IaaS સાથે પ્રેકટિસ કરો

![image](/images/practical-148.webp)

## IaaS શું છે?

**IaaS એટલે Infrastructure as a Service.** તેમાં Internet દ્વારા Computer Infrastructure ઉપલબ્ધ કરાવવામાં આવે છે.

IaaS દ્વારા આપણે નીચેની સુવિધાઓ મેળવી શકીએ છીએ:

1. Virtual Machine
2. CPU અને RAM
3. Storage
4. Networking
5. Operating System
6. Security અને Access Control

ભૌતિક Server ખરીદવાની જરૂર પડતી નથી. Cloud Provider પાસેથી જરૂરિયાત મુજબ Infrastructure મેળવી શકાય છે.

## IaaS ના ઉદાહરણો

| Cloud Service | IaaS Service |
|---|---|
| Amazon Web Services (AWS) | Amazon EC2 |
| Microsoft Azure | Azure Virtual Machine |
| Google Cloud | Compute Engine |

## Amazon AWS પર IaaS નો પ્રયોગ

### પગલાં

1. **AWS Management Console** ખોલો.
2. AWS Account માં Sign in કરો.
3. **EC2** Service પસંદ કરો.
4. **Launch Instance** પર Click કરો.
5. Virtual Machine માટે નામ આપો.
6. Operating System પસંદ કરો, જેમ કે **Ubuntu Linux** અથવા **Windows Server**.
7. ઉપલબ્ધ Free Tier અથવા Free Offer માટે યોગ્ય Instance પસંદ કરો.
8. Login માટે **Key Pair** બનાવો અથવા પસંદ કરો.
9. Network અને Security Settings configure કરો.
10. Storage પસંદ કરો.
11. **Launch Instance** પર Click કરો.
12. Virtual Machine શરૂ થાય ત્યાં સુધી રાહ જુઓ.
13. Linux માટે **SSH** અથવા Windows માટે **Remote Desktop** દ્વારા Virtual Machine સાથે Connect કરો.
14. Virtual Machine પર જરૂરી Basic Operations કરો.

## IaaS ના ફાયદા

* Physical Server ખરીદવાની જરૂર નથી.
* જરૂરિયાત પ્રમાણે Resources વધારી અથવા ઘટાડી શકાય છે.
* ઝડપથી Virtual Machine બનાવી શકાય છે.
* Internet દ્વારા ગમે ત્યાંથી Access કરી શકાય છે.
* Testing અને Development માટે ઉપયોગી છે.
* પોતાની જરૂરિયાત મુજબ Operating System અને Software પસંદ કરી શકાય છે.
* Storage અને Computing Resources સરળતાથી ઉપલબ્ધ થાય છે.
