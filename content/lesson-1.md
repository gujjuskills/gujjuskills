# લેશન - ૧ : સલામત કામ કરવાની પધ્ધતિ 

## સુરક્ષાનો પ્રકાર 
### ૧) ઇલેક્ટ્રિકલ સેફટી :
#### શું કરવું : 
- પ્લગ અને વાયર તપાસીને ઉપયોગ કરવો
 
- ભીના હાથથી ઇલેક્ટ્રિકલ ઉપકરણ ન ચલાવવું

- કામ પૂરું થયા પછી ઉપકરણ બંધ કરવું
  
- ખરાબ વાયર હોય તો શિક્ષક અથવા જવાબદાર વ્યક્તિને જણાવવું

#### શું ના કરવું :   

- ખુલ્લા અથવા કપાયેલા વાયરને હાથ ન લગાવવો

- એક સોકેટમાં વધારે પ્લગ ન લગાવવા

- પાણીની નજીક ઇલેક્ટ્રિકલ ઉપકરણ ન વાપરવું

- જાતે ઇલેક્ટ્રિકલ રિપેર કરવાનો પ્રયાસ ન કરવો

### ૨) બેસવાની સાચી પધ્ધતિ :

#### શું કરવું : 

• ખુરશી પર સીધા બેસવું

• મોનિટરને આંખની યોગ્ય ઊંચાઈએ રાખવો

• પીઠને યોગ્ય ટેકો આપવો  

• લાંબા સમય સુધી કામ વચ્ચે થોડો આરામ લેવો

#### શું ના કરવું :   

• વાંકું વળીને બેસવું નહ
ીં
• સ્ક્રીનની ખૂબ નજીક બેસવું નહીં

• સતત ઘણા કલાકો સુધી બ્રેક વગર કામ ન કરવું

• ખોટી સ્થિતિમાં હાથ અને પગ રાખવા નહીં

### ૩) લેબની વ્યવસ્થા 
#### શું કરવું : 

• કાર્યસ્થળ સ્વચ્છ રાખવું

• વાયર અને કેબલ યોગ્ય રીતે ગોઠવવા

• સાધનો ઉપયોગ પછી યોગ્ય જગ્યાએ મૂકવા

• કચરો ડસ્ટબિનમાં નાખવો

#### શું ના કરવું :   

• કાર્યસ્થળ પર કચરો ફેલાવવો નહીં

• રસ્તામાં વાયર અથવા વસ્તુઓ રાખવી નહીં

• કાર્યસ્થળ પર ખાવાનું અથવા પીણું ઢોળવું નહીં  

• સાધનોને ગમે ત્યાં ન મૂકવા

### ૪) ડિજિટલ સુરક્ષા 
#### શું કરવું : 

• મજબૂત પાસવર્ડનો ઉપયોગ કરવો

• પાસવર્ડ કોઈને ન જણાવવો 

• એન્ટીવાયરસ સોફ્ટવેરનો ઉપયોગ કરવો  

• અજાણી ફાઇલ અથવા લિંક ખોલતા પહેલાં તપાસ કરવી  

• મહત્વપૂર્ણ ડેટાનો બેકઅપ રાખવો

#### શું ના કરવું :   

• પાસવર્ડ અન્ય વ્યક્તિ સાથે શેર ન કરવો 

• અજાણી લિંક પર ક્લિક ન કરવું 

• અજાણ્યા વ્યક્તિને વ્યક્તિગત માહિતી ન આપવી

• અજાણી વેબસાઇટ પરથી ફાઇલ ડાઉનલોડ ન કરવી 

• કમ્પ્યુટર પર અનધિકૃત સોફ્ટવેર ઇન્સ્ટોલ ન કરવું
 
### ૫) કટોકટીના ઉપાયો  
#### શું કરવું : 

• શાંતિથી અને સમજદારીપૂર્વક વર્તવું  

• તાત્કાલિક શિક્ષક અથવા જવાબદાર વ્યક્તિને જાણ કરવી

• ઇમરજન્સી બહાર નીકળવાના માર્ગનો ઉપયોગ કરવો

• આગ અથવા અકસ્માત સમયે સલામત સ્થળે જવું

• જરૂર પડે તો પ્રાથમિક સારવાર મેળવવી

#### શું ના કરવું : 

• કટોકટી સમયે ગભરાટ ન કરવો

• આગ અથવા જોખમી સ્થળની નજીક ન જવું
 
• લિફ્ટનો ઉપયોગ ન કરવો

• અન્ય લોકોને ધક્કામુક્કી ન કરવી  

• જવાબદાર વ્યક્તિની સૂચનાઓની અવગણના ન કરવી
