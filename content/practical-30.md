# પ્રેક્ટિકલ - ૩૦ : Linux GUI માં ફાઇલ / ફોલ્ડરનું સંચાલન

| પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|---|---|
| Desktop | કમ્પ્યુટર શરૂ થયા પછી દેખાતી મુખ્ય સ્ક્રીનને ડેસ્કટોપ કહે છે. અહીં ફાઇલ, ફોલ્ડર અને એપ્લિકેશનના આઇકન જોવા મળે છે. |
| Icon | ફાઇલ, ફોલ્ડર અથવા એપ્લિકેશનને દર્શાવતું નાનું ચિત્ર અથવા નિશાની આઇકન કહેવાય છે. |
| Launcher / Dash | એપ્લિકેશનને ઝડપથી ખોલવા અને ચલાવવા માટે ઉપયોગમાં લેવાતું સ્થાન Launcher / Dash કહેવાય છે. |
| Show Apps | કમ્પ્યુટરમાં ઇન્સ્ટોલ કરેલી તમામ એપ્લિકેશન જોવા અને ખોલવા માટે Show Apps નો ઉપયોગ થાય છે. |
| Top Panel | સ્ક્રીનની ઉપરની બાજુએ આવેલ પેનલને Top Panel કહે છે. તેમાં સમય, નેટવર્ક, અવાજ, બેટરી વગેરેની માહિતી જોવા મળે છે. |
| Files | ફાઇલ અને ફોલ્ડરને જોવા, ખોલવા, બનાવવા, કોપી કરવા, ખસેડવા અને મેનેજ કરવા માટે Files એપ્લિકેશનનો ઉપયોગ થાય છે. |
| Search Everywhere | સમગ્ર કમ્પ્યુટરમાં ફાઇલ, ફોલ્ડર, એપ્લિકેશન અથવા અન્ય માહિતી શોધવા માટે Search Everywhere નો ઉપયોગ થાય છે. |
| Main Menu | વિવિધ એપ્લિકેશન, સેટિંગ્સ અને સિસ્ટમ વિકલ્પો મેળવવા માટે Main Menu નો ઉપયોગ થાય છે. |
| Back / Forward | અગાઉ ખોલેલા ફોલ્ડર પર પાછા જવા માટે Back અને આગળના ફોલ્ડર પર જવા માટે Forward નો ઉપયોગ થાય છે. |
| Address Bar | હાલમાં ખુલેલા ફોલ્ડરનું સ્થાન અથવા પાથ દર્શાવતી જગ્યાને Address Bar કહે છે. |
| Search Current Folder | હાલમાં ખુલેલા ફોલ્ડરની અંદર જરૂરી ફાઇલ અથવા ફોલ્ડર શોધવા માટે તેનો ઉપયોગ થાય છે. |
| View | ફાઇલ અને ફોલ્ડરને Icon View, List View વગેરે અલગ અલગ રીતે જોવા માટે View વિકલ્પનો ઉપયોગ થાય છે. |
| Sort | ફાઇલ અને ફોલ્ડરને નામ, કદ, પ્રકાર અથવા તારીખ પ્રમાણે ગોઠવવા માટે Sort નો ઉપયોગ થાય છે. |
| Open with | કોઈ ફાઇલને ચોક્કસ એપ્લિકેશન દ્વારા ખોલવા માટે Open with વિકલ્પનો ઉપયોગ થાય છે. |
| Cut – Paste | ફાઇલ અથવા ફોલ્ડરને એક સ્થાનેથી કાપીને બીજા સ્થાન પર મૂકવા માટે Cut – Paste નો ઉપયોગ થાય છે. |
| Move To | ફાઇલ અથવા ફોલ્ડરને એક સ્થાનેથી બીજા સ્થાન પર ખસેડવા માટે Move To નો ઉપયોગ થાય છે. |
| Copy To | ફાઇલ અથવા ફોલ્ડરની નકલ બનાવીને બીજા સ્થાન પર મૂકવા માટે Copy To નો ઉપયોગ થાય છે. |
| Compress | એક અથવા વધુ ફાઇલ / ફોલ્ડરને ZIP જેવા સંકુચિત ફાઇલ ફોર્મેટમાં ફેરવવા માટે Compress નો ઉપયોગ થાય છે. |
| Rename | ફાઇલ અથવા ફોલ્ડરનું નામ બદલવા માટે Rename વિકલ્પનો ઉપયોગ થાય છે. |
| Set as Background | પસંદ કરેલી તસવીરને ડેસ્કટોપના Background તરીકે સેટ કરવા માટે Set as Background નો ઉપયોગ થાય છે. |
| Change Background | ડેસ્કટોપનું Background ચિત્ર બદલવા માટે Change Background વિકલ્પનો ઉપયોગ થાય છે. |
| Move to Trash | ફાઇલ અથવા ફોલ્ડરને Trash માં મોકલવા માટે Move to Trash નો ઉપયોગ થાય છે. |
| Restore from Trash | Trash માંથી ફાઇલ અથવા ફોલ્ડરને તેના અગાઉના સ્થાન પર પાછું લાવવા માટે Restore from Trash નો ઉપયોગ થાય છે. |
| Delete from Trash | Trash માં રહેલી ફાઇલ અથવા ફોલ્ડરને કાયમી રીતે કાઢી નાખવા માટે Delete from Trash નો ઉપયોગ થાય છે. |
| Properties | ફાઇલ અથવા ફોલ્ડરનું નામ, કદ, પ્રકાર, સ્થાન, પરવાનગી વગેરે માહિતી જોવા માટે Properties નો ઉપયોગ થાય છે. |
