# પ્રેક્ટિકલ – ૮ : પેનડ્રાઇવ અને ફાઇલ તથા ફોલ્ડર સંચાલનની પ્રેક્ટિસ
![image](/gujjuskills/images/pendrive-navigation.webp)
| પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|---|---|
| Insert pendrive | પેનડ્રાઇવને કમ્પ્યુટરના USB પોર્ટમાં જોડો. ત્યારબાદ **This PC** ખોલીને પેનડ્રાઇવની ડ્રાઇવ તપાસો. |
| Rename pendrive | **This PC** માં પેનડ્રાઇવ પર જમણું ક્લિક કરો, **Rename** પસંદ કરો, નવું નામ લખો અને **Enter** દબાવો. |
| Format pendrive | પેનડ્રાઇવ પર જમણું ક્લિક કરીને **Format** પસંદ કરો. જરૂરી ફાઇલ સિસ્ટમ પસંદ કરી **Start** પર ક્લિક કરો. ફોર્મેટ કરતાં પહેલાં મહત્વનો ડેટા બેકઅપ લેવો. |
| Create Folder | જરૂરી ડ્રાઇવ અથવા સ્થાન ખોલો. ખાલી જગ્યાએ જમણું ક્લિક કરીને **New → Folder** પસંદ કરો અને ફોલ્ડરનું નામ આપો. |
| Create Shortcut | ફાઇલ અથવા ફોલ્ડર પર જમણું ક્લિક કરીને **Create shortcut** પસંદ કરો અથવા **Send to → Desktop (create shortcut)** નો ઉપયોગ કરો. |
| Create File | જરૂરી સ્થાન પર જમણું ક્લિક કરીને **New** પસંદ કરો અને જરૂરી ફાઇલ પ્રકાર પસંદ કરો. ફાઇલનું નામ આપી તેને સેવ કરો. |
| Copy & Paste | ફાઇલ અથવા ફોલ્ડર પસંદ કરીને **Ctrl + C** દબાવો. ગંતવ્ય સ્થાન ખોલીને **Ctrl + V** દબાવો. |
| Cut & Paste | ફાઇલ અથવા ફોલ્ડર પસંદ કરીને **Ctrl + X** દબાવો. ગંતવ્ય સ્થાન ખોલીને **Ctrl + V** દબાવો. |
| Delete file / Folder | ફાઇલ અથવા ફોલ્ડર પસંદ કરીને **Delete** કી દબાવો અથવા જમણું ક્લિક કરીને **Delete** પસંદ કરો. |
| Eject Pendrive | પેનડ્રાઇવનો ડેટા ઉપયોગમાં ન હોય ત્યારે **Safely Remove / Eject** વિકલ્પ પસંદ કરો. ત્યારબાદ પેનડ્રાઇવને USB પોર્ટમાંથી કાઢો. |
