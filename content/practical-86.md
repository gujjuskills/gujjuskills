# પ્રેકટિકલ-૮૬ : ટેબલ ડેટા ફિલ્ટર કરો અને શોર્ટ કરો : MS-EXCEL

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| Filter records | **Filter records** નો ઉપયોગ Excel માં મોટા પ્રમાણમાં રહેલા ડેટામાંથી આપણી જરૂરિયાત મુજબના ચોક્કસ Records જોવા માટે થાય છે. Filter લાગુ કર્યા પછી માત્ર શરતને પૂર્ણ કરતા Records દેખાય છે અને બાકીના Records અસ્થાયી રીતે છુપાઈ જાય છે. Filter લાગુ કરવા માટે સૌપ્રથમ Table અથવા Data Range પસંદ કરો. ત્યારબાદ **Data → Filter** પસંદ કરો. દરેક Column ના Header પાસે આવેલા Drop-down Arrow પર ક્લિક કરીને જરૂરી Value અથવા Condition પસંદ કરી શકાય છે. ઉદાહરણ તરીકે, જો Student Data માં `City`, `Gender` અને `Marks` Column હોય તો માત્ર `Ahmedabad` ના Students, માત્ર `Male` Students અથવા `Marks > 50` ધરાવતા Students બતાવી શકાય છે. એક કરતાં વધુ Columns પર Filter લગાવી શકાય છે. Filter દૂર કરવા માટે **Data → Clear** અથવા સંબંધિત Column માં **Clear Filter** પસંદ કરી શકાય છે. Filter કરવાથી મૂળ Data Delete થતો નથી, માત્ર જરૂરી Records દેખાડવામાં આવે છે. |
| Sort data by multiple columns | **Sort data by multiple columns** નો ઉપયોગ એક કરતાં વધુ Columns ના આધારે Data ને ચોક્કસ ક્રમમાં ગોઠવવા માટે થાય છે. Excel માં **Data → Sort** પસંદ કર્યા પછી પ્રથમ Column ને મુખ્ય Sorting Column તરીકે પસંદ કરી શકાય છે અને ત્યારબાદ **Add Level** દ્વારા બીજા અને ત્રીજા Column ને Sorting માટે પસંદ કરી શકાય છે. ઉદાહરણ તરીકે, Student Data માં પ્રથમ `Class` ને **Smallest to Largest** અને પછી દરેક Class ની અંદર `Marks` ને **Largest to Smallest** પ્રમાણે Sort કરી શકાય છે. આ રીતે પહેલા Class પ્રમાણે Data ગોઠવાશે અને દરેક Class ની અંદર વધુ Marks ધરાવતા Students ઉપર આવશે. Multiple-column Sorting માં પ્રથમ પસંદ કરેલો Column સૌથી વધુ મહત્વનો હોય છે અને ત્યારબાદના Columns સમાન Value ધરાવતા Records વચ્ચેનો ક્રમ નક્કી કરે છે. Sorting કરતા પહેલાં સંપૂર્ણ Table અથવા Data Range પસંદ કરવું જરૂરી છે, જેથી Row નો સંબંધિત Data અલગ ન પડી જાય. |
