# લેશન - ૯૯ : ક્લાઉડ માં ઉપલબ્ધ સંસાધનો

| Type of Cloud | **1 Public Cloud** |
|---|---|
| **Introduction** | Public Cloud એ એવી Cloud સેવા છે જે Internet દ્વારા સામાન્ય લોકો અથવા વિવિધ સંસ્થાઓ માટે ઉપલબ્ધ હોય છે. Cloud Provider તેના સર્વર, Storage અને અન્ય Resources ઉપલબ્ધ કરાવે છે. |
| **Advantages** | 1. ખર્ચ ઓછો હોય છે.<br>2. સરળતાથી ઉપયોગ કરી શકાય છે.<br>3. જરૂરિયાત મુજબ Resources વધારી કે ઘટાડી શકાય છે.<br>4. Maintenance ની જવાબદારી Provider ની હોય છે. |
| **Disadvantages** | 1. Data Security અંગે ચિંતા રહી શકે છે.<br>2. Internet Connection જરૂરી છે.<br>3. Resources પર સંપૂર્ણ નિયંત્રણ મળતું નથી. |
| **Example** | Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP) |

| **Type of Cloud** | **2 Private Cloud** |
|---|---|
| **Introduction** | Private Cloud એવી Cloud Infrastructure છે જે માત્ર એક સંસ્થા અથવા ચોક્કસ Organization દ્વારા ઉપયોગમાં લેવામાં આવે છે. |
| **Advantages** | 1. Data પર વધુ નિયંત્રણ મળે છે.<br>2. Security અને Privacy વધુ હોય છે.<br>3. Organization ની જરૂરિયાત મુજબ તેને Customize કરી શકાય છે. |
| **Disadvantages** | 1. ખર્ચ વધારે હોઈ શકે છે.<br>2. Maintenance માટે વધારે Technical Knowledge જરૂરી છે.<br>3. Hardware અને Infrastructure ની જવાબદારી સંસ્થાની હોય છે. |
| **Example** | કોઈ મોટી કંપની દ્વારા પોતાની અંદર સ્થાપિત કરવામાં આવેલ Private Data Center અને Private Cloud. |

| **Type of Cloud** | **3 Hybrid Cloud** |
|---|---|
| **Introduction** | Hybrid Cloud એ Public Cloud અને Private Cloud બંનેનું સંયોજન છે. તેમાં સંસ્થા જરૂરિયાત મુજબ બંને Cloud નો ઉપયોગ કરી શકે છે. |
| **Advantages** | 1. Flexibility વધારે મળે છે.<br>2. Sensitive Data Private Cloud માં રાખી શકાય છે.<br>3. Public Cloud દ્વારા વધારાના Resources મેળવી શકાય છે.<br>4. ખર્ચ અને Performance વચ્ચે યોગ્ય સંતુલન રાખી શકાય છે. |
| **Disadvantages** | 1. Management વધારે જટિલ હોય છે.<br>2. Setup અને Maintenance માટે Technical Knowledge જરૂરી છે.<br>3. બંને Cloud વચ્ચે Data Transfer માટે યોગ્ય Network જરૂરી છે. |
| **Example** | કોઈ કંપની પોતાનો Sensitive Data Private Cloud માં રાખે અને Website માટે Public Cloud નો ઉપયોગ કરે. |

| **Type of Cloud** | **4 Community Cloud** |
|---|---|
| **Introduction** | Community Cloud એવી Cloud Infrastructure છે જે સમાન પ્રકારની જરૂરિયાતો ધરાવતી એકથી વધુ સંસ્થાઓ અથવા સમુદાય દ્વારા Share કરવામાં આવે છે. |
| **Advantages** | 1. ખર્ચ એકથી વધુ સંસ્થાઓ વચ્ચે વહેંચી શકાય છે.<br>2. સમાન Security અને Compliance જરૂરિયાતો પૂરી કરી શકાય છે.<br>3. Resources Share કરી શકાય છે. |
| **Disadvantages** | 1. Management જટિલ હોઈ શકે છે.<br>2. તમામ સભ્યો વચ્ચે યોગ્ય Coordination જરૂરી છે.<br>3. Customization મર્યાદિત હોઈ શકે છે. |
| **Example** | સરકારી વિભાગો માટે બનાવવામાં આવેલ Shared Cloud Infrastructure અથવા સમાન જરૂરિયાત ધરાવતી શૈક્ષણિક સંસ્થાઓની Shared Cloud. |

| **Type of Cloud** | **5 Multi Cloud** |
|---|---|
| **Introduction** | Multi Cloud એટલે એક સંસ્થા દ્વારા બે અથવા તેથી વધુ અલગ Cloud Providers ની Cloud Services નો ઉપયોગ કરવો. |
| **Advantages** | 1. એક જ Cloud Provider પર આધાર ઓછો થાય છે.<br>2. અલગ અલગ Providers ની શ્રેષ્ઠ Services નો ઉપયોગ કરી શકાય છે.<br>3. Availability અને Flexibility વધારી શકાય છે.<br>4. જરૂરિયાત મુજબ અલગ Cloud પસંદ કરી શકાય છે. |
| **Disadvantages** | 1. Management વધારે જટિલ બને છે.<br>2. અલગ અલગ Cloud Services માટે અલગ Configuration જરૂરી હોઈ શકે છે.<br>3. Monitoring અને Security સંભાળવી મુશ્કેલ બની શકે છે. |
| **Example** | કોઈ કંપની Website માટે AWS, Database માટે Microsoft Azure અને Analytics માટે Google Cloud નો ઉપયોગ કરે. |
