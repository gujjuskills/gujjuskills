# પ્રેકટિકલ-૪૪ : રેફરન્સ તત્વો બનાવો અને ફેરફાર કરો

| ટોપિક | સામાન્ય સમજ / કાર્ય |
|---|---|
| **ફૂટનોટ અને એન્ડનોટ દાખલ કરવી** | MS Word માં દસ્તાવેજના કોઈ શબ્દ અથવા વાક્ય માટે વધારાની માહિતી, સંદર્ભ અથવા નોંધ આપવા માટે **Footnote** અને **Endnote** દાખલ કરવામાં આવે છે. Footnote પેજના નીચેના ભાગમાં અને Endnote દસ્તાવેજ અથવા વિભાગના અંતે દેખાય છે. |
| **ફૂટનોટ અને એન્ડનોટના ગુણધર્મોમાં ફેરફાર કરવો** | Footnote અને Endnote ના નંબરનું ફોર્મેટ, સ્થાન, નંબરિંગની રીત અને અન્ય સેટિંગ્સમાં ફેરફાર કરી શકાય છે. આ માટે **References → Footnotes** માંથી જરૂરી વિકલ્પ પસંદ કરવામાં આવે છે. |
| **બિબ્લિયોગ્રાફી માટે Citation Source બનાવવી અને તેમાં ફેરફાર કરવો** | દસ્તાવેજમાં ઉપયોગમાં લીધેલા પુસ્તકો, વેબસાઇટ્સ, લેખો વગેરેના સંદર્ભો માટે Citation Source બનાવવામાં આવે છે. **References → Manage Sources** દ્વારા નવી Source ઉમેરી શકાય છે અને અગાઉની Source માં ફેરફાર કરી શકાય છે. |
| **બિબ્લિયોગ્રાફી માટે Citations દાખલ કરવી** | દસ્તાવેજમાં કોઈ માહિતીનો સ્ત્રોત દર્શાવવા માટે Citation દાખલ કરવામાં આવે છે. **References → Insert Citation** દ્વારા જરૂરી Source પસંદ કરી શકાય છે અને અંતે **Bibliography** વિકલ્પથી તમામ સંદર્ભોની યાદી બનાવી શકાય છે. |
