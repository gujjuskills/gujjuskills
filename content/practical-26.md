# પ્રેક્ટિકલ - ૨૬ : બેઝિક પાવરશેલ કમાન્ડલેટનો અભ્યાસ કરો.
| ક્રમાંક | PowerShell Cmdlet | સામાન્ય સમજ / ઉપયોગ |
|---:|---|---|
| 1 | `Get-Command` | ઉપલબ્ધ PowerShell કમાન્ડની યાદી મેળવવા માટે ઉપયોગ થાય છે. |
| 2 | `Get-Help` | કોઈ કમાન્ડ વિશે મદદ અને માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| 3 | `Get-Location` | વર્તમાન ફોલ્ડર અથવા સ્થાનની માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| 4 | `Set-Location` | વર્તમાન ફોલ્ડર અથવા સ્થાન બદલવા માટે ઉપયોગ થાય છે. |
| 5 | `Get-ChildItem` | ફોલ્ડરની અંદરની ફાઇલો અને ફોલ્ડરની યાદી જોવા માટે ઉપયોગ થાય છે. |
| 6 | `New-Item` | નવી ફાઇલ અથવા ફોલ્ડર બનાવવા માટે ઉપયોગ થાય છે. |
| 7 | `Copy-Item` | ફાઇલ અથવા ફોલ્ડરની નકલ કરવા માટે ઉપયોગ થાય છે. |
| 8 | `Move-Item` | ફાઇલ અથવા ફોલ્ડરને એક સ્થાનેથી બીજા સ્થાને ખસેડવા માટે ઉપયોગ થાય છે. |
| 9 | `Rename-Item` | ફાઇલ અથવા ફોલ્ડરનું નામ બદલવા માટે ઉપયોગ થાય છે. |
| 10 | `Remove-Item` | ફાઇલ અથવા ફોલ્ડરને દૂર અથવા ડિલીટ કરવા માટે ઉપયોગ થાય છે. |
| 11 | `Get-Content` | ફાઇલની અંદર રહેલું લખાણ અથવા માહિતી જોવા માટે ઉપયોગ થાય છે. |
| 12 | `Set-Content` | ફાઇલમાં નવું લખાણ અથવા માહિતી લખવા માટે ઉપયોગ થાય છે. |
| 13 | `Clear-Host` | PowerShell સ્ક્રીન પર દેખાતી માહિતી સાફ કરવા માટે ઉપયોગ થાય છે. |
| 14 | `Get-Process` | કમ્પ્યુટરમાં હાલમાં ચાલી રહેલી પ્રક્રિયાઓની માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| 15 | `Stop-Process` | ચાલી રહેલી પ્રક્રિયાને બંધ કરવા માટે ઉપયોગ થાય છે. |
| 16 | `Get-Service` | કમ્પ્યુટરમાં રહેલી Windows Servicesની માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| 17 | `Start-Service` | બંધ થયેલી Service શરૂ કરવા માટે ઉપયોગ થાય છે. |
| 18 | `Stop-Service` | ચાલી રહેલી Service બંધ કરવા માટે ઉપયોગ થાય છે. |
| 19 | `Get-History` | અગાઉ ચલાવેલી PowerShell કમાન્ડની યાદી જોવા માટે ઉપયોગ થાય છે. |
| 20 | `Restart-Computer` | કમ્પ્યુટરને ફરીથી શરૂ કરવા માટે ઉપયોગ થાય છે. |
