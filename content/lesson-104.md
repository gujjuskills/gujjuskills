# લેશન - ૧૦૪ : ડિરેક્ટરી સેવાઓ , એક્સેસ નિયત્રણ ગોપનિયતા સુરક્ષા , ઓડિટ

| Topic | Gujarati Answer |
|---|---|
| **What is Directory Services?** | Directory Services એ નેટવર્કમાં રહેલા Users, Computers, Devices અને અન્ય Resources ની માહિતી સંગ્રહિત, વ્યવસ્થિત અને મેનેજ કરવા માટેની સેવા છે. તેનો ઉપયોગ User Authentication, Resource Management અને Access Control માટે થાય છે. |
| **What is Security?** | Security એટલે Computer System, Network અને Data ને Unauthorized Access, Virus, Malware, Data Theft અને અન્ય જોખમોથી સુરક્ષિત રાખવાની પ્રક્રિયા. |
| **What is Access Control?** | Access Control એટલે કયા User ને કયા Data, File, Application અથવા Resource નો Access આપવો અને કયા User નો Access રોકવો તે નક્કી કરવાની પ્રક્રિયા. |
| **What is Privacy Protection?** | Privacy Protection એટલે વ્યક્તિગત અને સંવેદનશીલ માહિતીનું Unauthorized Access, Use અથવા Disclosure થી રક્ષણ કરવું. |
| **What is Audit and Security?** | Audit and Security એટલે System અને Network માં થયેલી Activities તથા Access નો Record રાખવો અને તેની તપાસ કરીને Security સંબંધિત ખામીઓ અથવા Unauthorized Activities શોધવી. |
