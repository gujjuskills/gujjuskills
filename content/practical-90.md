# પ્રેકટિકલ-૯૦ : ચાર્ટ બનાવો : MS-EXCEL

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| Create charts | **Create charts** એટલે Excel માં ઉપલબ્ધ ડેટાને ગ્રાફિક સ્વરૂપમાં રજૂ કરવાની પ્રક્રિયા. ચાર્ટ દ્વારા મોટા પ્રમાણમાં રહેલા ડેટાને સરળતાથી સમજાવી અને તેની સરખામણી કરી શકાય છે. ચાર્ટ બનાવવા માટે સૌપ્રથમ જરૂરી ડેટા પસંદ કરવામાં આવે છે. ત્યારબાદ **Insert → Charts** માંથી યોગ્ય ચાર્ટ પ્રકાર પસંદ કરવામાં આવે છે. Excel માં Column Chart, Bar Chart, Line Chart, Pie Chart, Area Chart વગેરે જેવા વિવિધ પ્રકારના ચાર્ટ બનાવી શકાય છે. ચાર્ટ બનાવ્યા પછી તેમાં **Chart Title, Axis Title, Legend, Data Labels** વગેરે ઉમેરી શકાય છે. ઉદાહરણ તરીકે, વિદ્યાર્થીઓના વિષયવાર ગુણ દર્શાવવા માટે Column Chart બનાવવાથી કયા વિષયમાં વધુ કે ઓછા ગુણ છે તે સરળતાથી જાણી શકાય છે. |
| Create chart sheets | **Create chart sheets** એટલે Excel માં ચાર્ટને વર્કશીટની અંદર રાખવાને બદલે તેને અલગ Chart Sheet પર દર્શાવવાની પ્રક્રિયા. સૌપ્રથમ જરૂરી ડેટા પસંદ કરીને ચાર્ટ બનાવવામાં આવે છે. ત્યારબાદ ચાર્ટ પર **Move Chart** વિકલ્પ પસંદ કરીને **New Sheet** પસંદ કરવામાં આવે છે. આ રીતે ચાર્ટ એક અલગ શીટમાં મૂકાય છે. Chart Sheet ખાસ કરીને ત્યારે ઉપયોગી છે જ્યારે ચાર્ટને મોટા કદમાં જોવો, પ્રેઝન્ટેશનમાં બતાવવો અથવા અલગથી પ્રિન્ટ કરવો હોય. Chart Sheet માં મુખ્યત્વે ચાર્ટ જ દેખાય છે, તેથી ડેટાનું ગ્રાફિકલ વિશ્લેષણ વધુ સરળ બને છે. |
