# લેશન - ૧૧૫ : પાયથોન ઓપરેટર્સ

### Arithmetic Operators

| Operator | Name | Example |
|---|---|---|
| `+` | ઉમેરણ (Addition) | `10 + 5 = 15` |
| `-` | બાદબાકી (Subtraction) | `10 - 5 = 5` |
| `*` | ગુણાકાર (Multiplication) | `10 * 5 = 50` |
| `/` | ભાગાકાર (Division) | `10 / 5 = 2.0` |
| `%` | શેષ (Modulus) | `10 % 3 = 1` |
| `**` | ઘાતાંક (Exponentiation) | `2 ** 3 = 8` |
| `//` | Floor Division | `10 // 3 = 3` |


### Comparison / Relational Operators

| Operator | Name | Example |
|---|---|---|
| `==` | સમાન (Equal to) | `10 == 10` → `True` |
| `!=` | અસમાન (Not Equal to) | `10 != 5` → `True` |
| `>` | કરતાં મોટું (Greater than) | `10 > 5` → `True` |
| `<` | કરતાં નાનું (Less than) | `5 < 10` → `True` |
| `>=` | કરતાં મોટું અથવા સમાન (Greater than or Equal to) | `10 >= 10` → `True` |
| `<=` | કરતાં નાનું અથવા સમાન (Less than or Equal to) | `5 <= 10` → `True` |


### Assignment Operators

| Operator | Name | Example |
|---|---|---|
| `=` | મૂલ્ય સોંપવું (Assignment) | `x = 10` |
| `+=` | ઉમેરણ સાથે મૂલ્ય સોંપવું | `x += 5` → `x = x + 5` |
| `-=` | બાદબાકી સાથે મૂલ્ય સોંપવું | `x -= 5` → `x = x - 5` |
| `*=` | ગુણાકાર સાથે મૂલ્ય સોંપવું | `x *= 5` → `x = x * 5` |
| `/=` | ભાગાકાર સાથે મૂલ્ય સોંપવું | `x /= 5` → `x = x / 5` |
| `%=` | શેષ સાથે મૂલ્ય સોંપવું | `x %= 3` → `x = x % 3` |
| `**=` | ઘાતાંક સાથે મૂલ્ય સોંપવું | `x **= 2` → `x = x ** 2` |
| `//=` | Floor Division સાથે મૂલ્ય સોંપવું | `x //= 3` → `x = x // 3` |
| `&=` | Bitwise AND સાથે મૂલ્ય સોંપવું | `x &= 3` → `x = x & 3` |
| `|=` | Bitwise OR સાથે મૂલ્ય સોંપવું | `x |= 3` → `x = x | 3` |
| `^=` | Bitwise XOR સાથે મૂલ્ય સોંપવું | `x ^= 3` → `x = x ^ 3` |
| `>>=` | Right Shift સાથે મૂલ્ય સોંપવું | `x >>= 2` → `x = x >> 2` |
| `<<=` | Left Shift સાથે મૂલ્ય સોંપવું | `x <<= 2` → `x = x << 2` |


### Bitwise Operators

| Operator | Name | Example |
|---|---|---|
| `&` | Bitwise AND | `5 & 3` → `1` |
| `|` | Bitwise OR | `5 | 3` → `7` |
| `^` | Bitwise XOR | `5 ^ 3` → `6` |
| `~` | Bitwise NOT | `~5` → `-6` |
| `<<` | Left Shift | `5 << 1` → `10` |
| `>>` | Right Shift | `5 >> 1` → `2` |


### Logical Operators

| Operator | Name | Example |
|---|---|---|
| `and` | તાર્કિક AND | `True and True` → `True` |
| `or` | તાર્કિક OR | `True or False` → `True` |
| `not` | તાર્કિક NOT | `not True` → `False` |


### Membership Operators

| Operator | Name | Example |
|---|---|---|
| `in` | સભ્ય છે (Membership) | `2 in [1, 2, 3]` → `True` |
| `not in` | સભ્ય નથી (Not Membership) | `5 not in [1, 2, 3]` → `True` |


### Identity Operators

| Operator | Name | Example |
|---|---|---|
| `is` | એક જ Object છે | `x is y` |
| `is not` | એક જ Object નથી | `x is not y` |
