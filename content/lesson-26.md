## લેશન - ૨૬ : પાવરપોઈન્ટનો પરિચય અને તેના ફાયદા

### what is power point ?

પાવરપોઈન્ટ એ Microsoft દ્વારા બનાવવામાં આવેલ પ્રેઝન્ટેશન સોફ્ટવેર છે. તેનો ઉપયોગ માહિતી, વિચારો અને વિષયને સ્લાઇડ્સ દ્વારા સરળ અને આકર્ષક રીતે રજૂ કરવા માટે થાય છે. તેમાં ટેક્સ્ટ, ચિત્રો, ચાર્ટ, ટેબલ, ઓડિયો, વિડિયો અને એનિમેશન ઉમેરી શકાય છે.

| Advantages (keypoints) | Tips for presentation (key points) |
|---|---|
| માહિતી સરળતાથી રજૂ કરી શકાય છે | સ્લાઇડમાં ઓછું અને જરૂરી લખાણ રાખવું |
| પ્રેઝન્ટેશનને આકર્ષક બનાવી શકાય છે | સરળ અને સ્પષ્ટ ફોન્ટનો ઉપયોગ કરવો |
| ચિત્રો અને ગ્રાફ દ્વારા માહિતી સમજાવી શકાય છે | યોગ્ય રંગો અને ડિઝાઇન પસંદ કરવી |
| ઓડિયો અને વિડિયો ઉમેરી શકાય છે | જરૂરી હોય ત્યાં ચિત્રો અને ચાર્ટનો ઉપયોગ કરવો |
| એનિમેશન અને ટ્રાન્ઝિશનનો ઉપયોગ કરી શકાય છે | દરેક સ્લાઇડને વ્યવસ્થિત રાખવી |
| સમયની બચત થાય છે | ખૂબ વધારે એનિમેશનનો ઉપયોગ ટાળવો |
| માહિતીમાં ફેરફાર કરવો સરળ છે | પ્રેઝન્ટેશન પહેલાં સારી રીતે પ્રેક્ટિસ કરવી |
| શૈક્ષણિક અને વ્યવસાયિક કામમાં ઉપયોગી છે | પ્રેઝન્ટેશન દરમિયાન આત્મવિશ્વાસપૂર્વક બોલવું |
| માહિતીનું સંચાલન સરળ બને છે | મુખ્ય મુદ્દાઓ પર ધ્યાન કેન્દ્રિત કરવું |
