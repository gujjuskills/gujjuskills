# પ્રેકટિકલ-૧૫૩ : ADLC ના દરેક તબક્કામાં ભૂમિકાઓનું વર્ણન કરો

![image](/images/practical-153.webp)

### 1. Planning (આયોજન)
આ તબક્કામાં એપ્લિકેશન બનાવવાનો હેતુ અને જરૂરીયાતો નક્કી કરવામાં આવે છે.

**મુખ્ય ભૂમિકા:**
1. એપ્લિકેશનનો હેતુ નક્કી કરવો.
2. પ્રોજેક્ટની જરૂરિયાતો ઓળખવી.
3. સમય અને ખર્ચનો અંદાજ લગાવવો.
4. જરૂરી સંસાધનો નક્કી કરવા.
5. પ્રોજેક્ટનું આયોજન તૈયાર કરવું.

### 2. Analysis (વિશ્લેષણ)
આ તબક્કામાં વપરાશકર્તાની જરૂરિયાતો અને સિસ્ટમની જરૂરીયાતોનું વિશ્લેષણ કરવામાં આવે છે.

**મુખ્ય ભૂમિકા:**
1. વપરાશકર્તાની જરૂરિયાતો એકત્રિત કરવી.
2. સિસ્ટમની કાર્યાત્મક જરૂરિયાતો નક્કી કરવી.
3. જરૂરી ડેટા અને માહિતીનું વિશ્લેષણ કરવું.
4. સિસ્ટમમાં આવનારી સમસ્યાઓ ઓળખવી.
5. સિસ્ટમની જરૂરીયાતોનું દસ્તાવેજીકરણ કરવું.

### 3. Design (ડિઝાઇન)
આ તબક્કામાં સિસ્ટમ કેવી રીતે કાર્ય કરશે તેની વિગતવાર ડિઝાઇન તૈયાર કરવામાં આવે છે.

**મુખ્ય ભૂમિકા:**
1. એપ્લિકેશનનું માળખું તૈયાર કરવું.
2. User Interface (UI) ની ડિઝાઇન કરવી.
3. ડેટાબેઝની ડિઝાઇન કરવી.
4. સિસ્ટમના વિવિધ મોડ્યુલ નક્કી કરવા.
5. ડેટા ફ્લો અને પ્રક્રિયાઓની ડિઝાઇન કરવી.

### 4. Implementation (અમલીકરણ)
આ તબક્કામાં તૈયાર કરેલી ડિઝાઇન મુજબ વાસ્તવિક એપ્લિકેશન બનાવવામાં આવે છે.

**મુખ્ય ભૂમિકા:**
1. પ્રોગ્રામિંગ અને કોડિંગ કરવું.
2. વિવિધ મોડ્યુલ વિકસાવવા.
3. ડેટાબેઝ તૈયાર કરવો.
4. વિવિધ સિસ્ટમ ઘટકોને જોડવા.
5. તૈયાર કરેલી એપ્લિકેશનને કાર્યરત બનાવવી.

### 5. Testing & Evaluation (ચકાસણી અને મૂલ્યાંકન)
આ તબક્કામાં એપ્લિકેશન યોગ્ય રીતે કાર્ય કરે છે કે નહીં તેની ચકાસણી કરવામાં આવે છે.

**મુખ્ય ભૂમિકા:**
1. એપ્લિકેશનની ચકાસણી કરવી.
2. Errors અને Bugs શોધવા.
3. મળેલી ભૂલોને સુધારવી.
4. એપ્લિકેશનની કાર્યક્ષમતાનું મૂલ્યાંકન કરવું.
5. વપરાશકર્તાની જરૂરિયાતો પૂર્ણ થાય છે કે નહીં તે તપાસવું.

### 6. Maintenance (જાળવણી)
એપ્લિકેશન બનાવ્યા પછી તેને યોગ્ય રીતે કાર્યરત રાખવા માટે આ તબક્કામાં જાળવણી કરવામાં આવે છે.

**મુખ્ય ભૂમિકા:**
1. એપ્લિકેશનમાં આવતી ભૂલો સુધારવી.
2. જરૂરી Updates કરવા.
3. નવી સુવિધાઓ ઉમેરવી.
4. એપ્લિકેશનની સુરક્ષા જાળવવી.
5. એપ્લિકેશનની કામગીરીમાં સુધારો કરવો.

## ADLC ના મુખ્ય તબક્કા

| ક્રમાંક | Phase | ગુજરાતી અર્થ |
|---|---|---|
| 1 | Planning | આયોજન |
| 2 | Analysis | વિશ્લેષણ |
| 3 | Design | ડિઝાઇન |
| 4 | Implementation | અમલીકરણ |
| 5 | Testing & Evaluation | ચકાસણી અને મૂલ્યાંકન |
| 6 | Maintenance | જાળવણી |
