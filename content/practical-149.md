## PaaS શું છે?

**PaaS (Platform as a Service)** એક Cloud Computing Service Model છે, જેમાં Application બનાવવા, ચલાવવા અને Deploy કરવા માટે જરૂરી Platform, Runtime Environment અને Development Tools Cloud Provider દ્વારા આપવામાં આવે છે.

Developer ને Server, Operating System અને Hardware Infrastructure જાતે Manage કરવાની જરૂર પડતી નથી.

## PaaS ના મુખ્ય ફાયદા

1. **સરળ Deployment:** Application ને ઝડપથી Cloud પર Deploy કરી શકાય છે.
2. **ઓછું Infrastructure Management:** Server અને Hardware ની ચિંતા કરવાની જરૂર રહેતી નથી.
3. **Scalability:** Application ની જરૂરિયાત પ્રમાણે Resources વધારી અથવા ઘટાડી શકાય છે.
4. **Cost Saving:** શરૂઆતમાં મોટા Hardware અથવા Server ખરીદવાની જરૂર પડતી નથી.
5. **Development Speed:** Developer Application Development પર વધુ ધ્યાન આપી શકે છે.
6. **Automatic Updates:** ઘણા PaaS Platforms પર Software અને Runtime Updates સરળતાથી મળે છે.

## Free PaaS Cloud Services

### 1. Google Cloud

Google Cloud વિવિધ Cloud Services આપે છે. PaaS માટે Google App Engine નો ઉપયોગ કરી શકાય છે.

**ઉપયોગ:**
* Web Application Deploy કરવા
* Application Hosting
* Automatic Scaling
* વિવિધ Programming Languages માટે Support

### 2. AWS

Amazon Web Services (AWS) માં PaaS પ્રકારની Services ઉપલબ્ધ છે. AWS Elastic Beanstalk નો ઉપયોગ Application Deploy અને Manage કરવા માટે કરી શકાય છે.

**ઉપયોગ:**
* Web Application Deployment
* Application Monitoring
* Automatic Scaling
* Cloud Application Management

## PaaS પર Basic Practice

PaaS નો ઉપયોગ કરીને સામાન્ય રીતે નીચેના Steps કરવામાં આવે છે:

1. Cloud Service Provider પર Account બનાવવું.
2. Free Tier અથવા Free Service પસંદ કરવી.
3. એક Cloud Project બનાવવો.
4. જરૂરી Runtime અથવા Platform પસંદ કરવું.
5. Application તૈયાર કરવી.
6. Application ને Cloud Platform પર Deploy કરવી.
7. Application ની Working ચકાસવી.
8. Cloud Console માંથી Application ને Monitor કરવી.
