# લેશન - ૧૦૩.૨ : માહિટી સુરક્ષા નબળાઈઓ અને જોખમ વ્યવસ્થાપન

## What is a Security Vulnerability?
| મુદ્દો | માહિતી |
|---|---|
| Security Vulnerability | સુરક્ષા નબળાઈ એટલે કમ્પ્યુટર, નેટવર્ક, સોફ્ટવેર અથવા માહિતી પ્રણાલીમાં રહેલી એવી ખામી કે નબળાઈ, જેનો ઉપયોગ અનધિકૃત વ્યક્તિ સિસ્ટમમાં પ્રવેશ કરવા, માહિતી ચોરવા અથવા નુકસાન કરવા માટે કરી શકે છે. |
| Example | જૂનું સોફ્ટવેર, નબળો પાસવર્ડ, ખોટી સિસ્ટમ સેટિંગ અથવા સુરક્ષા અપડેટનો અભાવ Security Vulnerability બની શકે છે. |
| Purpose | સુરક્ષા નબળાઈને ઓળખીને તેને દૂર કરવાથી માહિતી અને સિસ્ટમને સુરક્ષિત રાખી શકાય છે. |


## Types Security Vulnerability

| ક્રમ | Type | ગુજરાતી માહિતી |
|---|---|---|
| 1 | Software Vulnerability | સોફ્ટવેરમાં રહેલી ખામીને કારણે હુમલાખોર સિસ્ટમમાં પ્રવેશ મેળવી શકે છે. |
| 2 | Network Vulnerability | નેટવર્કની સુરક્ષા વ્યવસ્થામાં રહેલી ખામીને કારણે અનધિકૃત વ્યક્તિ નેટવર્કમાં પ્રવેશ કરી શકે છે. |
| 3 | Password Vulnerability | નબળા, સરળ અથવા વારંવાર ઉપયોગમાં લેવાતા પાસવર્ડને કારણે એકાઉન્ટની સુરક્ષા જોખમમાં આવી શકે છે. |
| 4 | Human Vulnerability | કર્મચારીની ભૂલ, અજાણતા ખોટી લિંક ખોલવી અથવા ગુપ્ત માહિતી શેર કરવાથી સુરક્ષા જોખમ ઊભું થઈ શકે છે. |
| 5 | Physical Vulnerability | કમ્પ્યુટર, સર્વર અથવા અન્ય ઉપકરણોની ભૌતિક સુરક્ષા ન હોવાને કારણે નુકસાન અથવા અનધિકૃત ઉપયોગ થઈ શકે છે. |
| 6 | Configuration Vulnerability | સિસ્ટમ અથવા નેટવર્કની ખોટી સેટિંગને કારણે સુરક્ષામાં નબળાઈ ઊભી થઈ શકે છે. |
| 7 | Malware Vulnerability | Virus, Worm, Trojan અથવા અન્ય Malware દ્વારા સિસ્ટમ અને માહિતી પર હુમલો થઈ શકે છે. |
| 8 | Web Application Vulnerability | વેબસાઇટ અથવા વેબ એપ્લિકેશનમાં રહેલી ખામીને કારણે માહિતી ચોરી અથવા અનધિકૃત પ્રવેશ થઈ શકે છે. |


## What is a Info. Security Risk Management?

| મુદ્દો | માહિતી |
|---|---|
| Information Security Risk Management | Information Security Risk Management એટલે માહિતી અને માહિતી પ્રણાલીઓ સાથે સંકળાયેલા સુરક્ષા જોખમોને ઓળખવા, તેનું મૂલ્યાંકન કરવા અને તેને ઘટાડવા માટે કરવામાં આવતી વ્યવસ્થિત પ્રક્રિયા. |
| Main Purpose | સંસ્થાની મહત્વપૂર્ણ માહિતી, કમ્પ્યુટર સિસ્ટમ, નેટવર્ક અને અન્ય ડિજિટલ સંસાધનોને સુરક્ષા જોખમોથી સુરક્ષિત રાખવાનો તેનો મુખ્ય હેતુ છે. |
| Process | તેમાં જોખમની ઓળખ, જોખમનું મૂલ્યાંકન, જોખમ ઘટાડવા માટેના પગલાં, સતત દેખરેખ અને સમયાંતરે સમીક્ષા કરવામાં આવે છે. |


## Key Components of ISRM

| ક્રમ | Component | ગુજરાતી માહિતી |
|---|---|---|
| 1 | Risk Identification | સિસ્ટમ, નેટવર્ક અને માહિતી સાથે સંકળાયેલા સંભવિત સુરક્ષા જોખમોને ઓળખવા. |
| 2 | Risk Assessment | ઓળખાયેલા જોખમની સંભાવના અને તેની અસરનું મૂલ્યાંકન કરવું. |
| 3 | Risk Analysis | જોખમથી સંસ્થાને કેટલું નુકસાન થઈ શકે છે તેનું વિશ્લેષણ કરવું. |
| 4 | Risk Treatment | જોખમ ઘટાડવા, ટાળવા, સ્વીકારવા અથવા નિયંત્રિત કરવા માટે યોગ્ય પગલાં લેવા. |
| 5 | Security Controls | Firewall, Antivirus, Access Control, Encryption અને અન્ય સુરક્ષા નિયંત્રણોનો ઉપયોગ કરવો. |
| 6 | Monitoring | સિસ્ટમ અને નેટવર્કની સતત દેખરેખ રાખવી અને નવી સુરક્ષા સમસ્યાઓ શોધવી. |
| 7 | Review | સુરક્ષા વ્યવસ્થાની સમયાંતરે સમીક્ષા કરીને જરૂરી સુધારા કરવા. |


## Benefits of ISRM

| ક્રમ | Benefit | ગુજરાતી માહિતી |
|---|---|---|
| 1 | Data Protection | મહત્વપૂર્ણ અને સંવેદનશીલ માહિતીને અનધિકૃત પ્રવેશ અને ચોરીથી સુરક્ષિત રાખવામાં મદદ કરે છે. |
| 2 | Risk Reduction | સુરક્ષા જોખમોને સમયસર ઓળખીને તેને ઘટાડવામાં મદદ કરે છે. |
| 3 | Prevents Security Incidents | Cyber Attack, Malware અને Data Breach જેવી સુરક્ષા ઘટનાઓની સંભાવના ઘટાડે છે. |
| 4 | Business Continuity | સુરક્ષા ઘટના બન્યા પછી પણ વ્યવસાયિક કામગીરી ચાલુ રાખવામાં મદદ કરે છે. |
| 5 | Compliance | સંસ્થાને લાગુ પડતા સુરક્ષા નિયમો અને નીતિઓનું પાલન કરવામાં મદદ કરે છે. |
| 6 | Cost Reduction | સુરક્ષા સમસ્યાઓથી થનારા નાણાકીય નુકસાનને ઘટાડવામાં મદદ કરે છે. |
| 7 | Better Security Awareness | કર્મચારીઓમાં માહિતી સુરક્ષા અંગે જાગૃતિ વધારવામાં મદદ કરે છે. |
| 8 | Improved Trust | ગ્રાહકો અને સંસ્થાના હિતધારકોનો સંસ્થા પ્રત્યેનો વિશ્વાસ વધારવામાં મદદ કરે છે. |
