# લેશન - 14 : હાર્ડવેર - સોફટવેરની સમસ્યાઓ અને તેનો ઉકેલ

| ક્રમાંક | સમસ્યા | ઉકેલ |
|:---:|:---|:---|
| 1 | CPU માંથી બીપનો અવાજ આવે અને કમ્પ્યુટર શરૂ ન થાય ત્યારે | RAM અને અન્ય હાર્ડવેરની તપાસ કરો. RAM કાઢીને સાફ કરી ફરીથી યોગ્ય રીતે લગાવો. જરૂર પડે તો RAM બદલો. |
| 2 | CPU માંથી POWER SUPPLY ન આવતી હોય અને કમ્પ્યુટર શરૂ ન થાય ત્યારે | પાવર કેબલ, પ્લગ, પાવર સ્વિચ અને SMPS તપાસો. SMPS ખરાબ હોય તો તેને બદલો. |
| 3 | કમ્પ્યુટર વારંવાર RESTART થાય ત્યારે | CPU નું તાપમાન, RAM, SMPS અને વાયરસની તપાસ કરો. CPU ફેન સાફ કરો અને જરૂરી હોય તો થર્મલ પેસ્ટ લગાવો. |
| 4 | સ્પીકરમાં અવાજ ન આવે ત્યારે | સ્પીકરનું કનેક્શન, વોલ્યુમ સેટિંગ અને સાઉન્ડ ડ્રાઇવર તપાસો. જરૂરી હોય તો સાઉન્ડ ડ્રાઇવર ફરીથી ઇન્સ્ટોલ કરો. |
| 5 | કીબોર્ડ અને માઉસ કામ ન કરે ત્યારે | USB/PS2 કનેક્શન તપાસો અને બીજા પોર્ટમાં લગાવી જુઓ. ડ્રાઇવર તપાસો અને જરૂર પડે તો કીબોર્ડ અથવા માઉસ બદલો. |
| 6 | મોનિટર પર ડિસ્પ્લે જોવા ન મળે ત્યારે | મોનિટરનો પાવર, VGA/HDMI કેબલ અને કનેક્શન તપાસો. RAM અને ગ્રાફિક્સ કાર્ડ પણ તપાસો. |
| 7 | DISK BOOT FAILURE મેસેજ જોવા મળે ત્યારે | BIOS માં Boot Order તપાસો. HDD/SSD નું કનેક્શન અને તેની સ્થિતિ તપાસો. જરૂરી હોય તો Operating System ફરીથી ઇન્સ્ટોલ કરો. |
| 8 | APPLICATION SOFTWARE કાર્ય ન કરે ત્યારે | સોફ્ટવેરની Compatibility અને System Requirements તપાસો. સોફ્ટવેરને Update અથવા Reinstall કરો. |
| 9 | વાયરસના લીધે FILE/FOLDER ને નુકસાન થાય ત્યારે | વિશ્વસનીય Antivirus દ્વારા સંપૂર્ણ Scan કરો. અસરગ્રસ્ત ફાઇલને Backup માંથી Restore કરો અને Antivirus Update રાખો. |
| 10 | પ્રિન્ટર કાર્ય ન કરે ત્યારે | પ્રિન્ટરનું Power, USB/Network કનેક્શન, Paper અને Ink/Toner તપાસો. Printer Driver અને Print Queue પણ તપાસો. |
| 11 | INTERNET કનેક્શન ચાલતું ન હોય ત્યારે | LAN/Wi-Fi કનેક્શન, Router અને Modem તપાસો. Network Driver અને IP Settings તપાસો અને જરૂર પડે તો Router Restart કરો. |
| 12 | CD/DVD રાઇટર કામ ન કરે ત્યારે | CD/DVD Drive નું કનેક્શન અને Driver તપાસો. યોગ્ય Blank Disc વાપરો અને Drive ની Lens સાફ કરો. જરૂરી હોય તો Drive બદલો. |
| 13 | કમ્પ્યુટર સિસ્ટમ હેંગ થાય ત્યારે | અનાવશ્યક Program બંધ કરો અને કમ્પ્યુટર Restart કરો. RAM, CPU Temperature અને વાયરસની તપાસ કરો. |
| 14 | કમ્પ્યુટરની સ્પીડ ધીમી થઈ જાય ત્યારે | અનાવશ્યક Startup Programs બંધ કરો, Temporary Files અને Junk Files કાઢી નાખો. Virus Scan કરો અને જરૂર પડે તો RAM/SSD અપગ્રેડ કરો. |
