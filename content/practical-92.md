# પ્રેકટિકલ-૯૨ : ફોરમેટ ચાર્ટ : MS-EXCEL

| Topic | વિગતવાર માહિતી / જવાબ |
|---|---|
| Apply chart layouts | **Apply chart layouts** નો ઉપયોગ ચાર્ટમાં રહેલા વિવિધ ઘટકોની ગોઠવણી બદલવા માટે થાય છે. સૌપ્રથમ ચાર્ટને Select કરો. ત્યારબાદ **Chart Design → Quick Layout** પર ક્લિક કરો. અહીં અલગ અલગ Layout ઉપલબ્ધ હોય છે. જરૂરી Layout પસંદ કરતાં Chart Title, Axis Titles, Legend, Data Labels અને અન્ય Chart Elements ની ગોઠવણી આપમેળે બદલાય છે. ઉદાહરણ તરીકે, જો ચાર્ટમાં Data Labels ઉમેરવા હોય અથવા Legend ની સ્થિતિ બદલવી હોય તો યોગ્ય Quick Layout પસંદ કરી શકાય છે. આ સુવિધા દ્વારા દરેક Element ને અલગ અલગ ગોઠવવાની જરૂર રહેતી નથી. |
| Apply chart styles | **Apply chart styles** નો ઉપયોગ ચાર્ટનો દેખાવ અને Formatting બદલવા માટે થાય છે. ચાર્ટ Select કર્યા પછી **Chart Design → Chart Styles** વિભાગમાં વિવિધ તૈયાર Styles જોવા મળે છે. જરૂરી Style પસંદ કરતાં ચાર્ટના રંગ, Background, Border, Lines અને અન્ય Visual Effects બદલાઈ જાય છે. Chart Style પસંદ કરતી વખતે એવો Style પસંદ કરવો જોઈએ જે Data ને સરળતાથી સમજવામાં મદદ કરે. જરૂરિયાત મુજબ **Change Colors** વિકલ્પ દ્વારા ચાર્ટના રંગોની Scheme પણ બદલી શકાય છે. |
| Add alternative text to charts for accessibility | **Add alternative text to charts for accessibility** નો ઉપયોગ Chart ને Accessibility માટે યોગ્ય બનાવવા માટે થાય છે. ખાસ કરીને Screen Reader નો ઉપયોગ કરતા Users માટે આ ખૂબ ઉપયોગી છે. ચાર્ટ પર **Right Click → Edit Alt Text** પસંદ કરો અને Chart માં દર્શાવેલી માહિતીનું ટૂંકું પરંતુ સ્પષ્ટ વર્ણન લખો. Alt Text માં Chart નો પ્રકાર, તેમાં દર્શાવાતો મુખ્ય Data અને જરૂરી હોય તો મુખ્ય તારણ લખવું જોઈએ. ઉદાહરણ તરીકે, Sales Chart માટે લખી શકાય કે **“આ Column Chart માં 2025 દરમિયાન ચાર ત્રિમાસિક ગાળાના Sales દર્શાવવામાં આવ્યા છે. બીજા Quarter માં સૌથી વધુ Sales થયા છે.”** આ રીતે Screen Reader User ને ચાર્ટ જોયા વગર તેની માહિતી સમજવામાં મદદ મળે છે. |
