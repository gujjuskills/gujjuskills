# પ્રેકટિકલ-૯ : ડેસ્કટોપને કસ્ટમાઈઝ કરો
![image](/gujjuskills/images/desktop.webp)
| પ્રેકટિકલ ટૉપિક  | સામાન્ય માહિતી |
|:---:|:---|
| View | ડેસ્કટોપ પર આઇકોન કેવી રીતે દેખાશે અને ગોઠવાશે તે નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Sort by | ફાઇલો અને ફોલ્ડરને નામ, કદ, પ્રકાર અથવા તારીખ પ્રમાણે ગોઠવવા માટે ઉપયોગ થાય છે. |
| Refresh | ડેસ્કટોપની માહિતી અને આઇકોનને ફરીથી લોડ અથવા અપડેટ કરવા માટે ઉપયોગ થાય છે. |
| New Folder | ડેસ્કટોપ પર નવું ફોલ્ડર બનાવવા માટે ઉપયોગ થાય છે. |
| New Shortcut | કોઈ પ્રોગ્રામ, ફાઇલ, ફોલ્ડર અથવા વેબસાઇટ માટે શોર્ટકટ બનાવવા માટે ઉપયોગ થાય છે. |
| New – File Type | પસંદ કરેલા પ્રકારની નવી ફાઇલ બનાવવા માટે ઉપયોગ થાય છે. |
| Display Settings | સ્ક્રીનનું Resolution, Scale અને Orientation બદલવા માટે ઉપયોગ થાય છે. |
| Personalize | Wallpaper, Theme, Colors અને Lock Screen જેવી સેટિંગ્સ બદલવા માટે ઉપયોગ થાય છે. |
| Open in Terminal | પસંદ કરેલા સ્થાન પર Terminal ખોલવા માટે ઉપયોગ થાય છે. |
| Paste | Copy અથવા Cut કરેલી વસ્તુને પસંદ કરેલા સ્થાન પર મૂકવા માટે ઉપયોગ થાય છે. |
| Paste Shortcut | Copy કરેલી વસ્તુનો Shortcut બનાવવા માટે ઉપયોગ થાય છે. |
| Undo Delete | તાજેતરમાં Delete કરેલી વસ્તુને પાછી લાવવા માટે ઉપયોગ થાય છે. |
| Share Folder | ફોલ્ડરને અન્ય વ્યક્તિ અથવા ઉપકરણ સાથે Share કરવા માટે ઉપયોગ થાય છે. |
| Task Manager | ચાલી રહેલા Programs અને Processes જોવા તથા બંધ કરવા માટે ઉપયોગ થાય છે. |
| Taskbar Properties | Taskbar ની સ્થિતિ, દેખાવ અને સેટિંગ્સ બદલવા માટે ઉપયોગ થાય છે. |
| Widgets | હવામાન, સમાચાર અને અન્ય માહિતી ઝડપથી જોવા માટે ઉપયોગ થાય છે. |
| Start | Programs, Apps અને Settings ખોલવા માટે Start Menu ખોલે છે. |
| Pin to Start Menu | Program અથવા App ને Start Menu માં Pin કરવા માટે ઉપયોગ થાય છે. |
| Unpin From Start Menu | Start Menu માંથી Pin કરેલા Program અથવા App ને દૂર કરવા માટે ઉપયોગ થાય છે. |
| Search | Apps, Files, Settings અને અન્ય માહિતી શોધવા માટે ઉપયોગ થાય છે. |
| Task View | ખુલ્લી Windows જોવા અને Virtual Desktop બદલવા માટે ઉપયોગ થાય છે. |
| Chat | Chat અથવા Communication કરવા માટે ઉપયોગ થાય છે. |
| Unpin This Program From Taskbar | Taskbar માંથી Pin કરેલા Program ને દૂર કરવા માટે ઉપયોગ થાય છે. |
| Pin to Taskbar | Program અથવા App ને Taskbar પર Pin કરવા માટે ઉપયોગ થાય છે. |
| Language Bar | Keyboard અથવા Input Language બદલવા માટે ઉપયોગ થાય છે. |
| Network Access | Wi-Fi અથવા Network સાથે Connect થવા માટે ઉપયોગ થાય છે. |
| Volume | અવાજ વધારવા, ઘટાડવા અથવા Mute કરવા માટે ઉપયોગ થાય છે. |
| Date & Time | તારીખ અને સમય જોવા અથવા બદલવા માટે ઉપયોગ થાય છે. |
