##  લેશન - ૭.૧ મધરબોર્ડના ભાગોનું કાર્ય 

| ભાગ | કાર્ય |
|:---:|:---|
| **CPU / પ્રોસેસર** | CPU ને કમ્પ્યુટરનું મગજ કહેવામાં આવે છે. તે ડેટા પર પ્રક્રિયા કરે છે અને પ્રોગ્રામની સૂચનાઓનું અમલીકરણ કરે છે. |
| **CMOS બેટરી** | CMOS બેટરી સામાન્ય રીતે 3V ની બેટરી હોય છે. કમ્પ્યુટર બંધ હોવા છતાં BIOS સેટિંગ્સ, તારીખ અને સમય જાળવી રાખવામાં મદદ કરે છે. |
| **CPU ફેન કનેક્ટર** | CPU ફેનને મધરબોર્ડમાંથી વીજ પુરવઠો આપે છે. CPU વધારે ગરમ ન થાય તે માટે કૂલિંગ ફેન ચલાવે છે. |
| **ઇન્ટિગ્રેટેડ સર્કિટ (IC)** | IC એ નાની ઇલેક્ટ્રોનિક ચિપ છે જેમાં ઘણા ઇલેક્ટ્રોનિક ઘટકો હોય છે. તેનો ઉપયોગ નિયંત્રણ, પ્રોસેસિંગ અને અન્ય ઇલેક્ટ્રોનિક કાર્યો માટે થાય છે. |
| **કેપેસિટર** | કેપેસિટર થોડી માત્રામાં વિદ્યુત ઊર્જા સંગ્રહિત કરે છે. તે વીજ પુરવઠામાં વોલ્ટેજને સ્થિર રાખવામાં મદદ કરે છે. |
| **ROM / BIOS ચિપ** | BIOS ચિપમાં કમ્પ્યુટરને ચાલુ કરતી વખતે હાર્ડવેરની પ્રારંભિક તપાસ અને શરૂઆત માટે જરૂરી ફર્મવેર હોય છે. |
| **PCI સ્લોટ** | PCI સ્લોટમાં વિવિધ વિસ્તરણ કાર્ડ લગાવી શકાય છે, જેમ કે સાઉન્ડ કાર્ડ, નેટવર્ક કાર્ડ વગેરે. |
| **AGP સ્લોટ** | AGP એટલે **Accelerated Graphics Port**. તેનો ઉપયોગ જૂના કમ્પ્યુટરમાં ગ્રાફિક્સ કાર્ડ જોડવા માટે થતો હતો. |
| **હીટ સિંક** | હીટ સિંક CPU અથવા અન્ય ગરમ થતા ઘટકોમાંથી ગરમી દૂર કરે છે. સામાન્ય રીતે તે ધાતુનો બનેલો હોય છે. |
| **SATA કનેક્ટર** | SATA કનેક્ટરનો ઉપયોગ HDD, SSD અને DVD ડ્રાઇવ જેવા સ્ટોરેજ ઉપકરણોને મધરબોર્ડ સાથે જોડવા માટે થાય છે. |
| **RAM સ્લોટ** | RAM મોડ્યુલ આ સ્લોટમાં લગાવવામાં આવે છે. RAM કમ્પ્યુટર ચાલી રહ્યું હોય ત્યારે ડેટા અને પ્રોગ્રામને અસ્થાયી રીતે સંગ્રહિત કરે છે. |
| **પાવર કનેક્ટર** | પાવર સપ્લાય યુનિટ (PSU) માંથી મધરબોર્ડને જરૂરી વીજ પુરવઠો આપવા માટે તેનો ઉપયોગ થાય છે. |
