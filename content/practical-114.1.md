# પ્રેકટિકલ-૧૧૪.૧ : કેરેકટર ફંક્શનનો ઉપયોગ : MY SQL
| Character Function | કાર્ય |
|---|---|
| CHAR_LENGTH() | સ્ટ્રિંગમાં રહેલા અક્ષરોની કુલ સંખ્યા શોધવા માટે ઉપયોગ થાય છે. |
| LOWER() | આપેલા ટેક્સ્ટના તમામ અક્ષરોને નાના અક્ષરોમાં ફેરવે છે. |
| UPPER() | આપેલા ટેક્સ્ટના તમામ અક્ષરોને મોટા અક્ષરોમાં ફેરવે છે. |
| REVERSE() | આપેલા ટેક્સ્ટને ઊલટા ક્રમમાં દર્શાવે છે. |
| LEFT() | સ્ટ્રિંગની ડાબી બાજુથી જરૂરી સંખ્યામાં અક્ષરો મેળવવા માટે ઉપયોગ થાય છે. |
| RIGHT() | સ્ટ્રિંગની જમણી બાજુથી જરૂરી સંખ્યામાં અક્ષરો મેળવવા માટે ઉપયોગ થાય છે. |
| LTRIM() | સ્ટ્રિંગની શરૂઆતમાં રહેલી વધારાની ખાલી જગ્યા દૂર કરે છે. |
| RTRIM() | સ્ટ્રિંગના અંતમાં રહેલી વધારાની ખાલી જગ્યા દૂર કરે છે. |
| TRIM() | સ્ટ્રિંગની શરૂઆત અને અંતમાં રહેલી વધારાની ખાલી જગ્યા દૂર કરે છે. |
| REPLACE() | સ્ટ્રિંગમાં રહેલા ચોક્કસ અક્ષર અથવા શબ્દને બીજા અક્ષર અથવા શબ્દથી બદલવા માટે ઉપયોગ થાય છે. |
| INSERT() | સ્ટ્રિંગમાં ચોક્કસ સ્થાન પર અક્ષર અથવા શબ્દ ઉમેરવા માટે ઉપયોગ થાય છે. |
| POSITION() | સ્ટ્રિંગમાં આપેલા અક્ષર અથવા શબ્દનું સ્થાન શોધવા માટે ઉપયોગ થાય છે. |
| SUBSTR() | સ્ટ્રિંગમાંથી ચોક્કસ સ્થાનથી જરૂરી અક્ષરો મેળવવા માટે ઉપયોગ થાય છે. |
| CONCAT() | બે અથવા વધુ સ્ટ્રિંગને જોડવા માટે ઉપયોગ થાય છે. |
| STRCMP() | બે સ્ટ્રિંગની સરખામણી કરવા માટે ઉપયોગ થાય છે. |
| REPEAT() | આપેલા સ્ટ્રિંગને ચોક્કસ સંખ્યામાં પુનરાવર્તિત કરવા માટે ઉપયોગ થાય છે. |
| FIND_IN_SET() | આપેલા શબ્દનું comma-separated list માં સ્થાન શોધવા માટે ઉપયોગ થાય છે. |
| FIELD() | આપેલી યાદીમાં ચોક્કસ value નું સ્થાન શોધવા માટે ઉપયોગ થાય છે. |
| FORMAT() | સંખ્યાને ચોક્કસ format માં દર્શાવવા માટે ઉપયોગ થાય છે. |
