# પ્રેકટિકલ-૧૫૧ : ફ્રી ક્લાઉડમાં વેબસાઇટ હોસ્ટ કરો

![image](/images/practical-151.webp)

Cloud Hosting ની મદદથી આપણે પોતાની Website ને Internet પર મફતમાં Host કરી શકીએ છીએ. આ માટે કેટલીક Free Cloud Hosting Services ઉપલબ્ધ છે, જેમ કે GitHub Pages, Netlify અને Vercel.

### Website Host કરવાના Steps

1. **Website તૈયાર કરો**
   તમારી Website માટે HTML, CSS અને JavaScript જેવી Files તૈયાર કરો.

2. **Free Cloud Hosting પસંદ કરો**
   GitHub Pages, Netlify અથવા Vercel જેવી Free Hosting Service પસંદ કરો.

3. **Account બનાવો**
   પસંદ કરેલી Cloud Hosting Service પર Free Account બનાવો.

4. **Website Upload કરો**
   તમારી Website ની Files અથવા GitHub Repository ને Hosting Service સાથે Connect કરો.

5. **Deploy કરો**
   Deploy અથવા Publish વિકલ્પ પર Click કરો.

6. **Website URL મેળવો**
   Deployment પૂર્ણ થયા પછી તમને Website માટે એક Free URL મળશે.

7. **Website ચેક કરો**
   મળેલા URL ને Web Browser માં Open કરીને તમારી Website યોગ્ય રીતે કામ કરે છે કે નહીં તે ચેક કરો.

## ઉદાહરણ

**GitHub Pages** નો ઉપયોગ કરીને Static Website ને મફતમાં Host કરી શકાય છે.

### જરૂરી વસ્તુઓ

- Website Files
- GitHub Account
- GitHub Repository
- Internet Connection
