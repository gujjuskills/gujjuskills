# પ્રેકટિકલ-૯૮ : એડવાન્સ ચાર્ટ બનાવો અને તેમાં ફેરફાર કરો : MS-EXCEL


### Step 1: Excel ખોલો
Microsoft Excel ખોલીને નવી **Blank Workbook** બનાવો.

### Step 2: Data Enter કરો
Worksheet માં નીચે મુજબ ત્રણ Column બનાવો:

### Step 3: Data Select કરો
**Month થી TOTAL સુધીનો સંપૂર્ણ Data Table Select કરો.**

### Step 4: Chart Insert કરો
Excel ના Ribbon માંથી:

**Insert → Charts → Combo Chart**

પસંદ કરો.

### Step 5: Chart Type પસંદ કરો
**Sales** માટે **Column Chart** અને **TOTAL** માટે **Line Chart** પસંદ કરો.

### Step 6: Secondary Axis આપો
**TOTAL** Series માટે **Secondary Axis** પસંદ કરો, જેથી બંને Data Series સરળતાથી જોઈ શકાય.

### Step 7: Chart Title આપો
Chart નું Title બદલીને:

**Monthly Sales and Total**

આપો.

### Step 8: Chart Format કરો
Chart ને સુંદર બનાવવા માટે:

**Chart Design → Change Colors**

અને

**Format → Shape Styles**

નો ઉપયોગ કરો.

### Step 9: Legend અને Axis તપાસો
Chart માં **Legend, Horizontal Axis અને Vertical Axis** યોગ્ય રીતે દેખાય છે કે નહીં તે તપાસો.

### Step 10: Document Save કરો
છેલ્લે:

**File → Save As**

પર ક્લિક કરીને Excel Document ને Save કરો.

### પરિણામ
આ રીતે Simple Table માં રહેલા Data પરથી **Advanced Combo Chart** તૈયાર કરી શકાય છે.
