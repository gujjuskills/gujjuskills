# પ્રેકટિકલ-૧૦૭ : ટેબલ ડિઝાઇન કરવું : MY SQL

 | કાર્ય | કમાન્ડ |
|---|---|
| MySQL ના તમામ ડેટાબેઝનું લીસ્ટ જોવા માટે | `SHOW DATABASES;` |
| કોઈ ડેટાબેઝનો ઉપયોગ કરવા માટે | `USE database_name;` |
| ડેટાબેઝના બધા ટેબલ જોવા માટે | `SHOW TABLES;` |
| નવું ટેબલ બનાવવા માટે | `CREATE TABLE table_name (column1 datatype, column2 datatype);` |
| ટેબલનું સ્ટ્રક્ચર જોવા માટે | `DESC table_name;` |
| ટેબલમાં નવી ફિલ્ડ ઉમેરવા માટે | `ALTER TABLE table_name ADD column_name datatype;` |
| ટેબલના ફિલ્ડની ડેટાટાઇપ બદલવા માટે | `ALTER TABLE table_name MODIFY column_name datatype;` |
| ટેબલમાંથી ફિલ્ડને દૂર કરવા માટે | `ALTER TABLE table_name DROP COLUMN column_name;` |
| ડેટાબેઝમાંથી ટેબલને દૂર કરવા માટે | `DROP TABLE table_name;` |
