# પ્રેકટિકલ-૭૭ : નેવિગેટ કરો : MS-EXCEL

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| Search data | Excel વર્કબુકમાં જરૂરી ડેટા શોધવા માટે Find વિકલ્પનો ઉપયોગ કરવો. Ctrl + F દબાવીને જરૂરી શબ્દ, નંબર અથવા ડેટા લખવો અને Search કરવું. જરૂર મુજબ Find Next અથવા Find All વિકલ્પનો ઉપયોગ કરીને ડેટા શોધી શકાય છે. |
| Navigate to named cells, ranges or workbook elements | વર્કબુકમાં Named Cells, Named Ranges અથવા અન્ય Workbook Elements પર ઝડપથી જવા માટે Name Box અથવા Go To વિકલ્પનો ઉપયોગ કરવો. Ctrl + G અથવા F5 દબાવીને જરૂરી Cell Reference અથવા Named Range પસંદ કરીને Enter દબાવવું. |
| Insert and remove hyperlinks | Excelમાં કોઈ Cellમાં વેબસાઇટ, ફાઇલ, ઈમેલ અથવા વર્કબુકના અન્ય સ્થાનની Link ઉમેરવા માટે Insert > Link વિકલ્પનો ઉપયોગ કરવો. Hyperlink દૂર કરવા માટે સંબંધિત Cell પર Right Click કરીને Remove Hyperlink પસંદ કરવું. |
