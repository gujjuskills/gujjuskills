## લેશન - ૫૧ : પ્રાયમરી કી અને ફોરેન કી નુ અમલીકરણ

| પ્રાઇમરી કી (Primary Key) | ફોરેન કી (Foreign Key) |
|---|---|
| ટેબલમાં દરેક રેકોર્ડને અનન્ય રીતે ઓળખે છે. | એક ટેબલને બીજા ટેબલ સાથે જોડે છે. |
| તેમાં ડુપ્લિકેટ મૂલ્ય હોઈ શકતું નથી. | તેમાં ડુપ્લિકેટ મૂલ્ય હોઈ શકે છે. |
| તેમાં NULL મૂલ્ય હોઈ શકતું નથી. | તેમાં NULL મૂલ્ય હોઈ શકે છે. |
| દરેક ટેબલમાં સામાન્ય રીતે એક Primary Key હોય છે. | એક ટેબલમાં એક અથવા વધુ Foreign Key હોઈ શકે છે. |
| Primary Key ટેબલની ઓળખ માટે ઉપયોગમાં લેવાય છે. | Foreign Key સંબંધિત ટેબલની Primary Key સાથે સંબંધ બનાવે છે. |
| ઉદાહરણ: Student_ID | ઉદાહરણ: Student_ID |
| Primary Key ટેબલની અંદર અનન્ય હોવી જરૂરી છે. | Foreign Keyની કિંમત સંબંધિત ટેબલની Primary Key સાથે મેળ ખાતી હોવી જોઈએ. |
| તે Entity Integrity જાળવવામાં મદદ કરે છે. | તે Referential Integrity જાળવવામાં મદદ કરે છે. |
| ઉદાહરણ: Student ટેબલમાં Student_ID | ઉદાહરણ: Marks ટેબલમાં Student_ID |
| Primary Key દ્વારા રેકોર્ડને સરળતાથી શોધી શકાય છે. | Foreign Key દ્વારા સંબંધિત ટેબલના રેકોર્ડ સાથે જોડાણ કરી શકાય છે. |
