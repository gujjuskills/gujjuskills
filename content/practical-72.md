# પ્રેકટિકલ-૭૨ : એનિમેશન ઉમેરો
| Sr. No. | Topic Name | વિગતવાર સમજ |
|---|---|---|
| 1 | Animate Text and Graphic Elements | PowerPoint માં Text, Picture, Shape અને અન્ય Graphic Elements ને Animation આપી શકાય છે. Animation દ્વારા Slide પરની વસ્તુઓ ક્યારે અને કેવી રીતે દેખાશે તે નક્કી કરી શકાય છે. જેમ કે કોઈ Text ધીમે ધીમે દેખાય, ડાબી બાજુથી આવે અથવા Zoom Effect સાથે દેખાય. |
| 2 | Order Shapes, Images, and Text Boxes | Slide પર રહેલા Shapes, Images અને Text Boxes નો ક્રમ યોગ્ય રીતે ગોઠવી શકાય છે. કોઈ Object ને આગળ લાવવા માટે Bring Forward અથવા Bring to Front અને પાછળ મોકલવા માટે Send Backward અથવા Send to Back વિકલ્પનો ઉપયોગ કરી શકાય છે. |
| 3 | Group Shapes, Images, and Text Boxes | એકથી વધુ Shapes, Images અથવા Text Boxes ને Group કરીને એક Object તરીકે ઉપયોગ કરી શકાય છે. Group કરવાથી બધા Objects ને એકસાથે Move, Resize, Rotate અથવા Format કરી શકાય છે. જરૂર પડે ત્યારે Ungroup કરીને Objects ને ફરીથી અલગ કરી શકાય છે. |
| 4 | Configure Animation Effects | Animation Effect પસંદ કર્યા પછી તેના Options ને Configure કરી શકાય છે. Animation ની Direction, Duration, Delay અને Start Option જેવી Settings બદલી શકાય છે. Start માટે On Click, With Previous અને After Previous જેવા વિકલ્પોનો ઉપયોગ કરી શકાય છે. |
| 5 | Configure Animation Paths | Animation Path દ્વારા કોઈ Object Slide પર ચોક્કસ માર્ગે Move થાય તે નક્કી કરી શકાય છે. વિવિધ Motion Paths પસંદ કરીને Object ને સીધી રેખા, વળાંક અથવા અન્ય માર્ગ પર ચલાવી શકાય છે. જરૂર મુજબ Path ની Direction અને Distance પણ બદલી શકાય છે. |
| 6 | Reorder Animations on a Slide | એક Slide પર ઘણા Animation હોય ત્યારે તેમની Sequence બદલી શકાય છે. Animation Pane માં Animation ને ઉપર અથવા નીચે ખસેડીને તેનો ક્રમ બદલવામાં આવે છે. આથી કયો Object પહેલા અને કયો પછી Animate થશે તે નિયંત્રિત કરી શકાય છે. |
