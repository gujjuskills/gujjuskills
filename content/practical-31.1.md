# પ્રેક્ટિકલ - ૩૧.૧ : લિનક્સમાં ડેસ્કટોપને કસ્ટમાઇઝ કરવું.
| પ્રેક્ટિકલ વિકલ્પ | સામાન્ય માહિતી |
|---|---|
| **New Folder** | ડેસ્કટોપ પર નવું ફોલ્ડર બનાવવા માટે આ વિકલ્પનો ઉપયોગ થાય છે. |
| **Cut – Paste** | પસંદ કરેલી ફાઇલ અથવા ફોલ્ડરને એક સ્થાનેથી કાપીને બીજા સ્થાને મૂકવા માટે ઉપયોગ થાય છે. |
| **Select All** | ડેસ્કટોપ પર રહેલી બધી ફાઇલો અને ફોલ્ડરને એકસાથે પસંદ કરવા માટે ઉપયોગ થાય છે. |
| **Arrange Icon / By** | ડેસ્કટોપ પરના આઇકોનને નામ, કદ, પ્રકાર અથવા અન્ય ક્રમ પ્રમાણે ગોઠવવા માટે ઉપયોગ થાય છે. |
| **Show Desktop in Files** | ડેસ્કટોપમાં રહેલી ફાઇલો અને ફોલ્ડરને File Manager માં જોવા માટે ઉપયોગ થાય છે. |
| **Open in Terminal** | ડેસ્કટોપના સ્થાન પર Terminal ખોલવા માટે આ વિકલ્પનો ઉપયોગ થાય છે. |
| **Change Background** | ડેસ્કટોપનું બેકગ્રાઉન્ડ અથવા વૉલપેપર બદલવા માટે ઉપયોગ થાય છે. |
| **Desktop Icon Settings** | ડેસ્કટોપ પર કયા આઇકોન દેખાડવા અથવા છુપાવવા તે નક્કી કરવા માટે ઉપયોગ થાય છે. |
| **Desktop Settings** | ડેસ્કટોપની દેખાવ, થીમ, આઇકોન, વૉલપેપર વગેરે સંબંધિત સેટિંગ્સ બદલવા માટે ઉપયોગ થાય છે. |
| **Indicators / System Window** | સિસ્ટમની સ્થિતિ, નોટિફિકેશન, નેટવર્ક, અવાજ, બેટરી અને અન્ય સિસ્ટમ વિકલ્પો જોવા તથા નિયંત્રિત કરવા માટે ઉપયોગ થાય છે. |
