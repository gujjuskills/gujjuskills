# પ્રેકટિકલ-૫૩ : Ms-Powerpointમાં ફાઇલ ખોલો

| કૌશલ્ય | સામાન્ય સમજ / કાર્ય |
|---|---|
| **Open MS PowerPoint** | MS PowerPoint ખોલવા માટે **Start Menu → Microsoft Office → PowerPoint** પર ક્લિક કરો. PowerPoint શરૂ થયા પછી નવી પ્રેઝન્ટેશન બનાવી અથવા અગાઉની ફાઇલ ખોલી શકાય છે. |
| **Create a new PowerPoint file** | નવી PowerPoint ફાઇલ બનાવવા માટે **File → New → Blank Presentation** પસંદ કરો. ત્યારબાદ જરૂરી સ્લાઇડ ઉમેરો અને તેમાં શીર્ષક તથા ટેક્સ્ટ દાખલ કરો. |
| **Create a new PowerPoint file from a template** | ટેમ્પલેટમાંથી નવી PowerPoint ફાઇલ બનાવવા માટે **File → New** પસંદ કરો અને ઉપલબ્ધ ટેમ્પલેટમાંથી યોગ્ય ટેમ્પલેટ પસંદ કરો. ત્યારબાદ તેમાં જરૂરી માહિતી ઉમેરો. |
| **Open an existing PowerPoint file** | અગાઉથી બનાવેલી PowerPoint ફાઇલ ખોલવા માટે **File → Open → Browse** પસંદ કરો. જરૂરી `.ppt` અથવા `.pptx` ફાઇલ પસંદ કરીને **Open** પર ક્લિક કરો. |
