# લેશન - ૬૬ : એન્ડ યુજર ડીવાઇઝ અને સ્થાનિક નેટવર્કસની વૈશ્વિક ઈન્ટરનેટ સાથે કેવી રીતે ક્રિયા પ્રતિક્રિયા કરે છે તે સમજાવો

| Topics | માહિતી |
|---|---|
| Network Protocol | નેટવર્કમાં devices વચ્ચે data કેવી રીતે મોકલવો અને પ્રાપ્ત કરવો તેના નિયમોને Network Protocol કહે છે. |
| TCP/IP | TCP/IP એ Internet પર data communication માટે ઉપયોગમાં લેવાતા protocolsનો સમૂહ છે. TCP data ને યોગ્ય રીતે પહોંચાડે છે અને IP data ને યોગ્ય destination સુધી પહોંચાડે છે. |
| HTTP | HTTP (HyperText Transfer Protocol) વેબ browser અને web server વચ્ચે web pages અને અન્ય data મોકલવા માટે વપરાય છે. |
| HTTPS | HTTPS એ HTTPનું સુરક્ષિત સ્વરૂપ છે. તે encryption દ્વારા browser અને server વચ્ચેના dataને સુરક્ષિત રાખે છે. |
| FTP | FTP (File Transfer Protocol) નો ઉપયોગ network અથવા Internet પર files upload અને download કરવા માટે થાય છે. |
| SMTP | SMTP (Simple Mail Transfer Protocol) નો ઉપયોગ email મોકલવા માટે થાય છે. |
| POP3 & IMAP | POP3 અને IMAP email પ્રાપ્ત કરવા માટેના protocols છે. POP3 સામાન્ય રીતે emailને device પર download કરે છે, જ્યારે IMAP emailsને server સાથે synchronize રાખે છે. |
| DNS | DNS (Domain Name System) domain nameને IP addressમાં રૂપાંતરિત કરે છે. ઉદાહરણ તરીકે, websiteનું નામ તેના serverના IP address સાથે શોધી આપે છે. |
| RIP | RIP (Routing Information Protocol) એક routing protocol છે, જે networkમાં data માટે યોગ્ય route શોધવા માટે hop countનો ઉપયોગ કરે છે. |
| OSPF | OSPF (Open Shortest Path First) એક dynamic routing protocol છે, જે સૌથી ઓછા ખર્ચવાળા અથવા shortest path દ્વારા data મોકલવામાં મદદ કરે છે. |
| Gopher | Gopher એક જૂની Internet protocol/service છે, જે hierarchical menu દ્વારા documents અને information શોધવા અને મેળવવા માટે ઉપયોગમાં લેવાતી હતી. |
| Telnet | Telnet એક network protocol છે, જે remote computer અથવા server સાથે command-line દ્વારા જોડાવા માટે વપરાય છે. તેમાં data સામાન્ય રીતે encrypted હોતું નથી. |
| Wi-Fi (802.11) | Wi-Fi એ wireless networking technology છે. IEEE 802.11 standards દ્વારા computers, smartphones અને અન્ય devicesને wireless network સાથે જોડવામાં આવે છે. |
| Cellular Standards (3G, 4G, 5G) | Cellular standards mobile devicesને cellular network દ્વારા Internet અને communication services સાથે જોડે છે. 3G, 4G અને 5G તેમની અલગ અલગ speed અને technology દર્શાવે છે. |
| Standardization Organizations | Standardization Organizations network અને communication માટેના standards બનાવે છે. IEEE, IETF અને ITU જેવી સંસ્થાઓ networking અને Internet technologies માટે standards વિકસાવે છે. |
