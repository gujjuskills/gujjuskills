# પ્રેકટિકલ-૪૬ : ચિત્રો અને ટેક્સ બોક્સ દાખલ કરો

| ટોપિક | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| Shapes દાખલ કરો | MS Word માં વિવિધ આકારો જેમ કે રેખા, તીર, ચોરસ, વર્તુળ વગેરે દાખલ કરવા માટે **Insert → Shapes** નો ઉપયોગ થાય છે. આકારને જરૂર મુજબ રંગ, કદ અને સ્ટાઇલ આપી શકાય છે. |
| Pictures દાખલ કરો | દસ્તાવેજમાં કમ્પ્યુટર અથવા અન્ય સ્થાનેથી ચિત્ર દાખલ કરવા માટે **Insert → Pictures** નો ઉપયોગ થાય છે. ચિત્રનું કદ, સ્થાન અને ટેક્સ્ટની આસપાસનું ગોઠવણ બદલી શકાય છે. |
| 3D Models દાખલ કરો | દસ્તાવેજમાં ત્રિપરિમાણીય મોડેલ દાખલ કરવા માટે **Insert → 3D Models** નો ઉપયોગ થાય છે. 3D મોડેલને ફેરવીને અલગ અલગ દિશામાં જોઈ શકાય છે. |
| SmartArt Graphics દાખલ કરો | માહિતી, પ્રક્રિયા, સંબંધ અથવા સંગઠનને આકર્ષક રીતે દર્શાવવા માટે **Insert → SmartArt** નો ઉપયોગ થાય છે. તેમાં વિવિધ પ્રકારના SmartArt ગ્રાફિક્સ ઉપલબ્ધ હોય છે. |
| Screenshots અને Screen Clippings દાખલ કરો | કમ્પ્યુટર સ્ક્રીનનો ફોટો દસ્તાવેજમાં દાખલ કરવા માટે **Insert → Screenshot** નો ઉપયોગ થાય છે. Screen Clipping દ્વારા સ્ક્રીનના જરૂરી ભાગને પસંદ કરીને દાખલ કરી શકાય છે. |
| Text Boxes દાખલ કરો | દસ્તાવેજમાં ટેક્સ્ટને અલગ બોક્સમાં દર્શાવવા માટે **Insert → Text Box** નો ઉપયોગ થાય છે. Text Box ને ખસેડી, તેનું કદ, રંગ અને સ્ટાઇલ બદલી શકાય છે. |
