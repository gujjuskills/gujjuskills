# પ્રેકટિકલ-૧૨૩ : ફાયરવોલ સાથે પ્રોક્સી સર્વર / DHCP સર્વર સેટ કરો

![image](/images/practical-123.webp)

## કાર્ય કરવાની રીત

1. સર્વર કમ્પ્યુટરને નેટવર્ક સાથે જોડો.
2. સર્વરને યોગ્ય અને સ્થિર IP સરનામું આપો.
3. DHCP સર્વર ઇન્સ્ટોલ કરીને તેનું રૂપરેખાંકન કરો.
4. DHCP સર્વરમાં IP Address Range, Subnet Mask, Gateway અને DNS Server સેટ કરો.
5. પ્રોક્સી સર્વર ઇન્સ્ટોલ કરીને તેનું રૂપરેખાંકન કરો.
6. પ્રોક્સી સર્વર માટે જરૂરી Port Number સેટ કરો.
7. ફાયરવોલ સેટિંગમાં જરૂરી Port ને Allow કરો.
8. અનધિકૃત Port અને ટ્રાફિકને ફાયરવોલ દ્વારા Block કરો.
9. ક્લાયન્ટ કમ્પ્યુટરને DHCP દ્વારા આપમેળે IP Address મેળવવા માટે સેટ કરો.
10. ક્લાયન્ટ કમ્પ્યુટર પર IP Address યોગ્ય રીતે મળ્યું છે કે નહીં તે તપાસો.
11. ક્લાયન્ટમાંથી પ્રોક્સી સર્વર દ્વારા ઇન્ટરનેટ ઍક્સેસ તપાસો.
12. ફાયરવોલ યોગ્ય રીતે ટ્રાફિકને Allow અને Block કરે છે કે નહીં તે ચકાસો.
