# લેશન - ૭૦ : WI FI કેવી રીતે કામ કરે છે.

| Topics | માહિતી |
|---|---|
| **What is Wi-Fi** | Wi-Fi એ એક વાયરલેસ નેટવર્ક ટેકનોલોજી છે, જેના દ્વારા કમ્પ્યુટર, લેપટોપ, સ્માર્ટફોન, ટેબ્લેટ, સ્માર્ટ ટીવી અને અન્ય ઉપકરણોને વાયર વગર નેટવર્ક અથવા ઇન્ટરનેટ સાથે જોડવામાં આવે છે. Wi-Fi રેડિયો તરંગોનો ઉપયોગ કરીને ડેટા મોકલે અને પ્રાપ્ત કરે છે. Wi-Fi કનેક્શન માટે સામાન્ય રીતે રાઉટર અથવા વાયરલેસ એક્સેસ પોઇન્ટનો ઉપયોગ થાય છે. રાઉટર ઇન્ટરનેટ કનેક્શન મેળવીને તેને વાયરલેસ સિગ્નલમાં ફેરવે છે. Wi-Fi ધરાવતું ઉપકરણ આ સિગ્નલને પ્રાપ્ત કરીને ઇન્ટરનેટનો ઉપયોગ કરી શકે છે. |
| **Features of Wi-Fi** | Wi-Fi ની મુખ્ય વિશેષતાઓમાં વાયરલેસ કનેક્ટિવિટી, સરળ ઇન્સ્ટોલેશન, મોબિલિટી અને એક સાથે અનેક ઉપકરણોને કનેક્ટ કરવાની સુવિધાનો સમાવેશ થાય છે. Wi-Fi દ્વારા કેબલ વગર ઇન્ટરનેટનો ઉપયોગ કરી શકાય છે. Wi-Fi નેટવર્કમાં સ્માર્ટફોન, લેપટોપ, કમ્પ્યુટર, પ્રિન્ટર, સ્માર્ટ ટીવી અને અન્ય ઉપકરણોને જોડવામાં આવી શકે છે. Wi-Fi વિવિધ સ્પીડ અને રેન્જ માટે અલગ અલગ ધોરણોને સપોર્ટ કરે છે. Wi-Fi ઘર, ઓફિસ, શાળા, કોલેજ, હોટેલ અને જાહેર સ્થળોએ સરળતાથી ઉપયોગ કરી શકાય છે. |
| **Uses of Wi-Fi** | Wi-Fi નો ઉપયોગ ઇન્ટરનેટ બ્રાઉઝિંગ, ઓનલાઈન અભ્યાસ, ઓનલાઈન મીટિંગ, ઈ-મેઇલ, વિડિયો કોલ, વિડિયો સ્ટ્રીમિંગ અને ઓનલાઈન ગેમિંગ માટે થાય છે. Wi-Fi દ્વારા મોબાઇલ, લેપટોપ અને ટેબ્લેટ જેવા ઉપકરણોને ઇન્ટરનેટ સાથે કનેક્ટ કરી શકાય છે. નેટવર્ક પ્રિન્ટર, સ્માર્ટ ટીવી, સુરક્ષા કેમેરા અને અન્ય સ્માર્ટ ઉપકરણોને જોડવા માટે પણ Wi-Fi ઉપયોગી છે. ઘર અને ઓફિસમાં એક જ ઇન્ટરનેટ કનેક્શનને અનેક ઉપકરણો સાથે શેર કરવા માટે Wi-Fi નો વ્યાપક ઉપયોગ થાય છે. |
| **Advantages of Wi-Fi** | Wi-Fi નો સૌથી મોટો ફાયદો એ છે કે તેમાં નેટવર્ક કનેક્શન માટે દરેક ઉપકરણ સાથે અલગ કેબલ જોડવાની જરૂર પડતી નથી. Wi-Fi દ્વારા વપરાશકર્તા નક્કી કરેલી રેન્જની અંદર એક જગ્યાએથી બીજી જગ્યાએ જઈને ઇન્ટરનેટનો ઉપયોગ કરી શકે છે. એક જ Wi-Fi નેટવર્ક સાથે અનેક ઉપકરણો જોડાઈ શકે છે. Wi-Fi સ્થાપિત કરવું અને તેનો ઉપયોગ કરવો સરળ છે. તે ઘર, ઓફિસ, શાળા અને જાહેર સ્થળો માટે અનુકૂળ છે. Wi-Fi દ્વારા મોબાઇલ ઉપકરણોને સરળતાથી ઇન્ટરનેટ કનેક્શન આપી શકાય છે. |
| **Limitations** | Wi-Fi ની કેટલીક મર્યાદાઓ પણ છે. Wi-Fi સિગ્નલની રેન્જ મર્યાદિત હોય છે અને રાઉટરથી વધુ દૂર જતાં સિગ્નલ નબળું થઈ શકે છે. દિવાલો, દરવાજા અને અન્ય અવરોધો Wi-Fi સિગ્નલની શક્તિ ઘટાડે છે. એક જ સમયે ઘણા ઉપકરણો Wi-Fi સાથે જોડાય ત્યારે નેટવર્કની સ્પીડ ઘટી શકે છે. અન્ય વાયરલેસ ઉપકરણો અથવા નેટવર્કના કારણે સિગ્નલમાં દખલ થઈ શકે છે. યોગ્ય સુરક્ષા ન રાખવામાં આવે તો અનધિકૃત વ્યક્તિ નેટવર્કનો ઉપયોગ કરી શકે છે. |
| **How Does Wi-Fi Works** | Wi-Fi રેડિયો તરંગોની મદદથી કામ કરે છે. સૌપ્રથમ રાઉટર ઇન્ટરનેટ સર્વિસ પ્રોવાઇડર પાસેથી ઇન્ટરનેટ કનેક્શન મેળવે છે. રાઉટર ઇન્ટરનેટમાંથી મળતા ડેટાને વાયરલેસ રેડિયો સિગ્નલમાં રૂપાંતરિત કરે છે. સ્માર્ટફોન અથવા લેપટોપ જેવા Wi-Fi ઉપકરણો આ સિગ્નલને પ્રાપ્ત કરે છે અને તેને ઉપયોગી ડેટામાં ફેરવે છે. જ્યારે વપરાશકર્તા કોઈ વેબસાઇટ ખોલે છે અથવા ડેટા મોકલે છે, ત્યારે ઉપકરણ રેડિયો સિગ્નલ દ્વારા રાઉટરને ડેટા મોકલે છે. રાઉટર આ ડેટાને ઇન્ટરનેટ સુધી પહોંચાડે છે અને મળેલો જવાબ ફરી Wi-Fi દ્વારા ઉપકરણ સુધી પહોંચાડે છે. આ પ્રક્રિયા ખૂબ ઝડપથી થાય છે, તેથી વપરાશકર્તાને ઇન્ટરનેટ સતત કાર્યરત હોય તેમ અનુભવાય છે. |
| **Wi-Fi Standards** | Wi-Fi માટે IEEE 802.11 નામના વાયરલેસ નેટવર્ક ધોરણોનો ઉપયોગ થાય છે. અલગ અલગ સમયગાળા દરમિયાન વિવિધ Wi-Fi ધોરણો વિકસાવવામાં આવ્યા છે. 802.11n ને Wi-Fi 4, 802.11ac ને Wi-Fi 5 અને 802.11ax ને Wi-Fi 6 તરીકે ઓળખવામાં આવે છે. Wi-Fi 6 વધુ કાર્યક્ષમતા અને વધુ ઉપકરણો સાથે સારી કામગીરી માટે બનાવવામાં આવ્યું છે. Wi-Fi 7, જે 802.11be ધોરણ સાથે સંબંધિત છે, વધુ ઝડપ, ઓછો વિલંબ અને વધુ સારી નેટવર્ક કાર્યક્ષમતા માટે વિકસાવવામાં આવ્યું છે. |
| **Alternatives of Wi-Fi** | Wi-Fi ના વિકલ્પ તરીકે Ethernet, Bluetooth, Mobile Data, USB Tethering અને અન્ય વાયરલેસ ટેકનોલોજીનો ઉપયોગ કરી શકાય છે. Ethernet કેબલ દ્વારા સીધું નેટવર્ક કનેક્શન આપે છે અને સામાન્ય રીતે સ્થિર તથા વિશ્વસનીય કનેક્શન માટે ઉપયોગી છે. Bluetooth નો ઉપયોગ નજીકના ઉપકરણો વચ્ચે ડેટા ટ્રાન્સફર અને વાયરલેસ કનેક્શન માટે થાય છે. Mobile Data દ્વારા મોબાઇલ નેટવર્કનો ઉપયોગ કરીને ઇન્ટરનેટ મેળવી શકાય છે. USB Tethering દ્વારા મોબાઇલ ફોનનું ઇન્ટરનેટ કનેક્શન USB કેબલ મારફતે કમ્પ્યુટર સાથે શેર કરી શકાય છે. |
