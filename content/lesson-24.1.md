# લેશન - ૨૪.૧ : મેઇલિંગ ટેબ: MS-WORD
![image](/gujjuskills/images/practical-24.1.png)
| Mailings tab | ઉપયોગ |
|:---:|---|
| એન્વેલપ્સ (Envelopes) | પત્ર મોકલવા માટે એન્વેલપ પર સરનામું અને રિટર્ન એડ્રેસ તૈયાર કરવા માટે ઉપયોગ થાય છે. |
| લેબલ્સ (Labels) | સરનામાં, નામ અથવા અન્ય માહિતી ધરાવતા લેબલ બનાવવા અને પ્રિન્ટ કરવા માટે ઉપયોગ થાય છે. |
| સ્ટાર્ટ મેઇલ મર્જ (Start Mail Merge) | મેઇલ મર્જ પ્રક્રિયા શરૂ કરવા અને દસ્તાવેજનો પ્રકાર પસંદ કરવા માટે ઉપયોગ થાય છે. |
| સિલેક્ટ રિસિપિયન્ટ્સ (Select Recipients) | મેઇલ મર્જ માટે પ્રાપ્તકર્તાઓની યાદી અથવા ડેટા સ્રોત પસંદ કરવા માટે ઉપયોગ થાય છે. |
| એડિટ રિસિપિયન્ટ લિસ્ટ (Edit Recipient List) | પ્રાપ્તકર્તાઓની યાદીમાં ફેરફાર, પસંદગી અથવા ફિલ્ટર કરવા માટે ઉપયોગ થાય છે. |
| હાઇલાઇટ મર્જ ફીલ્ડ્સ (Highlight Merge Fields) | દસ્તાવેજમાં મર્જ ફીલ્ડ્સને હાઇલાઇટ કરીને સરળતાથી ઓળખવા માટે ઉપયોગ થાય છે. |
| એડ્રેસ બ્લોક (Address Block) | પ્રાપ્તકર્તાનું નામ અને સરનામું યોગ્ય ફોર્મેટમાં દસ્તાવેજમાં ઉમેરવા માટે ઉપયોગ થાય છે. |
| ગ્રીટિંગ લાઇન (Greeting Line) | પ્રાપ્તકર્તા માટે અભિવાદન અથવા શુભેચ્છા લાઇન ઉમેરવા માટે ઉપયોગ થાય છે. |
| ઇન્સર્ટ મર્જ ફીલ્ડ (Insert Merge Field) | ડેટા સ્રોતમાંથી નામ, સરનામું, ફોન નંબર વગેરે ચોક્કસ ફીલ્ડ દસ્તાવેજમાં ઉમેરવા માટે ઉપયોગ થાય છે. |
| રૂલ્સ (Rules) | મેઇલ મર્જમાં શરતો અને નિયમો લાગુ કરવા માટે ઉપયોગ થાય છે. |
| મેચ ફીલ્ડ્સ (Match Fields) | ડેટા સ્રોતના ફીલ્ડ્સને Wordના સંબંધિત ફીલ્ડ્સ સાથે જોડવા માટે ઉપયોગ થાય છે. |
| અપડેટ લેબલ્સ (Update Labels) | પ્રથમ લેબલની માહિતી અને ફોર્મેટિંગને બાકીના લેબલ્સમાં લાગુ કરવા માટે ઉપયોગ થાય છે. |
| પ્રીવ્યૂ રિઝલ્ટ્સ (Preview Results) | મેઇલ મર્જ કર્યા પછી દરેક પ્રાપ્તકર્તા માટે તૈયાર થનારી માહિતીનું પૂર્વાવલોકન કરવા માટે ઉપયોગ થાય છે. |
| ગો ટુ (Go To) | મેઇલ મર્જના વિવિધ રેકોર્ડ વચ્ચે આગળ અથવા પાછળ જવા માટે ઉપયોગ થાય છે. |
| ફાઇન્ડ રિસિપિયન્ટ (Find Recipient) | પ્રાપ્તકર્તાઓની યાદીમાં ચોક્કસ વ્યક્તિ અથવા રેકોર્ડ શોધવા માટે ઉપયોગ થાય છે. |
| ઓટો ચેક ફોર એરર્સ (Auto Check for Errors) | મેઇલ મર્જ દસ્તાવેજમાં રહેલી સંભવિત ભૂલો તપાસવા માટે ઉપયોગ થાય છે. |
| ફિનિશ એન્ડ મર્જ (Finish & Merge) | મેઇલ મર્જ પ્રક્રિયા પૂર્ણ કરીને દસ્તાવેજોને પ્રિન્ટ, એડિટ અથવા નવા દસ્તાવેજ તરીકે તૈયાર કરવા માટે ઉપયોગ થાય છે. |
