# ES-1.2 : કાર્યના ભવિષ્યનું અન્વેષણ કરો

### 2.1 Future of Work એટલે શું?
**Future of Work** એટલે ભવિષ્યમાં નોકરીઓ, કાર્યસ્થળો, કામ કરવાની રીતો અને જરૂરી કુશળતાઓમાં થનારા ફેરફારો. ટેકનોલોજી અને ડિજિટલ સાધનોના ઉપયોગથી અનેક ક્ષેત્રોમાં કામ કરવાની રીત બદલાઈ રહી છે.

ઉદાહરણ તરીકે, પહેલાં કેટલીક સંસ્થાઓમાં તમામ રેકોર્ડ કાગળ પર રાખવામાં આવતા હતા. હવે ઘણી જગ્યાએ કમ્પ્યુટર, સ્પ્રેડશીટ અને ડિજિટલ સિસ્ટમ દ્વારા રેકોર્ડ રાખવામાં આવે છે.

### 2.2 નોકરીઓ અને કાર્યસ્થળોમાં થતા ફેરફારો
- **Digital Technology:** કમ્પ્યુટર, મોબાઇલ એપ્લિકેશન અને ઑનલાઇન સિસ્ટમ દ્વારા કામ.
- **Automation:** કેટલીક પુનરાવર્તિત કામગીરી મશીન અથવા સોફ્ટવેર દ્વારા કરવી.
- **Artificial Intelligence (AI):** માહિતી સમજવા, વિશ્લેષણ કરવા અથવા અમુક કાર્યોમાં સહાય માટે AI નો ઉપયોગ.
- **Remote અથવા Hybrid Work:** કેટલીક નોકરીઓમાં ઓફિસની બહારથી અથવા ઓફિસ અને ઘર બંનેમાંથી કામ.
- **Freelancing અને Platform Based Work:** પ્રોજેક્ટ અથવા સેવા આધારે કામ મેળવવું.

આ વિકલ્પો દરેક ટ્રેડ અથવા નોકરીમાં સમાન રીતે ઉપલબ્ધ હોય એવું જરૂરી નથી.

### 2.3 ભવિષ્ય માટે ઉપયોગી કુશળતાઓ
| Skill | ઉપયોગ |
|---|---|
| Digital Literacy | ડિજિટલ સાધનોનો યોગ્ય ઉપયોગ |
| Communication | ગ્રાહક અને ટીમ સાથે સ્પષ્ટ સંવાદ |
| Problem Solving | નવી સમસ્યાનો ઉકેલ શોધવો |
| Adaptability | નવી ટેકનોલોજી અને પ્રક્રિયા શીખવી |
| Teamwork | સહકારથી કામ કરવું |
| Continuous Learning | સતત નવી કુશળતા વિકસાવવી |

### 2.4 Continuous Learning
**Continuous Learning** એટલે સતત નવી માહિતી અને કુશળતાઓ શીખતા રહેવું. ટેકનોલોજી, કામની પદ્ધતિઓ અને ગ્રાહકોની જરૂરિયાતો બદલાતી રહેતી હોવાથી શીખવાની પ્રક્રિયા ચાલુ રાખવી ઉપયોગી છે.

ઉદાહરણ: Excel ની મૂળભૂત કામગીરી જાણતો વિદ્યાર્થી આગળ Formulas, Charts અને અન્ય ઉપયોગી સુવિધાઓ શીખે છે.

### 2.5 Self-Learner કેવી રીતે બનવું?
Self-Learner એવી વ્યક્તિ છે જે પોતાની પહેલથી શીખવાનો પ્રયાસ કરે છે.
1. શીખવાનો હેતુ નક્કી કરો.
2. વિશ્વસનીય પુસ્તક, તાલીમ સામગ્રી અથવા શૈક્ષણિક વિડિયો પસંદ કરો.
3. જાતે પ્રેક્ટિસ કરો.
4. ભૂલ થાય તો તેનું કારણ શોધો.
5. જરૂર પડે ત્યારે શિક્ષક અથવા અનુભવી વ્યક્તિની મદદ લો.
6. પોતાની પ્રગતિ તપાસો.

### 2.6 પ્રવૃત્તિ: મારી ભવિષ્યની કુશળતા
1. મારા ટ્રેડમાં કયા ડિજિટલ સાધનો વપરાય છે?
2. ભવિષ્યમાં મારે કઈ નવી કુશળતા શીખવી છે?
3. હું તે ક્યાંથી શીખી શકું?
4. દર અઠવાડિયે શીખવા માટે કેટલો સમય આપીશ?

### 2.7 પુનરાવર્તન પ્રશ્નો
1. Future of Work નો અર્થ સમજાવો.
2. કામ કરવાની રીતોમાં ફેરફાર લાવતાં બે પરિબળો જણાવો.
3. Continuous Learning શું છે?
4. Self-Learner બનવા માટેની ચાર રીતો લખો.
