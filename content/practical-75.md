# પ્રેકટિકલ-૭૫ : MS-EXCEL માં ફાઇલ ખોલો

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| **Open MS Excel** | કમ્પ્યુટરમાં **Start Menu** અથવા **Search** દ્વારા MS Excel શોધીને તેના પર ક્લિક કરો. MS Excel ખુલશે અને તેની મુખ્ય વિન્ડો દેખાશે. |
| **Create a new Excel file** | MS Excel ખોલ્યા પછી **File → New → Blank Workbook** પસંદ કરો. નવી Excel વર્કબુક ખુલશે, જેમાં તમે ડેટા દાખલ કરી શકો છો. |
| **Create a new Excel file from a template** | **File → New** પર ક્લિક કરીને ઉપલબ્ધ **Template** પસંદ કરો. જરૂરી Template પસંદ કર્યા પછી **Create** પર ક્લિક કરો. |
| **Open an existing Excel file** | **File → Open** પર ક્લિક કરો અથવા **Ctrl + O** દબાવો. ત્યારબાદ જરૂરી Excel ફાઇલનું સ્થાન પસંદ કરીને ફાઇલ પર ડબલ ક્લિક કરો. |
