# લેશન - ૯૩ : GITHUBનો પરિચય


 **GitHub શું છે?**  GitHub એ એક ઓનલાઈન પ્લેટફોર્મ છે, જ્યાં ડેવલપર્સ પોતાના કોડને સ્ટોર, મેનેજ અને અન્ય લોકો સાથે શેર કરી શકે છે. તે Git વર્ઝન કંટ્રોલ સિસ્ટમનો ઉપયોગ કરે છે. 

### GitHub ના ઉપયોગો

| ઉપયોગ | માહિતી |
|---|---|
| **Version Control** | કોડમાં થયેલા ફેરફારોને ટ્રેક કરવા અને અગાઉના વર્ઝન પર પાછા જવા માટે ઉપયોગી છે. |
| **Collaboration** | એકથી વધુ લોકો સાથે મળીને એક જ પ્રોજેક્ટ પર કામ કરવા માટે ઉપયોગી છે. |
| **Code Storage** | પ્રોજેક્ટના સોર્સ કોડને ઓનલાઈન સુરક્ષિત રીતે સ્ટોર કરવા માટે ઉપયોગી છે. |
| **Open Source** | ઓપન સોર્સ પ્રોજેક્ટમાં કોડ શેર કરવા અને તેમાં યોગદાન આપવા માટે ઉપયોગી છે. |
| **Portfolio** | ડેવલપર્સ પોતાના પ્રોજેક્ટ અને કોડનું પોર્ટફોલિયો બનાવવા માટે GitHub નો ઉપયોગ કરી શકે છે. |
| **Project Management** | Issues, Projects અને અન્ય સુવિધાઓ દ્વારા પ્રોજેક્ટના કાર્યોને મેનેજ કરવા માટે ઉપયોગી છે. |
| **Hosting** | GitHub Pages જેવી સુવિધા દ્વારા વેબસાઇટને હોસ્ટ કરવા માટે ઉપયોગી છે. |

### GitHub નો વર્કફ્લો

| ક્રમ | પ્રક્રિયા | માહિતી |
|---|---|---|
| **1** | **Clone** | GitHub પર રહેલા રિપોઝિટરીને પોતાના કમ્પ્યુટરમાં કોપી કરવા માટે Clone નો ઉપયોગ કરવામાં આવે છે. |
| **2** | **Commit** | કોડમાં કરેલા ફેરફારોને લોકલી સેવ કરીને તેનો રેકોર્ડ બનાવવા માટે Commit કરવામાં આવે છે. |
| **3** | **Push** | લોકલ કમ્પ્યુટરમાં કરેલા Commit અને ફેરફારોને GitHub રિપોઝિટરીમાં મોકલવા માટે Push કરવામાં આવે છે. |
| **4** | **Pull** | GitHub રિપોઝિટરીમાંથી નવીનતમ ફેરફારોને પોતાના લોકલ કમ્પ્યુટરમાં મેળવવા માટે Pull કરવામાં આવે છે. |
