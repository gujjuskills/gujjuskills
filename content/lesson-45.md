# લેશન - ૪૫ : ડેટા મૉડેલિંગ અને વિઝ્યુલાઇઝેશન

 ### **ડેટા મોડેલિંગ અને વિઝ્યુઅલાઇઝેશન શું છે?** 
 
 ડેટા મોડેલિંગ એટલે વિવિધ ડેટાને વ્યવસ્થિત રીતે ગોઠવીને તેમની વચ્ચે સંબંધ સ્થાપિત કરવાની પ્રક્રિયા. ડેટા વિઝ્યુઅલાઇઝેશન એટલે ડેટાને ચાર્ટ, ગ્રાફ અને ડેશબોર્ડ દ્વારા સરળતાથી સમજાય તે રીતે રજૂ કરવું. 

### ડેટા મોડેલિંગ શું છે?

**ડેટા મોડેલિંગ** એટલે ડેટાને વ્યવસ્થિત રીતે ટેબલમાં ગોઠવીને વિવિધ ટેબલ વચ્ચે **સંબંધ (Relationship)** બનાવવાની પ્રક્રિયા.

1. ડેટાને ટેબલમાં ગોઠવવું.
2. ટેબલ વચ્ચે સંબંધ બનાવવો.
3. ડેટાનું વિશ્લેષણ સરળ બનાવવું.
4. Excel માં **Power Pivot** દ્વારા તેનો ઉપયોગ કરી શકાય છે.
   
| વિષય | માહિતી |
|---|---|
| **Power Pivot** | Power Pivot એ Excel નું શક્તિશાળી ટૂલ છે, જેનો ઉપયોગ મોટા પ્રમાણમાં ડેટાનું વિશ્લેષણ, વિવિધ ટેબલને જોડવા અને ડેટા મોડેલ બનાવવા માટે થાય છે. |
| **Data Relationships** | Data Relationships એટલે બે અથવા વધુ ટેબલ વચ્ચે સંબંધ બનાવવો. જેમ કે Customer ID અથવા Product ID દ્વારા અલગ અલગ ટેબલના ડેટાને જોડવા. |
| **DAX** | DAX (Data Analysis Expressions) એ Excel Power Pivot માં ગણતરી, Measure અને Calculated Column બનાવવા માટે વપરાતી ફોર્મ્યુલા ભાષા છે. |

**વિઝ્યુઅલાઇઝેશન શું છે?**

 ડેટાને ચાર્ટ, ગ્રાફ, ટેબલ અને ડેશબોર્ડ જેવા દૃશ્ય સ્વરૂપમાં રજૂ કરવાની પ્રક્રિયાને વિઝ્યુઅલાઇઝેશન કહે છે.

| વિષય | માહિતી |
|---|---|
| **Pivot Tables** | મોટા ડેટામાંથી સારાંશ, સરવાળો, સરેરાશ અને અન્ય વિશ્લેષણ ઝડપથી કરવા માટે Pivot Table નો ઉપયોગ થાય છે. |
| **Advanced Charts** | ડેટાને વધુ અસરકારક રીતે રજૂ કરવા માટે Combo Chart, Line Chart, Bar Chart, Pie Chart વગેરે જેવા અદ્યતન ચાર્ટનો ઉપયોગ થાય છે. |
| **Conditional Formatting** | ચોક્કસ શરત અથવા નિયમના આધારે સેલને રંગ, આઇકન અથવા ડેટા બાર દ્વારા હાઇલાઇટ કરવાની સુવિધા છે. |
| **Interactive Dashboard** | ચાર્ટ, Pivot Table, Slicer અને અન્ય વિઝ્યુઅલ્સની મદદથી ડેટાને એક જ જગ્યાએ ઇન્ટરેક્ટિવ રીતે રજૂ કરતું ડેશબોર્ડ. |
