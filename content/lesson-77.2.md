# લેશન - ૭૭.૨ : HTML : ફોર્મ ઈનપુટ ટાઈપ

| HTML Form Input Type |
|---|
| `text` – ટેક્સ્ટ દાખલ કરવા માટે |
| `password` – પાસવર્ડ દાખલ કરવા માટે |
| `email` – ઈમેલ સરનામું દાખલ કરવા માટે |
| `number` – સંખ્યા દાખલ કરવા માટે |
| `date` – તારીખ પસંદ કરવા માટે |
| `time` – સમય પસંદ કરવા માટે |
| `datetime-local` – તારીખ અને સમય પસંદ કરવા માટે |
| `month` – મહિનો અને વર્ષ પસંદ કરવા માટે |
| `week` – અઠવાડિયું પસંદ કરવા માટે |
| `color` – રંગ પસંદ કરવા માટે |
| `checkbox` – એક અથવા વધુ વિકલ્પ પસંદ કરવા માટે |
| `radio` – એક વિકલ્પ પસંદ કરવા માટે |
| `file` – ફાઇલ પસંદ કરવા માટે |
| `hidden` – છુપાયેલ ડેટા રાખવા માટે |
| `range` – રેન્જ અથવા મૂલ્ય પસંદ કરવા માટે |
| `search` – શોધ કરવા માટે |
| `tel` – ફોન નંબર દાખલ કરવા માટે |
| `url` – વેબ સરનામું દાખલ કરવા માટે |
| `submit` – ફોર્મ સબમિટ કરવા માટે |
| `reset` – ફોર્મનું ડેટા રીસેટ કરવા માટે |
| `button` – બટન બનાવવા માટે |
| `image` – ઈમેજ બટન બનાવવા માટે |
