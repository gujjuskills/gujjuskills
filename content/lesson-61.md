# લેશન - ૬૧ : લોકલ નેટવર્કસ

| Topics | માહિતી |
|---|---|
| Local Area Network | LAN એટલે Local Area Network. તે નાના ભૌગોલિક વિસ્તારમાં આવેલા કમ્પ્યુટર અને અન્ય ઉપકરણોને જોડતું નેટવર્ક છે. તેનો ઉપયોગ ઘર, શાળા, ઓફિસ અને કમ્પ્યુટર લેબમાં થાય છે. |
| Main Components | LAN ના મુખ્ય ઘટકોમાં કમ્પ્યુટર, સર્વર, નેટવર્ક સ્વિચ, રાઉટર, નેટવર્ક કેબલ, નેટવર્ક કાર્ડ અને કનેક્ટરનો સમાવેશ થાય છે. |
| Wireless LAN | Wireless LAN એટલે વાયર વગરનું સ્થાનિક નેટવર્ક. તેમાં Wi-Fi દ્વારા કમ્પ્યુટર, મોબાઇલ અને અન્ય ઉપકરણોને નેટવર્ક સાથે જોડવામાં આવે છે. |
| Benefits of LAN | LAN દ્વારા ફાઇલો અને ડેટા સરળતાથી શેર કરી શકાય છે. પ્રિન્ટર અને અન્ય સાધનોનો સામૂહિક ઉપયોગ કરી શકાય છે. ઝડપી ડેટા ટ્રાન્સફર થાય છે અને નેટવર્ક સંસાધનોનો કાર્યક્ષમ ઉપયોગ થાય છે. |
