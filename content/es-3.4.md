# ES-3.4 : ઇન્ટરનેટનો ઉપયોગ અને ઓનલાઇન સલામતી

## ❖ Internet શું છે?
Internet વિશ્વભરના કમ્પ્યુટરો અને ઉપકરણોને જોડતું વિશાળ નેટવર્ક છે. તેનો ઉપયોગ માહિતી મેળવવા, શીખવા, સંવાદ કરવા, ઑનલાઇન સેવાઓ વાપરવા અને નોકરીની તકો શોધવા માટે થાય છે.

## ❖ Search Engine નો ઉપયોગ
Search Engine દ્વારા માહિતી શોધી શકાય છે. શોધતી વખતે સ્પષ્ટ Keywords લખો. ઉદાહરણ: “ITI electrician apprenticeship eligibility” અથવા “Excel beginner tutorial”.

મળેલી માહિતી માટે નીચેની બાબતો તપાસો:
- માહિતી કોણે પ્રકાશિત કરી છે?
- પ્રકાશનની તારીખ શું છે?
- માહિતી સત્તાવાર અથવા વિશ્વસનીય સ્ત્રોતમાંથી છે?
- અન્ય વિશ્વસનીય સ્ત્રોતો પણ એ જ માહિતી સમર્થિત કરે છે?

## ❖ Online Safety
- મજબૂત અને અલગ Password વાપરો.
- OTP, Password અથવા બેંકની ગુપ્ત માહિતી કોઈને ન આપો.
- અજાણી Link અથવા Attachment ખોલતાં પહેલાં તપાસો.
- શંકાસ્પદ Job Offer માટે પહેલાં પૈસા ચૂકવવા કહેવામાં આવે તો સાવચેત રહો.
- Software અને ઉપકરણો અપડેટ રાખો.
- જાહેર કમ્પ્યુટર પર કામ પછી Sign Out કરો.
- વ્યક્તિગત માહિતી જાહેર રીતે શેર કરતાં પહેલાં વિચાર કરો.

## ❖ Online Scams ની ચેતવણી
શંકાસ્પદ સંકેતોમાં અતિશય મોટા વચનો, તાત્કાલિક નિર્ણય લેવા દબાણ, અસ્પષ્ટ કંપનીની વિગતો, અજાણી Link અને OTP માંગવી સામેલ હોઈ શકે છે. શંકા હોય તો સત્તાવાર વેબસાઇટ અથવા જાણીતા સંપર્ક દ્વારા માહિતી ચકાસો.

## ❖ પ્રાયોગિક પ્રવૃત્તિ
1. પોતાના ટ્રેડ માટે એક શૈક્ષણિક માહિતી શોધો.
2. બે સ્ત્રોતોની તુલના કરો.
3. એક સંભવિત શંકાસ્પદ સંદેશમાં કયા સંકેતો તપાસશો તે લખો.
4. મજબૂત Password બનાવવા માટેના ત્રણ નિયમ લખો. વાસ્તવિક Password અહીં લખશો નહીં.

## ❖ પુનરાવર્તન પ્રશ્નો
1. Internet ના ત્રણ ઉપયોગ જણાવો.
2. Search Engine માં Keywords શા માટે ઉપયોગી છે?
3. Online Scam ના ચાર સંકેતો લખો.
4. OTP અને Password ગુપ્ત રાખવા શા માટે જરૂરી છે?
