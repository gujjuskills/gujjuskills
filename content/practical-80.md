# પ્રેકટિકલ-૮૦ : કોલોબ્રેશન માટે સામગ્રીને ગોઠવો : MS-EXCEL

| Topic | ગુજરાતી વિગત |
|---|---|
| **Set a print area** | **Print Area સેટ કરવું:** Worksheet માંથી માત્ર જરૂરી ભાગને જ Print કરવા માટે પહેલા જરૂરી Cells Select કરો. ત્યારબાદ **Page Layout → Print Area → Set Print Area** પસંદ કરો. હવે Print કરતી વખતે માત્ર પસંદ કરેલો વિસ્તાર જ Print થશે. Print Area દૂર કરવા માટે **Page Layout → Print Area → Clear Print Area** પસંદ કરો. |
| **Save workbooks in alternative file formats** | **Workbook ને અલગ File Format માં Save કરવું:** Excel Workbook ને જરૂરિયાત મુજબ અલગ અલગ Format માં Save કરી શકાય છે. **File → Save As** પસંદ કરો અને **Save as type** માં જરૂરી Format પસંદ કરો, જેમ કે **Excel Workbook (.xlsx), Excel 97-2003 Workbook (.xls), PDF (.pdf), CSV (.csv)** વગેરે. ત્યારબાદ **Save** પર Click કરો. |
| **Configure print settings** | **Print Settings ગોઠવવી:** Worksheet Print કરતા પહેલાં Page ને યોગ્ય રીતે ગોઠવવા માટે **File → Print** અથવા **Page Layout** નો ઉપયોગ કરો. અહીં **Printer, Number of Copies, Page Orientation (Portrait/Landscape), Paper Size, Margins, Scaling** અને **Print Selection/Active Sheets/Entire Workbook** જેવી Settings પસંદ કરી શકાય છે. Print Preview દ્વારા Print પહેલાં પરિણામ ચકાસી શકાય છે. |
