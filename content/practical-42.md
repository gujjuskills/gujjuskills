# પ્રેકટિકલ-૪૨ : ટેબલોમાં ફેરફાર કરો

| ટોપિક | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| Sort table data | ટેબલમાં રહેલા ડેટાને ચડતા અથવા ઉતરતા ક્રમમાં ગોઠવવા માટે Sort વિકલ્પનો ઉપયોગ થાય છે. ટેક્સ્ટ, નંબર અથવા તારીખના આધારે ડેટા ગોઠવી શકાય છે. |
| Configure cell margins and spacing | સેલની અંદરના લખાણ અને સેલની બોર્ડર વચ્ચેનું અંતર Cell Margins દ્વારા ગોઠવી શકાય છે. સેલ વચ્ચેનું અંતર પણ જરૂરી મુજબ સેટ કરી શકાય છે. |
| Merge and split cells | બે અથવા વધુ સેલને એક સેલમાં જોડવા માટે Merge Cells નો ઉપયોગ થાય છે. એક સેલને બે અથવા વધુ સેલમાં વિભાજિત કરવા માટે Split Cells નો ઉપયોગ થાય છે. |
| Resize tables, rows, and columns | ટેબલની પહોળાઈ અને ઊંચાઈ, તેમજ Row અને Column નું કદ જરૂરિયાત મુજબ વધારી અથવા ઘટાડી શકાય છે. |
| Split tables | એક ટેબલને બે અલગ અલગ ટેબલમાં વિભાજિત કરવા માટે Split Table વિકલ્પનો ઉપયોગ થાય છે. જ્યાંથી ટેબલ વિભાજિત કરવું હોય ત્યાં કર્સર રાખીને આ વિકલ્પ પસંદ કરી શકાય છે. |
| Configure a repeating row header | લાંબા ટેબલમાં દરેક નવા પેજ પર ટેબલની Header Row ફરીથી દર્શાવવા માટે Repeat Header Rows વિકલ્પનો ઉપયોગ થાય છે. |
