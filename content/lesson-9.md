# લેશન - ૯ : ઓપરેટિંગ સિસ્ટમનો પરિચય

## OS શું છે?

**ઓપરેટિંગ સિસ્ટમ (OS)** એ એક સિસ્ટમ સોફ્ટવેર છે, જે કમ્પ્યુટરના હાર્ડવેર અને સોફ્ટવેર વચ્ચે સંકલન કરે છે અને કમ્પ્યુટરના સંસાધનોનું સંચાલન કરે છે.

## OS ના પ્રકાર અને વિશેષતાઓ

| OS નો પ્રકાર | વિશેષતા |
|---|---|
| **સિંગલ યુઝર (સિંગલ ટાસ્કિંગ)** | એક સમયે એક જ વપરાશકર્તા અને એક જ કાર્ય કરી શકે છે. |
| **સિંગલ યુઝર (મલ્ટી ટાસ્કિંગ)** | એક વપરાશકર્તા એક જ સમયે એકથી વધુ કાર્યો કરી શકે છે. |
| **મલ્ટી યુઝર** | એક જ સમયે અનેક વપરાશકર્તાઓ કમ્પ્યુટર સિસ્ટમનો ઉપયોગ કરી શકે છે. |
| **બેચ પ્રોસેસિંગ** | સમાન પ્રકારના અનેક કાર્યોને એક જૂથ એટલે કે બેચમાં એકસાથે પ્રક્રિયા કરવામાં આવે છે. |
| **રીયલ ટાઈમ** | ડેટા અથવા ઘટનાની પ્રક્રિયા ખૂબ જ ઓછા સમયમાં કરીને તરત જ પરિણામ આપે છે. |
| **ટાઈમ શેરિંગ** | CPU નો સમય અનેક વપરાશકર્તાઓ અથવા કાર્યો વચ્ચે વહેંચવામાં આવે છે. |
| **નેટવર્ક** | નેટવર્ક સાથે જોડાયેલા કમ્પ્યુટરો વચ્ચે સંસાધનો અને માહિતીની આપલે કરવામાં મદદ કરે છે. |
| **ડિસ્ટ્રિબ્યુટેડ** | અનેક કમ્પ્યુટરોની કામગીરીને એક સિસ્ટમની જેમ સંકલિત કરીને કાર્ય કરવામાં આવે છે. |
| **મોબાઇલ** | મોબાઇલ અને અન્ય પોર્ટેબલ ઉપકરણો માટે બનાવવામાં આવેલી ઓપરેટિંગ સિસ્ટમ. |
