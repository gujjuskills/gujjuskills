# પ્રેકટિકલ-૮૭ : રેફરન્સ દાખલ કરો : MS-EXCEL

| Topic | ગુજરાતી સમજૂતી |
|---|---|
| Insert relative, absolute, and mixed references | **Relative Reference:** Formula ને બીજી cell માં copy અથવા drag કરવાથી cell reference આપમેળે બદલાય છે. ઉદાહરણ તરીકે, `=A2+B2` ને નીચે copy કરવાથી તે `=A3+B3` બની જાય છે. **Absolute Reference:** Cell reference ને સ્થિર રાખવા માટે `$` ચિહ્નનો ઉપયોગ થાય છે. ઉદાહરણ તરીકે, `=$A$2*B2` માં `A2` હંમેશા સ્થિર રહેશે, જ્યારે `B2` copy કરતી વખતે બદલાશે. **Mixed Reference:** Row અથવા Column માંથી કોઈ એકને સ્થિર રાખવામાં આવે છે. `=$A2` માં Column A સ્થિર છે પરંતુ Row બદલાય છે. `=A$2` માં Row 2 સ્થિર છે પરંતુ Column બદલાય છે. આ references નો ઉપયોગ ખાસ કરીને formulas ને copy અથવા drag કરતી વખતે ચોક્કસ cell ને સ્થિર રાખવા માટે થાય છે. |
| Reference named ranges and named tables in formulas | **Named Range:** Excel માં કોઈ cell અથવા cells ના group ને સરળ નામ આપી શકાય છે. ઉદાહરણ તરીકે `A2:A10` ને `Sales` નામ આપ્યા પછી `=SUM(Sales)` લખીને કુલ મેળવી શકાય છે. Named Range formulas ને સમજવામાં સરળ બનાવે છે અને cell addresses યાદ રાખવાની જરૂર રહેતી નથી. **Named Table:** Excel Table ને નામ આપ્યા પછી તેના column names નો સીધો formula માં ઉપયોગ કરી શકાય છે. ઉદાહરણ તરીકે `SalesTable[Amount]` આખા Amount column ને દર્શાવે છે અને `=SUM(SalesTable[Amount])` થી Amount column નો કુલ મેળવી શકાય છે. Table માં નવી rows ઉમેરવામાં આવે ત્યારે named table reference સામાન્ય રીતે આપમેળે નવા data ને પણ આવરી લે છે. તેથી મોટા data સાથે કામ કરતી વખતે Named Ranges અને Named Tables formulas ને વધુ સરળ, વાંચવામાં સ્પષ્ટ અને વ્યવસ્થિત બનાવે છે. |
