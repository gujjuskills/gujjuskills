# પ્રેકટિકલ-૧૨૮.૧૦ : HTML-10 : લિસ્ટિંગ ટેગનો ઉપયોગ
``` text 
<!DOCTYPE html>
<html>
<head>
    <title>Use of Listing Tags</title>
</head>
<body>

    <h1>Use of Listing Tags</h1>

    <h2>An Unordered List</h2>

    <ul>
        <li>Computer</li>
        <li>Hard Disk</li>
        <li>Mother Board</li>
    </ul>

    <h2>An Ordered List</h2>

    <ol>
        <li>Computer</li>
        <li>Hard Disk</li>
        <li>Mother Board</li>
    </ol>

    <h2>A Description List</h2>

    <dl>
        <dt>Computer</dt>
        <dd>Its an electronic Device.</dd>

        <dt>Hard Disk</dt>
        <dd>Its an Storage Device.</dd>

        <dt>Keyboard</dt>
        <dd>Its an Input Device.</dd>
    </dl>

</body>
</html>

```
