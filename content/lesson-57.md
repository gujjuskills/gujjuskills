# લેશન - ૫૭ : ક્વેરીમાં વપરાતા ફંક્શનો

## MySQL String Functions

| ફંક્શન | ગુજરાતી ઉપયોગ / અર્થ |
|---|---|
| ASCII | અક્ષરનું ASCII કોડ નંબર આપે છે. |
| CONCAT | બે અથવા વધુ String ને જોડે છે. |
| FORMAT | સંખ્યાને નિર્ધારિત Decimal સ્થાન સાથે Format કરે છે. |
| INSERT | String માં ચોક્કસ સ્થાનેથી અક્ષરો બદલે છે. |
| INSTR | String માં આપેલ Substring કયા સ્થાન પર છે તે શોધે છે. |
| LEFT | String ની ડાબી બાજુના નિર્ધારિત અક્ષરો આપે છે. |
| LENGTH | String ની લંબાઈ Bytes માં આપે છે. |
| LOCATE | String માં Substring નું સ્થાન શોધે છે. |
| LOWER | String ના બધા અક્ષરોને નાના અક્ષરોમાં ફેરવે છે. |
| LTRIM | String ની ડાબી બાજુના વધારાના Space દૂર કરે છે. |
| SUBSTR | String માંથી નિર્ધારિત ભાગ કાઢે છે. |
| REPEAT | String ને નિર્ધારિત વખત પુનરાવર્તિત કરે છે. |
| REPLACE | String માંના આપેલ અક્ષર અથવા શબ્દને બીજા અક્ષર અથવા શબ્દથી બદલે છે. |
| REVERSE | String ને ઉલટાવીને આપે છે. |
| RIGHT | String ની જમણી બાજુના નિર્ધારિત અક્ષરો આપે છે. |
| RTRIM | String ની જમણી બાજુના વધારાના Space દૂર કરે છે. |
| STRCMP | બે String ની સરખામણી કરે છે. |
| TRIM | String ની શરૂઆત અને અંતના વધારાના Space દૂર કરે છે. |
| UPPER | String ના બધા અક્ષરોને મોટા અક્ષરોમાં ફેરવે છે. |

## MySQL Numeric Functions

| ફંક્શન | ગુજરાતી ઉપયોગ / અર્થ |
|---|---|
| ABS | સંખ્યાનું Absolute એટલે કે ધનાત્મક મૂલ્ય આપે છે. |
| AVG | સંખ્યાઓની સરેરાશ આપે છે. |
| CEIL | સંખ્યાથી મોટી અથવા સમાન સૌથી નાની પૂર્ણ સંખ્યા આપે છે. |
| COUNT | રેકોર્ડ અથવા મૂલ્યોની સંખ્યા ગણે છે. |
| DIV | બે સંખ્યાનું Integer Division કરે છે. |
| EXP | e ની આપેલ ઘાતનું મૂલ્ય આપે છે. |
| FLOOR | સંખ્યાથી નાની અથવા સમાન સૌથી મોટી પૂર્ણ સંખ્યા આપે છે. |
| MAX | સૌથી મોટી સંખ્યા શોધે છે. |
| MIN | સૌથી નાની સંખ્યા શોધે છે. |
| MOD | ભાગાકાર પછીનો શેષ આપે છે. |
| PI | π એટલે કે Pi નું મૂલ્ય આપે છે. |
| POW | સંખ્યાની ઘાતનું મૂલ્ય આપે છે. |
| RAND | 0 અને 1 વચ્ચે Random સંખ્યા આપે છે. |
| ROUND | સંખ્યાને નજીકની પૂર્ણ સંખ્યા અથવા નિર્ધારિત Decimal સુધી Round કરે છે. |
| SQRT | સંખ્યાનું Square Root આપે છે. |
| SUM | સંખ્યાઓનો કુલ સરવાળો આપે છે. |
| TRUNCATE | સંખ્યાને નિર્ધારિત Decimal સ્થાન પછી કાપી નાખે છે. |

## MySQL Date Functions

| ફંક્શન | ગુજરાતી ઉપયોગ / અર્થ |
|---|---|
| ADDDATE | તારીખમાં નિર્ધારિત દિવસ અથવા સમય ઉમેરે છે. |
| ADDTIME | સમય અથવા DateTime માં નિર્ધારિત સમય ઉમેરે છે. |
| CURRENT_DATE | વર્તમાન તારીખ આપે છે. |
| CURRENT_TIME | વર્તમાન સમય આપે છે. |
| CURRENT_TIMESTAMP | વર્તમાન તારીખ અને સમય આપે છે. |
| DATE | DateTime માંથી માત્ર તારીખ કાઢે છે. |
| DATE_FORMAT | તારીખને નિર્ધારિત Format માં દર્શાવે છે. |
| DAY | તારીખમાંથી દિવસની સંખ્યા આપે છે. |
| DAYNAME | તારીખ પરથી દિવસનું નામ આપે છે. |
| DAYOFMONTH | મહિનાનો દિવસ નંબર આપે છે. |
| DAYOFWEEK | અઠવાડિયામાં દિવસનો નંબર આપે છે. |
| DAYOFYEAR | વર્ષમાં દિવસનો નંબર આપે છે. |
| EXTRACT | તારીખમાંથી ચોક્કસ ભાગ જેમ કે Year, Month અથવા Day કાઢે છે. |
| HOUR | સમયમાંથી કલાક કાઢે છે. |
| LAST_DAY | આપેલી તારીખના મહિનાનો છેલ્લો દિવસ આપે છે. |
| MINUTE | સમયમાંથી મિનિટ કાઢે છે. |
| MONTH | તારીખમાંથી મહિનાનો નંબર આપે છે. |
| MONTHNAME | તારીખ પરથી મહિનાનું નામ આપે છે. |
| NOW | વર્તમાન તારીખ અને સમય આપે છે. |
| PERIOD_ADD | આપેલા Period માં નિર્ધારિત મહિનાઓ ઉમેરે છે. |
| PERIOD_DIFF | બે Period વચ્ચેના મહિનાઓનો તફાવત આપે છે. |
| SECOND | સમયમાંથી સેકન્ડ કાઢે છે. |
| SYSDATE | MySQL Server ની વર્તમાન તારીખ અને સમય આપે છે. |
| TIME | DateTime માંથી માત્ર સમય કાઢે છે. |
| WEEK | તારીખના અઠવાડિયાનો નંબર આપે છે. |
| WEEKDAY | તારીખના અઠવાડિયાના દિવસનો નંબર આપે છે. |
| WEEKOFYEAR | તારીખ વર્ષના કયા અઠવાડિયામાં આવે છે તે આપે છે. |
| YEAR | તારીખમાંથી વર્ષ આપે છે. |
| YEARWEEK | વર્ષ અને અઠવાડિયાનો નંબર આપે છે. |

## MySQL General Functions

| ફંક્શન | ગુજરાતી ઉપયોગ / અર્થ |
|---|---|
| BIN | સંખ્યાને Binary String માં ફેરવે છે. |
| CONNECTION_ID | વર્તમાન MySQL Connection નો ID આપે છે. |
| CURRENT_USER | MySQL માં Authentication માટે વપરાયેલ વર્તમાન User આપે છે. |
| DATABASE | હાલમાં પસંદ કરેલા Database નું નામ આપે છે. |
| IF | શરત સાચી હોય તો એક મૂલ્ય અને ખોટી હોય તો બીજું મૂલ્ય આપે છે. |
| SESSION_USER | વર્તમાન Session ના User નું નામ આપે છે. |
| SYSTEM_USER | MySQL સાથે જોડાયેલા System User નું નામ આપે છે. |
| USER | વર્તમાન MySQL User અને Host ની માહિતી આપે છે. |
| VERSION | MySQL Server નું Version દર્શાવે છે. |
