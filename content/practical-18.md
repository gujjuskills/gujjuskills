# પ્રેકટિકલ-૧૮ : હાર્ડડિસ્કની ગોઠવણી અને તેના ભાગ કરવા
![image](/gujjuskills/images/practical-18.png)
| પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|---|---|
| **ડિસ્ક મેનેજમેન્ટ ખોલો** | `Win + X` દબાવો અને **Disk Management** પસંદ કરો, અથવા Run માં `diskmgmt.msc` લખી **Enter** કરો. |
| **ડ્રાઇવનું નામ બદલો** | ડ્રાઇવ પર **Right-click → Change Drive Letter and Paths → Change** પસંદ કરો અને નવું drive letter પસંદ કરો. |
| **ડ્રાઇવ ફોર્મેટ કરો** | ડ્રાઇવ પર **Right-click → Format** પસંદ કરો. File System પસંદ કરી **Quick Format** જરૂર મુજબ પસંદ કરો અને **OK** કરો. |
| **પાર્ટિશન ડિલીટ કરો** | પાર્ટિશન પર **Right-click → Delete Volume** પસંદ કરો. આ પ્રક્રિયા પહેલાં જરૂરી ડેટાનો બેકઅપ લો. |
| **પાર્ટિશન બનાવો** | **Unallocated space** પર **Right-click → New Simple Volume** પસંદ કરો અને wizard મુજબ size, drive letter તથા file system સેટ કરો. |
| **પાર્ટિશન નાનું કરો** | પાર્ટિશન પર **Right-click → Shrink Volume** પસંદ કરો, કેટલી જગ્યા ઘટાડવી તે MB માં આપો અને **Shrink** કરો. |
| **પાર્ટિશન મોટું કરો** | પાર્ટિશન પર **Right-click → Extend Volume** પસંદ કરો અને ઉપલબ્ધ **Unallocated space** પસંદ કરીને **Extend** કરો. |
| **ડ્રાઇવની પ્રોપર્ટીઝ ખોલો** | **This PC** માં ડ્રાઇવ પર **Right-click → Properties** પસંદ કરો. અહીં સામાન્ય માહિતી, space અને tools જોઈ શકાય છે. |
| **ડ્રાઇવ ખોલો** | **This PC** અથવા **File Explorer** માં ડ્રાઇવના icon પર **double-click** કરીને ડ્રાઇવ ખોલો. |
