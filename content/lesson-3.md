# Lesson-3 : સલામતીને નિયમો અને ચિન્હો

## સલામતીના નિયમો

-કમ્પ્યુટર એ એક ઇલેક્ટિક ડિવાઇસ છે જેથી શોક લાગવાનો મુખ્ય ભય રહેલ છે.

– કમ્પ્યુટર સાથે કામ કરતાં સમયે નીચે જણાવેલ સલામતીના નિયમો અને બાબતોનું ધ્યાન રાખવું,

1. કમ્પ્યુટર કેબલ વ્યવસ્થિત પ્લગ-ઇન કરીને રાખવો

2. કમ્પ્યુટરની સાફ-સફાઇ અને રિપેરિંગ સમયે પાવર કેબલ કાઢી નાખવો.

3. પાવર કેબલ બ્રેક નથી તે ચેક કરવું

4. જે સ્થાન પર કમ્પ્યુટર રાખેલ છે તે જગ્યા પાણીવાળી કે ભેજવાળી નથી તે ચેક કરવું.

5. વરસાદની ઋતુમાં શોક લાગવાનો ભય વધારે હોય છે જેથી અજાણ્યા કમ્પ્યુટરને અડવું નહીં.

## સલામતીના ચિન્હો

સલામતી સાથેના વર્તન માટેનું માર્ગદર્શન મળી રહે તે માટે સલામતીના ચિન્હોનો ઉપયોગ થાય છે.

### સલામતીના ચિન્હોના ચાર પ્રકાર છે.

1. નિષેધાત્મક ચિન્હ

2. આદેશાત્મક ચિન્હ

3. ચેતવણી ચિન્હ

4. માહિતી ચિન્હ

#### 1. નિષેધાત્મક ચિન્હ

વર્તન ન કરવા માટેનું સૂચન કરે છે

આકાર : ગોળ

કલર : સફેદ બેકગ્રાઉન્ડ ઉપર લાલ બોર્ડર અને ક્રોસ

#### 2. આદેશાત્મક ચિન્હ

અમુક પ્રકારનું વર્તન કરવું જ જોઈએ જો તેમ ન કરવામાં આવે તો અકસ્માત થવાની સંભાવના રહેલ છે. તે માટેનું સૂચન કરે છે

આકાર : ગોળ

કલર : વાદળી બેકગ્રાઉન્ડ ઉપર સફેદ સિમ્બોલ

#### 3. ચેતવણી ચિન્હ

ભયજનક સ્થિતિ માટે સજાગ રહેવાનું સુચન કરે છે.

આકાર : ત્રિકોણ

કલર : પીળા બેકગ્રાઉન્ડ પર કાળો સિમ્બોલ

#### 4. માહિતી ચિન્હ

-સામાન્ય સાગવલતા મળી રહે તેવી ઉપયોગી માહિતી સૂચવે છે.

-આકાર : ચોરસ અથવા લંબગોળ

-કલર : લીલા બેકગ્રાઉન્ડ ઉપર સફેદ સિમ્બોલ
