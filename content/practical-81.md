# પ્રેકટિકલ-૮૧ : ડેટાની હેરફેર કરો : MS-EXCEL

| Topic | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| Paste data by using special paste options | Copy કરેલા ડેટાને જરૂરિયાત મુજબ Paste Special વિકલ્પનો ઉપયોગ કરીને પેસ્ટ કરી શકાય છે. તેમાં માત્ર Value, Formula, Format અથવા અન્ય જરૂરી વિકલ્પ પસંદ કરી શકાય છે. |
| Fill cells by using Auto Fill | Auto Fill દ્વારા એકસરખા ડેટા, ક્રમ, તારીખો અથવા ફોર્મ્યુલાને આપમેળે આગળના સેલમાં ભરવામાં આવે છે. Fill Handle ને ખેંચીને આ કાર્ય કરી શકાય છે. |
| Insert and delete multiple columns or rows | એકસાથે ઘણી Rows અથવા Columns પસંદ કરીને Insert વિકલ્પથી નવી Rows અથવા Columns ઉમેરી શકાય છે અને Delete વિકલ્પથી દૂર કરી શકાય છે. |
| Insert and delete cells | જરૂરિયાત મુજબ નવા Cells ઉમેરવા માટે Insert Cells અને Cells દૂર કરવા માટે Delete Cells વિકલ્પનો ઉપયોગ કરવામાં આવે છે. Cells ખસેડવાની દિશા પણ પસંદ કરી શકાય છે. |
