# લેશન - ૨૨.૩ : હોમ ટેબ : MS Word

| Home tab | ઉપયોગ |
|:---:|:---|
| Home Tab | MS Word માં લખાણને સંપાદિત અને ફોર્મેટ કરવા માટેનો મુખ્ય ટેબ. |
| Cut – Paste | પસંદ કરેલા લખાણને એક જગ્યાએથી દૂર કરીને બીજી જગ્યાએ મૂકવા માટે ઉપયોગ થાય છે. |
| Copy – Paste | પસંદ કરેલા લખાણની નકલ કરીને બીજી જગ્યાએ મૂકવા માટે ઉપયોગ થાય છે. |
| Format Painter | એક લખાણનું formatting બીજા લખાણ પર લાગુ કરવા માટે ઉપયોગ થાય છે. |
| Font | લખાણનો ફોન્ટ અથવા અક્ષરનો પ્રકાર બદલવા માટે ઉપયોગ થાય છે. |
| Font Size | લખાણના અક્ષરોનું કદ બદલવા માટે ઉપયોગ થાય છે. |
| Grow Font | લખાણનું કદ વધારવા માટે ઉપયોગ થાય છે. |
| Shrink Font | લખાણનું કદ ઘટાડવા માટે ઉપયોગ થાય છે. |
| Change Case | લખાણને UPPERCASE, lowercase અથવા અન્ય case માં બદલવા માટે ઉપયોગ થાય છે. |
| Clear Formatting | લખાણ પર લાગુ કરેલું formatting દૂર કરવા માટે ઉપયોગ થાય છે. |
| Bold | લખાણને ઘાટું કરવા માટે ઉપયોગ થાય છે. |
| Italic | લખાણને ત્રાંસા અક્ષરમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
| Underline | લખાણની નીચે રેખા દોરવા માટે ઉપયોગ થાય છે. |
| Strikethrough | લખાણની વચ્ચે રેખા દોરવા માટે ઉપયોગ થાય છે. |
| Subscript | અક્ષર અથવા સંખ્યાને સામાન્ય લખાણની નીચે નાના કદમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
| Superscript | અક્ષર અથવા સંખ્યાને સામાન્ય લખાણની ઉપર નાના કદમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
| Text Effects | લખાણમાં વિવિધ text effects લાગુ કરવા માટે ઉપયોગ થાય છે. |
| Text Highlight Color | લખાણની પાછળ રંગ લગાવવા માટે ઉપયોગ થાય છે. |
| Font Color | લખાણના અક્ષરોનો રંગ બદલવા માટે ઉપયોગ થાય છે. |
| Bullets | યાદી બનાવતી વખતે દરેક મુદ્દા પહેલાં bullet ચિહ્ન મૂકવા માટે ઉપયોગ થાય છે. |
| Numbering | મુદ્દાઓની ક્રમબદ્ધ યાદી બનાવવા માટે સંખ્યાઓનો ઉપયોગ થાય છે. |
| Multilevel List | વિવિધ સ્તરની ક્રમબદ્ધ અથવા bullet યાદી બનાવવા માટે ઉપયોગ થાય છે. |
| Decrease Indent | લખાણને ડાબી બાજુ તરફ ખસેડવા માટે ઉપયોગ થાય છે. |
| Increase Indent | લખાણને જમણી બાજુ તરફ ખસેડવા માટે ઉપયોગ થાય છે. |
| Sort | લખાણ અથવા યાદીને અક્ષરક્રમ અથવા સંખ્યાક્રમ પ્રમાણે ગોઠવવા માટે ઉપયોગ થાય છે. |
| Show/Hide | paragraph marks અને અન્ય formatting ચિહ્નો દર્શાવવા અથવા છુપાવવા માટે ઉપયોગ થાય છે. |
| Align Text Left | લખાણને ડાબી બાજુ ગોઠવવા માટે ઉપયોગ થાય છે. |
| Center | લખાણને પેજની મધ્યમાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| Align Text Right | લખાણને જમણી બાજુ ગોઠવવા માટે ઉપયોગ થાય છે. |
| Justify | લખાણને ડાબી અને જમણી બંને બાજુ સમાન રીતે ગોઠવવા માટે ઉપયોગ થાય છે. |
| Line & Paragraph Spacing | લાઇન અને paragraph વચ્ચેનું અંતર બદલવા માટે ઉપયોગ થાય છે. |
| Shading | paragraph અથવા પસંદ કરેલા ભાગની પાછળનો રંગ બદલવા માટે ઉપયોગ થાય છે. |
| Border | paragraph અથવા પસંદ કરેલા લખાણની આસપાસ border લગાવવા માટે ઉપયોગ થાય છે. |
| Set Styles | લખાણ માટે predefined style પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Change Styles | document ના styles અને style set બદલવા માટે ઉપયોગ થાય છે. |
| Find | document માં કોઈ શબ્દ અથવા લખાણ શોધવા માટે ઉપયોગ થાય છે. |
| Go to | document માં ચોક્કસ page, section અથવા અન્ય સ્થાન પર ઝડપથી જવા માટે ઉપયોગ થાય છે. |
| Replace | document માં રહેલા શબ્દ અથવા લખાણને બીજા શબ્દ અથવા લખાણથી બદલવા માટે ઉપયોગ થાય છે. |
| Select | document માં લખાણ અથવા અન્ય વસ્તુઓ પસંદ કરવા માટે ઉપયોગ થાય છે. |
