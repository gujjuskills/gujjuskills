# પ્રેકટિકલ-૪ : અગ્નિશામક ઉપકરણનો ઉપયોગ


## અગ્નિશામક ઉપકરણ ઉપયોગ માટેના સ્ટેપ જણાવો.  
## PULL → AIM → SQUEEZE → SWEEP

**સ્ટેપ : 1**  સલામતી પિન ખેંચો.

**સ્ટેપ : 2**  અગ્નિશામકની નોઝલને આગના મૂળ તરફ નિશાન કરો.

**સ્ટેપ : 3**  હેન્ડલ દબાવી અગ્નિશામક દ્રવ્ય છોડો.

**સ્ટેપ : 4**  નોઝલને ડાબેથી જમણે હલાવી આગના મૂળ પર છંટકાવ કરો.
