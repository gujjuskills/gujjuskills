# પ્રેકટિકલ-૧૬૯.૨ : PY : 14 - સંખ્યાનો ફેકટોરિયલ (ક્રમગૂણિત) ગણો
```
num = int(input("Enter a number: "))

factorial = 1

for i in range(1, num + 1):
    factorial = factorial * i

print("\n----- Factorial Calculator -----")
print("Number:", num)
print("Factorial:", factorial)
```
### Output :
```
Enter a number: 5

----- Factorial Calculator -----
Number: 5
Factorial: 120

```
