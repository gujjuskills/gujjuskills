# લેશન - ૯૦ : જાવાસ્ક્રિપ્ટમાં પોપઅપ બોક્સનો ઉપયોગ

| What is Pop Up Box in JavaScript : |
|---|
| JavaScript માં Pop Up Box એ એક નાની વિન્ડો છે, જે વેબ પેજ પર વપરાશકર્તાને માહિતી બતાવવા, પુષ્ટિ મેળવવા અથવા માહિતી દાખલ કરાવવા માટે દેખાય છે. JavaScript માં મુખ્યત્વે ત્રણ પ્રકારના Pop Up Box છે: Alert Dialog Box, Confirmation Dialog Box અને Prompt Dialog Box. |

| 1 - Alert Dialog Box : | |
|---|---|
| **અર્થ :** | Alert Dialog Box નો ઉપયોગ વપરાશકર્તાને કોઈ માહિતી, સંદેશ અથવા ચેતવણી બતાવવા માટે થાય છે. |
| **Syntax :** | `alert("Message");` |
| **ઉદાહરણ :** | `alert("Welcome to GujjuSkills");` |
| **પરિણામ :** | સ્ક્રીન પર સંદેશ સાથે OK બટન દેખાય છે. |
| **મુખ્ય ઉપયોગ :** | માહિતી અથવા ચેતવણી દર્શાવવા માટે. |

| 2 - Confirmation Dialog Box : | |
|---|---|
| **અર્થ :** | Confirmation Dialog Box નો ઉપયોગ વપરાશકર્તા પાસેથી કોઈ કાર્ય કરવા માટે પુષ્ટિ મેળવવા માટે થાય છે. |
| **Syntax :** | `confirm("Are you sure?");` |
| **ઉદાહરણ :** | `confirm("Do you want to delete this record?");` |
| **પરિણામ :** | સ્ક્રીન પર OK અને Cancel બટન દેખાય છે. |
| **મુખ્ય ઉપયોગ :** | વપરાશકર્તાની પુષ્ટિ મેળવવા માટે. |

| 3 - Prompt Dialog Box : | |
|---|---|
| **અર્થ :** | Prompt Dialog Box નો ઉપયોગ વપરાશકર્તા પાસેથી કોઈ માહિતી અથવા value દાખલ કરાવવા માટે થાય છે. |
| **Syntax :** | `prompt("Enter your name");` |
| **ઉદાહરણ :** | `prompt("Enter your name:");` |
| **પરિણામ :** | સ્ક્રીન પર Input Box સાથે OK અને Cancel બટન દેખાય છે. |
| **મુખ્ય ઉપયોગ :** | વપરાશકર્તા પાસેથી માહિતી મેળવવા માટે. |
