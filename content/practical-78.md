# પ્રેકટિકલ-૭૮ : વર્કશીટ અને વર્કબુક ફોરમેટ કરો : MS-EXCEL

| Topic                                  | Gujarati Answer                                                                                                                                                                           |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Modify page setup**                  | પેજનું કદ, ઓરિએન્ટેશન, માર્જિન અને સ્કેલિંગ જેવી સેટિંગમાં ફેરફાર કરી શકાય છે. Page Layout ટૅબમાંથી **Page Setup** વિકલ્પ પસંદ કરીને જરૂરી ફેરફાર કરો.                                    |
| **Adjust row height and column width** | ડેટા યોગ્ય રીતે દેખાય તે માટે Row ની ઊંચાઈ અને Column ની પહોળાઈ બદલી શકાય છે. Row અથવા Column પસંદ કરીને તેની બોર્ડર ખેંચી શકાય છે અથવા **Format** વિકલ્પનો ઉપયોગ કરી શકાય છે.            |
| **Customize headers and footers**      | પ્રિન્ટેડ પેજમાં પેજ નંબર, તારીખ, ફાઇલનું નામ અથવા અન્ય માહિતી દર્શાવવા Header અને Footer કસ્ટમાઇઝ કરી શકાય છે. **Insert** ટૅબમાંથી Header & Footer વિકલ્પ પસંદ કરીને જરૂરી માહિતી ઉમેરો. |
