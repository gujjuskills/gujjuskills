# લેશન - ૮૩ : જાવા સ્ક્રિપ્ટ ડેટા ટાઈપ , વેરિએબલ ,કોન્સેન્ટ ,ડેટા ટાઈપમાં ફેરફાર

| વિષય | વિગતવાર ગુજરાતી માહિતી |
|---|---|
| **What is Data Types** | JavaScript માં Data Type એ કોઈ Variable માં કયા પ્રકારની Value સંગ્રહિત છે તે દર્શાવે છે. JavaScript માં Data Types મુખ્યત્વે બે પ્રકારના હોય છે: **Primitive Data Types** અને **Non-Primitive Data Types**. Data Type ની મદદથી JavaScript જાણી શકે છે કે Variable માં Text, Number, Boolean, Object વગેરેમાંથી કઈ પ્રકારની Value છે. |
| **1 - Primitive data type** | Primitive Data Type એ મૂળભૂત Data Type છે, જે એક જ Value ને Represent કરે છે. JavaScript માં મુખ્ય 7 Primitive Data Types છે: **String, Number, BigInt, Boolean, Undefined, Null અને Symbol**. Primitive Value સામાન્ય રીતે સીધી Value તરીકે Store થાય છે. String નો ઉપયોગ Text માટે, Number નો ઉપયોગ સંખ્યાઓ માટે, Boolean નો ઉપયોગ True અથવા False માટે, Undefined નો ઉપયોગ Value ન આપેલી હોય ત્યારે, Null નો ઉપયોગ ખાલી Value દર્શાવવા માટે, BigInt નો ઉપયોગ ખૂબ મોટી પૂર્ણ સંખ્યાઓ માટે અને Symbol નો ઉપયોગ Unique Identifier માટે થાય છે. |
| **2 - Non - Primitive data type** | Non-Primitive Data Type ને Reference Data Type પણ કહેવામાં આવે છે. તેમાં એકથી વધુ Values અથવા Complex Data Structure Store કરી શકાય છે. JavaScript માં મુખ્ય Non-Primitive Data Types તરીકે **Object, Array અને Function** નો ઉપયોગ થાય છે. Object માં Key અને Value ના સ્વરૂપમાં Data Store કરી શકાય છે, Array માં એકથી વધુ Values Store કરી શકાય છે અને Function માં Program ના ચોક્કસ કામ માટે Code Store કરવામાં આવે છે. |
| **What is Variable** | Variable એ Memory માં Data અથવા Value Store કરવા માટે આપવામાં આવેલું નામ છે. JavaScript માં Variable Declare કરવા માટે મુખ્યત્વે **var, let અને const** Keywords નો ઉપયોગ થાય છે. Variable ની Value Program દરમિયાન જરૂરિયાત મુજબ બદલી શકાય છે, પરંતુ `const` દ્વારા બનાવેલા Variable ને ફરીથી નવી Value Assign કરી શકાતી નથી. Variable નો Scope નક્કી કરે છે કે તેને Program ના કયા ભાગમાંથી Access કરી શકાય છે. |
| **(1) Local variable** | જે Variable કોઈ **Function અથવા Block ની અંદર** Declare કરવામાં આવે તેને Local Variable કહેવામાં આવે છે. Local Variable નો Scope મર્યાદિત હોય છે અને સામાન્ય રીતે તેને જે Function અથવા Block માં Declare કરવામાં આવ્યો હોય તેની અંદર જ Access કરી શકાય છે. Function અથવા Block ની બહારથી તેને સીધો Access કરી શકાતો નથી. Local Variable નો ઉપયોગ Program માં Data ને ચોક્કસ ભાગ સુધી મર્યાદિત રાખવા માટે થાય છે. |
| **(2) Global variable** | જે Variable કોઈ Function અથવા Block ની બહાર Declare કરવામાં આવે તેને Global Variable કહેવામાં આવે છે. Global Variable ને તેના Scope ના નિયમો અનુસાર Program ના વિવિધ Functions અથવા Blocks માં Access કરી શકાય છે. Global Variable નો Scope મોટો હોય છે, તેથી તેનો ઉપયોગ Program ના ઘણા ભાગોમાં જરૂરી હોય તેવી Value માટે કરી શકાય છે. જોકે અનાવશ્યક Global Variables નો ઉપયોગ કરવાથી Program ને Manage કરવું મુશ્કેલ બની શકે છે. |
| **What is Constant** | Constant એવી Value છે જેને એકવાર Declare અને Initialize કર્યા પછી ફરીથી બીજી Value Assign કરી શકાતી નથી. JavaScript માં Constant બનાવવા માટે **const** Keyword નો ઉપયોગ થાય છે. `const` Variable ને Declare કરતી વખતે Value આપવી જરૂરી છે. Constant નો ઉપયોગ એવી Values માટે કરવામાં આવે છે જે Program દરમિયાન બદલાવાની નથી, જેમ કે કોઈ Fixed Configuration Value અથવા Mathematical Constant. |
| **What is Data Types Conversion** | એક Data Type ની Value ને બીજા Data Type માં બદલવાની પ્રક્રિયાને **Data Type Conversion** કહેવામાં આવે છે. JavaScript માં Data Type Conversion બે રીતે થઈ શકે છે: **Implicit Conversion** અને **Explicit Conversion**. Implicit Conversion માં JavaScript પોતાની રીતે Data Type બદલે છે, જ્યારે Explicit Conversion માં Programmer પોતાની જરૂરિયાત મુજબ Conversion Method નો ઉપયોગ કરીને Data Type બદલે છે. |
| **Data Types Conversion Table** | JavaScript માં વિવિધ Data Types ને Convert કરવા માટે અલગ અલગ Methods નો ઉપયોગ થાય છે. **String ને Number માં** બદલવા માટે `Number()` અથવા `parseInt()` અને `parseFloat()` નો ઉપયોગ કરી શકાય છે. **Number ને String માં** બદલવા માટે `String()` નો ઉપયોગ થાય છે. **Value ને Boolean માં** બદલવા માટે `Boolean()` નો ઉપયોગ થાય છે. **Boolean ને Number માં** બદલવા માટે `Number()` નો ઉપયોગ થાય છે. `parseInt()` String માંથી પૂર્ણાંક Number મેળવવા માટે અને `parseFloat()` Decimal Number મેળવવા માટે ઉપયોગી છે. |
