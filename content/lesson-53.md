# લેશન - ૫૩ : ટ્રાન્સેક્સન નો ખ્યાલ
## 1. ટ્રાન્ઝેક્શન શું છે?

ટ્રાન્ઝેક્શન (Transaction) એટલે ડેટાબેઝમાં કરવામાં આવતી એક અથવા વધુ કામગીરીઓનો સમૂહ, જે એક સંપૂર્ણ કાર્ય તરીકે ગણવામાં આવે છે.

ટ્રાન્ઝેક્શન દરમિયાન ડેટાબેઝમાં ડેટા વાંચવો, ડેટા ઉમેરવો, બદલવો અથવા કાઢી નાખવો જેવી કામગીરી થઈ શકે છે. ટ્રાન્ઝેક્શન સફળતાપૂર્વક પૂર્ણ થાય ત્યારે તેને Commit કરવામાં આવે છે. જો કોઈ કારણસર ટ્રાન્ઝેક્શન પૂર્ણ ન થઈ શકે તો કરવામાં આવેલા ફેરફારોને Rollback કરીને અગાઉની સ્થિતિમાં પાછા જઈ શકાય છે.

### ઉદાહરણ

બેંકમાં એક ખાતામાંથી બીજા ખાતામાં ₹5,000 ટ્રાન્સફર કરવાના હોય ત્યારે મુખ્યત્વે બે કામગીરી થાય છે:

પ્રથમ ખાતામાંથી ₹5,000 ઘટાડવા.
બીજા ખાતામાં ₹5,000 ઉમેરવા.

આ બંને કામગીરી એક જ ટ્રાન્ઝેક્શનનો ભાગ છે. જો બંને કામગીરી સફળ થાય તો ટ્રાન્ઝેક્શન Commit થાય છે. જો કોઈ કામગીરીમાં ભૂલ થાય તો ટ્રાન્ઝેક્શન Rollback થઈ શકે છે.

## 2.ટ્રાન્ઝેક્શનની કામગીરીઓ

  1. Read Operation: ડેટાબેઝમાંથી ડેટા વાંચવા માટે વપરાય છે.
  2. Write Operation: ડેટાબેઝમાં ડેટા ઉમેરવા અથવા બદલવા માટે વપરાય છે.
  3. Commit Operation: ટ્રાન્ઝેક્શન સફળ થાય ત્યારે ફેરફારો કાયમી રીતે સાચવવા માટે વપરાય છે.
  4. Rollback Operation: ભૂલ થાય ત્યારે કરેલા ફેરફારો પાછા ખેંચવા માટે વપરાય છે.
