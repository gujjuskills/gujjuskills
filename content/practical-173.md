# Sum of numbers between two numbers
```
start = int(input("Enter first number: "))
end = int(input("Enter second number: "))

total = 0

for i in range(start, end + 1):
    total = total + i

print("Sum =", total)
```
### Output :

Enter first number: 5

Enter second number: 15

Sum = 110
