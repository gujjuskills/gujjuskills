# પ્રેકટિકલ-૭ : વિન્ડોસ પર ઈન્ટરફેસ અને નેવિગેશનની પ્રેકટિસ
![image](/gujjuskills/images/windows-interface.webp)
| ક્રમ | પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|:---:|:---:|:---|
| 1 | ડેસ્કટોપ (Desktop) | કમ્પ્યુટર ચાલુ કર્યા પછી દેખાતી મુખ્ય સ્ક્રીનને ડેસ્કટોપ કહેવામાં આવે છે. |
| 2 | ટાસ્કબાર (Taskbar) | સ્ક્રીનના નીચેના ભાગમાં આવેલ પટ્ટી, જેમાં સ્ટાર્ટ મેનુ, ખુલેલી એપ્લિકેશન અને સિસ્ટમ આઇકોન હોય છે. |
| 3 | આઇકોન (Icon) | ફાઇલ, ફોલ્ડર, પ્રોગ્રામ અથવા અન્ય વસ્તુનું નાનું ગ્રાફિકલ ચિહ્ન. |
| 4 | આ પીસી (This PC) | કમ્પ્યુટરની ડ્રાઇવ, ફોલ્ડર અને સ્ટોરેજ ડિવાઇસ જોવા અને ઍક્સેસ કરવા માટે ઉપયોગ થાય છે. |
| 5 | માઇક્રોસોફ્ટ ઓફિસ પર પાછા જવું (Back to Microsoft Office – Alt + Left Arrow) | અગાઉ ખોલેલા સ્થાન અથવા પેજ પર પાછા જવા માટે ઉપયોગ થાય છે. |
| 6 | વિન્ડોઝ પર આગળ જવું (Forward to Windows – Alt + Right Arrow) | અગાઉ પાછા ગયેલા સ્થાનથી આગળના સ્થાન પર જવા માટે ઉપયોગ થાય છે. |
| 7 | તાજેતરનું સ્થાન (Recent Location) | તાજેતરમાં ખોલેલા અથવા ઉપયોગમાં લીધેલા ફોલ્ડર અને સ્થાનની યાદી. |
| 8 | માઇક્રોસોફ્ટ ઓફિસ પર ઉપર જવું (Up to Microsoft Office – Alt + Up Arrow) | વર્તમાન ફોલ્ડરના એક સ્તર ઉપરના ફોલ્ડરમાં જવા માટે ઉપયોગ થાય છે. |
| 9 | એડ્રેસ બાર (Address Bar) | હાલમાં ખુલેલા ફોલ્ડર અથવા સ્થાનનું પાથ બતાવે છે અને અન્ય સ્થાન પર જવા માટે ઉપયોગ કરી શકાય છે. |
| 10 | સર્ચ બોક્સ (Search Box) | ફાઇલ, ફોલ્ડર, એપ્લિકેશન અથવા અન્ય માહિતી શોધવા માટે ઉપયોગ થાય છે. |
| 11 | C: ડ્રાઇવ (C: Drive) | સામાન્ય રીતે Windows ઓપરેટિંગ સિસ્ટમ અને પ્રોગ્રામ્સ જ્યાં ઇન્સ્ટોલ થયેલા હોય તેવી મુખ્ય ડ્રાઇવ. |
| 12 | અન્ય ડ્રાઇવ્સ (D:, E:, F:) | કમ્પ્યુટરમાં ઉપલબ્ધ અન્ય સ્ટોરેજ ડ્રાઇવ્સ, જેમ કે પાર્ટિશન, હાર્ડ ડિસ્ક અથવા અન્ય સ્ટોરેજ. |
| 13 | હોમ (Home) | File Explorerનું મુખ્ય સ્થાન, જ્યાં વારંવાર ઉપયોગમાં લેવાતા ફોલ્ડર અને તાજેતરની ફાઇલો જોવા મળે છે. |
| 14 | વનડ્રાઇવ (OneDrive) | Microsoftની ક્લાઉડ સ્ટોરેજ સેવા, જેમાં ફાઇલો ઓનલાઈન સંગ્રહિત અને સિંક્રોનાઇઝ કરી શકાય છે. |
| 15 | ડેસ્કટોપ (Desktop) | ડેસ્કટોપ પર રાખેલી ફાઇલો, ફોલ્ડર અને શોર્ટકટ જોવા માટેનું સ્થાન. |
| 16 | ડાઉનલોડ્સ (Downloads) | ઇન્ટરનેટ પરથી ડાઉનલોડ કરેલી ફાઇલો સામાન્ય રીતે આ ફોલ્ડરમાં સંગ્રહિત થાય છે. |
| 17 | ડોક્યુમેન્ટ્સ (Documents) | ટેક્સ્ટ ફાઇલ, PDF અને અન્ય દસ્તાવેજો સંગ્રહિત કરવા માટેનું ફોલ્ડર. |
| 18 | પિક્ચર્સ (Pictures) | ફોટા અને અન્ય ચિત્રો સંગ્રહિત કરવા માટેનું ફોલ્ડર. |
| 19 | મ્યુઝિક (Music) | સંગીત અને ઓડિયો ફાઇલો સંગ્રહિત કરવા માટેનું ફોલ્ડર. |
| 20 | વીડિયો (Videos) | વીડિયો ફાઇલો સંગ્રહિત કરવા માટેનું ફોલ્ડર. |
| 21 | ક્વિક ઍક્સેસમાં પિન કરવું (Pin to Quick Access) | વારંવાર ઉપયોગમાં લેવાતા ફોલ્ડરને Quick Accessમાં સરળતાથી ખોલવા માટે ઉમેરવાની સુવિધા. |
| 22 | નેટવર્ક (Network) | નેટવર્ક સાથે જોડાયેલા કમ્પ્યુટર અને અન્ય ઉપલબ્ધ નેટવર્ક ડિવાઇસ જોવા માટે ઉપયોગ થાય છે. |
| 23 | નવું ફોલ્ડર (New Folder) | નવી ફોલ્ડર બનાવવા માટે ઉપયોગ થાય છે. |
| 24 | શોર્ટકટ (Shortcut) | ફાઇલ, ફોલ્ડર અથવા પ્રોગ્રામને ઝડપથી ખોલવા માટે બનાવવામાં આવેલી લિંક. |
| 25 | ડોક્યુમેન્ટ ફોર્મેટ (Document Format) | ફાઇલ કયા પ્રકારના ફોર્મેટમાં સાચવવામાં આવી છે તે દર્શાવે છે, જેમ કે DOCX, PDF વગેરે. |
| 26 | કોમ્પ્રેસ્ડ (ઝિપ્ડ) ફોલ્ડર (Compressed – Zipped Folder) | એક અથવા વધુ ફાઇલોને ZIP ફોર્મેટમાં સંકુચિત કરીને ઓછી જગ્યામાં સંગ્રહિત કરવાની સુવિધા. |
| 27 | કટ (Cut) – Ctrl + X | પસંદ કરેલી ફાઇલ અથવા ટેક્સ્ટને મૂળ સ્થાનેથી દૂર કરીને અન્ય સ્થળે મૂકવા માટે તૈયાર કરે છે. |
| 28 | કોપી (Copy) – Ctrl + C | પસંદ કરેલી ફાઇલ અથવા ટેક્સ્ટની નકલ ક્લિપબોર્ડમાં રાખે છે. |
| 29 | પેસ્ટ (Paste) – Ctrl + V | Cut અથવા Copy કરેલી વસ્તુને પસંદ કરેલા સ્થાન પર મૂકવા માટે ઉપયોગ થાય છે. |
| 30 | નામ બદલવું (Rename) | ફાઇલ અથવા ફોલ્ડરનું નામ બદલવા માટે ઉપયોગ થાય છે. |
| 31 | શેર (Share) | ફાઇલ અથવા ફોલ્ડરને અન્ય વ્યક્તિ અથવા એપ્લિકેશન સાથે શેર કરવા માટે ઉપયોગ થાય છે. |
| 32 | સોર્ટ (Sort) | ફાઇલો અને ફોલ્ડરને નામ, તારીખ, પ્રકાર, કદ વગેરે પ્રમાણે ગોઠવવા માટે ઉપયોગ થાય છે. |
| 33 | વ્યૂ (View) | ફાઇલો અને ફોલ્ડર કેવી રીતે દેખાય તે પસંદ કરવા માટે ઉપયોગ થાય છે, જેમ કે Icons, List અથવા Details. |
| 34 | વ્યૂ – શો (View – Show) | File Explorerમાં જરૂરી વિકલ્પો અથવા ઘટકોને બતાવવા અથવા છુપાવવા માટે ઉપયોગ થાય છે. |
| 35 | સિલેક્ટ ઓલ (Select All) | ફોલ્ડરમાં રહેલી બધી ફાઇલો અને ફોલ્ડરને એકસાથે પસંદ કરવા માટે ઉપયોગ થાય છે. |
| 36 | સિલેક્ટ નન (Select None) | પસંદ કરેલી બધી ફાઇલો અને ફોલ્ડરની પસંદગી દૂર કરવા માટે ઉપયોગ થાય છે. |
| 37 | ઇન્વર્ટ સિલેક્શન (Invert Selection) | પસંદ કરેલી વસ્તુઓની પસંદગી દૂર કરીને બાકીની વસ્તુઓ પસંદ કરે છે. |
| 38 | પ્રોપર્ટીઝ (Properties) | ફાઇલ અથવા ફોલ્ડર વિશેની માહિતી, જેમ કે કદ, પ્રકાર, સ્થાન અને તારીખ જોવા માટે ઉપયોગ થાય છે. |
| 39 | ઓપ્શન્સ (Options) | File Explorerની વિવિધ સેટિંગ્સ અને પસંદગીઓ બદલવા માટે ઉપયોગ થાય છે. |
| 40 | ક્વિક ઍક્સેસમાંથી અનપિન કરવું (Unpin from Quick Access) | Quick Accessમાંથી પિન કરેલું ફોલ્ડર દૂર કરવા માટે ઉપયોગ થાય છે. |
| 41 | અનડુ (Undo) – Ctrl + Z | છેલ્લે કરેલું કાર્ય રદ કરવા માટે ઉપયોગ થાય છે. |
| 42 | રીડુ (Redo) – Ctrl + Y | Undo કરેલું કાર્ય ફરીથી કરવા માટે ઉપયોગ થાય છે. |
| 43 | રિસાઇકલ બિન (Recycle Bin) | ડિલીટ કરેલી ફાઇલો અને ફોલ્ડર અસ્થાયી રીતે અહીં સંગ્રહિત થાય છે. |
| 44 | ડિલીટ (Delete) | પસંદ કરેલી ફાઇલ અથવા ફોલ્ડરને Recycle Binમાં મોકલવા માટે ઉપયોગ થાય છે. |
| 45 | રિસ્ટોર (Restore) | Recycle Binમાંથી ડિલીટ કરેલી ફાઇલ અથવા ફોલ્ડરને તેના મૂળ સ્થાન પર પાછું લાવવા માટે ઉપયોગ થાય છે. |
| 46 | Shift + Delete | ફાઇલ અથવા ફોલ્ડરને Recycle Binમાં મોકલ્યા વગર કાયમી રીતે ડિલીટ કરવા માટે ઉપયોગ થાય છે. |
| 47 | રિસાઇકલ બિન ખાલી કરવું (Empty Recycle Bin) | Recycle Binમાં રહેલી બધી ડિલીટ કરેલી ફાઇલો અને ફોલ્ડરને કાયમી રીતે દૂર કરવા માટે ઉપયોગ થાય છે. |
