## લેશન - ૧૯ : Linux કમાન્ડ્સ

| લિનક્સ કમાન્ડ | ઉપયોગ |
|---|---|
| `date` | વર્તમાન તારીખ અને સમય દર્શાવવા માટે ઉપયોગ થાય છે. |
| `clear` | ટર્મિનલ સ્ક્રીન સાફ કરવા માટે ઉપયોગ થાય છે. |
| `cal` | કેલેન્ડર દર્શાવવા માટે ઉપયોગ થાય છે. |
| `who` | હાલમાં સિસ્ટમમાં લૉગિન થયેલા યુઝર્સની માહિતી દર્શાવવા માટે ઉપયોગ થાય છે. |
| `ls` | વર્તમાન ડિરેક્ટરીમાં રહેલી ફાઇલો અને ડિરેક્ટરીઓની યાદી દર્શાવવા માટે ઉપયોગ થાય છે. |
| `mkdir` | નવી ડિરેક્ટરી બનાવવા માટે ઉપયોગ થાય છે. |
| `rmdir` | ખાલી ડિરેક્ટરી દૂર કરવા માટે ઉપયોગ થાય છે. |
| `cd` | ડિરેક્ટરી બદલવા માટે ઉપયોગ થાય છે. |
| `cd ..` | વર્તમાન ડિરેક્ટરીમાંથી એક સ્તર ઉપર જવા માટે ઉપયોગ થાય છે. |
| `echo` | સ્ક્રીન પર ટેક્સ્ટ અથવા મેસેજ દર્શાવવા માટે ઉપયોગ થાય છે. |
| `pwd` | વર્તમાન વર્કિંગ ડિરેક્ટરીનું પાથ દર્શાવવા માટે ઉપયોગ થાય છે. |
| `bc` | કમાન્ડ લાઇન પર ગણિતીય ગણતરી કરવા માટે ઉપયોગ થાય છે. |
| `cat` | ફાઇલની સામગ્રી દર્શાવવા અથવા ફાઇલોને જોડવા માટે ઉપયોગ થાય છે. |
| `cp` | ફાઇલ અથવા ડિરેક્ટરીની નકલ કરવા માટે ઉપયોગ થાય છે. |
| `rm` | ફાઇલ અથવા ડિરેક્ટરી દૂર કરવા માટે ઉપયોગ થાય છે. |
| `mv` | ફાઇલ અથવા ડિરેક્ટરીને ખસેડવા અથવા તેનું નામ બદલવા માટે ઉપયોગ થાય છે. |
| `man` | Linux કમાન્ડનું મેન્યુઅલ અને ઉપયોગની માહિતી જોવા માટે ઉપયોગ થાય છે. |
| `wc` | ફાઇલમાં રહેલા શબ્દો, લાઇનો અને અક્ષરોની સંખ્યા જાણવા માટે ઉપયોગ થાય છે. |
| `grep` | ફાઇલ અથવા ટેક્સ્ટમાં ચોક્કસ શબ્દ અથવા પેટર્ન શોધવા માટે ઉપયોગ થાય છે. |
| `lp` | દસ્તાવેજ અથવા ફાઇલને પ્રિન્ટ કરવા માટે ઉપયોગ થાય છે. |
| `more` | લાંબા ટેક્સ્ટ અથવા ફાઇલને પેજ પ્રમાણે જોવા માટે ઉપયોગ થાય છે. |
| `sort` | ટેક્સ્ટ અથવા ફાઇલની લાઇનોને ક્રમમાં ગોઠવવા માટે ઉપયોગ થાય છે. |
| `chmod` | ફાઇલ અથવા ડિરેક્ટરીની પરવાનગી (Permissions) બદલવા માટે ઉપયોગ થાય છે. |
| `passwd` | યુઝરનો પાસવર્ડ બદલવા માટે ઉપયોગ થાય છે. |
