# લેશન - ૨૪.૩ : વ્યૂ ટેબ : MS-WORD
![image](/gujjuskills/images/lesson-24.3.png)
| View Tab | ઉપયોગ |
|:---:|---|
| Print Layout | દસ્તાવેજને પ્રિન્ટ થયા પછી જે રીતે દેખાશે તે રીતે જોવા માટે. |
| Full Screen Reading | દસ્તાવેજને સંપૂર્ણ સ્ક્રીન પર વાંચવા માટે. |
| Web Layout | દસ્તાવેજને વેબ પેજની જેમ જોવા માટે. |
| Outline | દસ્તાવેજની રૂપરેખા અને હેડિંગ ગોઠવવા માટે. |
| Draft | દસ્તાવેજને ઝડપથી લખવા અને સંપાદિત કરવા માટે. |
| Ruler | માર્જિન, ઇન્ડેન્ટ અને ટેબ સેટ કરવા માટે. |
| Gridlines | લખાણ, ચિત્રો અને અન્ય વસ્તુઓને યોગ્ય રીતે ગોઠવવા માટે. |
| Navigation Pane | દસ્તાવેજમાં પેજ, હેડિંગ અને શબ્દો શોધવા માટે. |
| Zoom | દસ્તાવેજને મોટો અથવા નાનો કરીને જોવા માટે. |
| 100% | દસ્તાવેજને તેના મૂળ 100% કદમાં જોવા માટે. |
| One Page | એક સમયે એક સંપૂર્ણ પેજ જોવા માટે. |
| Two Page | એક સમયે બે પેજ જોવા માટે. |
| Page Width | પેજની પહોળાઈને સ્ક્રીન પ્રમાણે જોવા માટે. |
| New Window | એ જ દસ્તાવેજની નવી વિન્ડો ખોલવા માટે. |
| Arrange All | ખુલેલી બધી વિન્ડોને એકસાથે ગોઠવવા માટે. |
| Split | દસ્તાવેજની વિન્ડોને બે ભાગમાં વહેંચવા માટે. |
| View Side by Side | બે દસ્તાવેજોને બાજુ બાજુમાં જોવા અને સરખાવવા માટે. |
| Synchronous Scrolling | બે દસ્તાવેજોને એકસાથે સ્ક્રોલ કરવા માટે. |
| Reset Window Position | બાજુ બાજુમાં ખુલેલી વિન્ડોની સ્થિતિ ફરી સેટ કરવા માટે. |
| Switch Windows | ખુલેલી Word વિન્ડો વચ્ચે બદલવા માટે. |
| Macros | વારંવાર કરવાના કાર્યોને આપમેળે કરવા માટે. |
