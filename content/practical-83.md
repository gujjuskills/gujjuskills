# પ્રેકટિકલ-૮૩ : નામવાળી રેન્જને વ્યાખ્યાયિત કરો અને રેફરન્સ આપો : MS-EXCEL

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| **Define a named range** | Excel માં કોઈ ચોક્કસ Cell અથવા Cells ના સમૂહને સરળતાથી ઓળખવા માટે આપેલું નામ **Named Range** કહેવાય છે. Named Range બનાવવા માટે Cells પસંદ કરી **Name Box** માં નામ લખી **Enter** દબાવી શકાય છે. |
| **Name a table** | Excel માં Table ને ઓળખવા માટે તેનું નામ આપી શકાય છે. Table પસંદ કર્યા પછી **Table Design → Table Name** માં યોગ્ય નામ દાખલ કરી શકાય છે. |
| **Summarize data visually Insert spark lines** | **Sparklines** એ Cell ની અંદર Data નો નાનો Graph બતાવવાનું સાધન છે. તે Data નો Trend સરળતાથી સમજવામાં મદદ કરે છે. તેને **Insert → Sparklines** માંથી ઉમેરવામાં આવે છે. |
| **Apply built in conditional formatting** | Conditional Formatting દ્વારા ચોક્કસ શરત પ્રમાણે Cells ને આપમેળે Highlight કરી શકાય છે. **Home → Conditional Formatting** માંથી **Highlight Cells Rules, Data Bars, Color Scales** વગેરેનો ઉપયોગ કરી શકાય છે. |
| **Remove conditional formatting** | Conditional Formatting દૂર કરવા માટે Cells પસંદ કરો અને **Home → Conditional Formatting → Clear Rules** પસંદ કરો. ત્યારબાદ જરૂરી મુજબ **Clear Rules from Selected Cells** અથવા **Clear Rules from Entire Sheet** પસંદ કરી શકાય છે. |
