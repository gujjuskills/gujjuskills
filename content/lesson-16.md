# લેશન - ૧૬ : સામાન્ય ડોસ કમાન્ડ્સ
| ડોસ આદેશ | ઉપયોગ |
|:---:|:---|
| **DATE** | કમ્પ્યુટરની તારીખ જોવા અથવા બદલવા માટે ઉપયોગ થાય છે. |
| **TIME** | કમ્પ્યુટરનો સમય જોવા અથવા બદલવા માટે ઉપયોગ થાય છે. |
| **DIR** | વર્તમાન ફોલ્ડરની ફાઇલો અને ફોલ્ડરોની યાદી જોવા માટે ઉપયોગ થાય છે. |
| **CLS** | સ્ક્રીન પર દેખાતી બધી માહિતી સાફ કરવા માટે ઉપયોગ થાય છે. |
| **CD** | વર્તમાન ડિરેક્ટરી બદલવા માટે ઉપયોગ થાય છે. |
| **CD..** | એક લેવલ ઉપરની ડિરેક્ટરીમાં જવા માટે ઉપયોગ થાય છે. |
| **MD** | નવી ડિરેક્ટરી અથવા ફોલ્ડર બનાવવા માટે ઉપયોગ થાય છે. |
| **RD** | ડિરેક્ટરી અથવા ફોલ્ડર દૂર કરવા માટે ઉપયોગ થાય છે. |
| **REN** | ફાઇલ અથવા ફોલ્ડરનું નામ બદલવા માટે ઉપયોગ થાય છે. |
| **DEL** | ફાઇલને કાઢી નાખવા માટે ઉપયોગ થાય છે. |
| **COPY** | એક અથવા વધુ ફાઇલોની નકલ કરવા માટે ઉપયોગ થાય છે. |
| **COPY CON** | કીબોર્ડ દ્વારા નવી ટેક્સ્ટ ફાઇલ બનાવવા માટે ઉપયોગ થાય છે. |
| **XCOPY** | ફાઇલો તેમજ ડિરેક્ટરીઓની નકલ કરવા માટે ઉપયોગ થાય છે. |
| **CHKDSK** | ડિસ્કની તપાસ કરવા અને ડિસ્કની ભૂલો શોધવા માટે ઉપયોગ થાય છે. |
| **PROMPT** | DOS કમાન્ડ પ્રોમ્પ્ટનો દેખાવ બદલવા માટે ઉપયોગ થાય છે. |
| **TREE** | ડિરેક્ટરી અને સબડિરેક્ટરીનું વૃક્ષાકાર માળખું જોવા માટે ઉપયોગ થાય છે. |
| **VER** | DOS અથવા Windows નું વર્ઝન જાણવા માટે ઉપયોગ થાય છે. |
| **PATH** | પ્રોગ્રામ શોધવા માટેની ડિરેક્ટરીનો પાથ સેટ કરવા માટે ઉપયોગ થાય છે. |
| **PRINT** | ટેક્સ્ટ ફાઇલને પ્રિન્ટ કરવા માટે મોકલવા માટે ઉપયોગ થાય છે. |
| **FORMAT** | ડિસ્ક અથવા ડ્રાઇવને ઉપયોગ માટે તૈયાર કરવા અને ફોર્મેટ કરવા માટે ઉપયોગ થાય છે. |
| **TYPE** | ટેક્સ્ટ ફાઇલની અંદરની માહિતી સ્ક્રીન પર જોવા માટે ઉપયોગ થાય છે. |
| **EDIT** | ટેક્સ્ટ ફાઇલ બનાવવા અથવા તેમાં ફેરફાર કરવા માટે ઉપયોગ થાય છે. |
| **MOVE** | ફાઇલ અથવા ફોલ્ડરને એક સ્થાનેથી બીજા સ્થાને ખસેડવા માટે ઉપયોગ થાય છે. |
| **LABEL** | ડિસ્ક અથવા ડ્રાઇવનું નામ જોવા અથવા બદલવા માટે ઉપયોગ થાય છે. |
| **COMP** | બે ફાઇલોની સરખામણી કરવા માટે ઉપયોગ થાય છે. |
| **SYS** | ડ્રાઇવમાં સિસ્ટમ ફાઇલો ટ્રાન્સફર કરવા માટે ઉપયોગ થાય છે. |
| **PING** | નેટવર્ક અથવા કમ્પ્યુટર સાથે કનેક્શન તપાસવા માટે ઉપયોગ થાય છે. |
| **EXIT** | DOS કમાન્ડ પ્રોમ્પ્ટ અથવા કમાન્ડ વિન્ડોમાંથી બહાર નીકળવા માટે ઉપયોગ થાય છે. |
