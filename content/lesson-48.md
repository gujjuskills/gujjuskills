# લેશન - ૪૮ : ડેટાબેઝ સ્કીમાં

| ❖ **ડેટાબેઝ સ્કીમા શું છે?** |
|:---|
| ડેટાબેઝ સ્કીમા એ ડેટાબેઝમાં ડેટા કેવી રીતે ગોઠવાયેલો છે તેની રચના અથવા નકશો છે. તેમાં ટેબલ, કૉલમ, ડેટા પ્રકાર, કી અને ટેબલ વચ્ચેના સંબંધોની માહિતી હોય છે. સ્કીમા ડેટાબેઝની રચનાને સમજવામાં અને ડેટાને યોગ્ય રીતે વ્યવસ્થિત કરવામાં મદદ કરે છે. |

| ❖ **સ્કીમા બનાવવી :** |
|:---|
| ડેટાબેઝ સ્કીમા બનાવવા માટે સૌપ્રથમ જરૂરી ટેબલ અને કૉલમ નક્કી કરવામાં આવે છે. ત્યારબાદ દરેક કૉલમનો ડેટા પ્રકાર, Primary Key અને Foreign Key નક્કી કરવામાં આવે છે. અંતે ટેબલ વચ્ચેના સંબંધો નક્કી કરીને સ્કીમા તૈયાર કરવામાં આવે છે. |

| ❖ **ડેટાબેઝ સ્કીમાના પ્રકાર :** |
|:---|
| ડેટાબેઝ સ્કીમા મુખ્યત્વે ત્રણ પ્રકારની હોય છે: Physical Database Schema, Logical Database Schema અને View Schema. |

| **1 - ભૌતિક ડેટાબેઝ સ્કીમા (Physical Database Schema)** |
|:---|
| આ સ્કીમા ડેટાબેઝમાં ડેટા ભૌતિક રીતે કેવી રીતે સંગ્રહિત થાય છે તે દર્શાવે છે. તેમાં ફાઇલનું સ્થાન, સ્ટોરેજ, ઇન્ડેક્સ અને ડેટા સંગ્રહ કરવાની પદ્ધતિ જેવી માહિતીનો સમાવેશ થાય છે. |

| **2 - તાર્કિક ડેટાબેઝ સ્કીમા (Logical Database Schema)** |
|:---|
| આ સ્કીમા ડેટાબેઝમાં ટેબલ, કૉલમ, Primary Key, Foreign Key અને ટેબલ વચ્ચેના સંબંધોને દર્શાવે છે. તે ડેટાની તાર્કિક રચના સમજાવે છે. |

| **3 - વ્યૂ સ્કીમા (View Schema)** |
|:---|
| આ સ્કીમા યુઝરને ડેટાબેઝનો જરૂરી ભાગ જોવા માટેનું દૃશ્ય પ્રદાન કરે છે. તેમાં યુઝરની જરૂરિયાત મુજબ પસંદ કરેલો ડેટા દર્શાવવામાં આવે છે. |

| ❖ **ડેટાબેઝ સ્કીમા ડિઝાઇન :** |
|:---|
| ડેટાબેઝ સ્કીમા ડિઝાઇન એટલે ડેટાબેઝમાં ડેટાને ટેબલ અને તેમના સંબંધોના સ્વરૂપમાં યોગ્ય રીતે ગોઠવવાની પ્રક્રિયા. સારી સ્કીમા ડિઝાઇન ડેટાની પુનરાવર્તનતા ઘટાડે છે અને ડેટાની સુસંગતતા જાળવે છે. |

| ❖ **ડેટાબેઝ સ્કીમા ડિઝાઇનની યાદી :** |
|:---|
| **1. સ્ટાર સ્કીમા (Star Schema)** |
| **2. સ્નોફ્લેક સ્કીમા (Snowflake Schema)** |
| **3. ગેલેક્સી સ્કીમા (Galaxy Schema)** |
| **4. ફેક્ટ કોન્સ્ટેલેશન સ્કીમા (Fact Constellation Schema)** |
| **5. હાઇબ્રિડ સ્કીમા (Hybrid Schema)** |
