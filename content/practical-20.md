# પ્રેકટિકલ-૨૦ : સોફ્ટવેરને વિન્ડોસમાં ઇન્સ્ટોલ કરવું

![image](/gujjuskills/images/practical-20.png)

## સોફ્ટવેર ડાઉનલોડ અને ઇન્સ્ટોલ કરવાની પ્રક્રિયા

### 1. ઇન્ટરનેટ કનેક્શન ચાલુ કરવું

સૌપ્રથમ કમ્પ્યુટરને ઇન્ટરનેટ સાથે કનેક્ટ કરવું.

### 2. વેબ બ્રાઉઝર ખોલવું

Google Chrome, Microsoft Edge અથવા Mozilla Firefox જેવા કોઈપણ વેબ બ્રાઉઝરને ખોલવું.

### 3. સોફ્ટવેરની સત્તાવાર વેબસાઇટ શોધવી

સર્ચ એન્જિનમાં જરૂરી સોફ્ટવેરનું નામ લખીને તેની સત્તાવાર વેબસાઇટ શોધવી.

ઉદાહરણ:

`Google Chrome Download`

### 4. Download વિકલ્પ પસંદ કરવો

સોફ્ટવેરની સત્તાવાર વેબસાઇટ ખોલ્યા પછી **Download** અથવા **Download Now** બટન પર ક્લિક કરવું.

### 5. ઇન્સ્ટોલેશન ફાઇલ ડાઉનલોડ કરવી

Download બટન પર ક્લિક કર્યા પછી સોફ્ટવેરની ઇન્સ્ટોલેશન ફાઇલ કમ્પ્યુટરમાં ડાઉનલોડ થશે.

સામાન્ય રીતે આ ફાઇલ **Downloads** ફોલ્ડરમાં સેવ થાય છે.

### 6. ડાઉનલોડ કરેલી ફાઇલ ખોલવી

Downloads ફોલ્ડરમાં જઈને ડાઉનલોડ કરેલી Setup અથવા Installer ફાઇલ પર બે વખત ક્લિક કરવું.

### 7. User Account Control ની પરવાનગી આપવી

વિન્ડોઝમાં સુરક્ષા માટે User Account Control સંદેશ દેખાઈ શકે છે.

જો સોફ્ટવેર વિશ્વસનીય અને સત્તાવાર સ્ત્રોત પરથી ડાઉનલોડ કરેલું હોય, તો **Yes** પસંદ કરવું.

### 8. Installation શરૂ કરવું

ઇન્સ્ટોલેશન વિઝાર્ડ ખુલ્યા પછી સ્ક્રીન પર આપેલા સૂચનો વાંચવા અને **Next**, **Install** અથવા **Continue** વિકલ્પ પસંદ કરવા.

### 9. જરૂરી વિકલ્પો પસંદ કરવા

કેટલાક સોફ્ટવેરમાં Installation Location, Shortcut અને અન્ય વિકલ્પો પસંદ કરવા માટે પૂછવામાં આવે છે.

જરૂરિયાત મુજબ યોગ્ય વિકલ્પ પસંદ કરવો.

### 10. Installation પૂર્ણ થવાની રાહ જોવી

સોફ્ટવેરની ફાઇલો કમ્પ્યુટરમાં ઇન્સ્ટોલ થશે.

આ પ્રક્રિયામાં થોડો સમય લાગી શકે છે.

### 11. Finish વિકલ્પ પસંદ કરવો

ઇન્સ્ટોલેશન પૂર્ણ થયા પછી **Finish** બટન પર ક્લિક કરવું.

### 12. સોફ્ટવેર શરૂ કરવું

Desktop પર બનાવેલા Shortcut અથવા Start Menu માંથી સોફ્ટવેર ખોલી તેનો ઉપયોગ કરી શકાય છે.

| 1 | Google Chrome | ઇન્ટરનેટ બ્રાઉઝ કરવા માટે |
