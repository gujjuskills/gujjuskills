# પ્રેકટિકલ-૧૫૮ : સ્પ્રેડશીટ માટે AI સાધનોનો ઉપયોગ કરો

![image](/images/practical-158.webp)

## AI Tools દ્વારા કરી શકાય તેવા કાર્યો

1. Data Entry અને Data Cleaning
2. Formula અને Function બનાવવું
3. Data Analysis કરવું
4. Duplicate Data શોધવું અને દૂર કરવું
5. Table બનાવવી અને Format કરવું
6. Charts અને Graphs બનાવવું
7. Pivot Table બનાવવી
8. Data Sort અને Filter કરવું
9. Conditional Formatting માટે નિયમો બનાવવું
10. Excel Formula ની ભૂલો શોધવી અને સુધારવી
11. Data પરથી Summary અને Report બનાવવી
12. Excel Automation માટે VBA Code બનાવવું
13. Dataમાંથી મહત્વપૂર્ણ માહિતી શોધવી
14. Spreadsheet માટે Ideas અને Suggestions મેળવવા
15. Complex Excel Functions સમજવા અને ઉપયોગ કરવા

## Useful AI Tools for Spreadsheet

| AI Tool | ઉપયોગ |
|---|---|
| **Microsoft Copilot for Excel** | Excelમાં Data Analysis, Formula અને Insights |
| **Microsoft Excel Ideas / Analyze Data** | Automatic Insights અને Charts |
| **Rows AI** | AI આધારિત Spreadsheet Analysis |
| **Numerous AI** | Spreadsheetમાં AI Formula અને Text Processing |
| **Formula Bot** | Natural Languageમાંથી Excel Formula બનાવવું |
