# પ્રેકટિકલ-૮૪ : ટેબલ બનાવો અને ફોરમેટ કરો : MS-EXCEL

| Topic | વિગતવાર જવાબ |
|---|---|
| Create excel tables from cell ranges | સેલ રેન્જમાંથી Excel Table બનાવવા માટે સૌપ્રથમ જરૂરી ડેટા ધરાવતી cell range પસંદ કરો. ત્યારબાદ **Insert → Table** પસંદ કરો અથવા `Ctrl + T` દબાવો. **Create Table** ડાયલોગ બોક્સમાં પસંદ કરેલી cell range તપાસો અને જો પ્રથમ row માં heading હોય તો **My table has headers** વિકલ્પ પસંદ કરો. ત્યારબાદ **OK** પર ક્લિક કરતાં પસંદ કરેલો ડેટા Table માં રૂપાંતરિત થઈ જશે. |
| Apply table styles | Excel Table પર અલગ અલગ **Table Styles** લાગુ કરવા માટે Table માં કોઈપણ cell પસંદ કરો. ત્યારબાદ **Table Design → Table Styles** માંથી જરૂરી style પસંદ કરો. અહીં Header Row, Total Row, Banded Rows અને Banded Columns જેવા વિકલ્પોનો ઉપયોગ કરીને Table નું દેખાવ અને formatting બદલી શકાય છે. |
| Convert tables to cell ranges | Excel Table ને સામાન્ય cell range માં ફેરવવા માટે Table માં કોઈપણ cell પસંદ કરો. ત્યારબાદ **Table Design → Convert to Range** પસંદ કરો. પુષ્ટિ માટે દેખાતા સંદેશામાં **Yes** પસંદ કરો. ત્યારબાદ Table ની વિશેષતાઓ દૂર થઈ જશે અને ડેટા સામાન્ય cell range તરીકે રહેશે, જોકે લાગુ કરેલું formatting સામાન્ય રીતે યથાવત્ રહે છે. |
