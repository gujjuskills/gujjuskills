## લેશન - ૩૮ : રેફરન્સ અને સેલ નેમિંગના પ્રકારો

### સેલ રેફરન્સ શું છે?

 સેલ રેફરન્સ  Excel માં કોઈ ચોક્કસ સેલનું સ્થાન દર્શાવતું સરનામું સેલ રેફરન્સ કહેવાય છે. તે Column Letter અને Row Number થી બને છે. 
 ઉદાહરણ  `A1`, `B5`, `C10` વગેરે. 

### સેલ રેફરન્સના પ્રકાર

| ક્રમાંક | પ્રકાર | વર્ણન | ઉદાહરણ |
|---|---|---|---|
| 1 | Relative Reference (સાપેક્ષ રેફરન્સ) | Formula ને બીજા સેલમાં Copy અથવા Move કરવાથી Row અને Column બંનેનું રેફરન્સ બદલાય છે. | `A1` |
| 2 | Absolute Reference (નિરપેક્ષ રેફરન્સ) | Formula Copy અથવા Move કરવાથી Row અને Columnનું રેફરન્સ બદલાતું નથી. Row અને Column પહેલાં `$` ચિહ્ન વપરાય છે. | `$A$1` |
| 3 | Mixed Reference (મિશ્ર રેફરન્સ) | Row અથવા Columnમાંથી માત્ર એકનું રેફરન્સ સ્થિર રહે છે અને બીજું બદલાય છે. | `$A1` અથવા `A$1` |
