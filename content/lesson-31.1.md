# લેશન - ૩૧.૧ : એનિમેશન ટેબ : MS PowerPoint
![image](/gujjuskills/images/practical-31.1.png)
| Animation Tab | ઉપયોગ |
|---|---|
| **Animation Tab** | PowerPoint માં ઑબ્જેક્ટ, ટેક્સ્ટ અથવા ચિત્ર પર એનિમેશન લાગુ કરવા માટે Animation Tab નો ઉપયોગ થાય છે. |
| **Preview** | લાગુ કરેલું એનિમેશન સ્લાઇડમાં કેવી રીતે દેખાશે તે જોવા માટે Preview નો ઉપયોગ થાય છે. |
| **Animation** | પસંદ કરેલા ટેક્સ્ટ અથવા ઑબ્જેક્ટને વિવિધ પ્રકારની એનિમેશન ઇફેક્ટ આપવા માટે તેનો ઉપયોગ થાય છે. |
| **Add Animation** | એક જ ઑબ્જેક્ટમાં એક કરતાં વધુ એનિમેશન ઇફેક્ટ ઉમેરવા માટે Add Animation નો ઉપયોગ થાય છે. |
| **Animation Pane** | સ્લાઇડમાં લાગુ કરેલા તમામ એનિમેશનની યાદી જોવા અને તેની ક્રમબદ્ધતા બદલવા માટે Animation Pane નો ઉપયોગ થાય છે. |
| **Trigger** | કોઈ ચોક્કસ ઑબ્જેક્ટ પર ક્લિક કરવાથી એનિમેશન શરૂ કરવા માટે Trigger નો ઉપયોગ થાય છે. |
| **Animation Painter** | એક ઑબ્જેક્ટનું એનિમેશન બીજા ઑબ્જેક્ટ પર કૉપી કરવા માટે Animation Painter નો ઉપયોગ થાય છે. |
| **Start** | એનિમેશન ક્યારે શરૂ થશે તે નક્કી કરવા માટે Start વિકલ્પનો ઉપયોગ થાય છે. જેમ કે On Click, With Previous અને After Previous. |
| **Duration** | એનિમેશન કેટલા સમય સુધી ચાલશે તે નક્કી કરવા માટે Duration નો ઉપયોગ થાય છે. |
| **Delay** | એનિમેશન શરૂ થતાં પહેલાં કેટલો સમય રાહ જોવી તે નક્કી કરવા માટે Delay નો ઉપયોગ થાય છે. |
| **Reorder Animation** | એકથી વધુ એનિમેશનનો ક્રમ આગળ અથવા પાછળ કરવા માટે Reorder Animation નો ઉપયોગ થાય છે. |
