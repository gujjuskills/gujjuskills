## પ્રેક્ટિકલ - ૩૨ : લિનક્સમાં સિસ્ટમ સેટિંગ્સનું સંચાલન કરવું.

| પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|---|---|
| Wi-Fi | Wi-Fi સેટિંગ દ્વારા ઉપલબ્ધ વાયરલેસ નેટવર્ક શોધી, કનેક્ટ અથવા ડિસ્કનેક્ટ કરી શકાય છે. |
| Network | નેટવર્ક સેટિંગ દ્વારા ઈન્ટરનેટ કનેક્શન, IP સરનામું, પ્રોક્સી અને અન્ય નેટવર્ક વિકલ્પોનું સંચાલન કરી શકાય છે. |
| Bluetooth | Bluetooth દ્વારા વાયરલેસ ઉપકરણો જેમ કે માઉસ, કીબોર્ડ, હેડફોન વગેરેને કનેક્ટ અને મેનેજ કરી શકાય છે. |
| Displays | ડિસ્પ્લે સેટિંગ દ્વારા સ્ક્રીનનું રિઝોલ્યુશન, ઓરિએન્ટેશન, સ્કેલિંગ અને એકથી વધુ ડિસ્પ્લેનું સંચાલન કરી શકાય છે. |
| Sound | સાઉન્ડ સેટિંગ દ્વારા સ્પીકર, માઇક્રોફોન, વોલ્યુમ અને ઓડિયો ઇનપુટ તથા આઉટપુટનું સંચાલન કરી શકાય છે. |
| Power | પાવર સેટિંગ દ્વારા સ્ક્રીન બંધ થવાનો સમય, સ્લીપ મોડ અને પાવર બચત સંબંધિત વિકલ્પો બદલી શકાય છે. |
| Multitasking | મલ્ટીટાસ્કિંગ સેટિંગ દ્વારા વિન્ડોઝ, વર્કસ્પેસ અને એપ્લિકેશનો વચ્ચે કાર્ય કરવાની રીતને નિયંત્રિત કરી શકાય છે. |
| Appearance | અપિયરન્સ સેટિંગ દ્વારા ડેસ્કટોપની થીમ, બેકગ્રાઉન્ડ, આઇકોન અને અન્ય દેખાવ સંબંધિત વિકલ્પો બદલી શકાય છે. |
| Ubuntu Desktop | Ubuntu Desktop સેટિંગ દ્વારા ડેસ્કટોપનું વર્તન, ડોક, આઇકોન અને અન્ય ડેસ્કટોપ વિકલ્પોનું સંચાલન કરી શકાય છે. |
| Apps | Apps સેટિંગ દ્વારા ઇન્સ્ટોલ કરેલી એપ્લિકેશનો, ડિફોલ્ટ એપ્સ અને એપ સંબંધિત પરવાનગીઓનું સંચાલન કરી શકાય છે. |
| Notification | Notification સેટિંગ દ્વારા વિવિધ એપ્લિકેશનોની સૂચનાઓ ચાલુ અથવા બંધ કરી શકાય છે અને સૂચનાઓ કેવી રીતે દેખાય તે નક્કી કરી શકાય છે. |
| Search | Search સેટિંગ દ્વારા સિસ્ટમમાં શોધ કરતી વખતે કઈ સામગ્રી અને એપ્લિકેશનો શોધમાં દર્શાવવી તે નિયંત્રિત કરી શકાય છે. |
| Online Accounts | Online Accounts દ્વારા Google જેવી ઓનલાઈન સેવાઓના એકાઉન્ટને Ubuntu સાથે જોડીને તેનો ઉપયોગ કરી શકાય છે. |
| Sharing | Sharing સેટિંગ દ્વારા ફાઇલો, મીડિયા અને અન્ય સંસાધનોને નેટવર્ક પર શેર કરવાની સુવિધાઓનું સંચાલન કરી શકાય છે. |
| Mouse & Touch Pad | Mouse & Touch Pad સેટિંગ દ્વારા માઉસની ઝડપ, સ્ક્રોલિંગ અને ટચપેડના ટચ તથા ક્લિક સંબંધિત વિકલ્પો બદલી શકાય છે. |
| Keyboard | Keyboard સેટિંગ દ્વારા કીબોર્ડ લેઆઉટ, ભાષા, શોર્ટકટ અને ટાઇપિંગ સંબંધિત વિકલ્પોનું સંચાલન કરી શકાય છે. |
| Color | Color સેટિંગ દ્વારા સ્ક્રીનના રંગ પ્રોફાઇલ અને રંગ સંબંધિત સેટિંગ્સનું સંચાલન કરી શકાય છે. |
| Printers | Printers સેટિંગ દ્વારા પ્રિન્ટર ઉમેરવા, દૂર કરવા અને પ્રિન્ટિંગ સંબંધિત વિકલ્પોનું સંચાલન કરી શકાય છે. |
| Accessibility | Accessibility સેટિંગ દ્વારા દૃષ્ટિ, શ્રવણ અને અન્ય જરૂરિયાતો ધરાવતા વપરાશકર્તાઓ માટે ઉપયોગી સુવિધાઓ સક્રિય કરી શકાય છે. |
| Privacy & Security | Privacy & Security સેટિંગ દ્વારા વ્યક્તિગત માહિતી, સ્થાન, કેમેરા, માઇક્રોફોન અને અન્ય સુરક્ષા તથા ગોપનીયતા વિકલ્પોનું સંચાલન કરી શકાય છે. |
| System | System સેટિંગ દ્વારા તારીખ અને સમય, વપરાશકર્તા, સિસ્ટમની માહિતી અને અન્ય મુખ્ય સિસ્ટમ સેટિંગ્સનું સંચાલન કરી શકાય છે. |
