# લેશન - ૬૦ : મૂળભૂત નેટવર્ક પ્રોટોકોલનો પરિચય

| Topics | માહિતી |
|---|---|
| What is Network Protocol? | નેટવર્ક પ્રોટોકોલ એ કમ્પ્યુટર અને અન્ય ઉપકરણો વચ્ચે ડેટાની આપલે કરવા માટેના નિયમો અને પ્રક્રિયાઓનો સમૂહ છે. તે ડેટા કેવી રીતે મોકલવો, પ્રાપ્ત કરવો અને સમજવો તે નક્કી કરે છે. |
| HTTP / HTTPS | **HTTP (HyperText Transfer Protocol)** વેબ બ્રાઉઝર અને વેબ સર્વર વચ્ચે વેબ પેજ અને અન્ય ડેટા ટ્રાન્સફર કરવા માટે વપરાય છે. **HTTPS** એ HTTPનું સુરક્ષિત સંસ્કરણ છે, જે ડેટાને એન્ક્રિપ્ટ કરે છે. |
| FTP | **FTP (File Transfer Protocol)** એક કમ્પ્યુટરથી બીજા કમ્પ્યુટરમાં ફાઇલો મોકલવા અને મેળવવા માટે વપરાય છે. |
| SMTP, POP3, IMAP | **SMTP (Simple Mail Transfer Protocol)** ઈમેલ મોકલવા માટે વપરાય છે. **POP3 (Post Office Protocol 3)** ઈમેલ સર્વરમાંથી ઈમેલ ડાઉનલોડ કરવા માટે વપરાય છે. **IMAP (Internet Message Access Protocol)** સર્વર પર રહેલા ઈમેલને ઍક્સેસ અને મેનેજ કરવા માટે વપરાય છે. |
| IP | **IP (Internet Protocol)** નેટવર્ક પર ઉપકરણોને ઓળખવા માટે IP Addressનો ઉપયોગ કરે છે અને ડેટા પેકેટને યોગ્ય ગંતવ્ય સુધી પહોંચાડવામાં મદદ કરે છે. |
| TCP | **TCP (Transmission Control Protocol)** ડેટાને વિશ્વસનીય રીતે મોકલવા માટે વપરાય છે. તે ડેટા યોગ્ય ક્રમમાં અને ભૂલ વગર પ્રાપ્ત થાય તેની ખાતરી કરવામાં મદદ કરે છે. |
