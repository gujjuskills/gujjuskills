# પ્રેકટિકલ-૧૧૪.૨ : નંબર ફંક્શનનો ઉપયોગ : MY SQL
| નંબર ફંક્શન | કાર્ય |
|---|---|
| `PI()` | π (પાઈ) નું મૂલ્ય આપે છે. |
| `SQRT()` | આપેલ સંખ્યાનું વર્ગમૂળ આપે છે. |
| `POW()` | આપેલ સંખ્યાની ઘાતની ગણતરી કરે છે. |
| `MOD()` | ભાગાકાર કર્યા પછીનો શેષ આપે છે. |
| `DIV()` | બે સંખ્યાઓનો પૂર્ણાંક ભાગફલ આપે છે. |
| `ABS()` | સંખ્યાનું ધનાત્મક મૂલ્ય આપે છે. |
| `RAND()` | 0 અને 1 વચ્ચેની રેન્ડમ સંખ્યા આપે છે. |
| `ROUND()` | સંખ્યાને નિર્ધારિત દશાંશ સ્થાન સુધી રાઉન્ડ કરે છે. |
| `TRUNCATE()` | સંખ્યાના દશાંશ ભાગને કાપીને મૂલ્ય આપે છે. |
| `CEIL()` | સંખ્યાને નજીકની મોટી પૂર્ણ સંખ્યા તરફ રાઉન્ડ કરે છે. |
| `FLOOR()` | સંખ્યાને નજીકની નાની પૂર્ણ સંખ્યા તરફ રાઉન્ડ કરે છે. |
| `GREATEST()` | આપેલ સંખ્યાઓમાંથી સૌથી મોટી સંખ્યા આપે છે. |
| `LEAST()` | આપેલ સંખ્યાઓમાંથી સૌથી નાની સંખ્યા આપે છે. |
| `DEGREES()` | રેડિયનને ડિગ્રીમાં રૂપાંતરિત કરે છે. |
| `RADIANS()` | ડિગ્રીને રેડિયનમાં રૂપાંતરિત કરે છે. |
| `SIN()` | આપેલ ખૂણાનું સાઈન મૂલ્ય આપે છે. |
| `COS()` | આપેલ ખૂણાનું કોસાઈન મૂલ્ય આપે છે. |
| `TAN()` | આપેલ ખૂણાનું ટેન્જન્ટ મૂલ્ય આપે છે. |
| `MAX()` | આપેલ શ્રેણીમાંથી સૌથી મોટી સંખ્યા આપે છે. |
| `MIN()` | આપેલ શ્રેણીમાંથી સૌથી નાની સંખ્યા આપે છે. |
| `SUM()` | આપેલ સંખ્યાઓનો કુલ સરવાળો કરે છે. |
| `AVG()` | આપેલ સંખ્યાઓની સરેરાશ કાઢે છે. |
| `COUNT()` | આપેલ શ્રેણીમાં રહેલી સંખ્યાત્મક એન્ટ્રીઓની સંખ્યા ગણે છે. |
