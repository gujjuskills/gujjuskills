# લેશન - ૪૪ : પાવર ક્વેરીસ

## ❖ પાવર ક્વેરી શું છે?

**પાવર ક્વેરી (Power Query)** એ Microsoft Excel માં ઉપલબ્ધ એક શક્તિશાળી Data Transformation અને Data Management ટૂલ છે. તેનો ઉપયોગ વિવિધ સ્ત્રોતોમાંથી ડેટા મેળવવા, ડેટાને સાફ કરવા, બદલવા, ગોઠવવા અને Excel માં લોડ કરવા માટે થાય છે.

પાવર ક્વેરી દ્વારા વારંવાર કરવાના ડેટા ક્લીનિંગ અને ટ્રાન્સફોર્મેશનના કામને આપમેળે કરી શકાય છે.

## ❖ પાવર ક્વેરીના તબક્કાઓ

**Connect → Transform → Combine → Load**

ડેટા મેળવવો, તેમાં ફેરફાર કરવો, અલગ ડેટાને જોડવો અને અંતે Excelમાં લોડ કરવો.

## ❖ પાવર ક્વેરીથી શું કરી શકાય?

ડેટા Import, Sort, Filter, Clean, Merge, Append, Split, Combine અને Duplicate Data દૂર કરી શકાય છે.

## ❖ પાવર ક્વેરીના ફાયદા

સમયની બચત થાય છે, Manual કામ ઘટે છે અને Data Cleaning સરળ બને છે. Query ને Refresh કરીને નવા ડેટા પર પણ એ જ પ્રક્રિયા ફરીથી કરી શકાય છે.
