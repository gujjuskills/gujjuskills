# લેશન - ૬૫ : સમગ્ર નેટવર્કમાં રાઉટિંગ

| Topic | માહિતી |
|---|---|
| What is routing? | રાઉટિંગ એ નેટવર્કમાં ડેટા પેકેટને તેના સ્ત્રોતથી યોગ્ય ગંતવ્ય સુધી પહોંચાડવાની પ્રક્રિયા છે. રાઉટર ડેટા માટે યોગ્ય માર્ગ પસંદ કરે છે. |
| What is a router? | રાઉટર એ નેટવર્ક ઉપકરણ છે જે વિવિધ નેટવર્કને જોડે છે અને ડેટા પેકેટને યોગ્ય ગંતવ્ય સુધી મોકલે છે. |
| How does routing work? | રાઉટર ડેટાના ગંતવ્ય IP એડ્રેસને તપાસે છે અને રાઉટિંગ ટેબલની મદદથી શ્રેષ્ઠ માર્ગ પસંદ કરીને ડેટા પેકેટને આગળ મોકલે છે. |
| What are the types of routing? | રાઉટિંગના મુખ્ય બે પ્રકાર છે: 1. Static Routing 2. Dynamic Routing |
| Static Routing | Static Routing માં રાઉટિંગ માર્ગ નેટવર્ક એડમિનિસ્ટ્રેટર દ્વારા મેન્યુઅલી સેટ કરવામાં આવે છે. નેટવર્કમાં ફેરફાર થાય ત્યારે માર્ગને મેન્યુઅલી બદલવો પડે છે. |
| Dynamic Routing | Dynamic Routing માં રાઉટર રાઉટિંગ પ્રોટોકોલની મદદથી શ્રેષ્ઠ માર્ગ આપમેળે પસંદ કરે છે. નેટવર્કમાં ફેરફાર થાય ત્યારે રાઉટિંગ ટેબલ આપમેળે અપડેટ થાય છે. |
