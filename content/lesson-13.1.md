

## લેશન - ૧૩.૧ : વિવિધ પ્રકારની મેમરી અને તેની વિશેષતાઓ

| **મેમરીનો પ્રકાર** | **સામાન્ય માહિતી** |
|:---:|:---:|
| **પ્રાથમિક મેમરી (Primary Memory)** | કમ્પ્યુટર દ્વારા સીધી ઍક્સેસ કરી શકાય તેવી મુખ્ય મેમરી. |
| **RAM (રેન્ડમ ઍક્સેસ મેમરી)** | RAM અસ્થાયી મેમરી છે. કમ્પ્યુટર ચાલુ હોય ત્યારે પ્રોગ્રામ અને ડેટા સંગ્રહિત કરે છે. વીજ પુરવઠો બંધ થતાં તેમાંનો ડેટા નષ્ટ થઈ જાય છે. |
| **ROM (રીડ ઓન્લી મેમરી)** | ROM કાયમી મેમરી છે. તેમાં સંગ્રહિત માહિતી સામાન્ય રીતે વીજ પુરવઠો બંધ થયા પછી પણ જળવાઈ રહે છે. |
| **કૅશ મેમરી (Cache Memory)** | ખૂબ ઝડપી મેમરી છે, જે CPU અને મુખ્ય મેમરી વચ્ચે કાર્ય કરે છે અને વારંવાર જરૂરી ડેટા ઝડપથી ઉપલબ્ધ કરાવે છે. |
| **દ્વિતીયક મેમરી (Secondary Memory)** | ડેટા અને પ્રોગ્રામને લાંબા સમય સુધી સંગ્રહિત કરવા માટે વપરાતી કાયમી મેમરી. |
| **પંચ કાર્ડ (Punch Card)** | કાગળના કાર્ડ પર છિદ્રોના સ્વરૂપમાં ડેટા સંગ્રહિત કરવાની જૂની પદ્ધતિ. |
| **મૅગ્નેટિક ટેપ (Magnetic Tape)** | ચુંબકીય પટ્ટી પર ડેટા સંગ્રહિત કરે છે. મોટા પ્રમાણમાં ડેટાના બૅકઅપ માટે ઉપયોગી છે. |
| **મૅગ્નેટિક ડિસ્ક (Magnetic Disk)** | ચુંબકીય સપાટી પર ડેટા સંગ્રહિત કરે છે. હાર્ડ ડિસ્ક અને ફ્લોપી ડિસ્ક તેના ઉદાહરણો છે. |
| **ઑપ્ટિકલ ડિસ્ક (Optical Disk)** | લેસર ટેક્નોલોજીનો ઉપયોગ કરીને ડેટા વાંચવા અને સંગ્રહિત કરવા માટે વપરાય છે. CD, DVD અને Blu-ray તેના ઉદાહરણો છે. |
| **ફ્લૅશ મેમરી (Flash Memory)** | અસ્થિર ન હોય તેવી મેમરી છે. USB ડ્રાઇવ, મેમરી કાર્ડ અને SSD જેવા ઉપકરણોમાં તેનો ઉપયોગ થાય છે.
