# લેશન - ૯૮ : ક્લાઉડ સર્વિસના ફાયદાઓ અને તેના વિવિધ પ્રકાર

## What is Cloud Computing :

Cloud Computing એટલે Internet દ્વારા કમ્પ્યુટર, સર્વર, સ્ટોરેજ, સોફ્ટવેર અને અન્ય IT સેવાઓનો ઉપયોગ કરવાની પદ્ધતિ. તેમાં પોતાના કમ્પ્યુટરમાં બધું સ્ટોર અથવા મેનેજ કરવાની જરૂર પડતી નથી. જરૂરિયાત મુજબ Cloud Service નો ઉપયોગ કરી શકાય છે.

## Characteristics of Cloud Computing :

| ક્રમ | Characteristic | ગુજરાતી માહિતી |
|---|---|---|
| 1 | On Demand Service | જરૂરિયાત મુજબ કોઈપણ સમયે Cloud Service મેળવી શકાય છે. |
| 2 | Resource Sharing | એક જ Cloud Infrastructure ના Resources ઘણા Users વચ્ચે વહેંચી શકાય છે. |
| 3 | Scalability | જરૂરિયાત પ્રમાણે Resources વધારી અથવા ઘટાડી શકાય છે. |
| 4 | Internet Access | Internet દ્વારા કોઈપણ સ્થળેથી Cloud Service નો ઉપયોગ કરી શકાય છે. |
| 5 | Pay as You Use | જેટલી Service નો ઉપયોગ કરવામાં આવે તેટલો જ ખર્ચ થાય છે. |

## Advantages and Disadvantages of Cloud Computing :

| ક્રમ | Advantages | Disadvantages |
|---|---|---|
| 1 | Hardware અને Software ખરીદવાનો ખર્ચ ઓછો થાય છે. | Cloud Service માટે Internet જરૂરી છે. |
| 2 | Internet દ્વારા કોઈપણ સ્થળેથી Data અને Services મેળવી શકાય છે. | Data Security અને Privacy નું જોખમ રહી શકે છે. |
| 3 | Data નો Backup સરળતાથી રાખી શકાય છે. | Cloud Provider ની Service બંધ થાય તો Service નો ઉપયોગ કરી શકાતો નથી. |
| 4 | જરૂરિયાત પ્રમાણે Resources વધારી અથવા ઘટાડી શકાય છે. | User પાસે Cloud Infrastructure પર સંપૂર્ણ Control હોતું નથી. |
| 5 | Software અને Security Updates ઘણી વખત આપમેળે થાય છે. | Sensitive Data Cloud પર Store કરવાથી Privacy સંબંધિત સમસ્યા થઈ શકે છે. |

## Types of Cloud Computing :

| ક્રમ | Type | ગુજરાતી માહિતી |
|---|---|---|
| 1 | Public Cloud | Public Cloud માં Cloud Services સામાન્ય રીતે ઘણા Users માટે Internet દ્વારા ઉપલબ્ધ હોય છે. |
| 2 | Private Cloud | Private Cloud કોઈ એક Organization અથવા User માટે Dedicated હોય છે. |
| 3 | Hybrid Cloud | Hybrid Cloud માં Public Cloud અને Private Cloud બંનેનો સંયુક્ત ઉપયોગ થાય છે. |
| 4 | Community Cloud | Community Cloud સમાન જરૂરિયાત ધરાવતી Organizations અથવા Users દ્વારા શેર કરવામાં આવે છે. |

## Service Model of Cloud Computing :

| Infrastructure as a Service (IaaS) | Platform as a Service (PaaS) | Software as a Service (SaaS) |
|---|---|---|
| IaaS માં Virtual Machine, Storage અને Network જેવા Infrastructure Resources આપવામાં આવે છે. | PaaS માં Application બનાવવા અને ચલાવવા માટે Platform અને Development Tools આપવામાં આવે છે. | SaaS માં તૈયાર Software અથવા Application Internet દ્વારા ઉપયોગ કરવા માટે આપવામાં આવે છે. |
| User Operating System અને Applications ને Manage કરી શકે છે. | Developer Application પર ધ્યાન આપી શકે છે અને Infrastructure Provider દ્વારા Manage થાય છે. | User ને Software Install કરવાની જરૂર નથી. Browser અથવા App દ્વારા તેનો ઉપયોગ કરી શકાય છે. |
| Example: Amazon EC2 | Example: Google App Engine | Example: Google Workspace |
| ઉપયોગ: Server અને Infrastructure માટે. | ઉપયોગ: Application Development માટે. | ઉપયોગ: Ready Made Software માટે. |
