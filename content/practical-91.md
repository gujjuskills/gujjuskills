# પ્રેકટિકલ-૯૧ : ચાર્ટમાં ફેરફાર કરો : MS-EXCEL

| Topic | સામાન્ય સમજૂતી |
|---|---|
| Add data series to charts | Chart માં નવી Data Series ઉમેરવા માટે Chart પર ક્લિક કરો અને **Chart Design → Select Data** વિકલ્પ પસંદ કરો. ત્યારબાદ **Add** પર ક્લિક કરીને Series Name અને Series Values પસંદ કરો અને **OK** કરો. |
| Switch between rows and columns in source data | Chart માં Rows અને Columns વચ્ચે Data બદલવા માટે Chart પસંદ કરો અને **Chart Design → Switch Row/Column** વિકલ્પ પસંદ કરો. આથી Chart માં Data ની ગોઠવણી બદલાઈ જાય છે. |
| Add and modify chart elements | Chart ના Title, Axis Titles, Legend, Data Labels, Gridlines વગેરે ઉમેરવા અથવા બદલવા માટે Chart પસંદ કરો અને **Chart Design → Add Chart Element** નો ઉપયોગ કરો. જરૂરી Element પસંદ કરીને તેની Position અને Format બદલી શકાય છે. |
| Add trend lines to chart | Data માં રહેલા Trend અથવા Pattern દર્શાવવા માટે Chart પસંદ કરો અને **Chart Design → Add Chart Element → Trendline** પસંદ કરો. ત્યારબાદ Linear, Exponential, Moving Average વગેરેમાંથી જરૂરી Trendline પસંદ કરી શકાય છે. |
