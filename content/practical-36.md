# પ્રેકટિકલ-૩૬ : દસ્તાવેજો સાચવો અને શેર કરો

| ટોપિક | સામાન્ય સમજણ / કાર્ય |
|---|---|
| **વૈકલ્પિક ફાઇલ ફોર્મેટમાં દસ્તાવેજ સાચવવો** | MS Wordમાં દસ્તાવેજને વિવિધ ફાઇલ ફોર્મેટમાં સાચવી શકાય છે. **File → Save As** પસંદ કરીને જરૂરી ફાઇલ પ્રકાર પસંદ કરો. દસ્તાવેજને **.docx, .pdf, .txt, .rtf** વગેરે ફોર્મેટમાં સાચવી શકાય છે. |
| **દસ્તાવેજના મૂળભૂત ગુણધર્મોમાં ફેરફાર કરવો** | દસ્તાવેજના નામ, લેખક, વિષય અને અન્ય ગુણધર્મોમાં ફેરફાર કરી શકાય છે. **File → Info → Properties** માં જઈને દસ્તાવેજની જરૂરી માહિતી ઉમેરો અથવા બદલો. |
| **પ્રિન્ટ સેટિંગ્સમાં ફેરફાર કરવો** | દસ્તાવેજ પ્રિન્ટ કરતા પહેલાં પેજની સંખ્યા, પ્રિન્ટર, નકલની સંખ્યા, પેજ ઓરિએન્ટેશન અને પેપર સાઇઝ જેવી સેટિંગ્સ પસંદ કરી શકાય છે. **File → Print** માં જઈને જરૂરી સેટિંગ્સ કરો અને પછી **Print** પસંદ કરો. |
| **દસ્તાવેજ ઇલેક્ટ્રોનિક રીતે શેર કરવો** | MS Wordમાં દસ્તાવેજને ઇમેલ અથવા અન્ય માધ્યમથી ઇલેક્ટ્રોનિક રીતે શેર કરી શકાય છે. **File → Share** પસંદ કરીને દસ્તાવેજને અન્ય વ્યક્તિ સાથે શેર કરો અથવા **PDF** તરીકે સાચવીને ઇમેલ દ્વારા મોકલો. |
