# લેશન-૨૧: MS Office નો પરિચય

## MS Office શું છે?

**MS Office (Microsoft Office)** એ Microsoft દ્વારા વિકસાવવામાં આવેલું ઓફિસ એપ્લિકેશન્સનું સોફ્ટવેર પેકેજ છે. તેનો ઉપયોગ દસ્તાવેજ બનાવવા, ગણતરી કરવા, પ્રેઝન્ટેશન બનાવવા, ડેટાબેઝ મેનેજ કરવા, ઈમેલ મોકલવા અને અન્ય ઓફિસના કામ માટે થાય છે.

## Microsoft Office ની વિવિધ એપ્લિકેશન અને તેના ઉપયોગો

| એપ્લિકેશનનું નામ | ઉપયોગ |
| :--- | :--- |
| **MS Word** | દસ્તાવેજ, પત્ર, રિપોર્ટ અને અન્ય લખાણ તૈયાર કરવા માટે ઉપયોગ થાય છે. |
| **MS Excel** | ગણતરી, ટેબલ, ડેટા વિશ્લેષણ, ચાર્ટ અને હિસાબ રાખવા માટે ઉપયોગ થાય છે. |
| **MS PowerPoint** | પ્રેઝન્ટેશન અને સ્લાઇડ શો બનાવવા માટે ઉપયોગ થાય છે. |
| **MS Access** | ડેટાબેઝ બનાવવા, સંગ્રહિત કરવા અને મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| **MS Outlook** | ઈમેલ મોકલવા, પ્રાપ્ત કરવા અને સંપર્કો તથા કેલેન્ડર મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| **MS InfoPath** | ઇલેક્ટ્રોનિક ફોર્મ બનાવવા અને ડેટા એકત્રિત કરવા માટે ઉપયોગ થાય છે. |
| **MS OneNote** | નોંધો લખવા, સાચવવા અને વ્યવસ્થિત કરવા માટે ઉપયોગ થાય છે. |
| **MS Publisher** | બ્રોશર, પોસ્ટર, બિઝનેસ કાર્ડ અને અન્ય પ્રકાશન સામગ્રી બનાવવા માટે ઉપયોગ થાય છે. |
| **MS Picture Manager** | ચિત્રો જોવા, ગોઠવવા અને મૂળભૂત રીતે સંપાદિત કરવા માટે ઉપયોગ થાય છે. |
