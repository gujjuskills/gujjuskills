# પ્રેકટિકલ-૯૩ : પાઇવોટ ટેબલ બનાવો : MS-EXCEL

| Topic | માહિતી |
|---|---|
| Create Pivot tables from cell ranges | પસંદ કરેલ Cell Range માંથી Pivot Table બનાવવા માટે સૌપ્રથમ ડેટા રેન્જ પસંદ કરો. ત્યારબાદ Insert ટેબમાં જઈ PivotTable પસંદ કરો. યોગ્ય Table અથવા Range પસંદ કરીને Pivot Table માટે New Worksheet અથવા Existing Worksheet પસંદ કરો. ત્યારબાદ જરૂરી Fields ને Rows, Columns, Values અને Filters વિસ્તારમાં Drag and Drop કરીને ડેટાનું વિશ્લેષણ કરી શકાય છે. |
| Manipulate fields (columns) to get desired analysis | Pivot Table માં જરૂરી વિશ્લેષણ મેળવવા માટે Fields ને Rows, Columns, Values અને Filters વિસ્તારમાં ગોઠવી શકાય છે. કોઈ Field ને એક વિભાગમાંથી બીજા વિભાગમાં Drag કરીને રિપોર્ટનું સ્વરૂપ બદલી શકાય છે. Field ને Remove કરવા માટે તેને PivotTable Fields વિસ્તારની બહાર Drag કરી શકાય છે. Values માં Sum, Count, Average, Maximum અને Minimum જેવી ગણતરીઓ પસંદ કરી શકાય છે. |
| Use Filters for pivot tables | Pivot Table માં જરૂરી માહિતી જ જોવા માટે Filters નો ઉપયોગ કરી શકાય છે. કોઈ Field ને Filters વિસ્તારમાં Drag કરીને ચોક્કસ Category, Item અથવા Value પસંદ કરી શકાય છે. Report Filter દ્વારા પસંદ કરેલા વિકલ્પ મુજબ Pivot Table નું પરિણામ આપમેળે બદલાય છે. Filters નો ઉપયોગ કરીને મોટા ડેટામાંથી જરૂરી માહિતી ઝડપથી શોધી અને તેનું વિશ્લેષણ કરી શકાય છે. |
| Represent data as Count, Sum, Average & % of row / column | Pivot Table માં Values Field દ્વારા ડેટાને વિવિધ રીતે રજૂ કરી શકાય છે. Count દ્વારા રેકોર્ડની સંખ્યા, Sum દ્વારા કુલ મૂલ્ય અને Average દ્વારા સરેરાશ મૂલ્ય મેળવી શકાય છે. Show Values As વિકલ્પનો ઉપયોગ કરીને ડેટાને % of Row Total અથવા % of Column Total તરીકે પણ દર્શાવી શકાય છે. આ વિકલ્પો દ્વારા અલગ અલગ કેટેગરી વચ્ચે સરળતાથી સરખામણી કરી શકાય છે. |
| Group data in Columns & rows for aggregate reports | Pivot Table માં તારીખ, સમય, સંખ્યા અથવા અન્ય સંબંધિત ડેટાને Group કરી શકાય છે. Rows અથવા Columns માં રહેલા ડેટાને યોગ્ય જૂથોમાં ગોઠવીને Aggregate Report બનાવી શકાય છે. ઉદાહરણ તરીકે તારીખને Months, Quarters અથવા Years પ્રમાણે Group કરી શકાય છે. Grouping દ્વારા મોટા ડેટાને સરળ અને સમજવામાં સરળ રિપોર્ટમાં રૂપાંતરિત કરી શકાય છે. |
