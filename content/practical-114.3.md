# પ્રેકટિકલ-૧૧૪.૩ : તારીખ ફંક્શનનો ઉપયોગ : MY SQL

| તારીખ ફંક્શન | કાર્ય |
|---|---|
| `NOW()` | વર્તમાન તારીખ અને સમય દર્શાવે છે. |
| `CURRENT_DATE()` | વર્તમાન તારીખ દર્શાવે છે. |
| `CURRENT_TIME()` | વર્તમાન સમય દર્શાવે છે. |
| `DAY()` | આપેલી તારીખમાંથી દિવસ મેળવે છે. |
| `MONTH()` | આપેલી તારીખમાંથી મહિનો મેળવે છે. |
| `YEAR()` | આપેલી તારીખમાંથી વર્ષ મેળવે છે. |
| `DAYNAME()` | આપેલી તારીખના દિવસનું નામ દર્શાવે છે. |
| `MONTHNAME()` | આપેલી તારીખના મહિનાનું નામ દર્શાવે છે. |
| `DATEDIFF()` | બે તારીખો વચ્ચેના દિવસોનો તફાવત આપે છે. |
| `SUBDATE()` | આપેલી તારીખમાંથી નિર્ધારિત સમયગાળો ઘટાડે છે. |
| `ADDDATE()` | આપેલી તારીખમાં નિર્ધારિત સમયગાળો ઉમેરે છે. |
| `WEEK()` | આપેલી તારીખનું અઠવાડિયું નંબર આપે છે. |
| `WEEKDAY()` | આપેલી તારીખનો અઠવાડિયાનો દિવસ નંબર આપે છે. |
| `DAYOFYEAR()` | વર્ષમાં આપેલા દિવસનો ક્રમ નંબર આપે છે. |
| `LAST_DAY()` | આપેલા મહિનાની છેલ્લી તારીખ દર્શાવે છે. |
| `HOUR()` | આપેલા સમયમાંથી કલાક મેળવે છે. |
| `MINUTE()` | આપેલા સમયમાંથી મિનિટ મેળવે છે. |
| `SECOND()` | આપેલા સમયમાંથી સેકન્ડ મેળવે છે. |
| `PERIOD_ADD()` | આપેલા પિરિયડમાં નિર્ધારિત મહિનાઓ ઉમેરે છે. |
| `PERIOD_DIFF()` | બે પિરિયડ વચ્ચેના મહિનાઓનો તફાવત આપે છે. |
| `SUBTIME()` | આપેલા સમયમાંથી નિર્ધારિત સમય ઘટાડે છે. |
| `ADDTIME()` | આપેલા સમય સાથે નિર્ધારિત સમય ઉમેરે છે. |
