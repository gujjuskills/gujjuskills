# લેશન - ૧૮: લિનક્સ ઓપરેટિંગ સિસ્ટમનો પરિચય

## ❖ લિનક્સનો ઇતિહાસ :

લિનક્સ ઓપરેટિંગ સિસ્ટમની શરૂઆત 1991માં લિનસ ટોરવાલ્ડ્સ દ્વારા કરવામાં આવી હતી.  
લિનક્સ યુનિક્સ જેવી ઓપરેટિંગ સિસ્ટમ છે અને તે ઓપન સોર્સ છે.  
લિનક્સનું કર્નલ સૌપ્રથમ લિનસ ટોરવાલ્ડ્સે વિકસાવ્યું હતું.  
આજે લિનક્સનો ઉપયોગ કમ્પ્યુટર, સર્વર, મોબાઇલ અને અન્ય ઉપકરણોમાં થાય છે.

## ❖ લિનક્સનો પરિચય :

લિનક્સ એક ઓપન સોર્સ અને મફત ઓપરેટિંગ સિસ્ટમ છે.  
તે વપરાશકર્તા અને કમ્પ્યુટર હાર્ડવેર વચ્ચે ઇન્ટરફેસ તરીકે કાર્ય કરે છે.  
લિનક્સ સુરક્ષિત, વિશ્વસનીય અને મલ્ટિ-યુઝર ઓપરેટિંગ સિસ્ટમ છે.  
તેમાં કમાન્ડ લાઇન તેમજ ગ્રાફિકલ યુઝર ઇન્ટરફેસ બંને ઉપલબ્ધ છે.

## ❖ લિનક્સ ઇન્ટરફેસ :

લિનક્સમાં મુખ્યત્વે બે પ્રકારના ઇન્ટરફેસ હોય છે:

1. કમાન્ડ લાઇન ઇન્ટરફેસ (CLI)
2. ગ્રાફિકલ યુઝર ઇન્ટરફેસ (GUI)

## ❖ લિનક્સના ઉદાહરણ :

Ubuntu, Debian, Fedora, Linux Mint, Red Hat અને Kali Linux વગેરે લિનક્સના ઉદાહરણો છે.

## ❖ લિનક્સ માળખું :

લિનક્સનું મુખ્ય માળખું નીચેના ભાગોથી બનેલું છે:

1. હાર્ડવેર
2. કર્નલ
3. શેલ
4. સિસ્ટમ યુટિલિટીઝ
5. એપ્લિકેશન સોફ્ટવેર

## ❖ લિનક્સના ફાયદા અને મર્યાદા :

| લિનક્સના ફાયદા | લિનક્સની મર્યાદા |
|:---:|:---:|
| ઓપન સોર્સ અને મફત છે. | નવા વપરાશકર્તા માટે શરૂઆતમાં ઉપયોગ કરવો મુશ્કેલ હોઈ શકે છે. |
| વધુ સુરક્ષિત અને વિશ્વસનીય છે. | કેટલાક ખાસ સોફ્ટવેર લિનક્સમાં ઉપલબ્ધ ન હોઈ શકે. |
| ઓછી હાર્ડવેર ક્ષમતાવાળા કમ્પ્યુટરમાં પણ સારી રીતે ચાલી શકે છે. | કેટલાક હાર્ડવેર માટે ડ્રાઇવર સપોર્ટ મર્યાદિત હોઈ શકે છે. |
| મલ્ટિ-યુઝર અને મલ્ટિ-ટાસ્કિંગ સુવિધા આપે છે. | કેટલીક કામગીરી માટે કમાન્ડ લાઇનનું જ્ઞાન જરૂરી બની શકે છે. |
