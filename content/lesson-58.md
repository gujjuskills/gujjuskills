# લેશન - ૫૮ : નામકરણની પધ્ધતિઓ

### નામકરણની પદ્ધતિ એટલે શું?

પ્રોગ્રામિંગમાં વેરિએબલ, ફંક્શન, ક્લાસ, ફાઇલ વગેરેને એકસરખી અને સમજવામાં સરળ રીતથી નામ આપવાના નિયમોને નામકરણની પદ્ધતિ કહેવામાં આવે છે.

### સામાન્ય નિયમો

| નિયમ | માહિતી | ઉદાહરણ |
|---|---|---|
| Use lowercase | નામ લખતી વખતે શક્ય હોય ત્યાં સુધી નાના અક્ષરોનો ઉપયોગ કરવો. | `student`, `username`, `totalmarks` |
| Use underscore | બે અથવા વધુ શબ્દોના નામને અલગ કરવા માટે અન્ડરસ્કોર `_` નો ઉપયોગ કરી શકાય છે. | `student_name`, `total_marks` |
| descriptive Names | નામ એવું હોવું જોઈએ કે તે વેરિએબલ અથવા ફંક્શનનો હેતુ સરળતાથી સમજાવે. | `student_name` ના બદલે `sn` ન લખવું |
| singular / plural | એક વસ્તુ માટે એકવચન અને એકથી વધુ વસ્તુઓ માટે બહુવચન નામનો યોગ્ય ઉપયોગ કરવો. | `student` અને `students` |

### ટિપ્સ

| ટિપ્સ | માહિતી |
|---|---|
| રિજર્વ વર્ડ્સ  | નામ શક્ય તેટલું સ્પષ્ટ અને અર્થપૂર્ણ રાખવું. |
| ID નો ઉપયોગ | ઓળખ માટે ID નો ઉપયોગ કરી શકાય છે, જેમ કે `student_id`. |
| ફોરેન કી | નામકરણમાં અક્ષરોના કેસનો એકસરખો નિયમ જાળવવો. |
| સંક્ષિપ્ત  નામ | વેરિએબલ અથવા ફંક્શન માટે તેના કાર્યને દર્શાવતું યોગ્ય નામ પસંદ કરવું. |
