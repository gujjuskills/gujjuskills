# લેશન - ૭૩.૨ : ડોમેન નેમ સિસ્ટમ

| Topics | માહિતી |
|:---|:---|
| **DNS** | DNS નું સંપૂર્ણ નામ **Domain Name System** છે. DNS ડોમેન નામને IP Address માં રૂપાંતરિત કરે છે. ઉદાહરણ તરીકે, `www.google.com` ને કમ્પ્યુટર સમજી શકે તેવા IP Address સાથે જોડે છે. DNS ને ઇન્ટરનેટની ફોનબુક પણ કહેવામાં આવે છે. |
| **Types of DNS** | **1. Recursive DNS Server:** યુઝરની DNS વિનંતી શોધીને યોગ્ય IP Address આપે છે. **2. Root DNS Server:** DNS સિસ્ટમનું સૌથી ઉપરનું સ્તર છે. **3. TLD DNS Server:** `.com`, `.org`, `.in` જેવા Top Level Domain ની માહિતી સંભાળે છે. **4. Authoritative DNS Server:** ચોક્કસ Domain Name માટે સાચો IP Address આપે છે. |
