# પ્રેકટિકલ-૭૩ : કોમેન્ટ ઉમેરો અને મેનેજ કરો
## Add & Manage Comments

| Topic | સામાન્ય સમજ / કાર્ય |
|---|---|
| Add comments | Microsoft Word માં કોઈ ચોક્કસ શબ્દ, વાક્ય અથવા ભાગ અંગે નોંધ અથવા સૂચન આપવા માટે Comment નો ઉપયોગ કરવામાં આવે છે. Comment ઉમેરવા માટે જરૂરી Text પસંદ કરો અને Review Tab માં જઈને New Comment વિકલ્પ પસંદ કરો. ત્યારબાદ Comment Box માં જરૂરી માહિતી લખો અને Comment Post કરો. Comment દ્વારા Document માં ફેરફાર કર્યા વગર સૂચન, પ્રશ્ન અથવા નોંધ ઉમેરી શકાય છે. |
| Review and reply to comments | Document માં રહેલા Comments ને વાંચવા અને તેના જવાબ આપવા માટે Review Tab માં Comments વિભાગનો ઉપયોગ કરવામાં આવે છે. જરૂરી Comment પસંદ કરીને તેમાં આપેલો પ્રશ્ન અથવા સૂચન વાંચી શકાય છે. જવાબ આપવા માટે Reply વિકલ્પ પસંદ કરી જરૂરી જવાબ લખી શકાય છે. કામ પૂર્ણ થયા પછી Comment ને Resolve કરીને તેને પૂર્ણ થયેલ તરીકે દર્શાવી શકાય છે. જરૂર હોય તો Comment ને Edit અથવા Delete પણ કરી શકાય છે. |
