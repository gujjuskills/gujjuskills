# લેશન - ૧૦૩.૧ : માહિતી સુરક્ષા અને ધમકીઓની ઝાંખી

### Overview of Information Security

| Topic | માહિતી |
|---|---|
| Information Security | માહિતી સુરક્ષા એટલે કમ્પ્યુટર, નેટવર્ક, ફાઇલો અને અન્ય ડિજિટલ માહિતીને અનધિકૃત ઉપયોગ, ચોરી, નુકસાન અને દુરુપયોગથી સુરક્ષિત રાખવાની પ્રક્રિયા. |
| Confidentiality | માત્ર અધિકૃત વ્યક્તિ જ માહિતીને જોઈ અથવા ઉપયોગ કરી શકે તેની ખાતરી કરવી. |
| Integrity | માહિતી સાચી અને સંપૂર્ણ રહે તથા તેમાં અનધિકૃત ફેરફાર ન થાય તેની ખાતરી કરવી. |
| Availability | જરૂરી સમયે અધિકૃત વપરાશકર્તાને માહિતી અને સિસ્ટમ ઉપલબ્ધ રહે તેની ખાતરી કરવી. |
| Password Security | મજબૂત પાસવર્ડનો ઉપયોગ કરવો અને પાસવર્ડ અન્ય વ્યક્તિ સાથે શેર ન કરવો. |
| Data Protection | મહત્વપૂર્ણ ડેટાનો બેકઅપ રાખવો અને તેને સુરક્ષિત રીતે સંગ્રહિત કરવો. |
| Network Security | નેટવર્કને અનધિકૃત પ્રવેશ, હુમલા અને અન્ય જોખમોથી સુરક્ષિત રાખવું. |

### List out Security Threats

| No. | Topic | માહિતી |
|---:|---|---|
| 1 | Malware | કમ્પ્યુટર અથવા ડેટાને નુકસાન પહોંચાડવા માટે બનાવવામાં આવેલ દૂષિત સોફ્ટવેર. |
| 2 | Virus | એવી દૂષિત પ્રોગ્રામ ફાઇલ જે અન્ય ફાઇલો સાથે જોડાઈને ફેલાઈ શકે છે અને સિસ્ટમને નુકસાન પહોંચાડી શકે છે. |
| 3 | Worm | એવું દૂષિત સોફ્ટવેર જે પોતે જ નેટવર્ક દ્વારા અન્ય કમ્પ્યુટરમાં ફેલાઈ શકે છે. |
| 4 | Trojan Horse | ઉપયોગી સોફ્ટવેર જેવું દેખાતું પરંતુ અંદરથી નુકસાનકારક દૂષિત પ્રોગ્રામ. |
| 5 | Phishing | નકલી ઇમેલ, મેસેજ અથવા વેબસાઇટ દ્વારા પાસવર્ડ અને અન્ય વ્યક્તિગત માહિતી મેળવવાનો પ્રયાસ. |
| 6 | Ransomware | ડેટાને લોક અથવા એન્ક્રિપ્ટ કરીને તેને પાછું મેળવવા માટે પૈસાની માંગ કરતું દૂષિત સોફ્ટવેર. |
| 7 | Spyware | વપરાશકર્તાની જાણકારી વગર તેની પ્રવૃત્તિ અથવા માહિતી પર નજર રાખતું સોફ્ટવેર. |
| 8 | Password Attack | પાસવર્ડનો અંદાજ લગાવી અથવા વિવિધ પદ્ધતિઓ દ્વારા પાસવર્ડ મેળવવાનો પ્રયાસ. |
| 9 | Social Engineering | વ્યક્તિને છેતરીને ગુપ્ત માહિતી અથવા સુરક્ષા સંબંધિત માહિતી મેળવવાની પદ્ધતિ. |
| 10 | Data Theft | મહત્વપૂર્ણ અથવા વ્યક્તિગત ડેટાની અનધિકૃત રીતે ચોરી કરવી. |
| 11 | Unauthorized Access | પરવાનગી વગર કમ્પ્યુટર, નેટવર્ક અથવા ડેટામાં પ્રવેશ મેળવવો. |
| 12 | Denial of Service | સિસ્ટમ અથવા વેબસાઇટ પર વધારે પ્રમાણમાં વિનંતીઓ મોકલીને તેને સામાન્ય વપરાશકર્તાઓ માટે ઉપલબ્ધ ન રહેવા દેવી. |
