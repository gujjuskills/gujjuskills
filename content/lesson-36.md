# લેશન - ૩૬ : ડેટા ટેબ : MS-Excel
![image](/images/lesson-36.png)
| **Data Tab** | ઉપયોગ  |
|---|---|
| **From Access** | MS Access માંથી ડેટા મેળવવા માટે. |
| **From Web** | વેબસાઇટમાંથી ડેટા મેળવવા માટે. |
| **From Text** | ટેક્સ્ટ ફાઇલમાંથી ડેટા મેળવવા માટે. |
| **From Other Sources** | અન્ય સ્ત્રોતોમાંથી ડેટા મેળવવા માટે. |
| **Existing Connections** | પહેલેથી ઉપલબ્ધ કનેક્શનનો ઉપયોગ કરવા માટે. |
| **Refresh All** | તમામ ડેટા કનેક્શનને તાજું કરવા માટે. |
| **Connections** | ડેટા કનેક્શનનું સંચાલન કરવા માટે. |
| **Properties** | કનેક્શનના ગુણધર્મો જોવા અથવા બદલવા માટે. |
| **Edit Links** | અન્ય ફાઇલો સાથેની લિંક્સમાં ફેરફાર કરવા માટે. |
| **Sort** | ડેટાને ચડતા અથવા ઉતરતા ક્રમમાં ગોઠવવા માટે. |
| **Filter** | જરૂરી ડેટા પસંદ કરીને જોવા માટે. |
| **Text to Columns** | એક જ કૉલમના ડેટાને અલગ અલગ કૉલમમાં વહેંચવા માટે. |
| **Remove Duplicates** | પુનરાવર્તિત ડેટા દૂર કરવા માટે. |
| **Data Validation** | સેલમાં દાખલ થનારા ડેટા માટે નિયમો નક્કી કરવા માટે. |
| **Consolidate** | વિવિધ રેન્જ અથવા વર્કશીટના ડેટાને એકત્રિત કરવા માટે. |
| **What-if-Analysis** | અલગ અલગ પરિસ્થિતિઓના આધારે પરિણામનું વિશ્લેષણ કરવા માટે. |
| **Group** | પસંદ કરેલી પંક્તિઓ અથવા કૉલમને જૂથમાં ગોઠવવા માટે. |
| **Ungroup** | બનાવેલા જૂથને દૂર કરવા માટે. |
| **Sub Total** | ડેટાના જૂથ માટે પેટા સરવાળો અથવા અન્ય ગણતરી કરવા માટે. |
| **Show Detail** | છુપાયેલી વિગતવાર માહિતી દર્શાવવા માટે. |
| **Hide Detail** | વિગતવાર માહિતીને છુપાવવા માટે. |
