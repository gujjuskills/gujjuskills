# લેશન - ૪૧ : પાઇવોટ ટેબલ અને પાઇવોટ ચાર્ટ

## **❖ Excel માં Pivot Table શું છે?** 
 
 Pivot Table એ Excel માં મોટા પ્રમાણમાં રહેલા ડેટાને સરળતાથી **સારાંશ (Summary), વિશ્લેષણ (Analysis) અને સરખામણી (Comparison)** કરવા માટેનું એક શક્તિશાળી સાધન છે. તે ડેટાને વિવિધ રીતે ગોઠવીને કુલ, સરેરાશ, ગણતરી વગેરે સરળતાથી દર્શાવે છે. 
 
 ## **❖ Pivot Table ના ઉપયોગો :**  
 
 1. મોટા ડેટાનો સારાંશ બનાવવા માટે.
  2. ડેટાનું વિશ્લેષણ કરવા માટે.
 3. કુલ, સરેરાશ અને ગણતરી મેળવવા માટે.
 4. વિવિધ ડેટાની સરખામણી કરવા માટે.
 5. ડેટાને સરળતાથી ફિલ્ટર અને ગોઠવવા માટે.
 
## **❖ Excel માં Pivot Chart શું છે?**
 
 Pivot Chart એ Pivot Table માં રહેલા ડેટાનું **ગ્રાફિકલ સ્વરૂપે (Graphical Form)** પ્રસ્તુતિકરણ કરતું ચાર્ટ છે. તે ડેટાને વધુ સરળતાથી સમજવામાં મદદ કરે છે. 
 
##  **❖ Pivot Chart ના ઉપયોગો :**
1. ડેટાને ગ્રાફના સ્વરૂપમાં દર્શાવવા માટે.
2. ડેટાની સરખામણી સરળ બનાવવા માટે.
3. ડેટામાં રહેલા ટ્રેન્ડ અને પેટર્ન સમજવા માટે.
4. રિપોર્ટને વધુ સરળ અને આકર્ષક બનાવવા માટે.
5. Pivot Table ના ડેટાનું દૃશ્યમાન વિશ્લેષણ કરવા માટે.
