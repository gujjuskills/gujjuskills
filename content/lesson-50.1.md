# લેશન - ૫૦.૧ : DDl,DML,DCL સ્ટેટમેન્ટ અને વિવિધ ડેટા ટાઈપ્સ



### What is Data Types?

Database માં કોઈ Column માં કયા પ્રકારનો Data સંગ્રહિત કરી શકાય તે નક્કી કરતો પ્રકાર એટલે Data Type. 

## SQL Data Types

### 1 – Binary Data Types

| Data Type | માહિતી |
|---|---|
| `binary` | બાઈનરી ડેટા સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. તેની લંબાઈ નિશ્ચિત હોય છે. |
| `varbinary` | બદલાતી લંબાઈનો બાઈનરી ડેટા સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `image` | બાઈનરી સ્વરૂપે મોટા ડેટા જેમ કે Image અથવા File સંગ્રહિત કરવા માટે ઉપયોગ થતો Data Type. |

### 2 – Approximate Numeric Data Type

| Data Type | માહિતી |
|---|---|
| `float` | દશાંશ સંખ્યાઓને અંદાજિત ચોકસાઈ સાથે સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `real` | દશાંશ સંખ્યાઓને અંદાજિત ચોકસાઈ સાથે સંગ્રહિત કરવા માટે ઉપયોગ થાય છે અને `float` કરતાં ઓછી ચોકસાઈ ધરાવે છે. |

### 3 – Exact Numeric Data Type

| Data Type | માહિતી |
|---|---|
| `int` | પૂર્ણ સંખ્યાઓ (Integer) સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `smallint` | નાની શ્રેણીની પૂર્ણ સંખ્યાઓ સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `bit` | `0` અથવા `1` જેવી Binary/Boolean કિંમત સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `decimal` | ચોક્કસ દશાંશ સંખ્યાઓ સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `numeric` | ચોક્કસ દશાંશ સંખ્યાઓ સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. `decimal` અને `numeric` સામાન્ય રીતે સમાન રીતે કામ કરે છે. |

### 4 – Character String Data Types

| Data Type | માહિતી |
|---|---|
| `char` | નિશ્ચિત લંબાઈનો Character/String Data સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `varchar / varchar2` | બદલાતી લંબાઈનો Character/String Data સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. `VARCHAR2` મુખ્યત્વે Oracle Database માં વપરાય છે. |
| `text` | લાંબો Character અથવા Text Data સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |

### 5 – Date & Time Data Types

| Data Type | માહિતી |
|---|---|
| `date` | તારીખ સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `time` | સમય સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
| `timestamp` | તારીખ અને સમય બંનેને સંગ્રહિત કરવા માટે ઉપયોગ થાય છે. |
