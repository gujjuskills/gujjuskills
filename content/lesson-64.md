# લેશન - ૬૪ : નેટવર્ક કઈ રીતે બનાવવામાં આવે છે

| Topics | માહિતી |
|---|---|
| **Computer Network Components** | 1. NIC (નેટવર્ક ઈન્ટરફેસ કાર્ડ) |
| | 2. Hub (હબ) |
| | 3. Switch (સ્વિચ) |
| | 4. Router (રાઉટર) |
| | 5. Modem (મોડેમ) |
| | 6. Cables અને Connectors (કેબલ અને કનેક્ટર્સ) |
| **NIC** | 1. NIC એ કમ્પ્યુટરને નેટવર્ક સાથે જોડવાનું સાધન છે. |
| | 2. તે ડેટા મોકલવા અને પ્રાપ્ત કરવાની સુવિધા આપે છે. |
| | 3. દરેક NICનું પોતાનું MAC Address હોય છે. |
| **HUB** | 1. Hub અનેક કમ્પ્યુટરને નેટવર્કમાં જોડે છે. |
| | 2. તે મળેલો ડેટા બધા જોડાયેલા કમ્પ્યુટરને મોકલે છે. |
| | 3. Hub Physical Layer પર કાર્ય કરે છે. |
| **SWITCH** | 1. Switch અનેક નેટવર્ક ઉપકરણોને જોડે છે. |
| | 2. તે ડેટાને યોગ્ય ઉપકરણ સુધી પહોંચાડે છે. |
| | 3. Switch MAC Addressનો ઉપયોગ કરે છે. |
| | 4. તે Hub કરતાં વધુ કાર્યક્ષમ છે. |
| **ROUTER** | 1. Router બે અથવા વધુ નેટવર્કને જોડે છે. |
| | 2. તે ડેટા માટે યોગ્ય માર્ગ પસંદ કરે છે. |
| | 3. Router IP Addressનો ઉપયોગ કરે છે. |
| | 4. તેનો ઉપયોગ ઇન્ટરનેટ સાથે જોડાણ માટે થાય છે. |
| **MODEM** | 1. Modem એ Modulator-Demodulatorનું ટૂંકું નામ છે. |
| | 2. તે સિગ્નલનું રૂપાંતર કરે છે. |
| | 3. તે ઇન્ટરનેટ સાથે જોડવામાં મદદ કરે છે. |
| **Cables and Connectors** | 1. Cables ઉપકરણો વચ્ચે ડેટા ટ્રાન્સફર કરવા માટે વપરાય છે. |
| | 2. Twisted Pair, Coaxial અને Fiber Optic Cable મુખ્ય કેબલ છે. |
| | 3. Connectors કેબલને વિવિધ ઉપકરણો સાથે જોડે છે. |
| | 4. RJ45 Ethernet નેટવર્કમાં સામાન્ય Connector છે. |
