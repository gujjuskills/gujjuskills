# લેશન - ૬૪ : નેતવર્ક કઈ રીતે બનાવવામાં આવે છે

| Topics | માહિતી |
|---|---|
| Computer Network Components | કમ્પ્યુટર નેટવર્ક બનાવવા માટે જરૂરી મુખ્ય ઘટકોને નેટવર્ક કમ્પોનન્ટ્સ કહેવામાં આવે છે. તેમાં NIC, Hub, Switch, Router, Modem, Cables અને Connectors વગેરેનો સમાવેશ થાય છે. |
| NIC | NIC (Network Interface Card) એ કમ્પ્યુટરને નેટવર્ક સાથે જોડવાનું સાધન છે. તે કમ્પ્યુટરને નેટવર્ક પર ડેટા મોકલવા અને પ્રાપ્ત કરવાની સુવિધા આપે છે. |
| HUB | Hub એ નેટવર્કમાં અનેક કમ્પ્યુટરને જોડતું ઉપકરણ છે. તે એક કમ્પ્યુટર પાસેથી મળેલો ડેટા નેટવર્ક સાથે જોડાયેલા તમામ કમ્પ્યુટરને મોકલે છે. |
| SWITCH | Switch એ નેટવર્કમાં અનેક ઉપકરણોને જોડે છે અને ડેટાને યોગ્ય ઉપકરણ સુધી પહોંચાડે છે. તે Hub કરતાં વધુ કાર્યક્ષમ અને ઝડપી છે. |
| ROUTER | Router બે અથવા વધુ નેટવર્કને જોડે છે અને ડેટાને યોગ્ય નેટવર્ક સુધી પહોંચાડવા માટે શ્રેષ્ઠ માર્ગ પસંદ કરે છે. તેનો ઉપયોગ ઇન્ટરનેટ સાથે જોડાણ માટે પણ થાય છે. |
| MODEM | Modem એ ડિજિટલ અને એનાલોગ સિગ્નલ વચ્ચે રૂપાંતર કરતું ઉપકરણ છે. તે કમ્પ્યુટર અથવા નેટવર્કને ઇન્ટરનેટ સેવા સાથે જોડવામાં મદદ કરે છે. |
| Cables and Connectors | Cables નેટવર્કના વિવિધ ઉપકરણો વચ્ચે ડેટા ટ્રાન્સફર કરવા માટે ઉપયોગમાં લેવાય છે. Connectors દ્વારા કેબલને કમ્પ્યુટર, Switch, Router વગેરે સાથે જોડવામાં આવે છે. |
