## લેશન - ૪૦ : ટિપ્સ એન્ડ ટ્રિક્સ

### ટિપ્સ અને ટ્રિક્સ

| ક્રમ | MS Excel Tips and Tricks |
|---:|---|
| 1 | **Ctrl + C** નો ઉપયોગ પસંદ કરેલા ડેટાની Copy કરવા માટે થાય છે. |
| 2 | **Ctrl + V** નો ઉપયોગ Copy કરેલા ડેટાને Paste કરવા માટે થાય છે. |
| 3 | **Ctrl + X** નો ઉપયોગ પસંદ કરેલા ડેટાને Cut કરવા માટે થાય છે. |
| 4 | **Ctrl + Z** નો ઉપયોગ છેલ્લી કરેલી ક્રિયા Undo કરવા માટે થાય છે. |
| 5 | **Ctrl + Y** નો ઉપયોગ Undo કરેલી ક્રિયાને ફરીથી કરવા માટે થાય છે. |
| 6 | **Ctrl + S** નો ઉપયોગ Excel ફાઇલ Save કરવા માટે થાય છે. |
| 7 | **Ctrl + F** નો ઉપયોગ Worksheet માં કોઈ શબ્દ અથવા ડેટા શોધવા માટે થાય છે. |
| 8 | **Ctrl + H** નો ઉપયોગ Find and Replace માટે થાય છે. |
| 9 | **Ctrl + A** નો ઉપયોગ ડેટા અથવા સમગ્ર Worksheet પસંદ કરવા માટે થાય છે. |
| 10 | **Ctrl + P** નો ઉપયોગ Worksheet અથવા Workbook Print કરવા માટે થાય છે. |
| 11 | **Alt + =** દબાવવાથી પસંદ કરેલા ડેટાનો **AutoSum** ઝડપથી કરી શકાય છે. |
| 12 | **Ctrl + ;** દબાવવાથી વર્તમાન તારીખ Cell માં દાખલ કરી શકાય છે. |
| 13 | **Ctrl + Shift + ;** દબાવવાથી વર્તમાન સમય Cell માં દાખલ કરી શકાય છે. |
| 14 | **F2** દબાવીને Cell માં રહેલા ડેટાને ઝડપથી Edit કરી શકાય છે. |
| 15 | **Ctrl + 1** નો ઉપયોગ Format Cells Dialog Box ખોલવા માટે થાય છે. |
| 16 | **Ctrl + Shift + L** નો ઉપયોગ Data Filter ચાલુ અથવા બંધ કરવા માટે થાય છે. |
| 17 | **Ctrl + Arrow Key** નો ઉપયોગ ડેટાની શરૂઆત અથવા અંત સુધી ઝડપથી જવા માટે થાય છે. |
| 18 | **Ctrl + Shift + Arrow Key** નો ઉપયોગ ડેટાની મોટી Range ઝડપથી Select કરવા માટે થાય છે. |
| 19 | **Double Click Fill Handle** દ્વારા બાજુના ડેટા મુજબ Formula ઝડપથી Copy કરી શકાય છે. |
| 20 | **Freeze Panes** નો ઉપયોગ Heading ને સ્ક્રોલ કરતી વખતે સ્થિર રાખવા માટે થાય છે. |
| 21 | **Sort** નો ઉપયોગ ડેટાને A થી Z, Z થી A અથવા નાના થી મોટા ક્રમમાં ગોઠવવા માટે થાય છે. |
| 22 | **Filter** નો ઉપયોગ જરૂરી ડેટા જ જોવા માટે થાય છે. |
| 23 | **SUM()** Function નો ઉપયોગ સંખ્યાઓનો સરવાળો કરવા માટે થાય છે. |
| 24 | **AVERAGE()** Function નો ઉપયોગ સરેરાશ શોધવા માટે થાય છે. |
| 25 | **MAX()** Function નો ઉપયોગ સૌથી મોટી સંખ્યા શોધવા માટે થાય છે. |
| 26 | **MIN()** Function નો ઉપયોગ સૌથી નાની સંખ્યા શોધવા માટે થાય છે. |
| 27 | **COUNT()** Function નો ઉપયોગ સંખ્યાવાળા Cells ગણવા માટે થાય છે. |
| 28 | **IF()** Function નો ઉપયોગ શરત મુજબ પરિણામ મેળવવા માટે થાય છે. |
| 29 | **Merge & Center** નો ઉપયોગ એકથી વધુ Cells ને જોડીને Text ને Center કરવા માટે થાય છે. |
| 30 | **Conditional Formatting** નો ઉપયોગ ચોક્કસ શરત મુજબ Cells ને Highlight કરવા માટે થાય છે. |
