# લેશન - ૭૬.૧ : HTML નો પરિચય

# T-76.1
## HTML નો પરિચય

| Topics | માહિતી |
|---|---|
| **HTML નો પરિચય** | HTML નું પૂર્ણ નામ **HyperText Markup Language** છે. તેનો ઉપયોગ વેબ પેજ બનાવવા માટે થાય છે. HTML વેબ પેજની રચના અને સામગ્રીને ગોઠવવા માટે વિવિધ Tags નો ઉપયોગ કરે છે. HTML પ્રોગ્રામને વેબ બ્રાઉઝરમાં ચલાવી શકાય છે. |
| **HTML Structure** | HTML દસ્તાવેજની મૂળભૂત રચનામાં `<!DOCTYPE html>`, `<html>`, `<head>` અને `<body>` Tags નો સમાવેશ થાય છે. `<head>` વિભાગમાં પેજની માહિતી અને `<body>` વિભાગમાં વેબ પેજ પર દેખાતી સામગ્રી લખવામાં આવે છે. |
| **HTML Program** | HTML પ્રોગ્રામમાં Heading, Paragraph, Link, Image, List, Table અને Form જેવા Elements નો ઉપયોગ કરી શકાય છે. HTML ફાઇલને `.html` એક્સટેન્શનથી સેવ કરવામાં આવે છે અને તેને વેબ બ્રાઉઝરમાં ખોલીને પરિણામ જોઈ શકાય છે. |
