# પ્રેકટિકલ-૧૯ : OS ઇન્સ્ટોલ કરતાં પડતી સામાન્ય મુશ્કેલીઓી
![image](/gujjuskills/images/practical-19.png)
| ક્રમાંક | મુશ્કેલી | નિવારણ |
|---|---|---|
| 1 | OS ઇન્સ્ટોલ કરતી વખતે Error Message આવે ત્યારે | ઇન્સ્ટોલેશન મીડિયા, OS ફાઇલ અને હાર્ડ ડિસ્કની ચકાસણી કરવી. જરૂરી હોય તો OS ફરીથી ઇન્સ્ટોલ કરવું. |
| 2 | કમ્પ્યુટર વારંવાર Restart થાય ત્યારે | RAM, પાવર સપ્લાય અને CPUનું તાપમાન તપાસવું. RAM કાઢીને સાફ કરી ફરીથી લગાવવી. |
| 3 | કમ્પ્યુટર સિસ્ટમ Hang થાય ત્યારે | RAM અને હાર્ડ ડિસ્કની ચકાસણી કરવી. બિનજરૂરી પ્રોગ્રામ બંધ કરી સિસ્ટમ ફરીથી શરૂ કરવી. |
| 4 | "Disk Boot Failure" મેસેજ જોવા મળે ત્યારે | Hard Disk યોગ્ય રીતે જોડાયેલી છે કે નહીં તે તપાસવું અને BIOS માં Boot Device/Boot Order ચકાસવું. |
| 5 | કીબોર્ડ કામ ન કરે ત્યારે | Keyboardનું USB/PS2 કનેક્શન તપાસવું અને બીજા USB પોર્ટમાં જોડીને ચકાસવું. |
| 6 | મોનિટર પર Display જોવા ન મળે ત્યારે | Monitorનું Power અને VGA/HDMI કેબલ તપાસવું. RAM અને Display કનેક્શન પણ તપાસવું. |
