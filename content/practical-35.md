# પ્રેકટિકલ-૩૫ : ફોરમેટ દસ્તાવેજો

| ટોપિક | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| **દસ્તાવેજના પેજ સેટ કરવું** | MS Word માં પેજનું કદ, ઓરિએન્ટેશન, માર્જિન અને પેજ લેઆઉટ સેટ કરવું. Page Size માંથી જરૂરી પેજ સાઇઝ પસંદ કરવી અને Orientation માંથી Portrait અથવા Landscape પસંદ કરવું. |
| **સ્ટાઇલ સેટ લાગુ કરવી** | દસ્તાવેજના લખાણને સુંદર અને વ્યવસ્થિત બનાવવા માટે Heading, Title, Subtitle વગેરે Style Sets લાગુ કરવા. આથી સમગ્ર દસ્તાવેજમાં એકસરખી ફોર્મેટિંગ જાળવી શકાય છે. |
| **હેડર અને ફૂટર દાખલ કરી તેમાં ફેરફાર કરવો** | પેજના ઉપરના ભાગમાં Header અને નીચેના ભાગમાં Footer ઉમેરવા. તેમાં દસ્તાવેજનું નામ, તારીખ, પેજ નંબર વગેરે માહિતી દાખલ કરી શકાય છે અને જરૂર મુજબ તેમાં ફેરફાર કરી શકાય છે. |
| **પેજની પૃષ્ઠભૂમિના તત્વોને ગોઠવવા** | પેજની પૃષ્ઠભૂમિમાં Watermark, Page Color અને Page Border જેવા તત્વો ઉમેરવા અથવા તેમાં ફેરફાર કરવો. આથી દસ્તાવેજને વધુ આકર્ષક અને વ્યવસ્થિત બનાવી શકાય છે. |
