# લેશન - ૮૧ : જાવા સ્ક્રિપ્ટ નો પરિચય અને તેની એપ્લિકેશન

| Topic | Information |
|---|---|
| **What is JavaScript?** | JavaScript એક લોકપ્રિય અને શક્તિશાળી Programming Language છે. તેનો ઉપયોગ મુખ્યત્વે Web Pages ને Interactive અને Dynamic બનાવવા માટે થાય છે. JavaScript દ્વારા Button Click, Form Validation, Popup, Animation, Menu, Slider વગેરે Interactive Features બનાવી શકાય છે. JavaScript સામાન્ય રીતે HTML અને CSS સાથે ઉપયોગમાં લેવામાં આવે છે. HTML વેબપેજનું Structure બનાવે છે, CSS Design અને Styling કરે છે, જ્યારે JavaScript વેબપેજમાં Functionality અને Interaction ઉમેરે છે. |
| **Features of JavaScript** | **1. Easy to Learn:** JavaScript ની Syntax પ્રમાણમાં સરળ છે અને શરૂઆત કરનાર માટે શીખવી સરળ છે. |
| | **2. Lightweight:** JavaScript એક Lightweight Programming Language છે.|
| |**3. Interpreted Language:** JavaScript Code ને Browser દ્વારા સીધો Execute કરી શકાય છે.|
| | **4. Object Oriented:** JavaScript માં Objects, Properties અને Methods નો ઉપયોગ કરી શકાય છે.|
| |**5. Event Driven:** Mouse Click, Keyboard Input અને Form Submission જેવા Events પર Action લઈ શકાય છે.|
| | **6. Dynamic:** Program ચાલતી વખતે Variables અને Objects ની Values બદલી શકાય છે.|
| | **7. Cross Platform:** JavaScript વિવિધ Operating Systems અને Web Browsers પર ચાલી શકે છે.|
| |**8. Versatile:** JavaScript નો ઉપયોગ Frontend તેમજ Backend Development માટે કરી શકાય છે. |
| **History of JavaScript** | JavaScript ની શરૂઆત **1995** માં Netscape કંપનીમાં **Brendan Eich** દ્વારા કરવામાં આવી હતી. શરૂઆતમાં તેનું નામ **Mocha** હતું. ત્યારબાદ તેનું નામ LiveScript અને પછી JavaScript રાખવામાં આવ્યું. JavaScript ને Web Browsers માં Interactive Web Pages બનાવવા માટે વિકસાવવામાં આવી હતી. પછી JavaScript ને Standard બનાવવા માટે તેને **ECMAScript** Standard હેઠળ વિકસાવવામાં આવી. સમય જતાં JavaScript માં ઘણા નવા Features ઉમેરાયા અને આજે તેનો ઉપયોગ Web Development, Server Side Development, Mobile Applications અને અન્ય ક્ષેત્રોમાં પણ થાય છે. |
| **Application of JavaScript** | JavaScript નો ઉપયોગ **Web Development, Form Validation, Interactive Websites, Web Applications, Server Side Development, Mobile Applications, Browser Games, Animations, Dynamic Menus, Online Calculators, API Integration અને Real Time Applications** માટે થાય છે. Node.js જેવી Technology દ્વારા JavaScript નો ઉપયોગ Server Side Programming માટે પણ કરી શકાય છે. |
| **JavaScript Example** | JavaScript નો સરળ Example:```javascript.let name = "GujjuSkills";.console.log("Welcome to " + name);.```..આ Example માં `name` Variable માં **GujjuSkills** Value Store કરવામાં આવી છે. `console.log()` દ્વારા Console માં **Welcome to GujjuSkills** Message Display કરવામાં આવે છે. |
