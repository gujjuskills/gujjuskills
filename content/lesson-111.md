## Python History:

Python એ એક ઉચ્ચ સ્તરની, સરળ અને લોકપ્રિય Programming Language છે. Python નો વિકાસ Guido van Rossum દ્વારા કરવામાં આવ્યો હતો.

Python પર કામ December 1989માં શરૂ થયું હતું અને તેનો પ્રથમ જાહેર સંસ્કરણ Python 0.9.0 February 1991માં રજૂ કરવામાં આવ્યો હતો.

Python 1.0 જાન્યુઆરી 1994માં રજૂ થયું. ત્યારબાદ Python 2.0 વર્ષ 2000માં આવ્યું અને Python 3.0 વર્ષ 2008માં રજૂ થયું.

Python 3 હાલમાં Python ની મુખ્ય અને સક્રિય રીતે વિકસાવવામાં આવતી આવૃત્તિ છે.

Python નો ઉપયોગ Web Development, Software Development, Data Science, Artificial Intelligence, Machine Learning, Automation અને ઘણા અન્ય ક્ષેત્રોમાં થાય છે.


## Why the Name is Python:

Python નામ કોઈ સાપ પરથી રાખવામાં આવ્યું નથી.

Python ના સર્જક Guido van Rossum ને British comedy television series "Monty Python's Flying Circus" પસંદ હતી. આ કાર્યક્રમથી પ્રેરાઈને તેમણે Programming Language નું નામ "Python" રાખ્યું.
