
## લેશન - ૭.૨  પ્રોસેસરના વિવિધ પ્રકારો

| વિગત | માહિતી |
|---|---|
| **પ્રોસેસર એટલે:** | પ્રોસેસર એ કમ્પ્યુટરનું મુખ્ય ભાગ છે, જે પ્રોગ્રામની સૂચનાઓનું અર્થઘટન કરીને ડેટા પર પ્રક્રિયા કરે છે અને પરિણામ આપે છે. તેને CPU (Central Processing Unit) પણ કહેવામાં આવે છે. |
| **પ્રોસેસરના 4 કાર્ય સિદ્ધાંત:** | 1. સૂચના મેળવવી (Fetch)<br>2. સૂચનાનું અર્થઘટન કરવું (Decode)<br>3. સૂચના પર પ્રક્રિયા કરવી (Execute)<br>4. પરિણામ સંગ્રહિત કરવું (Store) |
| **કોર એટલે:** | કોર એ પ્રોસેસરની અંદર રહેલું સ્વતંત્ર પ્રોસેસિંગ યુનિટ છે. એક કરતાં વધુ કોર ધરાવતા પ્રોસેસરને મલ્ટી કોર પ્રોસેસર કહેવામાં આવે છે. |
| **પ્રોસેસર નિર્માણકારો:** | Intel, AMD, Apple, Qualcomm, MediaTek, IBM વગેરે. |
| **INTEL ના પ્રોસેસરો:** | Intel Core i3, Intel Core i5, Intel Core i7, Intel Core i9, Intel Xeon વગેરે. |
| **AMD ના પ્રોસેસરો:** | AMD Ryzen 3, AMD Ryzen 5, AMD Ryzen 7, AMD Ryzen 9, AMD Threadripper વગેરે. |
