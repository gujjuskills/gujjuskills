# પ્રેકટિકલ-૧૫૪ : open stack નો ઉપયોગ કરીને VM બનાવો

![image](/images/practical-154.webp)

OpenStack નો ઉપયોગ કરીને Virtual Machine (VM) બનાવવા માટે નીચેના પગલાં અનુસરો:

1. સૌપ્રથમ **OpenStack Dashboard (Horizon)** માં Login કરો.
2. Dashboard માંથી **Project** વિભાગ પસંદ કરો.
3. **Compute → Instances** પર ક્લિક કરો.
4. **Launch Instance** બટન પર ક્લિક કરો.
5. VM માટે **Instance Name** દાખલ કરો.
6. જરૂરી **Flavor** પસંદ કરો.
7. VM માટે જરૂરી **Image** પસંદ કરો.
8. યોગ્ય **Network** પસંદ કરો.
9. જરૂરિયાત મુજબ **Security Group** પસંદ કરો.
10. જો જરૂરી હોય તો **Key Pair** પસંદ કરો.
11. તમામ સેટિંગ્સ ચકાસ્યા પછી **Launch Instance** પર ક્લિક કરો.
12. થોડા સમય પછી OpenStack માં નવી **Virtual Machine (VM)** બનાવવામાં આવશે.
13. **Instances** વિભાગમાં જઈને VM ની સ્થિતિ **Running** છે કે નહીં તે ચકાસો.
