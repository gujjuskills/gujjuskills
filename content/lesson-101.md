# લેશન - ૧૦૧ : એપ્લિકેશન ડેવલપમેંટ લાઈફ સાયકલના દરેક તબક્કાઓનું વર્ણન

| SDLC Phase | Role / Description |
|---|---|
| **1. Planning and requirement analysis** | પ્રોજેક્ટના હેતુ, જરૂરિયાતો, બજેટ, સમય અને જરૂરી સંસાધનો નક્કી કરવામાં આવે છે. ગ્રાહક અને Stakeholders પાસેથી જરૂરી માહિતી એકત્ર કરવામાં આવે છે. |
| **2. Defining Requirements** | Software માટેની તમામ Functional અને Non-functional Requirements નક્કી કરવામાં આવે છે. Requirements ને દસ્તાવેજમાં નોંધવામાં આવે છે જેથી Development Team તેને સરળતાથી સમજી શકે. |
| **3. Designing the Software** | Softwareનું Architecture, Database, User Interface અને અન્ય Technical Design તૈયાર કરવામાં આવે છે. Software કેવી રીતે કામ કરશે તેની વિગતવાર યોજના બનાવવામાં આવે છે. |
| **4. Developing the project** | Developers તૈયાર કરેલા Design અને Requirements મુજબ Software નો Code લખે છે. જરૂરી Features અને Functions વિકસાવવામાં આવે છે અને Database સાથે Integration કરવામાં આવે છે. |
| **5. Testing** | Softwareમાં રહેલી ભૂલો અને ખામીઓ શોધવા માટે Testing કરવામાં આવે છે. Software Requirements મુજબ યોગ્ય રીતે કાર્ય કરે છે કે નહીં તે તપાસવામાં આવે છે. |
| **6. Deployment** | Testing પૂર્ણ થયા પછી Software ને Production Environment અથવા User માટે ઉપલબ્ધ કરવામાં આવે છે. Software ને Server પર Install અને Configure કરવામાં આવે છે. |
| **7. Maintenance** | Software Release થયા પછી તેમાં આવતી Errors દૂર કરવામાં આવે છે. જરૂરી Updates, Security Fixes અને નવા Features ઉમેરવામાં આવે છે જેથી Software યોગ્ય રીતે કાર્ય કરતું રહે. |
