# પ્રેકટિકલ-૫૪ : પાવરપોઈન્ટ પ્રસ્તુતિઓ ફોરમેટ કરો
| કૌશલ્ય | સામાન્ય સમજ / કાર્ય |
|---|---|
| **Add slides** | નવી સ્લાઇડ ઉમેરવા માટે **Home → New Slide** પર ક્લિક કરો અથવા **Ctrl + M** દબાવો. જરૂરિયાત મુજબ એકથી વધુ સ્લાઇડ ઉમેરી શકાય છે. |
| **Add titles and text** | સ્લાઇડમાં શીર્ષક અને ટેક્સ્ટ ઉમેરવા માટે સંબંધિત **Title** અથવા **Text Box** માં ક્લિક કરીને જરૂરી માહિતી ટાઇપ કરો. |
| **Select slide layouts** | સ્લાઇડનું યોગ્ય લેઆઉટ પસંદ કરવા માટે **Home → Layout** પર ક્લિક કરો અને જરૂરી લેઆઉટ જેમ કે **Title Slide, Title and Content** વગેરે પસંદ કરો. |
| **Add PowerPoint templates** | પ્રેઝન્ટેશનને આકર્ષક બનાવવા માટે **Design** ટેબમાંથી ઉપલબ્ધ PowerPoint **Templates/Themes** પસંદ કરો અને તેને સ્લાઇડ પર લાગુ કરો. |
| **Duplicate slides** | સ્લાઇડની નકલ બનાવવા માટે સ્લાઇડ પસંદ કરી **Home → New Slide → Duplicate Selected Slides** પસંદ કરો અથવા સ્લાઇડ પર રાઇટ ક્લિક કરીને **Duplicate Slide** પસંદ કરો. |
