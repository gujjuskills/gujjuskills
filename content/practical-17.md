# પ્રેકટિકલ - ૧૭ : Windows Operating System ઇન્સ્ટોલ કરવું
![image](/gujjuskills/images/practical-17.png)

**બૂટેબલ પેન ડ્રાઇવ દ્વારા Windows OS ઇન્સ્ટોલ કરવાની સ્ટેપ્સ જણાવો.**

| સ્ટેપ | કાર્ય / સમજુતી |
|:---|:---|
| 1 | કમ્પ્યુટરમાં બૂટેબલ Windows પેન ડ્રાઇવ કનેક્ટ કરો. |
| 2 | કમ્પ્યુટર ચાલુ કરીને **Boot Menu** અથવા **BIOS/UEFI** ખોલવા માટે યોગ્ય કી દબાવો. |
| 3 | Boot Device તરીકે **USB Pen Drive** પસંદ કરો અને Enter દબાવો. |
| 4 | Windows Setup શરૂ થયા પછી ભાષા, સમય અને કીબોર્ડની સેટિંગ પસંદ કરી **Next** પર ક્લિક કરો. |
| 5 | **Install Now** પર ક્લિક કરીને Windows ઇન્સ્ટોલેશન શરૂ કરો. |
| 6 | Product Key દાખલ કરો અથવા ઉપલબ્ધ વિકલ્પ મુજબ **I don't have a product key** પસંદ કરો અને Windows Edition પસંદ કરો. |
| 7 | **Custom: Install Windows only** વિકલ્પ પસંદ કરીને Windows ઇન્સ્ટોલ કરવાનું ડ્રાઇવ અથવા પાર્ટિશન પસંદ કરો. |
| 8 | જરૂરી પાર્ટિશન પસંદ કરીને **Next** દબાવો. Windows ફાઇલોની કૉપી અને ઇન્સ્ટોલેશન શરૂ થશે. |
| 9 | ઇન્સ્ટોલેશન પૂર્ણ થયા પછી કમ્પ્યુટર આપમેળે Restart થશે. જરૂરી હોય તો પેન ડ્રાઇવ કાઢી લો. |
| 10 | Windows શરૂ થયા પછી Region, Keyboard, User Account, Password અને અન્ય જરૂરી સેટિંગ પૂર્ણ કરો. |
| 11 | Windows Desktop દેખાય પછી જરૂરી Drivers અને Windows Updates ઇન્સ્ટોલ કરો. |
