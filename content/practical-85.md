# પ્રેકટિકલ-૮૫ : ટેબલો અને ટેબલ ડેટા કરો : MS-EXCEL

| Topic | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| Add or remove table rows and columns | **Rows અને Columns ઉમેરવા:** Table માં નવી Row અથવા Column ઉમેરવા માટે Table Layout અથવા Insert વિકલ્પનો ઉપયોગ કરી શકાય છે. જરૂરીયાત મુજબ નવી Row/Column ઉમેરવાથી Table નો વિસ્તાર વધારી શકાય છે. **Rows અને Columns દૂર કરવા:** અનાવશ્યક Row અથવા Column પસંદ કરીને Delete વિકલ્પ દ્વારા દૂર કરી શકાય છે. |
| Configure table style options | Table ને આકર્ષક અને વ્યવસ્થિત બનાવવા માટે વિવિધ **Table Style Options** નો ઉપયોગ કરી શકાય છે. તેમાં Header Row, Total Row, Banded Rows, Banded Columns અને First/Last Column જેવા વિકલ્પોનો સમાવેશ થાય છે. આ વિકલ્પો દ્વારા Table ની દેખાવ અને વાંચવાની સરળતા સુધારી શકાય છે. |
| Insert and configure total rows | Table માં **Total Row** ઉમેરવાથી સંખ્યાત્મક માહિતીનો કુલ સરવાળો સરળતાથી મેળવી શકાય છે. Total Row માં Sum, Average, Count, Max, Min જેવી ગણતરીઓ પસંદ કરી શકાય છે. જરૂરી Column માટે યોગ્ય ગણતરી પસંદ કરીને Table ના અંતે કુલ પરિણામ દર્શાવી શકાય છે. |
