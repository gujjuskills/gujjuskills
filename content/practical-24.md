# પ્રેકટિકલ-૨૪ : સામાન્ય DOS કમાન્ડનો ઉપયોગ: (ભાગ-A )
![image](/gujjuskills/images/practical-24.webp)
| પ્રેક્ટિકલ ટોપિક | સામાન્ય માહિતી |
|---|---|
| **DOS શું છે?** | DOS એટલે **Disk Operating System**. તે કમાન્ડ દ્વારા કમ્પ્યુટરની ફાઇલો, ફોલ્ડર અને ડિસ્કનું સંચાલન કરવા માટેની ઓપરેટિંગ સિસ્ટમ છે. |
| **DOS કેવી રીતે શરૂ કરવું?** | Windows માં **Command Prompt** ખોલવા માટે `Win + R` દબાવીને `cmd` લખો અને **Enter** દબાવો. |
| **DATE** | કમ્પ્યુટરની વર્તમાન તારીખ જોવા અથવા બદલવા માટે `DATE` કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `DATE` |
| **TIME** | કમ્પ્યુટરનો વર્તમાન સમય જોવા અથવા બદલવા માટે `TIME` કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `TIME` |
| **DIR** | વર્તમાન ફોલ્ડરમાં રહેલી ફાઇલો અને ફોલ્ડરની યાદી જોવા માટે `DIR` કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `DIR` |
| **CLS** | Command Prompt ની સ્ક્રીન સાફ કરવા માટે `CLS` કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `CLS` |
| **CD** | બીજા ફોલ્ડરમાં જવા માટે `CD` કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `CD DATA` |
| **CD..** | વર્તમાન ફોલ્ડરમાંથી એક લેવલ ઉપર જવા માટે `CD..` કમાન્ડનો ઉપયોગ થાય છે. |
| **MD** | નવું ફોલ્ડર બનાવવા માટે `MD` એટલે કે **Make Directory** કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `MD DATA` |
| **RD** | ફોલ્ડર દૂર કરવા માટે `RD` એટલે કે **Remove Directory** કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `RD DATA` |
| **REN** | ફાઇલ અથવા ફોલ્ડરનું નામ બદલવા માટે `REN` એટલે કે **Rename** કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `REN OLD.TXT NEW.TXT` |
| **DEL** | ફાઇલ કાઢી નાખવા માટે `DEL` એટલે કે **Delete** કમાન્ડનો ઉપયોગ થાય છે. ઉદાહરણ: `DEL TEST.TXT` |
