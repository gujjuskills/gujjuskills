# ES-4.2 : AI કેવી રીતે કામ કરે છે?

## ❖ AI કેવી રીતે કામ કરે છે?
AI ની કાર્યપદ્ધતિ સિસ્ટમના પ્રકાર પ્રમાણે બદલાય છે. ઘણી AI સિસ્ટમમાં માહિતી (Data) નો ઉપયોગ કરીને પેટર્ન ઓળખવામાં અથવા આગાહી/જવાબ તૈયાર કરવામાં આવે છે.

સામાન્ય રીતે પ્રક્રિયામાં નીચેના તબક્કા હોઈ શકે છે:
1. **Data:** જરૂરી માહિતી એકત્રિત અથવા ઉપલબ્ધ કરવી.
2. **Training અથવા Configuration:** પસંદ કરેલી પદ્ધતિ પ્રમાણે સિસ્ટમને પેટર્ન ઓળખવા અથવા નિયમો અનુસરવા તૈયાર કરવી.
3. **Processing:** નવી માહિતી આપતાં સિસ્ટમ તેનો વિશ્લેષણ કરે છે.
4. **Output:** જવાબ, વર્ગીકરણ, ભલામણ અથવા આગાહી આપે છે.
5. **Evaluation:** પરિણામ કેટલું યોગ્ય છે તે તપાસવું અને જરૂર મુજબ સુધારો કરવો.

બધી AI સિસ્ટમ એકસરખી રીતે તાલીમ લેતી નથી. કેટલીક નિર્ધારિત નિયમો, કેટલીક Machine Learning અને કેટલીક અન્ય પદ્ધતિઓ પર આધારિત હોય છે.

## ❖ Data શું છે અને તે શા માટે મહત્વપૂર્ણ છે?
**Data (માહિતી/ડેટા)** એટલે એકત્રિત કરેલી વિગતો, જેમ કે લખાણ, સંખ્યા, ચિત્ર, અવાજ અથવા માપન.

AI સિસ્ટમ માટે Data મહત્વપૂર્ણ છે કારણ કે તેમાંથી પેટર્ન શીખવા, સરખામણી કરવા અથવા પરિણામ તૈયાર કરવા માટે માહિતી મળે છે. અપૂર્ણ, ખોટો અથવા પક્ષપાત ધરાવતો Data પરિણામને અસર કરી શકે છે.

ઉદાહરણ: જો મશીનની ખામી ઓળખવા માટેની સિસ્ટમને યોગ્ય અને વિવિધ પ્રકારના ઉદાહરણો ન મળે, તો કેટલીક ખામીઓ ઓળખવામાં તે નિષ્ફળ જઈ શકે છે.

## ❖ Machine Learning અને Deep Learning
**Machine Learning (ML):** AI નો એવો અભિગમ જેમાં સિસ્ટમ Data માંથી પેટર્ન શીખીને આગાહી અથવા નિર્ણયમાં મદદ કરે છે, દરેક નિયમ હાથથી લખવાની જરૂરિયાત ઘટાડે છે.

**Deep Learning (DL):** Machine Learning નો એક પ્રકાર, જેમાં અનેક સ્તરો ધરાવતા Neural Networks નો ઉપયોગ થાય છે. તે ચિત્ર, અવાજ અને ભાષા જેવા જટિલ Data પર કામ કરવા માટે વપરાય છે.

| મુદ્દો | Machine Learning | Deep Learning |
|---|---|---|
| સંબંધ | AI નો એક અભિગમ | ML નો એક ભાગ |
| પદ્ધતિ | વિવિધ અલ્ગોરિધમ્સ | બહુસ્તરીય Neural Networks |
| Data અને Computing | જરૂરિયાત કાર્ય પ્રમાણે બદલાય | ઘણી પરિસ્થિતિમાં વધુ Data અને Computing જરૂરી થઈ શકે |
| ઉદાહરણ | ગ્રાહકના વ્યવહાર પરથી ભલામણ | ચિત્રોમાં વસ્તુઓ ઓળખવી |

આ સરખામણી સામાન્ય સમજ માટે છે; વાસ્તવિક સિસ્ટમની ક્ષમતા અને જરૂરિયાતો અલગ હોઈ શકે છે.

## ❖ સરળ ઉદાહરણ
ધારો કે એક સિસ્ટમને સારા અને ખામીવાળા ઉત્પાદનોના ચિત્રો આપવામાં આવે છે. તાલીમ દરમિયાન તે ચિત્રોમાં રહેલા પેટર્ન શીખી શકે છે. પછી નવા ચિત્રને જોઈને તે ખામી હોવાની શક્યતા બતાવી શકે છે. આ પરિણામને માનવી દ્વારા ચકાસવું જરૂરી હોઈ શકે છે.

- તે કયો જવાબ અથવા પરિણામ આપે છે?
- પરિણામ ખોટું હોય તો શું અસર થઈ શકે?
- પરિણામની ચકાસણી કેવી રીતે કરશો?
