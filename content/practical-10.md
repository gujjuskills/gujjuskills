# પ્રેકટિકલ-૧૦ : યુઝર એકાઉન્ટ્સનું સેટિંગ અને મેનેજમેન્ટ
![image](/gujjuskills/images/account-menu.webp)
| પ્રેક્ટિકલ સ્ટેપ | સામાન્ય માહિતી |
|---|---|
| Control Panel | Control Panel ખોલવા માટે Windows Search માં **Control Panel** લખીને Open કરો. |
| User Accounts | Control Panel માં **User Accounts** પસંદ કરીને યુઝર એકાઉન્ટની સેટિંગ્સ મેનેજ કરી શકાય છે. |
| Change User Name | **User Accounts → Change your account name** પર ક્લિક કરીને યુઝરનું નામ બદલી શકાય છે. |
| Change User Type | **User Accounts → Change your account type** પસંદ કરીને Standard User અથવા Administrator પ્રકાર બદલી શકાય છે. |
| Create New User | **Settings → Accounts → Other users → Add account** દ્વારા નવું યુઝર એકાઉન્ટ બનાવી શકાય છે. |
| Create Password | **User Accounts → Create a password** દ્વારા યુઝર એકાઉન્ટ માટે પાસવર્ડ બનાવી શકાય છે. |
| Change User Photo | **Settings → Accounts → Your info → Adjust your photo** દ્વારા યુઝરનો ફોટો બદલી શકાય છે. |
| Delete User | **Settings → Accounts → Other users** માંથી યુઝર પસંદ કરીને **Remove** દ્વારા એકાઉન્ટ ડિલીટ કરી શકાય છે. |
| Windows + L | **Windows + L** કી દબાવવાથી કમ્પ્યુટર તરત જ Lock થાય છે. |
