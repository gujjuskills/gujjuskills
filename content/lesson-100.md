# લેશન - ૧૦૦ : એપ્લિકેશન ડેવલપમેંટ લાઈફ સાયકલ તબક્કાઓ ઓળખો
## What is the SDLC?



**SDLC (Software Development Life Cycle)** એ સોફ્ટવેર અથવા એપ્લિકેશનને આયોજનથી લઈને વિકાસ, ટેસ્ટિંગ, Deployment અને Maintenance સુધી વ્યવસ્થિત રીતે બનાવવાની પ્રક્રિયા છે. 

## The Stages of SDLC

| Sr. No. | Stage | માહિતી |
|---:|---|---|
| 1 | Planning | પ્રોજેક્ટના હેતુ, જરૂરિયાતો, સમય અને સંસાધનોનું આયોજન કરવામાં આવે છે. |
| 2 | Requirement Analysis | ગ્રાહક અથવા વપરાશકર્તાની જરૂરિયાતો એકત્રિત કરીને તેનું વિશ્લેષણ કરવામાં આવે છે. |
| 3 | Design | એપ્લિકેશનનું UI, Database, Architecture અને System Design તૈયાર કરવામાં આવે છે. |
| 4 | Development | તૈયાર કરેલા Design અને Requirements મુજબ Software અથવા Application નો Code લખવામાં આવે છે. |
| 5 | Testing | Application માં રહેલી ભૂલો અને ખામીઓ શોધવા માટે વિવિધ પ્રકારના Testing કરવામાં આવે છે. |
| 6 | Deployment | Testing પૂર્ણ થયા પછી Application ને Live Environment અથવા User માટે ઉપલબ્ધ કરવામાં આવે છે. |
| 7 | Maintenance | Application ને સતત જાળવવામાં આવે છે અને જરૂરી Updates, Improvements તથા Bug Fixes કરવામાં આવે છે. |
