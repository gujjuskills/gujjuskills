# પ્રેકટિકલ-૧૧૬ : નેટવર્ક જોડાણો જુઓ

![image](public/images/practical-116.webp)

## નેટવર્ક કનેક્શન સુધી પહોંચવાના સ્ટેપ્સ

### રીત - 1

1. **Control Panel** ખોલો.
2. **Network and Sharing Center** પસંદ કરો.
3. **Change adapter settings** પર ક્લિક કરો.

### રીત - 2

1. **Windows + R** કી દબાવો.
2. Run વિન્ડોમાં `ncpa.cpl` લખો.
3. **Enter** કી દબાવો.

## નેટવર્ક કનેક્શન દ્વારા કઈ કઈ માહિતી મેળવી શકાય છે?

નેટવર્ક કનેક્શન દ્વારા નીચેની માહિતી મેળવી શકાય છે:

1. નેટવર્ક એડેપ્ટરનું નામ
2. કનેક્શનની સ્થિતિ
3. IP Address
4. Subnet Mask
5. Default Gateway
6. DNS Server
7. MAC Address
