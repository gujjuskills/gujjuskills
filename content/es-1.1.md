# ES-1.1 : તમારા ભવિષ્યને આકાર આપતી કુશળતા
## What it means to be skilled today?

### ❖ પરિચય
આજના સમયમાં સફળ થવા માટે માત્ર શૈક્ષણિક લાયકાત અથવા ટેકનિકલ જ્ઞાન પૂરતું નથી. વ્યક્તિએ પોતાનું કામ યોગ્ય રીતે કરવું, અન્ય લોકો સાથે અસરકારક રીતે વાતચીત કરવી, સમયનું આયોજન કરવું અને નવી પરિસ્થિતિઓમાં શીખતા રહેવું જરૂરી છે.

ઉદાહરણ તરીકે, ITI માં ઇલેક્ટ્રિશિયનનો અભ્યાસ કરતો વિદ્યાર્થી વાયરિંગ કરવાનું જાણે છે. આ તેની ટેકનિકલ કુશળતા છે. જો તે ગ્રાહકને કામ સમજાવી શકે, સલામતીના નિયમોનું પાલન કરે અને કામ સમયસર પૂર્ણ કરે, તો તેની કાર્યસ્થળની અસરકારકતા વધે છે.

### ❖ Employability Skills એટલે શું?
**Employability Skills** એટલે નોકરી મેળવવા, કામમાં સારું પ્રદર્શન કરવા અને કારકિર્દીનો વિકાસ કરવા મદદરૂપ થતી કુશળતાઓ, વલણો અને વર્તણૂકો.

સરળ ભાષામાં, કામ મેળવવા અને કામમાં સફળ થવા માટે જરૂરી વ્યવહારુ કુશળતાઓને Employability Skills કહેવામાં આવે છે.

### ❖ મુખ્ય Employability Skills
| Skill | ગુજરાતી અર્થ | ઉદાહરણ |
|---|---|---|
| Communication | સંવાદ કૌશલ્ય | પોતાની વાત સ્પષ્ટ રીતે સમજાવવી |
| Teamwork | ટીમમાં કામ | સહકર્મચારીઓ સાથે મળીને કાર્ય કરવું |
| Problem Solving | સમસ્યા ઉકેલવી | ખામીનું કારણ શોધવું |
| Time Management | સમય વ્યવસ્થાપન | કામ સમયસર પૂર્ણ કરવું |
| Digital Skills | ડિજિટલ કુશળતા | કમ્પ્યુટર અને સોફ્ટવેર વાપરવું |
| Adaptability | અનુકૂલન ક્ષમતા | નવી પ્રક્રિયા શીખવી |
| Critical Thinking | વિવેચનાત્મક વિચારશક્તિ | નિર્ણય પહેલાં માહિતી તપાસવી |

### ❖ Employability Skills શા માટે જરૂરી છે?
1. **નોકરી મેળવવા:** ઇન્ટરવ્યૂમાં સ્પષ્ટ જવાબ આપવો અને પોતાની કુશળતા રજૂ કરવી.
2. **કાર્યસ્થળે સારું કામ કરવા:** સૂચનાઓ સમજવી અને જવાબદારીપૂર્વક કામ કરવું.
3. **ટીમવર્ક માટે:** અન્ય લોકો સાથે સહકાર રાખવો.
4. **સમસ્યાઓ ઉકેલવા:** કારણ શોધીને યોગ્ય ઉકેલ પસંદ કરવો.
5. **કારકિર્દી વિકસાવવા:** નવી કુશળતાઓ શીખવી અને નવી તકો માટે તૈયાર રહેવું.
6. **સ્વરોજગાર માટે:** ગ્રાહક સાથે વ્યવહાર અને કામનું આયોજન કરવું.

### ❖ Technical Skills અને Employability Skills
| Technical Skills | Employability Skills |
|---|---|
| ચોક્કસ ટ્રેડ અથવા કામ માટેનું ટેકનિકલ જ્ઞાન | કામ મેળવવા અને અસરકારક રીતે કામ કરવા મદદરૂપ સામાન્ય કુશળતાઓ |
| ઉદાહરણ: ઇલેક્ટ્રિકલ વાયરિંગ | ઉદાહરણ: ગ્રાહકને કામ સમજાવવું |
| ઉદાહરણ: Excel Formula વાપરવો | ઉદાહરણ: ટીમ સાથે માહિતી વહેંચવી |

બંને પ્રકારની કુશળતાઓ એકબીજાની પૂરક છે. વિદ્યાર્થીએ ટેકનિકલ કુશળતા સાથે સંવાદ, સમય વ્યવસ્થાપન અને સમસ્યા ઉકેલવાની કુશળતા પણ વિકસાવવી જોઈએ.

### ❖ પ્રવૃત્તિ: મારી કુશળતાઓ ઓળખો
નીચેના પ્રશ્નોના જવાબ લખો.
- હું કયા ITI ટ્રેડમાં અભ્યાસ કરું છું?
- હું કયું ટેકનિકલ કામ સારી રીતે કરી શકું છું?
- મારી એક સારી Employability Skill કઈ છે?
- મારે કઈ કુશળતા સુધારવાની જરૂર છે?
- તેને સુધારવા માટે હું કયું પગલું લઈશ?

### ❖ પુનરાવર્તન પ્રશ્નો

### 1. Employability Skills ની વ્યાખ્યા આપો.

Employability Skills એટલે રોજગાર મેળવવા, નોકરીમાં સફળ થવા અને કાર્યસ્થળે પોતાની જવાબદારીઓ સારી રીતે નિભાવવા માટે જરૂરી કૌશલ્યોને રોજગારલક્ષી કૌશલ્યો કહેવામાં આવે છે.

### 2. Employability Skills ના ચાર ઉદાહરણ આપો.

1. Communication Skills (સંવાદ કૌશલ્ય)
2. Time Management (સમય વ્યવસ્થાપન)
3. Teamwork (ટીમમાં સાથે મળીને કામ કરવાની ક્ષમતા)
4. Problem Solving (સમસ્યાનું નિરાકરણ કરવાની ક્ષમતા)

### 3. Technical Skills અને Employability Skills વચ્ચેનો તફાવત લખો.

| Technical Skills | Employability Skills |
|---|---|
| કોઈ ચોક્કસ કાર્ય કરવા માટે જરૂરી ટેકનિકલ જ્ઞાન અને કુશળતા છે. | નોકરી મેળવવા અને કાર્યસ્થળે સફળ થવા માટે જરૂરી સામાન્ય કૌશલ્યો છે. |
| તે ચોક્કસ સાધન, ટેકનોલોજી અથવા કામ સાથે સંબંધિત છે. | તે સંવાદ, સમય વ્યવસ્થાપન અને ટીમવર્ક સાથે સંબંધિત છે. |
| ઉદાહરણ: કમ્પ્યુટર પ્રોગ્રામિંગ, ટાઇપિંગ અને મશીન ચલાવવું. | ઉદાહરણ: સંવાદ કૌશલ્ય, નેતૃત્વ અને સમસ્યાનું નિરાકરણ. |

### 4. કાર્યસ્થળે Communication અને Time Management શા માટે જરૂરી છે?

**Communication (સંવાદ કૌશલ્ય):**

કાર્યસ્થળે યોગ્ય રીતે વાતચીત કરવા, માહિતીની આપલે કરવા, સૂચનાઓ સમજવા અને સહકર્મચારીઓ સાથે સારા સંબંધો જાળવવા માટે Communication જરૂરી છે. તે ગેરસમજ ઘટાડે છે અને કામની ગુણવત્તા સુધારે છે.

**Time Management (સમય વ્યવસ્થાપન):**

સમયસર કામ પૂરું કરવા, કાર્યોને પ્રાથમિકતા આપવા, સમયનો યોગ્ય ઉપયોગ કરવા અને કામનો બોજ ઘટાડવા માટે Time Management જરૂરી છે. તેનાથી કાર્યક્ષમતા વધે છે અને નિર્ધારિત સમયમર્યાદામાં કામ પૂર્ણ થાય છે.
