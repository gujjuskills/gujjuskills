# પ્રેકટિકલ-૮૨ : સેલ અને રેન્જને ફોરમેટ કરો : MS-EXCEL

| Topic | માહિતી |
|---|---|
| Merge and Unmerge cells | બે અથવા વધુ સેલને એક સેલમાં જોડવા માટે **Merge Cells** વિકલ્પનો ઉપયોગ કરવામાં આવે છે. જોડાયેલા સેલને ફરીથી અલગ કરવા માટે **Unmerge Cells** વિકલ્પનો ઉપયોગ કરવામાં આવે છે. |
| Modify cell alignment, orientation and indentation | સેલમાં રહેલા લખાણની ગોઠવણી બદલવા માટે **Alignment** નો ઉપયોગ થાય છે. લખાણની દિશા બદલવા માટે **Orientation** અને લખાણને અંદરથી અંતર આપવા માટે **Indentation** નો ઉપયોગ કરવામાં આવે છે. |
| Format cells using Format Painter | એક સેલમાં કરેલું ફોર્મેટિંગ બીજા સેલમાં લાગુ કરવા માટે **Format Painter** નો ઉપયોગ થાય છે. તેનાથી Font, Size, Color, Border અને અન્ય Formatting સરળતાથી Copy કરી શકાય છે. |
| Wrap text within cells | સેલમાં લખાણ લાંબું હોય અને તે એક જ લાઇનમાં ન આવતું હોય ત્યારે **Wrap Text** નો ઉપયોગ થાય છે. તે લખાણને સેલની પહોળાઈ પ્રમાણે એકથી વધુ લાઇનમાં દર્શાવે છે. |
| Apply number formats | સંખ્યાઓને જરૂરી સ્વરૂપમાં દર્શાવવા માટે **Number Format** નો ઉપયોગ થાય છે. જેમ કે Number, Currency, Percentage, Date અને Time વગેરે Format લાગુ કરી શકાય છે. |
| Apply cell formats from the Format cells dialog box | **Format Cells** Dialog Box દ્વારા સેલનું Number, Alignment, Font, Border, Fill અને Protection જેવા વિવિધ Formatting વિકલ્પો એક જ જગ્યાએથી લાગુ કરી શકાય છે. |
| Apply cell styles | સેલને તૈયાર અને એકસરખું Formatting આપવા માટે **Cell Styles** નો ઉપયોગ થાય છે. તેમાં Heading, Title, Total અને અન્ય વિવિધ તૈયાર Styles ઉપલબ્ધ હોય છે. |
| Clear cell formatting | સેલમાંથી લાગુ કરેલું Formatting દૂર કરવા માટે **Clear Formatting** નો ઉપયોગ થાય છે. તે સેલનું મૂળ લખાણ અથવા ડેટા દૂર કરતું નથી, માત્ર Formatting દૂર કરે છે. |
