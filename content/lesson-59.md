# લેશન - ૫૯ : કોમ્પ્યુટર નેટવર્કનો ખ્યાલ

| Topics | માહિતી |
|---|---|
| What is Network? | બે અથવા વધુ કમ્પ્યુટર તથા અન્ય ઉપકરણોને એકબીજા સાથે જોડીને માહિતી અને સંસાધનોની આપલે કરવાની વ્યવસ્થાને કમ્પ્યુટર નેટવર્ક કહેવામાં આવે છે. |
| Use of Network | ફાઇલો અને ડેટાની આપલે, પ્રિન્ટર જેવા સાધનોની વહેંચણી, ઇન્ટરનેટનો ઉપયોગ, સંદેશાવ્યવહાર અને સંસાધનોની વહેંચણી માટે નેટવર્કનો ઉપયોગ થાય છે. |
| Types of Network | નેટવર્કને તેના વિસ્તાર અને ઉપયોગના આધારે PAN, LAN, CAN, MAN અને WAN જેવા પ્રકારોમાં વહેંચવામાં આવે છે. |
| PAN | Personal Area Network એટલે વ્યક્તિગત વિસ્તારનું નેટવર્ક. તેનો ઉપયોગ વ્યક્તિની આસપાસના નાના વિસ્તારમાં મોબાઇલ, કમ્પ્યુટર, સ્માર્ટવોચ વગેરે જોડવા માટે થાય છે. |
| LAN | Local Area Network એટલે સ્થાનિક વિસ્તારનું નેટવર્ક. તેનો ઉપયોગ ઘર, ઓફિસ, શાળા અથવા લેબોરેટરી જેવા નાના વિસ્તારમાં થાય છે. |
| CAN | Campus Area Network એટલે કેમ્પસ વિસ્તારનું નેટવર્ક. તેનો ઉપયોગ કોલેજ, યુનિવર્સિટી અથવા મોટા કેમ્પસમાં આવેલી વિવિધ ઇમારતોને જોડવા માટે થાય છે. |
| MAN | Metropolitan Area Network એટલે મહાનગર વિસ્તારનું નેટવર્ક. તેનો ઉપયોગ શહેર અથવા મોટા શહેરી વિસ્તારમાં વિવિધ નેટવર્કને જોડવા માટે થાય છે. |
| WAN | Wide Area Network એટલે વિશાળ વિસ્તારનું નેટવર્ક. તેનો ઉપયોગ દેશો અથવા સમગ્ર વિશ્વમાં આવેલા કમ્પ્યુટર અને નેટવર્કને જોડવા માટે થાય છે. ઇન્ટરનેટ તેનું મુખ્ય ઉદાહરણ છે. |
