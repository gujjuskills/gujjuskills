# લેશન - ૪૬ : DBMS અને RDBMS નો ખ્યાલ

## DBMS અને RDBMS

| ક્રમાંક | DBMS | RDBMS |
|---|---|---|
| 1 | DBMS એટલે Database Management System. | RDBMS એટલે Relational Database Management System. |
| 2 | ડેટા ફાઇલ અથવા અન્ય સ્વરૂપમાં સંગ્રહિત થઈ શકે છે. | ડેટા ટેબલના સ્વરૂપમાં સંગ્રહિત થાય છે. |
| 3 | ટેબલ વચ્ચે સંબંધ હોવો જરૂરી નથી. | ટેબલ વચ્ચે સંબંધ સ્થાપિત કરી શકાય છે. |
| 4 | Primary Key નો ઉપયોગ મર્યાદિત હોઈ શકે છે. | Primary Key નો ઉપયોગ દરેક Record ને અનન્ય ઓળખવા માટે થાય છે. |
| 5 | Foreign Key નો ઉપયોગ જરૂરી નથી. | Foreign Key દ્વારા બે અથવા વધુ ટેબલને જોડવામાં આવે છે. |
| 6 | ડેટાની પુનરાવર્તનતા વધારે હોઈ શકે છે. | ડેટાની પુનરાવર્તનતા ઘટાડવામાં આવે છે. |
| 7 | નાના અને સરળ Database માટે વધુ યોગ્ય છે. | મોટા અને જટિલ Database માટે વધુ યોગ્ય છે. |
| 8 | Data Integrity માટે મર્યાદિત સુવિધાઓ હોય છે. | Constraints દ્વારા Data Integrity જાળવવામાં આવે છે. |
| 9 | Normalization નો ઉપયોગ સામાન્ય રીતે ઓછો થાય છે. | ડેટાની પુનરાવર્તનતા ઘટાડવા માટે Normalization નો ઉપયોગ થાય છે. |
| 10 | એકસાથે ઘણા વપરાશકર્તાઓ માટેની સુવિધા મર્યાદિત હોઈ શકે છે. | એકસાથે ઘણા વપરાશકર્તાઓને વધુ સારી રીતે સપોર્ટ કરે છે. |
| 11 | File System આધારિત Database વગેરે. | MySQL, Oracle, PostgreSQL અને SQL Server વગેરે. |
| 12 | DBMS ની રચના પ્રમાણમાં સરળ હોય છે. | RDBMS વધુ વ્યવસ્થિત અને નિયમબદ્ધ હોય છે. |
| 13 | SQL નો ઉપયોગ સિસ્ટમ પ્રમાણે મર્યાદિત હોઈ શકે છે. | SQL નો વ્યાપક ઉપયોગ Database ને મેનેજ કરવા માટે થાય છે. |
| 14 | Record માં ડેટા સંગ્રહિત કરવામાં આવે છે. | Record ટેબલની Row તરીકે સંગ્રહિત થાય છે. |
| 15 | Field ડેટાના ચોક્કસ પ્રકારની માહિતી દર્શાવે છે. | Field ટેબલના Column તરીકે દર્શાવવામાં આવે છે. |
| 16 | Constraints ની સુવિધા મર્યાદિત હોઈ શકે છે. | Primary Key, Foreign Key, Unique, Not Null વગેરે Constraints ઉપલબ્ધ છે. |
| 17 | ડેટા વચ્ચે સંબંધ હોવો જરૂરી નથી. | વિવિધ ટેબલ વચ્ચે સંબંધ સ્થાપિત કરી શકાય છે. |
| 18 | નાના અને સરળ Application માટે ઉપયોગી છે. | Banking, Business, Education અને મોટા Web Applications માટે ઉપયોગી છે. |
