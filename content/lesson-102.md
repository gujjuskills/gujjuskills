# લેશન - ૧૦૨ : ઓપન સ્ટેક

## What is Open Stack?

OpenStack એક ઓપન સોર્સ ક્લાઉડ કમ્પ્યુટિંગ પ્લેટફોર્મ છે. તેનો ઉપયોગ સર્વર, સ્ટોરેજ, નેટવર્ક અને અન્ય ક્લાઉડ સંસાધનોને મેનેજ કરવા માટે થાય છે. OpenStack દ્વારા ખાનગી અને જાહેર ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર બનાવી અને સંચાલિત કરી શકાય છે.

## How it works

| Topic | માહિતી |
|---|---|
| **Nova** | Nova OpenStack ની Compute સેવા છે. તે વર્ચ્યુઅલ મશીન અથવા ઇન્સ્ટન્સ બનાવવાનું, ચલાવવાનું અને મેનેજ કરવાનું કામ કરે છે. |
| **Swift** | Swift Object Storage સેવા છે. તેનો ઉપયોગ ફાઇલો અને અન્ય ડેટાને ઑબ્જેક્ટ તરીકે સ્ટોર કરવા માટે થાય છે. |
| **Neutron** | Neutron Networking સેવા છે. તે વર્ચ્યુઅલ નેટવર્ક, IP સરનામાં, રાઉટર અને નેટવર્ક કનેક્ટિવિટીનું સંચાલન કરે છે. |
| **Cinder** | Cinder Block Storage સેવા છે. તે વર્ચ્યુઅલ મશીન માટે persistent block storage ઉપલબ્ધ કરાવે છે. |
| **Keystone** | Keystone Identity સેવા છે. તે યુઝર, પ્રોજેક્ટ, authentication અને authorizationનું સંચાલન કરે છે. |

## Benefits of Open Stack

| Topic | માહિતી |
|---|---|
| **ઓપન સોર્સ** | OpenStack ઓપન સોર્સ પ્લેટફોર્મ હોવાથી તેનો સોર્સ કોડ ઉપલબ્ધ છે અને સંસ્થાઓ પોતાની જરૂરિયાત મુજબ તેમાં ફેરફાર કરી શકે છે. |
| **સ્કેલેબિલિટી** | જરૂરિયાત પ્રમાણે કમ્પ્યુટિંગ, સ્ટોરેજ અને નેટવર્ક સંસાધનોને વધારી અથવા ઘટાડી શકાય છે. |
| **કોમ્યુનિટી સપોર્ટ** | OpenStack પાસે વિશાળ વૈશ્વિક ડેવલપર અને યુઝર કમ્યુનિટી છે, જેના કારણે દસ્તાવેજો, માર્ગદર્શન અને ટેક્નિકલ સપોર્ટ ઉપલબ્ધ છે. |
| **વિવિધતા** | OpenStack વિવિધ પ્રકારના ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર, હાર્ડવેર અને ટેક્નોલોજી સાથે કામ કરી શકે છે. |
