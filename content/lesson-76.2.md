# લેશન - ૭૬.૨ : HTML ટેગ

| Tags | ઉપયોગ |
|---|---|
| HTML | HTML દસ્તાવેજનું મૂળ માળખું બનાવવા માટે ઉપયોગ થાય છે. |
| Head | વેબ પેજની મેટા માહિતી, CSS, સ્ક્રિપ્ટ વગેરે રાખવા માટે ઉપયોગ થાય છે. |
| Title | બ્રાઉઝરના ટેબમાં વેબ પેજનું શીર્ષક દર્શાવવા માટે ઉપયોગ થાય છે. |
| Body | વેબ પેજ પર દેખાતી તમામ સામગ્રી રાખવા માટે ઉપયોગ થાય છે. |
| P | ફકરો (Paragraph) બનાવવા માટે ઉપયોગ થાય છે. |
| H1 થી H6 | વિવિધ સ્તરના શીર્ષકો (Headings) બનાવવા માટે ઉપયોગ થાય છે. |
| IMG | વેબ પેજમાં ઈમેજ દર્શાવવા માટે ઉપયોગ થાય છે. |
| A | અન્ય વેબ પેજ અથવા વેબસાઇટની લિંક બનાવવા માટે ઉપયોગ થાય છે. |
| Marquee | ટેક્સ્ટ અથવા અન્ય સામગ્રીને સ્ક્રોલિંગ સ્વરૂપે દર્શાવવા માટે ઉપયોગ થાય છે. |
| BR | નવી લાઇન શરૂ કરવા માટે ઉપયોગ થાય છે. |
| UL | Unordered List એટલે કે બુલેટવાળી યાદી બનાવવા માટે ઉપયોગ થાય છે. |
| OL | Ordered List એટલે કે ક્રમવાળી યાદી બનાવવા માટે ઉપયોગ થાય છે. |
| LI | યાદીમાં કોઈ એક વસ્તુ (List Item) દર્શાવવા માટે ઉપયોગ થાય છે. |
| DL | Description List એટલે કે વર્ણનાત્મક યાદી બનાવવા માટે ઉપયોગ થાય છે. |
| DT | Description List માં શબ્દ અથવા વિષય દર્શાવવા માટે ઉપયોગ થાય છે. |
| DD | DT માં આપેલા શબ્દ અથવા વિષયનું વર્ણન દર્શાવવા માટે ઉપયોગ થાય છે. |
| Table | કોષ્ટક (Table) બનાવવા માટે ઉપયોગ થાય છે. |
| TH | કોષ્ટકમાં Heading અથવા શીર્ષક દર્શાવવા માટે ઉપયોગ થાય છે. |
| TR | કોષ્ટકમાં એક Row બનાવવા માટે ઉપયોગ થાય છે. |
| TD | કોષ્ટકમાં Data અથવા Cell દર્શાવવા માટે ઉપયોગ થાય છે. |
| B | ટેક્સ્ટને Bold એટલે કે ઘાટા અક્ષરમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
| I | ટેક્સ્ટને Italic એટલે કે ત્રાંસા અક્ષરમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
| STRONG | ટેક્સ્ટને મહત્વપૂર્ણ (Strong Importance) તરીકે દર્શાવવા માટે ઉપયોગ થાય છે. |
| SMALL | ટેક્સ્ટને સામાન્ય ટેક્સ્ટ કરતાં નાના કદમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
| EM | ટેક્સ્ટ પર ભાર (Emphasis) આપવા માટે ઉપયોગ થાય છે. |
| DEL | કાઢી નાખેલા અથવા Deleted ટેક્સ્ટને દર્શાવવા માટે ઉપયોગ થાય છે. |
| MARK | ટેક્સ્ટને Highlight કરવા માટે ઉપયોગ થાય છે. |
| INS | ઉમેરવામાં આવેલ અથવા Inserted ટેક્સ્ટ દર્શાવવા માટે ઉપયોગ થાય છે. |
| SUP | Superscript એટલે કે ટેક્સ્ટને ઉપરની બાજુ નાના અક્ષરમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
| SUB | Subscript એટલે કે ટેક્સ્ટને નીચેની બાજુ નાના અક્ષરમાં દર્શાવવા માટે ઉપયોગ થાય છે. |
