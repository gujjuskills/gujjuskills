# 3. Learning How to Learn

### 3.1 અર્થ
**Learning How to Learn** એટલે પોતાની શીખવાની પ્રક્રિયાને સમજવી અને વધુ અસરકારક રીતે શીખવાની રીતો અપનાવવી. દરેક વિદ્યાર્થી એકસરખી રીતે શીખતો નથી. કોઈ વાંચીને, કોઈ ઉદાહરણ જોઈને, તો કોઈ જાતે પ્રેક્ટિસ કરીને વધુ સારી રીતે સમજે છે.

### 3.2 શીખવાની વિવિધ રીતો
- **વાંચીને શીખવું:** પુસ્તક, નોંધો અને લેખ વાંચવા.
- **જોઈને શીખવું:** ચિત્રો, પ્રદર્શન અને વિડિયોનો ઉપયોગ.
- **કરીને શીખવું:** પ્રેક્ટિકલ કાર્ય જાતે કરવું.
- **ચર્ચા કરીને શીખવું:** શિક્ષક અને સહાધ્યાયીઓ સાથે ચર્ચા.
- **પુનરાવર્તન કરીને શીખવું:** શીખેલી બાબતો ફરી યાદ કરવી અને પ્રશ્નો ઉકેલવા.

એક જ રીત દરેક વિષય માટે શ્રેષ્ઠ હોય એવું નથી. વિષય અને પરિસ્થિતિ પ્રમાણે રીત પસંદ કરવી જોઈએ.

### 3.3 અસરકારક રીતે શીખવાની ટેવો
| રીત | શું કરવું? |
|---|---|
| Goal Setting | અભ્યાસનું સ્પષ્ટ લક્ષ્ય નક્કી કરવું |
| Note Making | મહત્વના મુદ્દા પોતાની ભાષામાં લખવા |
| Practice | વારંવાર પ્રેક્ટિસ કરવી |
| Self Testing | જાતે પ્રશ્નો બનાવી જવાબ આપવા |
| Revision | શીખેલી બાબતોનું પુનરાવર્તન કરવું |
| Reflection | શું સમજાયું અને શું સુધારવું તે વિચારવું |

### 3.4 પરિસ્થિતિ પ્રમાણે શીખવાની રીત બદલો
ધારો કે વિદ્યાર્થીને Excel Formula સમજાતો નથી. માત્ર વ્યાખ્યા વાંચવાને બદલે તે નાનું Dataset બનાવે, Formula દાખલ કરે અને પરિણામ ચકાસે. જો ભૂલ થાય તો Formula ફરી તપાસે અને જરૂર પડે તો માર્ગદર્શન મેળવે.

### 3.5 પ્રવૃત્તિ: મારી Learning Strategy
વાક્યો પૂર્ણ કરો.
1. મને સૌથી સારી રીતે શીખવામાં મદદ મળે છે જ્યારે હું __________.
2. કોઈ વિષય સમજાતો ન હોય ત્યારે હું __________.
3. શીખેલી બાબતો યાદ રાખવા માટે હું __________.
4. મારી શીખવાની પદ્ધતિમાં એક સુધારો __________ છે.

### 3.6 પુનરાવર્તન પ્રશ્નો
1. Learning How to Learn નો અર્થ શું છે?

3. Self Testing અને Revision કેવી રીતે મદદરૂપ થાય છે?
4. શીખવાના હેતુ પ્રમાણે પદ્ધતિ બદલવી શા માટે જરૂરી છે?
