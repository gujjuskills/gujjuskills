# લેશન - ૬૨ : લોકલ નેટવર્ક પર કોમ્યુનિકેશન, કોમ્યુનિકેશનના નિયમો

| Topics | માહિતી |
|---|---|
| **Computer Network Topologies** | કમ્પ્યુટર નેટવર્કમાં વિવિધ કમ્પ્યુટર અને નેટવર્ક ઉપકરણોને એકબીજા સાથે જોડવાની ભૌતિક અથવા તાર્કિક રચનાને **Network Topology** કહેવામાં આવે છે. |
| **List of Network Topologies** | 1. **BUS**  2. **RING**  3. **STAR**  4. **MESH**  5. **TREE**  6. **HYBRID** |
| **BUS** | **BUS Topology** માં બધા કમ્પ્યુટર એક જ મુખ્ય કેબલ સાથે જોડાયેલા હોય છે. આ મુખ્ય કેબલને **Backbone Cable** કહેવામાં આવે છે. ડેટા મુખ્ય કેબલ દ્વારા એક કમ્પ્યુટરથી બીજા કમ્પ્યુટર સુધી પહોંચે છે. આ ટોપોલોજી સરળ અને ઓછા ખર્ચાળ છે, પરંતુ મુખ્ય કેબલમાં ખામી આવે તો આખું નેટવર્ક બંધ થઈ શકે છે. |
| **RING** | **RING Topology** માં બધા કમ્પ્યુટર એક બંધ વર્તુળના આકારમાં જોડાયેલા હોય છે. દરેક કમ્પ્યુટર બે પડોશી કમ્પ્યુટર સાથે જોડાયેલું હોય છે. ડેટા એક દિશામાં અથવા કેટલીક રચનાઓમાં બંને દિશામાં પસાર થઈ શકે છે. એક કનેક્શનમાં ખામી આવે તો સમગ્ર નેટવર્કની કામગીરી અસરગ્રસ્ત થઈ શકે છે. |
| **STAR** | **Star Topology** માં બધા કમ્પ્યુટર એક કેન્દ્રીય ઉપકરણ જેમ કે **Hub અથવા Switch** સાથે જોડાયેલા હોય છે. એક કમ્પ્યુટરમાં ખામી આવે તો અન્ય કમ્પ્યુટર પર સામાન્ય રીતે અસર થતી નથી. પરંતુ Hub અથવા Switchમાં ખામી આવે તો સમગ્ર નેટવર્ક બંધ થઈ શકે છે. |
| **TREE** | **Tree Topology** એ એવી નેટવર્ક રચના છે જેમાં અનેક Star Topology ને એક હાયરાર્કિકલ માળખામાં જોડવામાં આવે છે. તેમાં મુખ્ય ઉપકરણથી અન્ય ઉપકરણો અને કમ્પ્યુટર સુધી જોડાણ કરવામાં આવે છે. મોટા નેટવર્ક માટે તેનો ઉપયોગ થાય છે. |
| **MESH** | **Mesh Topology** માં દરેક કમ્પ્યુટર અથવા નોડ અન્ય કમ્પ્યુટર સાથે સીધા જોડાયેલા હોય છે. તેથી ડેટા માટે એકથી વધુ માર્ગ ઉપલબ્ધ રહે છે. આ ટોપોલોજી ખૂબ વિશ્વસનીય છે, પરંતુ તેમાં વધુ કેબલ અને ખર્ચની જરૂર પડે છે. |
| **HYBRID** | **Hybrid Topology** બે અથવા વધુ અલગ પ્રકારની Network Topology ને જોડીને બનાવવામાં આવે છે. ઉદાહરણ તરીકે **Star અને Bus Topology** ને જોડીને Hybrid Topology બનાવી શકાય છે. મોટા અને જટિલ નેટવર્કમાં તેનો ઉપયોગ થાય છે. |
| **POINT TO POINT** | **Point to Point Topology** માં બે નેટવર્ક ઉપકરણો વચ્ચે સીધું જોડાણ હોય છે. ડેટા એક ઉપકરણથી બીજા ઉપકરણ સુધી સીધો મોકલવામાં આવે છે. આ સરળ અને ઝડપી સંચાર પદ્ધતિ છે. |
| **Principles of Communications** | **Communication ના સિદ્ધાંતો:** સંદેશ મોકલનાર અને પ્રાપ્ત કરનાર હોવા જોઈએ. સંદેશ સ્પષ્ટ અને યોગ્ય હોવો જોઈએ. સંચાર માટે યોગ્ય માધ્યમનો ઉપયોગ કરવો જોઈએ. સંદેશ યોગ્ય સમયે અને યોગ્ય વ્યક્તિ સુધી પહોંચવો જોઈએ. પ્રાપ્તકર્તા તરફથી **Feedback** મળવું પણ જરૂરી છે. |
