# પ્રેકટિકલ-૧૩૦.૧ : JS-1 : જાવાસ્ક્રિપ્ટ સાથે એક સરળ પ્રોગ્રામ બનાવવો


```
<!DOCTYPE html>
<html>
<head>
    <title>Light JavaScript Program</title>
</head>

<body>

<h2>Light JavaScript Program</h2>

<img id="bulb" src="off.gif" width="150">

<br><br>

<button onclick="document.getElementById('bulb').src='on.gif'">
    Turn on the Light
</button>

<button onclick="document.getElementById('bulb').src='off.gif'">
    Turn off the Light
</button>

</body>
</html>
```
