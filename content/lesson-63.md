# લેશન - ૬૩ : ઇથરનેટ નેટવર્ક કી રીતે કાર્ય કરે

| Topic | માહિતી |
|---|---|
| **What is Ethernet?** | Ethernet એ કમ્પ્યુટર અને અન્ય નેટવર્ક ઉપકરણોને LAN (Local Area Network) દ્વારા જોડવા માટે ઉપયોગમાં લેવાતી વાયર્ડ નેટવર્ક ટેક્નોલોજી છે. તે કેબલ દ્વારા એક ઉપકરણથી બીજા ઉપકરણ સુધી ડેટા મોકલે છે. |
| **Advantages of Ethernet** | 1. ઝડપી અને વિશ્વસનીય ડેટા ટ્રાન્સફર થાય છે.<br>2. સ્થિર નેટવર્ક કનેક્શન મળે છે.<br>3. સુરક્ષા સારી હોય છે.<br>4. નેટવર્કમાં ઓછું Latency હોય છે.<br>5. લાંબા સમય સુધી વિશ્વસનીય રીતે કામ કરે છે.<br>6. ઘણા ઉપકરણોને નેટવર્ક સાથે જોડી શકાય છે. |
| **Disadvantages of Ethernet** | 1. કેબલની જરૂર પડે છે.<br>2. ઉપકરણની ગતિશીલતા મર્યાદિત થાય છે.<br>3. લાંબા કેબલના કારણે વાયરિંગ જટિલ બની શકે છે.<br>4. કેબલ અથવા કનેક્ટર ખરાબ થાય તો નેટવર્ક કનેક્શન બંધ થઈ શકે છે.<br>5. મોટા નેટવર્ક માટે વધારાના Switch અને અન્ય ઉપકરણોની જરૂર પડી શકે છે. |
| **How Ethernet Works** | કમ્પ્યુટર અથવા અન્ય ઉપકરણ Ethernet કેબલ દ્વારા Network Switch અથવા Router સાથે જોડાય છે. ઉપકરણ ડેટાને Ethernet Frame માં રૂપાંતરિત કરીને મોકલે છે. Switch યોગ્ય ઉપકરણનું MAC Address ઓળખીને ડેટાને તે ઉપકરણ સુધી પહોંચાડે છે. આ રીતે ડેટા ઝડપથી અને વિશ્વસનીય રીતે એક ઉપકરણથી બીજા ઉપકરણ સુધી પહોંચે છે. |
