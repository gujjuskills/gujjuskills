# લેશન - ૬૯ : હોમ નેટવર્ક કેવું દેખાય

| Wired Network (વાયરડ નેટવર્ક) | Wireless Network (વાયરલેસ નેટવર્ક) |
|---|---|
| LAN કેબલ દ્વારા જોડાણ કરવામાં આવે છે | Wi Fi દ્વારા વાયર વિના જોડાણ કરવામાં આવે છે |
| Ethernet કેબલનો ઉપયોગ થાય છે | Wireless સિગ્નલનો ઉપયોગ થાય છે |
| Router | Wireless Router |
| Switch | Wireless Access Point |
| Ethernet Network Card | Wi Fi Adapter |
| UTP કેબલ | કેબલની જરૂરિયાત નથી |
| RJ 45 Connector | Wireless Antenna |
| Desktop Computer | Laptop |
| Network Printer | Smartphone |
| Network Storage | Tablet |
| કનેક્શન વધુ સ્થિર હોય છે | કનેક્શન સરળતાથી સ્થાપિત કરી શકાય છે |
| વધુ સુરક્ષિત નેટવર્ક બનાવી શકાય છે | મોબાઇલ ઉપકરણો માટે વધુ અનુકૂળ છે |
| કેબલ લગાવવાની જરૂર પડે છે | કેબલ લગાવવાની જરૂર પડતી નથી |
