## પ્રેકટિકલ-૧૫ : સ્ક્રીન કેપ્ચરિંગ અને રેકોર્ડિંગ

| **સ્ક્રીન કેપ્ચરિંગ** | **સ્ક્રીન રેકોર્ડિંગ** |
|:---|:---|
| સ્ક્રીન કેપ્ચરિંગ એટલે કમ્પ્યુટર સ્ક્રીન પર દેખાતી માહિતીનો ફોટો એટલે કે **Screenshot** લેવો. | સ્ક્રીન રેકોર્ડિંગ એટલે કમ્પ્યુટર સ્ક્રીન પર થતી પ્રવૃત્તિને **વિડિયો સ્વરૂપે રેકોર્ડ** કરવી. |
| 1. સ્ક્રીન પર જરૂરી માહિતી ખોલો. | 1. સ્ક્રીન રેકોર્ડિંગ માટેનું સાધન અથવા સોફ્ટવેર ખોલો. |
| 2. Windows માં `Windows + Shift + S` દબાવો. | 2. રેકોર્ડિંગ માટે જરૂરી સ્ક્રીન અથવા વિન્ડો પસંદ કરો. |
| 3. સ્ક્રીનનો જરૂરી ભાગ પસંદ કરો. | 3. **Record** બટન પર ક્લિક કરો. |
| 4. પસંદ કરેલ ભાગનો Screenshot લેવામાં આવશે. | 4. સ્ક્રીન પર થતી જરૂરી કામગીરી કરો. |
| 5. Screenshot ને જરૂરી સ્થળે Save કરો. | 5. કામગીરી પૂર્ણ થયા પછી **Stop** બટન પર ક્લિક કરો. |
| 6. Screenshot નો ઉપયોગ માહિતી સાચવવા, સમજાવવા અથવા શેર કરવા માટે કરી શકાય છે. | 6. રેકોર્ડ થયેલ વિડિયો સાચવો અને જરૂર મુજબ તેનો ઉપયોગ કરો. |
| **ઉપયોગ:** ભૂલનો Screenshot, શૈક્ષણિક માહિતી, સૂચનાઓ અને મહત્વપૂર્ણ માહિતી સાચવવા માટે. | **ઉપયોગ:** પ્રેક્ટિકલ કાર્ય, ટ્યુટોરીયલ, સોફ્ટવેરની પ્રક્રિયા અને શૈક્ષણિક વિડિયો બનાવવા માટે. |
