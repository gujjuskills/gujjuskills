# લેશન - ૩૦.૧ : સ્લાઇડ શો ટેબ : MS-POWERPOINT

| Slide Show Tab | ઉપયોગ |
|---|---|
| From Beginning | શરૂઆતની સ્લાઇડથી Slide Show શરૂ કરવા માટે ઉપયોગ થાય છે. |
| From Current Slide | હાલમાં પસંદ કરેલી સ્લાઇડથી Slide Show શરૂ કરવા માટે ઉપયોગ થાય છે. |
| Broadcast Slide Show | Slide Show ને ઓનલાઈન અન્ય લોકો સાથે શેર અથવા પ્રસારિત કરવા માટે ઉપયોગ થાય છે. |
| Custom Slide Show | પસંદ કરેલી સ્લાઇડ્સનો કસ્ટમ Slide Show બનાવવા અને રજૂ કરવા માટે ઉપયોગ થાય છે. |
| Set Up Slide Show | Slide Show ની સેટિંગ્સ, સ્લાઇડ્સની રેન્જ, સમય અને પ્રસ્તુતિની રીત નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Hide Slide | પસંદ કરેલી સ્લાઇડને Slide Show દરમિયાન છુપાવવા માટે ઉપયોગ થાય છે. |
| Rehearse Timings | દરેક સ્લાઇડ માટે રજૂઆતનો સમય નક્કી અને પ્રેક્ટિસ કરવા માટે ઉપયોગ થાય છે. |
| Record Slide Show | Slide Show દરમિયાન અવાજ, સમય અને પ્રસ્તુતિને રેકોર્ડ કરવા માટે ઉપયોગ થાય છે. |
| Resolution | Slide Show માટે સ્ક્રીન અથવા ડિસ્પ્લેનું Resolution પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Show On | Slide Show કયા મોનિટર અથવા સ્ક્રીન પર દર્શાવવો તે પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Use Presenter View | પ્રસ્તુતકર્તાને Notes, આગામી સ્લાઇડ અને અન્ય નિયંત્રણો જોવા માટે Presenter View ચાલુ કરવા માટે ઉપયોગ થાય છે. |
