# પ્રેકટિકલ-૩૭ : સમસ્યાઓ માટે દસ્તાવેજોનુ નિરીક્ષણ કરો

| ટોપિક | સામાન્ય સમજ / કાર્ય |
|---|---|
| છુપાયેલા ગુણધર્મો અને વ્યક્તિગત માહિતી શોધી દૂર કરવી | MS Word માં **File → Info → Check for Issues → Inspect Document** પર જઈને Document Inspector ચલાવવો. તેમાં રહેલી Author Name, Comments, Hidden Text, Personal Information વગેરે તપાસીને જરૂરી ન હોય તેવી માહિતી **Remove All** દ્વારા દૂર કરવી. |
| Accessibility સમસ્યાઓ શોધી સુધારવી | MS Word માં **File → Info → Check for Issues → Check Accessibility** પસંદ કરવું. Accessibility Checker દ્વારા દર્શાવેલી ભૂલો તપાસવી અને Alt Text, Heading, Table વગેરેને યોગ્ય રીતે સુધારવા. |
| Compatibility સમસ્યાઓ શોધી સુધારવી | MS Word માં **File → Info → Check for Issues → Check Compatibility** પસંદ કરવું. જૂના Word વર્ઝનમાં કામ ન કરતી સુવિધાઓ અથવા Formattingની સમસ્યાઓ તપાસીને જરૂરી સુધારા કરવા. |
| દસ્તાવેજનું અંતિમ નિરીક્ષણ | દસ્તાવેજમાં રહેલી Formatting, Spelling, Comments, Hidden Information, Accessibility અને Compatibility સંબંધિત સમસ્યાઓ તપાસીને જરૂરી સુધારા કર્યા પછી દસ્તાવેજને સાચવવો. |
