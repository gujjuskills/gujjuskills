# પ્રેકટિકલ-૨૧ : બ્લૂ-ટૂથ અને વાઇ-ફાઈ સાથે કાર્ય કરવું

| ક્રમ | ઇન્ટરનેટ કનેક્શન ગોઠવવાની પ્રક્રિયા | GSWAN કનેક્શન ગોઠવવાની પ્રક્રિયા |
|---|---|---|
| 1 | કમ્પ્યુટર ચાલુ કરો અને **Settings** ખોલો. | કમ્પ્યુટર ચાલુ કરો અને **Network Settings** ખોલો. |
| 2 | **Network & Internet** વિકલ્પ પસંદ કરો. | ઉપલબ્ધ GSWAN નેટવર્ક તપાસો. |
| 3 | **Ethernet** વિકલ્પ પસંદ કરો. | GSWAN માટે જરૂરી નેટવર્ક સેટિંગ્સ તપાસો. |
| 4 | કમ્પ્યુટરને **LAN/Ethernet કેબલ** દ્વારા Router અથવા Network Port સાથે જોડો. | જરૂરી હોય તો LAN કેબલ યોગ્ય રીતે જોડો. |
| 5 | Ethernet કનેક્શન **Connected** છે કે નહીં તે તપાસો. | આપવામાં આવેલ **IP Address, Subnet Mask, Gateway અને DNS** દાખલ કરો. |
| 6 | જો જરૂરી હોય તો **IP Settings** માં જઈ **Automatic (DHCP)** પસંદ કરો. | દાખલ કરેલી નેટવર્ક સેટિંગ્સ **Save/OK** કરો. |
| 7 | જો Static IP આપવામાં આવેલ હોય તો **IP Address, Subnet Mask, Gateway અને DNS** દાખલ કરો. | GSWAN કનેક્શન સ્થાપિત થાય તેની રાહ જુઓ. |
| 8 | સેટિંગ્સ **Save** કરો. | કનેક્શનની સ્થિતિ **Connected** છે કે નહીં તે તપાસો. |
| 9 | વેબ બ્રાઉઝર ખોલીને કોઈ વેબસાઇટ ખોલો. | જરૂરી GSWAN સેવા અથવા વેબસાઇટ ખોલીને કનેક્શન ચકાસો. |
| 10 | ઇન્ટરનેટ કનેક્શન સફળતાપૂર્વક કાર્ય કરે છે કે નહીં તે ચકાસો. | GSWAN કનેક્શન સફળતાપૂર્વક કાર્ય કરે છે કે નહીં તે ચકાસો. |

## બ્લૂ-ટૂથ અને વાઇ-ફાઈ કનેક્શન 

| Wi-Fi કનેક્શન ગોઠવવાની પ્રક્રિયા | Bluetooth કનેક્શન ગોઠવવાની પ્રક્રિયા |
|---|---|
| 1. કમ્પ્યુટર ચાલુ કરો અને **Settings** ખોલો. | 1. કમ્પ્યુટર ચાલુ કરો અને **Settings** ખોલો. |
| 2. **Network & Internet** વિકલ્પ પસંદ કરો. | 2. **Bluetooth & Devices** વિકલ્પ પસંદ કરો. |
| 3. **Wi-Fi** વિકલ્પ પસંદ કરો. | 3. **Bluetooth** ને **ON** કરો. |
| 4. Wi-Fi ને **ON** કરો. | 4. Bluetooth ઉપકરણને પણ **ON** કરો અને Pairing Mode માં મૂકો. |
| 5. ઉપલબ્ધ Wi-Fi નેટવર્કમાંથી જરૂરી નેટવર્ક પસંદ કરો. | 5. **Add Device** પર ક્લિક કરો. |
| 6. **Connect** બટન પર ક્લિક કરો. | 6. **Bluetooth** વિકલ્પ પસંદ કરો. |
| 7. પૂછવામાં આવે ત્યારે Wi-Fi નો **Password** દાખલ કરો. | 7. ઉપલબ્ધ ઉપકરણોની યાદીમાંથી જરૂરી Bluetooth ઉપકરણ પસંદ કરો. |
| 8. **Next/Connect** પર ક્લિક કરો. | 8. **Pair/Connect** પર ક્લિક કરો. |
| 9. Wi-Fi કનેક્શન **Connected** છે કે નહીં તે તપાસો. | 9. બંને ઉપકરણો પર દેખાતો **Pairing Code** સરખો હોય તો **Pair** પસંદ કરો. |
| 10. વેબ બ્રાઉઝર ખોલીને ઇન્ટરનેટ કનેક્શન ચકાસો. | 10. Bluetooth કનેક્શન સફળતાપૂર્વક થયું છે કે નહીં તે તપાસો. |

**પરિણામ:** Wi-Fi અને Bluetooth કનેક્શન સફળતાપૂર્વક ગોઠવવામાં આવ્યા.
