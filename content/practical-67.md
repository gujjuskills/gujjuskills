# પ્રેકટિકલ-૬૭ : ફોરમેટ ચિત્રો અને ટેક્સ્ટ બોક્સો
| Topic | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| Apply artistic effects | ચિત્ર અથવા ગ્રાફિક પર Artistic Effects લાગુ કરીને તેને અલગ પ્રકારનો કલાત્મક દેખાવ આપવો. |
| Apply picture effects and picture styles | ચિત્ર પર વિવિધ Picture Effects અને Picture Styles લાગુ કરીને તેની રચના અને દેખાવને આકર્ષક બનાવવો. |

| Crop images | ચિત્રના અનિચ્છનીય ભાગોને દૂર કરીને જરૂરી ભાગને યોગ્ય કદ અને આકારમાં ગોઠવવો. |
| Format graphic elements | Graphic Elements માં રંગ, આકાર, Outline, Fill, Size અને Position જેવી Formatting કરવી. |
| Format SmartArt graphics | SmartArt Graphics માં Layout, રંગ, Style, આકાર અને કદમાં ફેરફાર કરીને માહિતી રજૂ કરવી. |
