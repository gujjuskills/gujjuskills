# 2. Creating and Editing Documents (MS Word)

## 2.1 MS Word નો પરિચય
MS Word એ Word Processing Software છે. તેનો ઉપયોગ પત્ર, રિપોર્ટ, Resume, અરજી અને અન્ય લખાણવાળા દસ્તાવેજો બનાવવા, સંપાદિત કરવા અને ફોર્મેટ કરવા માટે થાય છે.

## 2.2 દસ્તાવેજ બનાવવાના પગલાં
1. MS Word ખોલો.
2. Blank Document પસંદ કરો.
3. જરૂરી લખાણ લખો.
4. ભૂલ હોય તો લખાણ પસંદ કરીને સુધારો.
5. દસ્તાવેજને યોગ્ય નામથી Save કરો.
6. જરૂર મુજબ Print અથવા PDF તરીકે Export કરો, જો સુવિધા ઉપલબ્ધ હોય.

## 2.3 મુખ્ય Formatting Tools
| Tool | ઉપયોગ |
|---|---|
| Font | અક્ષરોનો પ્રકાર પસંદ કરવો |
| Font Size | અક્ષરોનું કદ બદલવું |
| Bold | લખાણને ઘાટું કરવું |
| Italic | લખાણને ત્રાંસું કરવું |
| Underline | લખાણની નીચે લીટી દોરવી |
| Alignment | લખાણને Left, Center, Right અથવા Justify ગોઠવવું |
| Bullets/Numbering | મુદ્દાઓને યાદી સ્વરૂપે ગોઠવવા |
| Save | દસ્તાવેજ સાચવવો |
| Print | કાગળ પર નકલ છાપવી |

## 2.4 Resume અથવા રિપોર્ટ માટે ઉપયોગ
Resume માં સામાન્ય રીતે સંપર્ક માહિતી, Career Objective અથવા Summary, શિક્ષણ, કુશળતાઓ અને અનુભવ (હોય તો) સામેલ થાય છે. રિપોર્ટમાં શીર્ષક, વિભાગો અને મુદ્દાઓ સ્પષ્ટ રીતે ગોઠવવા.

દસ્તાવેજને સુંદર બનાવવા માટે ખૂબ જુદા જુદા Font અથવા રંગોનો અતિરેક ન કરો. વાંચવામાં સરળતા સૌથી મહત્વની છે.

## 2.5 Save અને Print
- `Save` દ્વારા દસ્તાવેજ સાચવો.
- ફાઇલનું નામ અને સ્થાન યાદ રાખો.
- Print પહેલાં Print Preview તપાસો.
- કાગળનો ખર્ચ બચાવવા જરૂર મુજબ Pages અને Copies પસંદ કરો.

## 2.6 પ્રાયોગિક પ્રવૃત્તિ
MS Word માં “મારો પરિચય” શીર્ષકથી એક પાનું બનાવો. તેમાં તમારું નામ, ટ્રેડ, ત્રણ કુશળતાઓ અને કારકિર્દીનું એક લક્ષ્ય લખો. શીર્ષક Center કરો, મુદ્દાઓ માટે Bullets વાપરો અને ફાઇલ Save કરો.
