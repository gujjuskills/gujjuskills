# લેશન - ૯૭ : સુરક્ષાની સમસ્યાઓ અને પેમેન્ટ ગેટ વે

## Security Issues

| Issues | Details |
|---|---|
| Data Security | ગ્રાહકની વ્યક્તિગત અને ચુકવણી સંબંધિત માહિતી સુરક્ષિત રાખવી જરૂરી છે. |
| Encryption | Payment data ને સુરક્ષિત રાખવા માટે Encryption નો ઉપયોગ કરવામાં આવે છે. |
| Fraud Detection | નકલી અથવા શંકાસ્પદ transactions શોધીને fraud અટકાવવામાં આવે છે. |
| Authentication | User ની ઓળખ ચકાસવા માટે OTP, PIN, Password અથવા અન્ય authentication પદ્ધતિનો ઉપયોગ થાય છે. |
| Privacy | ગ્રાહકની payment અને personal information ને ગોપનીય રાખવી જરૂરી છે. |
| Secure Connection | Payment દરમિયાન સુરક્ષિત HTTPS connection નો ઉપયોગ કરવામાં આવે છે. |

## What is Payment Gateways

Payment Gateway એ એવી technology છે જે customer, merchant અને bank વચ્ચે online payment ને સુરક્ષિત રીતે process કરવામાં મદદ કરે છે. જ્યારે customer online payment કરે છે ત્યારે Payment Gateway payment information ને securely payment processor અથવા bank સુધી પહોંચાડે છે અને transaction નું પરિણામ merchant ને આપે છે.

## How do payment gateways work : Steps

| Step | Details |
|---|---|
| 1. Payment Initiation | Customer website અથવા application પર વસ્તુ અથવા સેવા પસંદ કરીને payment શરૂ કરે છે. |
| 2. Payment Details | Customer Credit Card, Debit Card, UPI, Net Banking અથવા અન્ય payment method પસંદ કરે છે. |
| 3. Secure Transfer | Payment Gateway payment information ને સુરક્ષિત રીતે encrypt કરીને payment processor સુધી મોકલે છે. |
| 4. Authentication | Bank અથવા payment service customer ની ઓળખ અને transaction ની ચકાસણી કરે છે. |
| 5. Transaction Processing | Bank transaction ને approve અથવા decline કરે છે. |
| 6. Payment Response | Payment Gateway transaction નું result merchant અને customer ને મોકલે છે. |
| 7. Payment Confirmation | Payment successful હોય તો merchant ને confirmation મળે છે અને order process થાય છે. |
