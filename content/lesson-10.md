## લેશન -૧૦ : વિન્ડોઝ OS ની મુખ્ય લાક્ષણિકતાઓ

| નામ | ઉપયોગ / વિશેષતા |
|---|---|
| ડેસ્કટોપ (Desktop) | કમ્પ્યુટર ચાલુ કર્યા પછી દેખાતી મુખ્ય સ્ક્રીન. અહીં વિવિધ આઇકન અને ટાસ્કબાર જોવા મળે છે. |
| આઇકન (Icon) | પ્રોગ્રામ, ફાઇલ, ફોલ્ડર અથવા અન્ય વસ્તુનું નાનું ચિત્રાત્મક પ્રતીક. |
| ટાસ્કબાર (Taskbar) | સ્ક્રીનના નીચેના ભાગમાં આવેલી પટ્ટી, જેમાં ચાલુ પ્રોગ્રામ, સ્ટાર્ટ મેનુ અને અન્ય વિકલ્પો હોય છે. |
| સ્ટાર્ટ મેનુ (Start Menu) | પ્રોગ્રામ, સેટિંગ્સ, ફાઇલો અને અન્ય સુવિધાઓ ખોલવા માટે ઉપયોગ થાય છે. |
| સિસ્ટમ ટ્રે (System Tray) | ટાસ્કબારના સૂચના વિસ્તારમાં સમય, અવાજ, નેટવર્ક અને અન્ય સિસ્ટમ આઇકન દર્શાવે છે. |
| કમ્પ્યુટર (Computer) | કમ્પ્યુટરમાં રહેલી ડ્રાઇવ, ફાઇલ અને ફોલ્ડર જોવા તથા વ્યવસ્થિત કરવા માટે ઉપયોગ થાય છે. |
| રિસાયકલ બિન (Recycle Bin) | કાઢી નાખેલી ફાઇલોને અસ્થાયી રીતે સંગ્રહિત કરે છે. જરૂર પડે ત્યારે ફાઇલ પુનઃસ્થાપિત કરી શકાય છે. |
| કંટ્રોલ પેનલ (Control Panel) | કમ્પ્યુટરની વિવિધ સેટિંગ્સ અને સિસ્ટમ વિકલ્પોમાં ફેરફાર કરવા માટે ઉપયોગ થાય છે. |
| ડિવાઇસિસ અને પ્રિન્ટર્સ (Devices & Printers) | કમ્પ્યુટર સાથે જોડાયેલા પ્રિન્ટર અને અન્ય ઉપકરણોને જોવા તથા સંચાલિત કરવા માટે ઉપયોગ થાય છે. |
| ઇન્ટરનેટ એક્સપ્લોરર (Internet Explorer) | ઇન્ટરનેટ પર વેબસાઇટ અને વેબ પેજ જોવા માટે ઉપયોગમાં લેવાતું વેબ બ્રાઉઝર. |
| એમ.એસ. પેઇન્ટ (MS Paint) | ચિત્ર દોરવા, રંગ ભરવા અને સરળ ચિત્રોમાં ફેરફાર કરવા માટે ઉપયોગ થાય છે. |
| નોટપેડ (Notepad) | સાદો ટેક્સ્ટ લખવા, જોવા અને સંપાદિત કરવા માટે ઉપયોગ થાય છે. |
| ક્લિક (Click) | માઉસનું ડાબું બટન એક વખત દબાવવાની ક્રિયા. |
| ડબલ ક્લિક (Double Click) | માઉસનું ડાબું બટન ઝડપથી બે વખત દબાવવાની ક્રિયા. |
| ડ્રેગ (Drag) | માઉસનું બટન દબાવીને વસ્તુને એક સ્થાનેથી બીજા સ્થાને ખસેડવાની ક્રિયા. |
| કૉપી (Copy) | ફાઇલ, ફોલ્ડર અથવા ટેક્સ્ટની નકલ બનાવવાની ક્રિયા. |
| કટ (Cut) | ફાઇલ, ફોલ્ડર અથવા ટેક્સ્ટને એક સ્થાનેથી દૂર કરીને બીજા સ્થાને ખસેડવા માટેની ક્રિયા. |
| પેસ્ટ (Paste) | કૉપી અથવા કટ કરેલી ફાઇલ, ફોલ્ડર અથવા ટેક્સ્ટને પસંદ કરેલા સ્થાને મૂકવાની ક્રિયા. |
