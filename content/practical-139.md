# પ્રેકટિકલ-૧૩૯ : CMSનો ઉપયોગ કરીને વેબસાઇટ બનાવો

# Create Website using CMS

## CMS શું છે?

CMS એટલે **Content Management System**. CMS ની મદદથી આપણે કોઈ ખાસ programming knowledge વગર website બનાવી અને manage કરી શકીએ છીએ.

CMS દ્વારા website પર text, images, videos, pages, blog posts અને અન્ય content સરળતાથી ઉમેરવા, edit કરવા અને delete કરવા માટેની સુવિધા મળે છે.

## CMS ની મદદથી Website કેવી રીતે બનાવવી?

CMS દ્વારા website બનાવવા માટે નીચેના steps follow કરી શકાય છે.

### Step 1: CMS પસંદ કરો

સૌ પ્રથમ તમારી જરૂરિયાત પ્રમાણે CMS પસંદ કરો.

કેટલાક લોકપ્રિય CMS:

| CMS | ઉપયોગ |
|---|---|
| WordPress | Blog અને Business Website |
| Joomla | Business અને Portal Website |
| Drupal | Advanced અને Large Website |
| Blogger | Simple Blog Website |
| Wix | Drag and Drop Website |

### Step 2: Domain Name પસંદ કરો

Website માટે એક unique domain name પસંદ કરો.

ઉદાહરણ:

`www.example.com`

Domain name website નું online address હોય છે.

### Step 3: Web Hosting મેળવો

Website ની files અને database store કરવા માટે web hosting ની જરૂર પડે છે.

Hosting website ને Internet પર ઉપલબ્ધ કરાવે છે.

### Step 4: CMS Install કરો

Hosting account માંથી પસંદ કરેલ CMS install કરો.

ઘણી hosting services માં CMS ને automatically install કરવાની સુવિધા આપવામાં આવે છે.

### Step 5: Content ઉમેરો

હવે website પર text, images, videos અને અન્ય જરૂરી માહિતી ઉમેરો.

Content સરળ, ઉપયોગી અને સમજવામાં સરળ હોવું જોઈએ.

### Step 6: Menu બનાવો

Website ના અલગ અલગ pages ને જોડવા માટે navigation menu બનાવો.

ઉદાહરણ:

`Home | About | Services | Blog | Contact`

### Step 7: Website Publish કરો

બધી settings અને content check કર્યા પછી website ને publish કરો.

હવે users Internet દ્વારા તમારી website જોઈ શકે છે.

## CMS ના ઉદાહરણો

**WordPress**, **Joomla**, **Drupal**, **Blogger** અને **Wix** લોકપ્રિય CMS platforms છે.
