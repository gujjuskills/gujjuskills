# લેશન - ૧૦૭ : જનરેટિવ AI નો ખ્યાલ

### What is Generative AI ?

| Topic | માહિતી |
|---|---|
| Definition | Generative AI એ Artificial Intelligence ની એવી ટેક્નોલોજી છે જે શીખેલા ડેટાના આધારે નવું અને મૂળ કન્ટેન્ટ બનાવી શકે છે. |
| Examples | Text, Image, Audio, Video, Code વગેરે પ્રકારનું કન્ટેન્ટ બનાવી શકે છે. |
| Uses | લેખ લખવા, ચિત્ર બનાવવા, પ્રશ્નોના જવાબ આપવા, અનુવાદ કરવા, કોડ લખવા અને વિવિધ સર્જનાત્મક કાર્યોમાં તેનો ઉપયોગ થાય છે. |


### How it Works :

| Topic | માહિતી |
|---|---|
| Learning | Generative AI મોટા પ્રમાણમાં ઉપલબ્ધ ડેટામાંથી પેટર્ન, ભાષા, માહિતી અને રચનાઓ શીખે છે. |
| Prediction | યુઝર દ્વારા આપવામાં આવેલા Prompt અથવા Inputના આધારે AI આગળ કઈ માહિતી અથવા શબ્દ યોગ્ય હોઈ શકે તેનું અનુમાન કરે છે. |
| Creation | શીખેલા પેટર્ન અને યુઝરના Promptના આધારે AI નવું Text, Image, Audio, Video અથવા અન્ય કન્ટેન્ટ તૈયાર કરે છે. |


### What can Generative AI Do :

| Topic | માહિતી |
|---|---|
| Text Generation | લેખ, ઈમેલ, વાર્તા, પ્રશ્નોના જવાબ, સારાંશ, અનુવાદ અને અન્ય પ્રકારનું ટેક્સ્ટ બનાવી શકે છે. |
| Image Generation | આપેલા Prompt અથવા વર્ણનના આધારે નવી Image અથવા Illustration બનાવી શકે છે. |
| Audio / Video Generation | Text અથવા Promptના આધારે Audio, Voice, Music અને Video જેવા કન્ટેન્ટનું સર્જન કરી શકે છે. |
