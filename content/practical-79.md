# પ્રેકટિકલ-૭૯ : વિકલ્પો અને દ્રશ્યોને કસ્ટમાઈઝ કરો : MS-EXCEL

| ક્રમાંક | Topic | વિગત |
|---|---|---|
| 1 | Display and modify content in different views | Excel માં વર્કશીટના ડેટાને અલગ અલગ Views માં જોઈ અને તેમાં ફેરફાર કરી શકાય છે. સામાન્ય રીતે Normal View, Page Layout View અને Page Break Preview નો ઉપયોગ થાય છે. Normal View માં ડેટા દાખલ અને સંપાદિત કરી શકાય છે, Page Layout View માં પ્રિન્ટ માટેનું લેઆઉટ જોઈ શકાય છે અને Page Break Preview માં પેજ બ્રેક જોઈ તથા ગોઠવી શકાય છે. |
| 2 | Freeze rows and columns | મોટા વર્કશીટમાં ઉપરની Row અથવા ડાબી બાજુના Column ને સ્થિર રાખવા માટે Freeze Panes નો ઉપયોગ થાય છે. આ સુવિધાથી નીચે અથવા જમણી બાજુ સ્ક્રોલ કરતી વખતે પણ Heading અથવા મહત્વપૂર્ણ માહિતી દેખાતી રહે છે. |
| 3 | Change window views | Excel વિન્ડોને જરૂરિયાત પ્રમાણે અલગ રીતે જોઈ શકાય છે. View Tab માંથી Normal, Page Layout અને Page Break Preview જેવા વિકલ્પો પસંદ કરી શકાય છે. એકથી વધુ Workbook સાથે કામ કરતી વખતે Window ને Arrange, Split અથવા New Window જેવી સુવિધાઓથી પણ ગોઠવી શકાય છે. |
| 4 | Modify basic workbook properties | Workbook ની મૂળભૂત Properties માં Title, Subject, Author, Category, Keywords અને Comments જેવી માહિતી ઉમેરી અથવા બદલી શકાય છે. આ માહિતીથી Workbook ને ઓળખવા, શોધવા અને વ્યવસ્થિત રાખવામાં સરળતા રહે છે. |
| 5 | Display formulas | Excel માં પરિણામને બદલે Cell માં ઉપયોગમાં લેવાયેલ Formula જોવા માટે Show Formulas વિકલ્પનો ઉપયોગ થાય છે. આ વિકલ્પથી Worksheet માં રહેલા બધા Formulas એકસાથે જોઈ શકાય છે અને Formula ચકાસવા અથવા ભૂલ શોધવા માટે મદદ મળે છે. |
