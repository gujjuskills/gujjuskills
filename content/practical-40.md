# પ્રેકટિકલ-૪૦ : દસ્તાવેજ વિભાગો બનાવો અને ગોઠવો

| ટોપિક | સામાન્ય સમજુતી / કાર્ય |
|---|---|
| **બહુવિધ કૉલમમાં ટેક્સ્ટનું ફોર્મેટિંગ** | MS Word માં ટેક્સ્ટને બે કે તેથી વધુ કૉલમમાં ગોઠવી શકાય છે. તેના માટે જરૂરી ટેક્સ્ટ પસંદ કરો અને **Layout → Columns** પર ક્લિક કરો. ત્યારબાદ **One, Two, Three, Left, Right** અથવા **More Columns** માંથી જરૂરી વિકલ્પ પસંદ કરો. More Columns દ્વારા કૉલમની સંખ્યા, પહોળાઈ અને વચ્ચેનું અંતર પણ નક્કી કરી શકાય છે. |
| **પેજ, સેક્શન અને કૉલમ બ્રેક્સ દાખલ કરવા** | દસ્તાવેજમાં અલગ ભાગ શરૂ કરવા માટે **Page Break, Section Break** અને **Column Break** નો ઉપયોગ થાય છે. **Page Break** નવા પેજથી લખાણ શરૂ કરે છે. **Section Break** દ્વારા દસ્તાવેજના અલગ વિભાગ માટે અલગ Page Setup, Orientation, Header/Footer વગેરે રાખી શકાય છે. **Column Break** દ્વારા કૉલમમાં લખાણને આગળની કૉલમથી શરૂ કરી શકાય છે. આ વિકલ્પો **Layout → Breaks** માંથી પસંદ કરી શકાય છે. |
| **સેક્શન માટે Page Setup ના વિકલ્પોમાં ફેરફાર કરવા** | MS Word માં દરેક Section માટે અલગ Page Setup રાખી શકાય છે. જરૂરી Section માં કર્સર રાખીને **Layout → Margins, Orientation, Size** વગેરે વિકલ્પોનો ઉપયોગ કરી શકાય છે. **Portrait** અથવા **Landscape** Orientation પસંદ કરી શકાય છે, પેજનું કદ બદલી શકાય છે અને Margins સેટ કરી શકાય છે. આ રીતે એક જ દસ્તાવેજના અલગ Sections માટે અલગ Page Setup રાખી શકાય છે. |
