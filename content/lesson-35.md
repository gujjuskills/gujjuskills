# લેશન - ૩૫ : ફોર્મુલા ટેબ : MS-Excel
![image](/images/lesson-35.png)
| Formula Tab | ઉપયોગ |
|---|---|
| Insert Function | વિવિધ ફંક્શન શોધવા અને દાખલ કરવા માટે ઉપયોગ થાય છે. |
| AutoSum | સંખ્યાઓનો સરવાળો, સરેરાશ, ગણતરી, મહત્તમ અને લઘુત્તમ મૂલ્ય ઝડપથી મેળવવા માટે ઉપયોગ થાય છે. |
| Recently Used | તાજેતરમાં ઉપયોગ કરેલા ફંક્શન પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Financial | નાણાકીય ગણતરીઓ અને ફાઇનાન્સ સંબંધિત ફંક્શન માટે ઉપયોગ થાય છે. |
| Logical | શરતો તપાસવા અને તાર્કિક પરિણામ મેળવવા માટે ઉપયોગ થાય છે. |
| Text | ટેક્સ્ટને જોડવા, અલગ કરવા અને તેમાં ફેરફાર કરવા માટે ઉપયોગ થાય છે. |
| Date & Time | તારીખ અને સમય સંબંધિત ગણતરીઓ માટે ઉપયોગ થાય છે. |
| Lookup & Reference | ડેટામાંથી ચોક્કસ માહિતી શોધવા અને સેલનો સંદર્ભ મેળવવા માટે ઉપયોગ થાય છે. |
| Math & Trig | ગાણિતિક અને ત્રિકોણમિતીય ગણતરીઓ માટે ઉપયોગ થાય છે. |
| More Functions | અન્ય વિવિધ પ્રકારના Excel Functions પસંદ કરવા માટે ઉપયોગ થાય છે. |
| Name Manager | Named Range ને બનાવવા, સંપાદિત કરવા અને મેનેજ કરવા માટે ઉપયોગ થાય છે. |
| Define Name | સેલ અથવા રેન્જને નામ આપવા માટે ઉપયોગ થાય છે. |
| Use in Formula | બનાવેલ Named Range ને ફોર્મ્યુલામાં દાખલ કરવા માટે ઉપયોગ થાય છે. |
| Create From Selection | પસંદ કરેલા ડેટામાંથી આપમેળે Named Range બનાવવા માટે ઉપયોગ થાય છે. |
| Trace Precedents | સક્રિય સેલના ફોર્મ્યુલામાં ઉપયોગ થયેલા સેલ શોધવા માટે ઉપયોગ થાય છે. |
| Trace Dependent | સક્રિય સેલના મૂલ્ય પર આધારિત અન્ય સેલ શોધવા માટે ઉપયોગ થાય છે. |
| Remove Arrows | Trace Precedents અથવા Trace Dependent દ્વારા દર્શાવેલા તીર દૂર કરવા માટે ઉપયોગ થાય છે. |
| Show Formulas | વર્કશીટમાં પરિણામની જગ્યાએ ફોર્મ્યુલા દર્શાવવા માટે ઉપયોગ થાય છે. |
| Error Checking | ફોર્મ્યુલામાં રહેલી ભૂલો શોધવા અને સુધારવામાં મદદ કરવા માટે ઉપયોગ થાય છે. |
| Evaluate Formula | ફોર્મ્યુલા કેવી રીતે ગણાય છે તે પગલુંવાર તપાસવા માટે ઉપયોગ થાય છે. |
| Watch Window | મહત્વના સેલના મૂલ્યો અને ફોર્મ્યુલાને એક જગ્યાએ જોવા માટે ઉપયોગ થાય છે. |
| Calculation Options | Excel માં ફોર્મ્યુલાની ગણતરી Automatic અથવા Manual રીતે નક્કી કરવા માટે ઉપયોગ થાય છે. |
| Calculate | વર્કબુકમાં બાકી રહેલી ગણતરીઓને ફરીથી ગણવા માટે ઉપયોગ થાય છે. |
| Calculate Sheet | સક્રિય વર્કશીટની તમામ ફોર્મ્યુલાની ગણતરી ફરીથી કરવા માટે ઉપયોગ થાય છે. |
