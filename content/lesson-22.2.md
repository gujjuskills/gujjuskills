# લેશન - ૨૨.૨ : ફાઇલ ટેબ: MS-WORD
![image](/gujjuskills/images/lesson-22.2.png)
| File tab | ઉપયોગ |
|---|---|
| **Save** | વર્તમાન ડોક્યુમેન્ટને સેવ કરવા માટે ઉપયોગ થાય છે. |
| **Save As** | ડોક્યુમેન્ટને નવા નામ, સ્થાન અથવા અલગ ફાઇલ ફોર્મેટમાં સેવ કરવા માટે ઉપયોગ થાય છે. |
| **Open** | અગાઉથી સેવ કરેલી Word ફાઇલ ખોલવા માટે ઉપયોગ થાય છે. |
| **Close** | હાલમાં ખુલેલી Word ફાઇલ બંધ કરવા માટે ઉપયોગ થાય છે. |
| **Info** | ડોક્યુમેન્ટની માહિતી, સુરક્ષા, પરવાનગી અને અન્ય વિગતો જોવા માટે ઉપયોગ થાય છે. |
| **Recent** | તાજેતરમાં ખોલેલી અથવા ઉપયોગમાં લીધેલી ફાઇલોની યાદી જોવા માટે ઉપયોગ થાય છે. |
| **New** | નવી Word ફાઇલ અથવા નવું ડોક્યુમેન્ટ બનાવવા માટે ઉપયોગ થાય છે. |
| **Print** | ડોક્યુમેન્ટની પ્રિન્ટ કાઢવા માટે ઉપયોગ થાય છે. |
| **Save & Send** | ડોક્યુમેન્ટને સેવ કરીને ઈમેલ અથવા અન્ય માધ્યમથી મોકલવા માટે ઉપયોગ થાય છે. |
| **Help** | MS Word અંગે મદદ અને માહિતી મેળવવા માટે ઉપયોગ થાય છે. |
| **Option** | MS Word ની સેટિંગ્સ અને વિવિધ વિકલ્પોમાં ફેરફાર કરવા માટે ઉપયોગ થાય છે. |
| **Exit** | MS Word પ્રોગ્રામમાંથી બહાર નીકળવા માટે ઉપયોગ થાય છે. |
