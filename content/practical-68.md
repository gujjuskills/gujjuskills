# પ્રેકટિકલ-૬૮ : ગ્રાફિક તત્વોમાં ટેક્સ્ટ ઉમેરો અને ફેરફાર કરો
# P 68: Add & Modify Text in Graphic Elements

| ક્રમ | Topic Name | વિગતવાર માહિતી |
|---|---|---|
| 1 | Add and Modify Text in Text Boxes | Text Box નો ઉપયોગ દસ્તાવેજમાં કોઈપણ જગ્યાએ લખાણ મૂકવા માટે થાય છે. Text Box ઉમેર્યા પછી તેમાં જરૂરી માહિતી ટાઇપ કરી શકાય છે. લખાણનો Font, Font Size, Color, Alignment, Bold, Italic અને Underline બદલી શકાય છે. Text Boxનું સ્થાન અને કદ પણ જરૂર મુજબ બદલી શકાય છે. |
| 2 | Add and Modify Text in Shapes | Shapesમાં લખાણ ઉમેરવાથી દસ્તાવેજ વધુ આકર્ષક અને સમજવામાં સરળ બને છે. Rectangle, Circle, Arrow, Star વગેરે Shapesમાં Text ઉમેરી શકાય છે. Shapeની અંદરના લખાણને Edit કરી શકાય છે અને તેનું Font, Size, Color તથા Alignment બદલી શકાય છે. |
| 3 | Add and Modify SmartArt Graphic Text | SmartArt નો ઉપયોગ માહિતી અથવા પ્રક્રિયાને આકર્ષક ગ્રાફિક સ્વરૂપમાં રજૂ કરવા માટે થાય છે. SmartArtમાં અલગ અલગ પ્રકારના Layout ઉપલબ્ધ હોય છે. તેમાં Text Pane અથવા સીધા Graphicમાં લખાણ ઉમેરી શકાય છે. નવા Elements ઉમેરવા, દૂર કરવા અને તેમની સ્થિતિ બદલવા પણ શક્ય છે. |
| 4 | Create, Insert and Modify Charts | Chart નો ઉપયોગ આંકડાઓને ગ્રાફિક સ્વરૂપમાં રજૂ કરવા માટે થાય છે. Column Chart, Bar Chart, Line Chart, Pie Chart વગેરે પ્રકારના Charts બનાવી શકાય છે. Chart બનાવ્યા પછી તેમાં Data, Chart Title, Legend, Axis Title અને Chart Styleમાં ફેરફાર કરી શકાય છે. |
